## 이 장에서 할 수 있게 되는 것

- 자본시장법 시행령이 로보어드바이저를 어떻게 부르는지 짚을 수 있습니다.
- 금융투자업규정의 요건(투자성향 분석 · 분산 · 점검)을 찾을 수 있습니다.
- 우리 서비스 안내 문구(투자 권유 아님)의 근거를 말할 수 있습니다.

## 다룰 질문

1. 「전자적 투자조언장치」 는 어느 조문에 있나요?
2. 로보어드바이저의 포트폴리오는 얼마나 자주 점검해야 하나요?
3. 적합성 원칙은 우리 화면 어디에 닿나요? 투자 성향을 묻는 까닭은 [투자 성향과 적합성](#/p/investor-profile-suitability) 장에서 따로 다룹니다.
4. 우리 앱은 투자 권유를 하나요? 화면의 「공시된 상품 정보 비교」 · 「투자 권유가 아님」 문구는 어떤 규칙에서 왔나요?
5. 로보어드바이저 테스트베드는 무엇을 확인하나요?

## 보여 줄 코드

- 법령 API 로 조문 받아 근거 문서 목록에 넣기(3.4 장과 연결)

## 우리 프로젝트와 닿는 곳

- 근거 답의 근거 문서 등급(법령 → 감독규정 → 협회 · 거래소 → 공시 → 뉴스)
- 로보 어드바이저 메뉴의 안내 문구 — 투자 성향 진단 · 자산 배분 · 상품 안내(「추천」 이 아니라 공시된 상품 정보를 같은 기준으로 나열) · 리밸런싱 · 패턴 신호
