# screenshots — 화면 캡처 (이름 규칙: `cap0N_*` · `final0N_*`)

`scripts/take_screenshots.py` 가 앱을 열어 찍은 화면 PNG 15장이 있습니다 (로그인 · 가입 · 앱 첫 화면 · 퀀트 · 미국 주식 · 종목 상세 등).

## 알아 둘 것

- 출력 폴더가 이 폴더로 고정돼 있다 (`take_screenshots.py` 의 `OUT`). 다시 찍으면 같은 이름을 덮어쓴다
- **지금 문서가 이 그림들을 직접 보여 주는 곳은 찾지 못했다.** 옛 README 작업 초안에서만 이름이 나온다. 문서에 넣는 그림은 각 문서 옆 `img/` 에 판 번호가 붙은 파일로 두는 것이 지금 규칙이다 ([문서 그림 지침](../docs/phase-3/00-management/standards/문서그림지침.md))
- 캡처는 개발 모드로 띄운 화면이므로 로그인 정보 · 개인 정보 · 키가 찍히지 않았는지 올리기 전에 눈으로 본다 (공개 저장소)
- 화면이 바뀌면 이 캡처는 낡는다. 새로 쓸 일이 없으면 지우는 것도 방법이다 (지울 때는 사용처 검색부터)
