## 2. 다시 찍기 — 명령 한 줄

앱을 개발 모드로 켠 뒤(`scripts/personal/start.ps1 -Dev -NoBrowser`) 저장소 뿌리에서:

```bash
python tools/demo/record_demo.py --ensure-account docs/영상/장면/V03-신호로-종목살피기.yaml   # 한 편
python tools/demo/record_demo.py --no-video docs/영상/장면/V03-신호로-종목살피기.yaml          # 영상 없이 단계만(누를 곳 확인)
python tools/demo/record_demo.py --inventory robo-screening,robo-patterns                          # 화면마다 누를 곳 목록
python tools/demo/record_demo.py --frames docs/영상/장면/F02-자료안내-출처와-이용조건.yaml       # 장 · 자막 순간 프레임도 남김(눈으로 훑기)
```

- 결과는 `tools/demo/out/`(git 에 넣지 않음) — `.webm`(1920×1080) · `.ko.vtt`(자막) · `.chapters.vtt`(장) · `.ch<n>.jpg`(장마다 제목 카드 그림) · `.json`(단계별 시각 · `go` 단계의 화면 키 · 시작 화면 · 줄인 기다림 · 콘솔 오류 · 실패한 응답).
- 계정은 이 PC 로컬 DB 의 시연 전용 계정이다(없으면 `--ensure-account` 가 만든다). 관리자 화면(F01)은 환경 변수 `DEMO_EMAIL` · `DEMO_PASSWORD` 로 관리자 계정을 넘긴다 — 파일에 쓰지 않는다.
- AI 답처럼 오래 기다리는 구간은 녹화를 멈췄다가 이어 붙이고, 화면 오른쪽 위에 「기다린 n초를 줄였습니다」 를 띄운다(답은 바꾸지 않는다).
- 브라우저 확인 창(`confirm`)은 기본 「취소」 — 장면이 「확인」 을 눌러야 하면 맨 위에 `dialogs: accept`.
- 영상에 보이면 안 되는 칸은 장면 맨 위 `mask` 에 선택자를 적는다(그 칸이 흐려진다 · F01 의 「이 PC 용량」 카드 `.cl-disk`). 관리자 · 개발용 표시처럼 영상에 나올 까닭이 없는 칸은 `hide`(감춤 · F01 의 「기능 완성도」 배지 `#view-completion-indicator`) — 둘 다 장면 파일에 밝혀 둔다.
- 녹화하는 동안 앱 코드(`app/` · `public/`)를 고치지 않는다 — 개발 모드 앱이 다시 켜지며 녹화가 깨진다.
- 앱에서 굴러가는 칸은 창이 아니라 내용 칸(`#main-content`)이다 — `scroll: {by: N}` 은 그 칸을 N 만큼 굴리고, `go` 로 화면을 옮기면 앱이 그 칸을 맨 위로 되돌린다(2026-10-18 · DF-134 — 그 전에는 창을 굴려 아무 일도 없었고, 앞 화면에서 내려간 자리를 물려받았다).

장면 파일 단계: `chapter`(장 제목) · `say`(자막) · `go`(화면 이동) · `click` · `fill` · `select` · `key` · `scroll`(`target` 은 그 칸이 보이게 · `by` 는 내용 칸을 그만큼) · `wait`(`cut: true` 면 기다림을 영상에서 줄임) · `ring`(강조) · `hover` · `pause` · `js`.

## 3. 어느 판이 나은가 — 바꿔 끼우는 기준

<표 3> 팀원 판으로 바꿀 때 보는 다섯

| 기준 | 좋은 판 |
|---|---|
| 끊김 | 장면 사이 멈춤 · 로딩 빈 화면이 없다 · 콘솔 오류 0(`.json` 의 `console_errors`) |
| 개발 티 | 화면에 키 · 계좌번호 · 내부 영어 낱말(`moderate` 같은) · 주소창이 보이지 않는다 |
| 자막 | 장마다 목적 · 과정 · 결과가 한 문장씩 · 투자 권유가 아니라는 고지 · **자막이 말하는 것이 화면에 실제로 보인다** |
| 출처 | 시세 · 지표가 나오면 그 화면이 실제로 읽는 출처를 한 줄(아래 <표 4>) |
| 길이 | 3분 안(`.json` 의 `over_limit` 이 false) |

## 4. 보관 · 올리기

```bash
python tools/demo/upload_hf.py --dry-run    # 올릴 파일 · 크기
```

- 발표 자료(`docs/2차/발표/발표자료.html`)는 `파일/발표/` mp4 를 바로 재생한다 — 파일이 git 에 있어 팀원도 `git pull` 한 번 뒤 그대로 재생된다(2026-10-20). v0.1 의 `media/` 폴더 방식은 v0.2(2026-10-19)부터 쓰지 않지만, 사용자 결정으로 옛 `media/` 도 함께 올렸다.
- 강사님 안내 — 화면이 바뀌면 영상도 늘 최신으로: 그 화면의 장면만 다시 찍어 올린다.

## 5. 앱 안에서 보기 — 사용법 창 「영상으로 보기」 (결정 D132 첫 단계)

화면 맨 위 윗줄의 「▶ 영상 1:03」 또는 「사용법」 창 안 「영상으로 보기」 칸을 누르면 그 자리에서 영상이 나온다. 여러 화면에 걸친 영상은 **그 화면이 처음 나오는 장부터** 튼다(차트 패턴 = 신호로 종목 살피기 ② 0:15) · 처음부터는 장 단추 ①. 영상이 없는 화면에는 칸 · 단추가 없다.

```bash
python tools/demo/help_videos.py build     # 녹화한 PC — tools/demo/out/ 의 녹화 결과로
python tools/demo/help_videos.py pull      # 다른 PC — HF 비공개에서 받아서(읽기 토큰은 그 순간에만 · 조직 회원이어야)
python tools/demo/help_videos.py status    # 지금 무엇이 있나 · 빠진 파일
python tools/demo/help_videos.py clear     # 지운다(영상 칸 · 단추가 숨는다)
```

- 영상은 git · 도커 이미지 밖 `data/help/` 에 둔다. compose 가 `./data` 를 앱 컨테이너에 이미 붙이고 있어 compose 를 고치지 않아도 보인다. 앱은 **로그인한 사람에게만** `/help/videos.json` · `/help/media/<파일>` 로 낸다.
- 영상 표(`data/help/videos.json` — 화면 키 → 영상 · 장)는 도구가 녹화 기록의 단계 시각 · 화면 키와 장 파일을 맞대어 만든다. 손으로 쓰지 않고, 영상을 다시 찍어도 git 을 고칠 일이 없다.
- 장 · 영상 제목에 편 번호 · 파일 이름 · 「장면」 · 「HF」 같은 말이 있으면 도구가 멈춘다(화면 글 점검).
- 자막은 영상에 들어 있어 자막 트랙은 켜지 않는다(켜면 같은 글이 두 줄로 겹친다 · 브라우저 CC 단추로 켤 수 있다).
- 브라우저는 새로 고침(Ctrl + F5)하면 새 표를 읽는다.

## 6. 발표 영상 — 사용법 영상과 따로 (2026-10-18 사용자 결정)

강사님 안내는 「주요 기능 동영상 … 각 3분 내외 · 목적 → 실행 과정 → 결과 · 설명이나 자막」(샘플 2:50)이다. 사용법 영상은 사용법 창에서 짧게 보려고 1분 안팎으로 찍었으므로, **발표에서 트는 영상은 같은 기능 15편을 따로 더 자세히** 찍는다 — 질문 묶음마다 무엇을 재는지, 결과 숫자를 읽는 법, 곁 기능(탭 · 서랍 · 재는 법), 다음 화면으로 이어짐을 자막으로 짚는다.

- 장면 파일: `발표/P-<영상>-<이름>.yaml`(이 폴더 아래 `발표/`) · 결과 이름은 `발표-<영상>-<이름>` · 길이 2:00 ~ 2:50 을 겨눈다(3분이 넘으면 `.json` 의 `over_limit`).
- 녹화 · 올리기는 사용법 영상과 폴더만 다르다 — 사용법 영상 표(5절)에 섞이지 않게:

```bash
python tools/demo/record_demo.py --frames --out tools/demo/out/present docs/영상/발표/P-V07-근거상담.yaml
python tools/demo/upload_hf.py --src tools/demo/out/present --prefix present      # HF present/ 로
```

- 자막은 화면에 실제로 보이는 것만 말한다 — 「자막 = 화면」 이 어긋나면(예: 「자료 없음」 화면에 「총 자산이 보인다」) 그 판은 쓰지 않는다.
- 장중 · 회차 뒤가 필요한 편: 모의 주문(국내 체결) · 모의 계좌(체결 뒤 숫자) · 리밸런싱(전 거래일 종가가 수집된 뒤 — 주말 · 공개 전이면 주문 산출이 「자료 준비 후 다시」) · 거시 · 산업 · 차트(장중 숫자) · 통합 대시보드(체결 뒤 계좌).
