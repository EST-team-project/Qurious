## 2026-09-29 — 격차표는 요구사항 추적표(RTM) v1.1 로 옮겼습니다

이 글의 4절 격차표(제안요청서 항목별 구현 격차)와 8절 「행별 확인 요청」 은 이제 [RTM v1.1](https://github.com/EST-team-project/Qurious/blob/main/docs/요구사항/RTM_v1.1.md) 이 맡습니다.

- 제안요청서 `rfp-2` 의 35칸이 어느 요구로 가는지 — RTM v1.1 1.2절 표 3 (3절 요구사항 19칸과 4.2절 제외 범위 3줄은 요구로, 나머지 16칸은 산출물 · 평가 기준 · 팀 역량이라 요구로 세지 않습니다).
- 요구 59개(강사님 원문 세부 기능 29 · 화면 필수 요소 10 · 제안요청서 15 · 공식 일정표 5)마다 설계 · API · 시험 · 진행 — RTM v1.1 3절.
- 이 글 4.2절의 「3차 잠정 행」 은 강사님 원문의 3차 세부 기능 15개(`P02-①-1` ~ `P02-⑤-3`)와 공식 일정표의 3차 기능 칸 16개(RTM v1.1 5.2절)로 바뀌었습니다.
- 행별 확인은 RTM v1.1 을 읽고, 요구 한 줄이 틀렸으면 [요구 대장](https://github.com/EST-team-project/Qurious/blob/main/docs/요구사항/요구-대장.tsv)의 그 줄을 고치는 PR 이나 Discord 한 줄로 받습니다. 요구마다의 담당 파트는 역할 희망 논의(D9 · #52) 뒤에 정합니다.

이 글의 원문과 댓글은 [기록 폴더](https://github.com/EST-team-project/Qurious/blob/main/docs/github-archive/2026-09-15/이슈-005/00-기록.md)에 그대로 있습니다. 이 글은 닫습니다.
