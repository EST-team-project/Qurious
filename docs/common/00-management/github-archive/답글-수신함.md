# 답글 수신함 — 팀원 답글을 붙여 넣는 곳

> 신설 2026-09-29 (KST) · S61 · 이동원 제안 — 「팀원 댓글이 올라오면 이슈 번호와 함께 문서로 정리해 계속 갱신하겠다」.
> **이동원이 붙여 넣고, Claude 가 세션마다 읽어 처리한다.** 처리가 끝난 항목은 「처리」 칸만 채우고 지우지 않는다(한 달에 한 번 비운다).

## 쓰는 법

1. 답글이 오면 아래 「받은 답글」 맨 **위**에 한 덩어리를 더한다 — 머리줄 한 줄 + 원문 그대로.
2. 원문은 **고치지 않고** 붙인다(맞춤법 · 줄바꿈 그대로). 표 · 그림이 있으면 「(그림 있음)」 만 적어도 된다.
3. 머리줄은 `### 받은 날(KST) · 새 번호 글 이름 · 작성자 아이디` — 예: `### 2026-09-30 · #21 D5 · rkdalstjr`
   답글이 어느 댓글에 달린 것인지 알면 뒤에 `· 「결론 초안」 댓글에 답글` 처럼 덧붙인다.
4. 저장소 규칙대로 **GitHub 에 올라온 글만** 여기에 둔다(이 저장소는 공개다). Discord 의견은 지금처럼 요지를 결정 대장에 옮긴다 — 원문이 필요하면 따로 말해 주기.

|:-:|---|---|

| 2 | 결정 · 의견이면 결정 대장에 반영할 줄을 모은다 | 결정 대장 v1.0 (09-30 뒤) |
