## How

- **원인** — git bash(mintty)는 파이썬에게 콘솔이 아니라 파이프입니다. 파이썬은 파이프에 쓸 때 로케일 인코딩(cp949)을 고르는데, ✅(U+2705)는 cp949 에 없습니다. Claude 셸에는 `PYTHONIOENCODING=utf-8` 이 잡혀 있어서 재현되지 않았습니다.
- **스크립트가 스스로 맞추게 했습니다.** 사용자 PC 의 환경변수(`PYTHONUTF8=1`)로 고치면 팀원 PC 에서 다시 죽습니다. 블록마다 `python -X utf8` 을 붙이면, 한 번 빠뜨리는 순간 다시 조용히 죽습니다.
- `hasattr(stream, "reconfigure")` 로 거르므로 작업 스케줄러의 `pythonw` 는 그대로 지나갑니다. 자식 단계에는 러너가 이미 `PYTHONIOENCODING=utf-8` 을 넣습니다.
