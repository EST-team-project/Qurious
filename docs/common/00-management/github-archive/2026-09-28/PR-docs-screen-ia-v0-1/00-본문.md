## Proof (트러블슈팅)

- 스캐너 첫 판은 `settings` 화면의 조작 API 에 `/broker/settings` 를 넣었습니다. 실제로는 **직접매매 화면 버튼이 `settings` 의 입력칸을 읽은 것**(숨은 의존)이었습니다 → 리스너 블록은 버튼이 있는 화면에만 붙도록 규칙을 고쳤습니다.
- 「숨은 의존」 후보 3건 중 1건(`app.html:5345`)은 여러 화면이 함께 쓰는 **공용 종목 검색 창**이었습니다 → 「공용 부품」으로 따로 보고합니다.
- 「저장처 두 갈래」로 보였던 증권사 설정은 **같은 `BrokerSettings` 한 행**이었습니다(`stocks.py:395-520`).
- 옛 A13 의 「새로고침하면 처음 화면으로 돌아간다」는 조사 기준 커밋 `04f476a` 에서도 틀린 서술이었습니다(해시 라우팅) → IA 1.1절에 정정.
