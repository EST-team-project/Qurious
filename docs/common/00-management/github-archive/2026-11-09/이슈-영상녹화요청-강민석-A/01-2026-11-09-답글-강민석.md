## LEAN 대사 정렬 전후 자료 제출 방식 및 확인 결과

@dev-dongwon05253 님 요청하신 3차 발표 영상 제작 건에 대해 검토했습니다.

강사님께서 발표 영상 제작을 요청하신 취지는 이해하고 있습니다. 다만 이번 LEAN 대사 정렬 작업은 동적인 화면보다 정렬 전후의 검증 결과와 수치 차이를 명확하게 전달하는 것이 핵심이라고 판단했습니다.

따라서 1분 내외의 시연 영상보다는 **실제 터미널에 출력한 대사 결과를 전후 사진 2장으로 비교하는 방식이 발표 자료로 더 적합하다**고 판단했습니다.

영상 대신 다음 두 장을 제출하는 방향으로 진행하겠습니다.

### 1. 정렬 전 (BEFORE)

**출처:** `daily/2026-11-02_v4.md`  
**기준일:** 2026-10-30 · 일지 40행

- 신호 일치: 40/40
- 보유 상태: 35/40
- 주문 방향: 2건
- 체결가 최대 차이: 440.8bp

### 2. 정렬 후 (AFTER)

**출처:** `daily/2026-11-06_v4.md`  
**기준일:** 2026-11-05 · 일지 44행

- 신호 일치: 공통 관측 41일 중 41/41
- 보유 상태: 44/44
- 주문 방향: 12/12
- 체결가 최대 차이: 0.0000bp
- 비용률: 10.76bp 동일
- 체결 수량: 12/12

참고로 정렬 후 신호 41/41은 44일 전체가 아닌 공통 관측 41일 기준입니다.

### 3. 정렬 개선의 주요 원인

관련 구현 커밋은 `26b4c1b9`입니다.

기존 LEAN의 일봉 데이터 처리와 그림자 일지의 다음 거래일 시가 체결 기준이 달랐던 문제를 개선했습니다.

주요 변경 사항은 다음과 같습니다.

- 수정종가와 원주가 시가 데이터 분리
- `next_open` 기준 체결 시점 정렬
- LEAN의 시장가 시가 체결 모델 적용
- 매수 예산 및 최대 보유 비중 통일
- 매도 비율 0.5 적용으로 부분 청산 방식 통일

### 4. 제출 방식 선택 이유

이번 자료는 시간의 흐름이나 조작 과정을 보여주는 것보다 정렬 전후의 결과를 비교하는 것이 중요합니다.

따라서 터미널 출력 사진 두 장을 사용하면 다음 장점이 있습니다.

1. 전후 수치를 한눈에 비교할 수 있습니다.
2. 발표 중 핵심 수치를 다시 확인하기 쉽습니다.
3. 불필요한 영상 재생 시간 없이 검증 결과에 집중할 수 있습니다.
4. 각 사진에 원본 보고서 경로와 기준일을 표시해 근거를 명확히 할 수 있습니다.

실제 터미널에서 기존 보고서와 산출물을 출력해 캡처하는 방식으로 준비하며, 새로운 대사 실행이나 실제 주문은 수행하지 않습니다.

**최종적으로 영상 대신 정렬 전후 터미널 결과 사진 2장을 발표 자료로 제출하는 방향을 제안합니다.**
