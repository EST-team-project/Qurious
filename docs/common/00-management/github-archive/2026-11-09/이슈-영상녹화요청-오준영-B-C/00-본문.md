## 쉬운 요약

1. 발표 영상을 가능한 한 많이 만들고 있습니다. 오준영 님 파트 두 편의 장면 파일을 만들었는데, **제 시연 계정에는 촬영에 필요한 상태(저장된 「시장 국면」 배분 · 「내 전략」 카드 · 국면 변경 이력)가 없어서** 끝까지 찍지 못합니다.
2. 그 상태가 실제로 있는 **오준영 님 환경에서 녹화**하는 쪽이 더 정확하다고 판단해 요청드립니다. 제가 시연 계정에 억지로 만들어 찍지는 않았습니다(「자막 = 화면」 원칙).
3. 장면 파일(대사 · 자막 · 누를 곳)은 이미 있으니 그대로 쓰셔도 되고, 직접 화면 녹화 도구로 찍으셔도 됩니다.

## 제 쪽에서 확인한 것 (`--no-video` · 영상 저장 없이 단계만)

- 앱이 켜진 상태에서 단계를 밟아 보았을 때, 두 편 모두 **셀렉터 오류가 아니라 선행 조건 때문에** 멈췄습니다: B 는 「국면 자동 변경」 칸이 안 풀림(마지막 저장 배분이 「최소분산」), C 는 「내 전략」 카드가 없어 전략 고르기가 안 됨.
- 선행 조건 단계만 뺀 임시 사본으로는 나머지 단계가 모두 통과했습니다(B 31/31 · 43/43, C 35/35 · 46/46). 다만 **선행 조건 단계 자체는 한 번도 밟아 보지 못했습니다.**
- 코드 읽기와 `--no-video` 확인이며 영상으로 녹화해 본 것은 아닙니다.

## 안전 (장면에 이미 반영한 것)

- 장면은 **읽기 · 조회 · 가리키기만** 합니다. 실제 주문 · 자동매매 시작 · 비상 정지 켜기 · 계좌 초기화 · 설정 저장 · 예약 · 활성화 단추는 누르지 않습니다.
- C 의 App Key · Secret · 계좌번호 칸은 `hide` 로 화면에서 통째로 가렸습니다. 직접 찍으실 때도 이 칸이 보이지 않게 부탁드립니다.
- B 는 「국면 자동 변경」 라벨을 눌러 **편집안만** 바꾸고 저장하지 않습니다.
