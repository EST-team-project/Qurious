## 3. 지표 정의 (`ta_utils.py` · 이동원 몫)

- 처음부터 평평한 열의 RSI: `ta_utils` 100, TA-Lib 50.
- EMA · MACD 시작값: `ta_utils` 는 첫 봉 값, TA-Lib · LEAN 은 처음 n 개 단순평균.
- ATR 첫 봉 TR 은 코드에 쓰여 있지 않고 `max(axis=1)` 의 skipna 부수효과(같은 파일의 `dmi` 는 `skipna=False`).
- `rma` 는 `ignore_na=True`, `ema` · `macd` 는 기본값 False. 코드 주석은 Pine v5.
- TradingView 화면 값과 대조한 것은 RSI 5일과 DMI 7일뿐입니다.
