## 요약

사용자 제안 「신호 순위에서 새로고침을 누르면 기준 시간대를 다시 보고 실시간 데이터와 같이 보고 싶다」의 **1단계**입니다. 사용자와 정한 범위는 (a) 기록 다시 읽기 + 지금 가격 표시이고, (c) 순위 전체를 실시간으로 다시 판단하는 것은 11월 12일 뒤 설계로 남깁니다.

- 신호 순위 필터 줄에 「새로고침」 단추: 지금 조건(필터 · 검색)으로 기록된 신호를 다시 읽고, 위 10종목에만 `GET /api/stocks/quote` 로 지금 가격을 읽어 종목 칸 아래 한 줄(「지금 72,300원 · 지연 시세 · 약 20분」)로 붙인다. 한 번에 5개씩.
- 안내 글: 「새로고침 13:12:34 (KST) · 기록된 신호를 다시 읽었습니다 — 신호는 새로 계산하지 않습니다」. 그 사이 조건이 바뀌면 낡은 가격은 붙이지 않는다.
- **신호는 다시 계산하지 않는다** — 일지 판 지문 대상 조각을 건드리지 않았다.
- 시험 `TC-RKS-18`(안내 글 · 가격 줄 · 단추 · 연결). `TC-RKS-12`(화면이 부르는 API)는 `/api/stocks/quote` 가 새로 부르는 사실을 반영해 고쳤다.
- 문서: RTM v1.82 · 테스트 계획서 v1.94 · API 명세서 v0.63(`API-STK-02` 부르는 화면에 `signal-rank`) · UI 명세서 v0.51(25.7절, 29 · 31절 Figma 구현 대조 주소) · 산출물목록 v3.14.
- 발표 자료: 8장 약점 표에 「신호를 실시간으로 다시 판단하지 않음 → 11월 12일 뒤 설계」 행 추가, 대본 8장 문장 갱신.
