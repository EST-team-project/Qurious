## 요약

사용자 피드백 「퀀트 화면의 규칙 신호 카드에도 필터」 — 퀀트 대시보드 「기본 일봉 규칙 신호 (관찰 목록)」 카드에 **신호(전체 · 매수 · 매도 · 관망) · 시장(전체 · KOSPI · KOSDAQ)** 필터를 더합니다. 신호 순위 화면 필터(#553)와 같은 낱말입니다.

- `quant.js`: 필터 줄을 카드 칸 앞에 JS 로 한 번 만든다(`app.html` 은 그대로). 카드 뿌리에 `data-qd-signal`(강력 매수 → 매수 / 강력 매도 → 매도 / 그 밖 관망)과 `data-qd-market`(`.KS` → KOSPI · `.KQ` → KOSDAQ)을 단다. 서버 응답은 그대로다.
- 카드는 처음 10장만 받으므로 필터를 거는 순간 나머지 21종목을 한 번 받아 붙이고 펼친 채로 거른다. 못 받으면 받은 카드만 거르고 「처음 10종목만 거른 결과」 라고 말한다.
- 개수 글은 「31종목 중 N개 일치」, 맞는 종목이 없으면 안내 한 줄.
- 시험 `TC-SCD-14 ~ 17`(카드 속성 · 필터 동작 · 나머지 받기 · 연결). TC-SCD 12 → 16.
- 문서: RTM v1.81 · 테스트 계획서 v1.93 · UI 명세서 v0.50(26.6절) · 산출물목록 v3.13.
