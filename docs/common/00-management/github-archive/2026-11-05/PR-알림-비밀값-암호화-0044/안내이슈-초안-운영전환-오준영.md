- 전화번호 · 채팅 ID · 이메일 주소 칸은 이번 범위 밖입니다(개인정보 처리방침 판단과 함께 후속).

- 동의 철회는 키가 깨져도 되도록 행을 읽지 않고 삭제합니다.

## 오준영 님 코드를 한 곳 고쳤습니다 — 확인 부탁

- `app/database/postgres.py`(#397) `get_pg_session` 의 503 처리기: 고정 문구 `str(CredentialStorageError())` → **예외가 가진 문구** `str(exc)`. 증권사 쪽은 같은 문구라 동작이 같고, 알림 화면에 「증권사…」 문구가 나가지 않게 하는 한 줄입니다. 시험 TC-NS-04 가 증권사 문구 유지도 확인합니다.

## 알아 두실 것

- 키가 새면 증권사 · 알림 두 표가 함께 노출됩니다(안 A 의 폭발 반경). 증권사 키를 바꿀 때는 알림도 같이 바꿔야 합니다.
- 동의문 · 처리방침의 「알림 설정은 암호화 저장을 하지 않습니다」 문구는 사실과 달라져 고쳤습니다. 동의문 판(`NOTIFY_CONSENT_VERSION`)은 올리지 않았습니다 — 보호가 강화되는 변경이라는 전제이며 법률 판단은 아닙니다.
- 일회용 PG 시험은 `QURIOUS_TEST_DATABASE_URL` 이 없으면 건너뜁니다. 건너뛴 채 통과로 보시면 안 됩니다.
