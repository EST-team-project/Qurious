## 주의 — 이동원이 덧붙이는 것

- 분할 비율이 정수가 아니거나 역분할이면 「수량 × 비율의 역수」가 **정수가 되지 않는다.** 증권사가 실제 어떻게 처리하는지(단주 · 현금 정산)와 장부 수량이 맞아야 하므로 A 안의 구현 조건이다.
- 비용(`trading_cost.cost_rate`)은 비율형이라 1주 손실이 가격 비율로 같이 움직이지만, 고정 호가 단위 같은 가격 단위 비용이 섞이면 어긋날 수 있다 — 읽지 않았다.
- 이 답은 **식의 정합성**이다. 보유 중 조정 사건에서 지금 코드가 무엇을 하는지(#561 질문 1)는 아직 오준영 님 답을 기다린다.
