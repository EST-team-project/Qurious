### 1. DSR — 연율 샤프 입력 · 시도 횟수 50 고정 (우선순위 높음)

**확인한 것** (원격 main `3e7d15b` · 읽기와 합성 수익률 재현만)
- `app/services/evaluation_risk.py:162~196` `deflated_sharpe_ratio` 의 표준오차 식은 **관측 주기(일) 단위 샤프**를 가정합니다(`n_observations − 1` 로 나눔). 그런데 `calculate_all_metrics`(`:206~246`)는 `sharpe_ratio`(`:68~83`, `× √252` 연율)를 그대로 넣습니다.
- 시도 횟수는 `n_trials=50` 기본값(`:206` · `performance_service.py:56`)이고 어디서도 실제 시도 수로 바뀌지 않습니다.
- 재현: `docs/phase-3/01-analysis/research/배경조사/2026-10-28-특강-1-3일차-점검/dsr-재현.py`(읽기만 · 저장소 루트에서 `python …` 한 줄). 평균 0(알파 없음)인 합성 일수익률에서 **DSR ≥ 0.95 를 넘는 비율이 T=60 에서 41.3% · T=250 에서 39.0%** 입니다. 같은 단순 식을 일 단위 샤프로 쓰면 0.3% · 0.0%. (일 변동성 1% · N=50 · 300회 · 합성 데이터이므로 실제 계좌의 숫자가 아니라 **식 단위가 만드는 편향의 크기**입니다.)
- 이미 알려진 문제입니다 — `2026-10-20-개념학습-범위문체/결과.md:225` 와 학습 장 10.2(열흘 예: 0.7085 대 0.0350). 다만 코드는 그대로이고 3차 할 일 문서에는 이 줄이 없습니다.

**특강 근거**: DSR ≥ 0.95 가 합격선(`2일차6 p04 · p07` · `3일차7 p03`) · 식에 시도 횟수 N 이 필수(`3일차7 p07` 퀴즈 1) · 높은 샤프라도 N 이 크면 우연일 수 있음(`3일차1 p02` 그래프 — N 이 10 → 100,000 으로 늘 때 기대 최대 샤프가 오르는 그림).
⚠️ 3일차7 p03 의 DSR **식 그림**은 기호 정의가 없고 3일차8 p05 와 모양이 달라 구현 근거로 쓰지 않습니다(원 출처 Bailey · López de Prado 2014).
