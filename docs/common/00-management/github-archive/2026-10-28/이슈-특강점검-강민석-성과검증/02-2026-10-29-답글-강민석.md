### [진행 결과] DSR 수정 및 후속 과제 정리

요청받은 ① DSR 수정 작업을 진행하고 커밋 및 푸시까지 완료했습니다. 완료한 항목과 이번 범위에서 진행하지 않은 항목을 구분해 공유합니다.

#### 1. 완료한 항목

**① DSR의 연율 Sharpe 입력 오류 수정**
- `calculate_all_metrics`에서 DSR 계산에 사용하는 Sharpe를 연율화 값에서 관측 주기 기준 값으로 환산했습니다.
- 관측 주기 기준 Sharpe를 사용하도록 수정해 표준오차 계산의 단위 불일치를 해결했습니다.

**② DSR 테스트 보강**
- 알파가 없는 합성 수익률에서 DSR이 과도하게 높아지는지 확인하는 테스트를 추가했습니다.
- 기대 최대 Sharpe 근사식 검증과 `n_trials < 1` 입력 검증을 추가했습니다.
- DSR 전용 테스트 20개 및 관련 위험 관리 테스트를 실행했고, 실패 없이 통과했습니다. `git diff --check`도 통과했습니다.

**③ 변경사항 반영**
- 변경 파일: `app/services/evaluation_risk.py`, `tests/test_qfrs_metrics.py`
- 커밋 및 원격 저장소 푸시를 완료했습니다.

#### 2. 이번에 진행하지 않은 항목과 이유

**① 실제 시도 횟수(T7) 연결 — 미완료**
- 현재 `n_trials=50`은 기본값이며, 실제 전략 시도 기록의 개수를 가져와 계산하는 구조는 이번 변경에 포함하지 않았습니다.
- 이유: 시도 기록을 실제 DSR 계산에 연결하려면 T7 기록의 식별 기준과 중복 제거, 어떤 시도를 하나의 독립적인 시행으로 볼지에 대한 정의가 필요합니다. 단순히 기록 행 개수를 세면 실제 시도 횟수와 달라질 수 있습니다.
- 후속 방향: T7 기록의 집계 기준을 협의한 뒤 실제 시행 횟수와 연결합니다.

**② 짧은 표본의 ‘참고용’ 표시 — 미완료**
- 현재는 표본 길이에 따라 DSR을 참고용으로 표시하는 기능을 추가하지 않았습니다.
- 이유: 어느 표본 길이부터 참고용으로 표시할지에 대한 기준이 확정되지 않았습니다. 임의의 기준을 추가하면 근거 없는 경고가 될 수 있습니다.
- 후속 방향: 최소 표본 기준을 사전 합의한 뒤 화면 표시와 함께 적용합니다.

**③ 정식 DSR 적용 여부 — 미결정**
- 실제 여러 시행의 Sharpe 분산을 사용하는 정식 DSR은 구현하지 않았습니다.
- 이번에는 실제 50회 시행의 Sharpe 분포를 수집하기 어려워, 단일 수익률 시계열에서 추정한 Sharpe 표준오차를 이용하는 근사 방식을 유지했습니다. 기대 최대 Sharpe는 두 분위수를 이용한 근사식으로 계산합니다.
- 한계: 이 근사 방식은 실제 시행 간 Sharpe 분포를 사용한 정식 DSR과 동일하지 않습니다. 따라서 결과를 정식 DSR과 동일한 수준의 검증으로 해석해서는 안 됩니다.
- 후속 방향: T7 시도 기록을 활용할 수 있는지 검토한 뒤 정식 DSR 전환 여부를 결정합니다.

#### 3. 나머지 이슈 항목

**슬리피지 민감도 — 미완료**
- 슬리피지 배수별 민감도(×0·×1·×2) 및 거래대금 대비 주문 규모 경고는 이번 변경에 포함하지 않았습니다.
- 이유: 이번 요청이 3차 마감 전 우선 처리할 DSR ① 항목으로 한정되어 있었으며, 슬리피지 스트레스 기준은 별도로 정해야 합니다.

**성과 화면 지표 — 미완료**
- 회복 일수, 최대 연속 손실 일수, 6개월 롤링 Sharpe 등의 추가는 진행하지 않았습니다.
- 이유: 표시할 지표와 기간 기준에 대한 결정이 필요하고, 이번 요청 범위가 DSR 수정에 한정되어 있기 때문입니다.

**강건성 검증(SCH-ROB) — 미완료**
- OOS 구간 사전 등록, 파라미터 민감도 표, PBO·몬테카를로·CPCV 적용은 진행하지 않았습니다.
- 이유: 검증 범위와 담당자 분담을 별도로 정해야 하며, DSR 수정만으로 강건성 검증이 완료되는 것은 아니기 때문입니다.

#### 4. 후속 확인 사항

- 개념 학습 장 10.2절의 DSR 예시 수치와 `performance-metrics-calc.md` 설명을 수정된 계산 결과에 맞춰 재확인해야 합니다. 이번 코드 테스트 통과만으로 문서 수치까지 검증된 것은 아닙니다.
- 이번 변경은 DSR 계산의 단위 불일치를 수정한 것이며, 실제 시행 횟수 연결이나 정식 DSR 적용까지 완료한 것은 아닙니다.

**결론:** 요청받은 DSR ① 수정과 관련 테스트는 완료했습니다. 실제 시행 횟수 연결, 짧은 표본의 참고용 표시, 정식 DSR 전환은 기준과 데이터 연결 방식을 추가로 결정해야 하므로 후속 과제로 남깁니다. 슬리피지·성과 화면·강건성 검증도 별도 범위로 유지합니다. 후속 과제는 현재 작업 내용이 끝나고 업무가 비었을 때 진행하겠습니다.
