## 무엇을 보나

**범위(이번에 보는 것)** — 스크리닝 화면에 더할 「신호 기록 순위」 탭과, 종목을 누르면 열리는 **오른쪽 서랍**(차트 + 근거 표 + 가격 두 줄)의 자리와 쓰임.

**범위 밖(이번에 보지 않는 것)** — 색 · 글꼴 · 모서리 · 섹터 거르기(섹터 소속이 ②-10 뒤에야 생김) · ADX · 상대 강도 열 · 장중 신호 재계산(판정표 3절 결정 ③) · 백엔드 계약(담당이 따로 정함 — 아래 「담당」).

**목표** — 투자를 처음 하는 사람이 **종목 하나를 눌러 「왜 매수 쪽인가」를 두 번 안에 쉬운 말로 읽고**, 보이는 가격이 **어느 날 종가인지 · 지금 값인지** 헷갈리지 않는다. 의견은 이 목표에 대고 내 주세요(「별로예요」 보다 「목표의 어디가 걸리는지」).

## 정할 것 넷

1. **자리** — 안 B(스크리닝 화면에 탭 둘: 「조건으로 찾기」 · 「신호 기록 순위」)로 갈까요?
   - A 새 메뉴 화면: 순위만 깔끔하지만 화면이 54개에서 하나 늘고 스크리닝과 겹침 · 메뉴 칸 부족
   - **B 탭(제안)**: 이름이 안 늘고 같은 화면에서 견줄 수 있음
   - C 지금 표를 순위로 갈아 끼움: 지금 표는 조건으로 거르는 도구이고 순위는 기록 읽기라 뜻이 달라 「같은 이름 다른 값」 위험
2. **서랍의 차트** — 일봉만 / 다중 주기 요약까지. (제안: 일봉만, 다중 주기는 서랍 아래 「다중 주기 ↗」 로 보냄)
3. **지금 가격을 어디에** — 순위 표 **모든 줄**에 보일까요, **서랍을 열 때만** 보일까요? 모든 줄이면 종목마다 시세를 불러 요청 수와 증권사 한도가 걸립니다. (제안: 서랍을 열 때만 · 표에는 「신호 기준 종가(날짜)」만)
4. **「중립」을 쉬운 말로 뭐라 부를까요** — 낱말 표(#159 T3)와 맞춰야 합니다. 예: 「중립」 그대로 / 「판단 보류」 / 「뚜렷하지 않음」.

## 약속(이미 정한 것 — 뒤집으려면 말씀해 주세요)

- 서랍의 설명 문장은 신장환 님 `GET /api/explain` 응답을 **그대로** 보입니다. 화면이 문장을 새로 짓지 않습니다.
- 숫자는 응답에 있는 값만 씁니다. 응답에 없으면 「모름」.
- 근거 n개 = `reasons` 줄 수(#351 결정). 「매수 쪽 a · 중립 b · 매도 쪽 c」 로 나눠 보이고 합이 n.
- 가격은 항상 **두 줄**: 「신호 기준 종가(MM-DD)」 / 「지금 가격 · 출처 · 시각」. 지금 값을 못 받으면 칸을 비우고 까닭을 씁니다 — 지난 종가나 평단가로 **말없이 채우지 않습니다**(판정표 (가)).
- 서랍은 표 **위에 겹쳐** 열립니다(왼쪽 메뉴 때문에 본문이 약 976px 라 표와 나란히 안 들어감 — 실제 앱 화면과 견줘 확인). 닫으면 가려진 칸이 다시 보입니다.
