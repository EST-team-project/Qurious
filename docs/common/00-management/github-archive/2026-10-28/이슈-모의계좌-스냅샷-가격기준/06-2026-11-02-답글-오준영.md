합의된 가격 근거/제외 기준을 실제 코드로 보완해 PR #477에 올렸습니다. 이전 배치 실행 성공과 이번 가격 신뢰성 구현을 구분해서 기록합니다.

- 계좌·성과 GET의 daily 저장을 제거했습니다. 명시적 수동 기록은 `manual`이며 daily를 덮어쓰지 못합니다.
- 보유 종목 전체의 출처·가격 기준 시각·대체 사유를 JSONB로 남깁니다. 시세 자체는 이 메타데이터에 저장하지 않습니다. 국내 주식은 해당 날짜의 검증된 수집 종가 또는 실제 정규장 마지막 체결 시각 15:30인 공급값만 인정합니다. 시각 없는 게이트웨이 값·장중 값은 종가로 간주하지 않습니다.
- 코인은 **응답의 실제 체결 시각 `trade_timestamp`**을 기준으로 0~300초를 확인합니다. 서버 수신 시각으로 신선도를 대신하지 않으며, 연결 실패 때 오래된 캐시도 돌려주지 않습니다.
- 대체/근거 누락이 하나라도 있으면 불완전 기록을 보존하고 지표에서 뺍니다. 과거 기록을 재작성하거나 근거 없는 보유 평가를 complete로 소급 인정하지 않습니다.
- 같은 회차의 완전한 daily 이웃만 수익률로 연결합니다. 불완전·누락·리셋 경계를 유효한 0%로 넣지 않고, 배분/벤치마크 차트도 같은 제외 기준을 사용합니다. 배치 결과에는 저장 성공/실패 외에 complete/incomplete 개수도 남깁니다.

실제 PostgreSQL에서 GET 부작용 없음, manual 덮어쓰기 방지, 불완전 구간 제외, 과거 근거 없는 기록/다른 회차 제외를 검증했고, 시세 시각·종가 대체 경계도 시험했습니다. 손절/장부까지 포함한 집중 시험 41건 통과, 전체 관련 결과는 [PR #477](https://github.com/EST-team-project/Qurious/pull/477)에 정리했습니다. DB 이전 `0037_snapshot_evidence`가 필요합니다.

**운영 확인은 아직 남아 있습니다.** 이번 코드는 미배포이므로 새 기준의 15:40 정기 실행을 확인한 것은 아닙니다. 기존에 확인한 10/28·29 예정 회차 성공과 10/22·23 원인 미확정 판단은 그대로 유지합니다. 배포 뒤 앱·worker·beat 동일 버전, Beat/worker 로그와 사용자별 저장 행을 대조해야 합니다.
