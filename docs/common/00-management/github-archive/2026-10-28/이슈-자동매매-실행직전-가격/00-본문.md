### 제안
1. **B-1**: 손절 판정을 위험 점검 단계의 지금 값(이미 있는 `quant_valuation` 값)으로 하고, 판정에 쓴 가격과 출처를 사이클 로그에 남긴다. 수정주가 비교는 #366 의 변환 식과 **한 곳**에서 처리(식은 신장환 님 제안 → 세 경로 합의).
2. **B-3 (이번 범위에 넣음)**: live 도 B-2 와 같이 체결 직전 지금 값으로 교체하고 `판단 X → 주문 Y` 를 사이클 로그에 남기며, **수량은 교체 뒤에 계산**한다. 주문 유형 정책(지정가 vs 시장가)은 별도 결정 — 시장가로 고정이면 그 사실을 문서에 못 박는다.
3. **B-4**: live 에도 건별 일손실 재점검을 두거나, 없는 것이 의도라면 이유를 문서에 적는다.
4. 위는 이슈 A 의 (나)에 해당 — 판단 신호는 일봉(저장) 그대로 둔다.
