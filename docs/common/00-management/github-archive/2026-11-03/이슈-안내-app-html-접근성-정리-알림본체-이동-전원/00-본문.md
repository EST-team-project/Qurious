# [안내] app.html 접근성 정리(label for · aria-label) · 동기화 배지 클릭 오류 수정 · 알림 설정 본체를 마이페이지 「알림」 구역으로 이동

> 초안(올림 — #506). 작성 2026-11-03. 코드 검토(`docs/phase-3/01-analysis/research/배경조사/2026-11-03-app-html-코드검토/결과.md`)에서 나온 것 가운데 **기능 동결(11-05) 전에도 안전한 것만** 했습니다. 줄 수 · 들여쓰기 · 화면 순서는 바꾸지 않았고, 화면 일괄 이동 · 자동 서식 · Tailwind 교체는 하지 않았습니다.

## 무엇을 바꿨나

**1. 동기화 배지(상단 「N분 전 동기화」)를 누르면 오류였던 것을 고쳤습니다.**
`app.html` 의 `onclick="triggerSync()"` 가 부르는 `triggerSync` 가 `core.js` 모듈 안에서만 보이는 함수라 전역에 없었습니다(코드로 읽으면 클릭 때 ReferenceError). `core.js` 에 `window.triggerSync = triggerSync;` 한 줄과, 배지에 `role="button" tabindex="0"` · Enter / Space 키 처리를 더했습니다. 브라우저에서 `typeof window.triggerSync === "function"` 임을 확인했습니다.

**2. 입력칸 이름표(`<label>`)에 `for="…"` 를 102곳 달았습니다.** 앞서 짝 없는 label 104개(58%)였습니다. 기존 줄에 속성만 끼워 넣었고(106줄이 「끼워 넣기」 뿐임을 줄별로 확인) 줄 수는 3,204 그대로입니다. 짝은 「바로 뒤 컨트롤」 로 정했고 라벨 글과 대상 id 102쌍을 눈으로 훑었습니다. 화면별 주담당이 보시기에 짝이 틀린 곳이 있으면 알려 주세요. `✕` 닫기 버튼 2개에 `aria-label="닫기"`, 외부 링크 1곳에 `rel="noopener noreferrer"` 도 더했습니다.

**3. 알림 설정 본체(약 240줄)를 마이페이지 「알림」 구역으로 옮겼습니다(②-31).** 칸 id(`noti-*`)는 그대로라 `settings.js` 는 안 바뀝니다. 서버 API · DB 는 안 바뀝니다.
- 주소 `#notification-settings` 는 그대로 쓸 수 있고, 마이페이지의 「알림」 구역을 엽니다(`#settings` 가 「증권사」 구역을 여는 것과 같은 방식). 메뉴 줄 「알림 설정」 도 그대로입니다.
- `app.html` 의 `data-view="notification-settings"` 는 **빈 껍데기**로 남겼습니다(처음 주소 이동 검사 · 기능 완성도 점수 · 사용법 키가 이 화면 키를 찾습니다).
- 코드: `public/js/viewalias.js` 에 `MYPAGE_HOSTED` 한 곳을 두고 `core.js` · `howto.js` · `mypage.js` 가 같이 씁니다. `main.js` 의 알림 불러오기 호출은 `mypage.js` 의 구역 전환으로 옮겼습니다.
- Open API(`#paper-openapi`)는 그대로 별도 화면입니다.

## 부탁드립니다

- **새 입력칸에는 `<label for="…">` 를 달아 주세요.** TC-AHS-08 이 짝 없는 label 이 3개를 넘으면 멈춥니다.
- **인라인 `onclick="…"` 을 새로 만들면 그 함수를 `window.…` 에 다는 줄도 같이** 넣어 주세요(TC-AHS-06). 가능하면 `addEventListener` 를 쓰세요.
- 화면 블록 안에는 `<script>` 를 넣지 마세요(TC-AHS-02).
- 이 변경으로 불편하거나 반대하시면 알려 주세요 — 되돌리기는 아래 한 줄씩입니다.

## 되돌리는 법

- 1 · 2번: `core.js` 의 `window.triggerSync` 줄과 배지 keydown 줄을 지우면 1번이 원래대로. 2번은 `for="…"` 가 끼워진 줄만 바뀐 것이라 해당 줄을 이전 판으로 되돌립니다.
- 3번: `viewalias.js` 의 `MYPAGE_HOSTED` 에서 `"notification-settings"` 를 빼고 `app.html` 의 알림 구역 본체를 빈 껍데기 앞으로 되돌린 뒤 `main.js` 의 호출을 살립니다. 한 커밋에 모았으니 그 커밋을 `git revert` 하면 됩니다.
