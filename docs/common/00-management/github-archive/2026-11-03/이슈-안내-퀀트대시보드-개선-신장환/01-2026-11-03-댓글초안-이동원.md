@janghwan-god 신장환 님, 본문(#512) 올린 뒤에 퀀트 대시보드 차트 쪽이 더 바뀌어 보충합니다. **본문의 「차트 위 매매 표식 · RSI 하위 창 · 크로스헤어 값 줄은 이 글의 범위에 없다」는 이제 틀립니다** — 공용 일봉 차트 작업에서 들어갔습니다.

## 바뀐 것
1. **퀀트 대시보드 차트가 공용 일봉 차트 부품으로 합쳐졌습니다.** `public/js/stockchart.js` 의 `mountDailyChart` 한 부품을 종목 근거 모달 · 모의투자 시세 · 스탑 차트와 같이 씁니다. `quant.js` 의 자체 차트 코드(`qdDrawChart` · `quantCandles` · `qdLoadLwc` 등)는 걷어냈고 신호 띠 · 외부 차트 링크 · 요청 경합 가드(`qdChartSeq`)는 그대로입니다. 해외 종목과 일봉을 못 받은 국내 종목은 지표 응답의 종가 줄(`quantRows`)을 부품에 넘깁니다.
2. **차트 내용**: 캔들(오름 빨강 · 내림 파랑) + 거래량 + 20 · 60일선 + 볼린저(켜고 끄는 칩 · `aria-pressed`) · 크로스헤어 값 줄(시 · 고 · 저 · 종 · 전일 대비 · 거래량) · RSI · MACD 하위 창 · 일정 표식(실적 · 배당락 · 주총) · 신호 한 점(마지막 기록 · 중립 점 · 「여러 주기(60분 · 일 · 주)를 합친 기록」 · 「그날 종가까지로 계산해 다음 거래일 낮에 기록」 설명). 신호 점은 종목 근거 모달 쪽에서만 붙고 퀀트 차트에는 아직 없습니다.
3. **지표 값은 화면에서 계산한 표시용 값입니다**(서버 신호 값과 섞지 않고 그림 설명에 그렇게 적음). 이동평균 · 볼린저 · RSI · MACD 정의는 서버 `ta_utils`(tv-2026)와 같은 값이 나오는지 시험 TC-SCH-04 · 04b 가 대조합니다(1 ~ 61봉 17가지 길이). 판 지문 함수(`_generate_signal` · `get_quant_indicators`)는 건드리지 않았습니다.
4. **검수에서 고친 것**: KIS 경로 일봉 날짜가 UTC 로 읽혀 하루 앞서 보이던 것(이제 KST 기준 `qdDay`) · 종목을 빠르게 바꿀 때 늦은 응답이 차트를 덮던 것 · 예외 때 차트 인스턴스 누수 · 「더 보기」 단추의 키보드 초점 소실 · 스탑가만 바뀌어도 차트를 통째로 다시 그리던 것.
5. **종목 근거 모달 신호 칸(날짜별 근거)**: 「N일 기준 · M일 HH:MM 계산」 머리 · 날짜 고르기 · 「늦게 계산」 칩이 더해졌습니다(서버는 `stock_hub.py` 의 허브 신호 칸에 `computed_at` · `record_kind` · `signal_on` 추가). 퀀트 대시보드의 「기록된 신호」 이름표가 가리키는 값이 이 칸입니다.
