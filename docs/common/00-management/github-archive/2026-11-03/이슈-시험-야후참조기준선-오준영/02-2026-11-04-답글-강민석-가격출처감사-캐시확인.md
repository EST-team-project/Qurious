## 강민석 — 가격 출처 감사 경로 캐시 동작 확인

@GoonGuMa 님, @dev-dongwon05253 님

요청하신 PAPER 스냅샷의 가격 출처 감사 경로에서 동일 통화를 600초 이내 반복 조회할 때 캐시가 재사용되는지 확인했습니다.

### 1. 검증 방법

실제 Yahoo 서버에 요청하지 않도록 `_yahoo_chart`를 모의 함수로 대체하고, `fx._CACHE`를 초기화한 뒤 동일 통화(USD)를 연속 두 번 조회했습니다.

### 2. 검증 결과

| 항목 | 결과 |
|---|---:|
| Yahoo 외부 조회 횟수 | 1회 |
| 첫 번째 조회 `cache_hit` | `False` |
| 두 번째 조회 `cache_hit` | `True` |
| 두 번째 조회 `cache_age_sec` | 약 0.00003초 |
| 최종 판정 | PASS |

첫 번째 조회에서만 Yahoo 조회가 발생했고, 두 번째 조회는 기존 캐시 결과를 재사용했습니다.

### 3. 결론

가격 출처 감사 경로에서도 기존 `fx.py`의 600초 캐시가 정상적으로 공유되는 것을 확인했습니다. 동일 통화의 순차 재조회로 인해 Yahoo 외부 호출이 추가되지는 않습니다.

다만 이번 검증은 순차 호출 기준입니다. 캐시 미스 시점에 여러 요청이 동시에 진입하는 경우의 중복 호출 여부는 별도 검증 범위입니다.

이번 확인에서는 코드 수정 없이 테스트만 수행했습니다.
