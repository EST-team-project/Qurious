@rkdalstjr 강민석 님, 본문(#514) 올린 뒤에 공용 차트가 검수에서 한 번 더 고쳐져 바뀐 곳을 보충합니다. **본문의 신호 표식 · 스탑 점선 설명 가운데 아래가 달라졌습니다.** `paper.js` 의 모의주문 · 스탑 계산 코드는 여전히 한 줄도 바꾸지 않았습니다.

## 본문과 달라진 것
1. **신호 표식은 화살표가 아니라 중립 점입니다.** 화살표(▲ ▼)는 「그 봉 마감에 신호가 났다」로 읽힐 수 있어서 점(글자 「신호 기록」)으로 바꿨고, 값 줄에 「여러 주기(60분 · 일 · 주)를 합친 기록」, 풀이에 「그날 종가까지로 계산해 다음 거래일 낮에 기록된다」와 기록 시각을 넣었습니다. 이 점은 **종목 근거 모달에만** 있고 모의투자 시세 · 스탑 차트에는 없습니다(본문 「한계」와 같음).
2. **스탑가만 바뀌면 차트를 다시 그리지 않습니다.** 스탑가 입력이 멈출 때마다(300ms) 칩 줄이 숨겨지고 「불러오는 중…」이 뜨며 화면이 흔들리던 것을 고쳐, 종목 · 기간이 같으면 점선 하나만 갈아 끼웁니다. 모의주문 화면에서 −10% 단추를 눌러 차트 요소가 그대로인 것을 확인했습니다.
3. **스탑 점선이 화면 밖에 놓이지 않게**: 변동이 좁은 자료에서 점선이 범위 밖으로 나가는 것을 확인했고, 점선이 마지막 종가에서 30% 안이면 가격 범위를 넓히고(「봉이 작게 보일 수 있다」 안내) 30% 를 넘으면 「범위 밖」을 글로 알립니다.
4. **작은 것들**: 칩 터치 크기 24px · 일봉 · 일정 캐시 5분 뒤 다시 받음(일정 실패는 캐시하지 않음) · 20 · 60일선 · MACD 선 색을 더 짙게 하고 칩 앞에 선 색 견본 · 차트 칸 `role="img"` + `aria-label` · 서랍 · 모달 기간 칩 `aria-pressed`(**`paper.js` 의 기간 칩 표시는 손대지 않았습니다**) · 아래 글의 「수정주가」는 서버 `basis` 를 따라 ETF · 지수는 「수정하지 않은 종가」.
5. **지표 값은 화면에서 계산한 표시용 값**이고 서버 `ta_utils` 와 같은 값이 나오는지 시험이 대조합니다(TC-SCH-04 · 04b, 1 ~ 61봉 17가지 길이). 판 지문 함수는 건드리지 않았습니다.

## 알아 둘 것
- **스탑 차트는 3개월로 고정돼 있습니다**(`paper.js` 가 부름 · 기간 칩은 시세 차트에만 있음) — 1개월 차트에서 스탑 점선이 어떻게 보이는지는 같은 부품을 직접 마운트해서만 확인했고 모의주문 화면에서는 3개월로 확인했습니다.
- RSI · MACD 창을 켠 채 일정 표식이 있으면 메인 창이 낮아져 봉이 납작해질 수 있습니다.
- `paper.js` 의 오늘 변경은 Open API 이동 몫(`loadPaperOpenApi` export · 요약 칸 갱신 · 화면 진입 분기 한 줄 삭제)뿐입니다.
- 시험 `tests/test_stockchart.py` TC-SCH-01 을 고쳤고(「검은 점선」 문구) 04 ~ 09 를 더했습니다. 이 시험이 읽는 이름은 본문에 적은 그대로 유지했습니다.
