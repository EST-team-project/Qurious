## 읽는 사람
@rkdalstjr 강민석 님 — 모의투자 화면(`paper.js` · `paper-*` 구역) 담당입니다. **화면만 고쳤고 서버 코드(`app/`) · 주문 · 계산 · 저장 로직은 바꾸지 않았습니다.** `paper.js` 의 모의주문 · 스탑 계산 코드는 한 줄도 안 건드렸습니다.

## 바뀐 것 둘
### 1. 시세 차트 · 스탑 차트가 공용 일봉 차트로 (11-03 사용자 결정)
- **왜**: 종목 근거 모달 · 모의투자 시세(`ps-chart`) · 스탑 차트(`ps-stop-chart`)가 `public/js/stockchart.js` 의 `mountDailyChart` 한 부품을 쓰는데 종가 선 하나만 그려 「차트를 모든 화면에서 더 상세하게」 요청이 있었습니다. 부품을 올리면 세 곳이 한 번에 바뀝니다.
- **무엇이**: 선 → **캔들(오름 빨강 · 내림 파랑) + 거래량 + 20 · 60일 이동평균 + 볼린저**(켜고 끄는 칩 · 처음엔 거래량과 20일선만 켜짐) · **크로스헤어 값 줄**(시 · 고 · 저 · 종 · 전일 대비 · 거래량) · **RSI · MACD 하위 창**(켜면 칸이 커짐 · 「화면에서 계산한 표시용 값」이라고 그림 설명에 적음) · 일정 표식(실적 · 배당락 · 주총 · `/api/calendar/events` 읽기). 기간 칩(1개월 · 3개월 · 1년)은 그대로입니다. 시가 · 고가 · 저가가 없는 종목(해외 등)은 예전처럼 종가 선입니다.
- **스탑 점선은 유지**했습니다(`scQuickStops` · `scWouldFireNow` 연결 그대로). 다만 오름 봉의 빨강에 묻혀 **색을 짙은 남색 2px 로 바꿨고** 요약 문구(`scSummary`)를 「검은 점선」으로 바꿨습니다. 시험 TC-SCH-01 의 단언도 같이 고쳤습니다.
- **지킨 이름**: `mountDailyChart(doc, box, note, { api })` 와 반환 `{draw, destroy}`(+ `setSignal` 추가) · `scCode` · `SC_PERIODS` · `SC_DEFAULT_PERIOD` · `scDirection` · `scQuickStops` · `scWouldFireNow` · `scPath` 모두 그대로입니다.
- **`app.html`**: 모의투자 쪽은 CSS 링크 한 줄, 차트 칸 높이(`ps-chart` 150 → 230px · `ps-stop-chart` 130 → 210px), 머리글 「일봉 종가」 → 「일봉」뿐입니다.
- **한계**: 신호 한 점 표식(마지막 기록 · 「그날 종가까지로 계산해 다음 거래일 낮에 기록」 설명 포함)은 종목 근거 모달에만 있고 모의투자 차트에는 없습니다. 분할 · 권리락 종목의 지표 일치는 확인하지 못했습니다.
### 2. Open API 설정 본체가 마이페이지 「외부 연동」 구역으로 (11-03 사용자 결정)
- `app.html` 의 `data-view="paper-openapi"` 본체(키 발급 · 엔드포인트 문서 · Alpaca Paper 연결 시험 카드 셋)를 마이페이지 `mp-sec-external` 구역으로 옮겼습니다. `po-*` 칸 id · API 경로는 그대로이고 `#paper-openapi` 주소는 살려 마이페이지 외부 연동 구역으로 갑니다.
- `paper.js` 는 `loadPaperOpenApi` 를 `export` 하고(마이페이지가 구역을 열 때 부름) 키 목록을 읽은 뒤 마이페이지 요약 칸을 맞추는 두 줄 + 화면 진입 분기 한 줄을 뺀 것뿐입니다. 서버 응답 · 키 발급 로직은 그대로입니다.
- 보안 검수에서 Alpaca 시크릿 칸에 `autocomplete` 를 달고(키 칸 `off` · 시크릿 `new-password`) 입력칸에 `aria-label` 을 달았습니다.
