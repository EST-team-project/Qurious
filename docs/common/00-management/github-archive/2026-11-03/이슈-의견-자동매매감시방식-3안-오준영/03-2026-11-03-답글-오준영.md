- 11/3 10:18:13 KST 실제 KIS 모의에서 원 매도 CANCELLED 1주 → 재주문 FILLED 1주를 확인했습니다. 독립 대조에서 시험 귀속 0주·기존 전략 1주·미체결 0건·위험 설정 원복을 확인했습니다. C5 실제 성공은 완료 항목입니다.
