## 주담당 채택 정책·구현 결과 정리 — 2026-10-08

이동원님 의견을 바탕으로 채택한 정책과 main에 반영된 결과를 정리합니다. 근거는 [데이터 담당 의견](https://github.com/EST-team-project/Qurious/issues/124#issuecomment-6052457321), PR #136, PR #145입니다. **이번 기록으로 이슈 완료 체크나 종료는 하지 않습니다.**

| 항목 | 채택 정책·구현 결과 |
|---|---|
| 가격·체결 기준 | **A 채택**. 자동·지금 점검·수동 미리보기/실행·제안 승인 모두 전 거래일 종가 기준. 실행은 판단일 다음 거래일 시가 예약이며 즉시 체결하지 않습니다. |
| 미갱신·휴장일·종가 누락 | 공통 준비 판정을 통과할 때까지 대기하고 다른 가격으로 대체하지 않습니다. |
| 입출금·수동 배당 후 판단 | **A 채택**. 현금·예산은 즉시 반영하고 리밸런싱 판단은 다음 일별 점검 회차로 이연합니다. 추가 이벤트·취소가 하루 1회 완료일을 초기화하지 않습니다. |
| 체결일 이전 계좌 변경 | 목표 비중 예약을 유지하고 시가로 조건·수량을 재계산합니다. 조건 해소 시 취소하며 재승인은 받지 않습니다. |
| 체결일 당일 이후 계좌 변경·설정 지문 변경 | 확인 대기를 유지하되 사용자가 미체결 예약을 취소할 수 있습니다. 과거 잔고 복원·과거 체결 재생·확인 대기 자동 해제는 이번 범위에 넣지 않았습니다. |
| 플랜 비활성화 | 확인 대기를 포함한 미체결 예약을 취소합니다. 갱신 완료 여부와 무관하게 처리합니다. |
| 예약일 휴장 정정 | 다음 확인된 거래일로 이동하고 이전/새 날짜·사유·변경 시각을 기록합니다. 계좌 변경 판단 기준일도 새 체결일을 사용합니다. 이미 확인 대기였던 예약은 자동 해제하지 않습니다. |
| 장기 미체결 | 지정된 거래일 시가만 사용합니다. 전체 러너 준비 및 해당 날짜 출처별 수집 완료 후 행 없음·거래정지·무거래를 확인하면 예약 전체를 **미체결**로 종료합니다. 체결일 자정이나 경과 일수만으로 만료시키지 않습니다. |
| 수집 지연과 체결 불가 구분 | `ingest_day.status=done`을 확인합니다. 출처 미상 종목은 주식·ETF 양쪽 완료를 요구합니다. 수집 미완료·실패·완료 기록 없음·거래량이 있는 잘못된 시가는 대기합니다. |
| 취소 후 새 판단·승인 | 취소 자체로 재판단하거나 장부를 복원하지 않습니다. 이후 판단은 기존 준비 조건과 일별 제한을 따릅니다. 새 자동 제안은 자동 실행 OFF면 승인, ON이면 예약으로 진행합니다. 별도 수동 실행도 공통 준비 조건을 따릅니다. |
| 준비 판정 범위 | 가격 단계만으로 완화하지 않고 전체 러너 성공 및 price/calendar 결과·기준일 검증을 유지합니다. |

### 구현과 검증

- PR #136에서 공통 종가 판단·현금 이벤트 판단 이연·목표 비중 예약을, PR #145에서 취소·휴장 이동·미체결 종료를 반영했습니다. 두 PR 모두 main에 병합됐습니다.
- `POST /api/rebalance/runs/{run_id}/cancel`과 화면의 예약 취소/확인 대기 예약 취소 버튼을 추가했습니다. 본인의 미체결 예약만 취소할 수 있고, 취소 재요청은 같은 결과를 반환합니다.
- 취소는 현금·보유 수량·미사용 예산을 유지하며, 사용자 잠금으로 취소와 정산을 직렬화합니다. 이미 체결/부분 체결된 이력을 취소하지 않습니다. 추가 DB 마이그레이션은 없습니다.
- main `2de6770`에서 리밸런싱 관련 검사와 마이그레이션 단일 head 검사 **125개 통과**(#124 예외 처리 13개 포함). JavaScript 구문과 모의 DOM의 버튼·요청·이력 표시도 확인했습니다. 운영 DB와 분리한 시험이며 실제 회차 운영 검증과 구분합니다.
- 설계서는 기존 판을 보존하고 **v0.3을 새로 작성**했습니다. 새 문서 파일은 현재 로컬 작성본이며 저장소 반영은 별도입니다.
