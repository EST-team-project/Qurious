# 랜딩 지수 티커 — 출처 판단 메모

## 결론(10-30 확정 · 구현함)
**수집 DB 의 지수 일봉(전일 종가 · 기준일 · 출처 문구)** 으로 한다 — 값은 가공하지 않고 그대로 보인다. 야후 값을 로그인 전 첫 화면에 새로 내보내는 것은 피한다(아래 「야후의 범위」). 사용자가 「정할 것」 넷을 모두 추천대로 정했고(수집 DB 지수 일봉 · 종가만 · 코스피 · 코스닥 · 12:30 회차 점검 사이 오늘) 구현했다 — 아래 「구현 결과」.

## 바로잡는 것 ① — 공개 지수 API 는 이미 있다
S165 프롬프트의 「공개 읽기 전용 지수 API 가 없음」 은 틀렸다. `GET /api/stocks/market`(`API-STK-01`)은 **인증이 없고** 쿠키 없이 `200` 이다(10-30 확인). 응답은 `{indices: [{name, price, symbol, change_pct}], from_cache}`(KOSPI · KOSDAQ · USD/KRW) · 값은 **야후**에서 받아 라우트 캐시(최대 2시간)에 둔다. 로그인 뒤 화면 머리의 지수 띠(`core.js`)가 같은 API 를 쓴다.

- 야후 약관 원문(작업메모 2026-10-16): 2(d)9 자동 수집 금지 · 2(e) 상업 목적 금지 · **2(h) 배포 금지** · 2(d)10 경쟁 데이터 피드 · 위젯 금지 · 도움말 SLN2310 「You must not redistribute information displayed on or provided by Yahoo Finance」. 표시(배포)에 걸리는 조항이라 **로그인 전 누구나 보는 화면**에는 더 걸린다.
- 그래서 티커의 선택지는 이렇게 읽힌다: 야후 그대로(기존 길 재사용 — TC-YH 는 안 깨지지만 「늘리지 않기」 의 뜻과 약관 2(h) 에 걸림) · 수집 DB 종가(제안).

## 이용 조건 근거 — 수집 DB 지수 일봉
`index_daily` 는 공공데이터포털 금융위원회 지수시세정보다. **공공누리 제4유형** — 출처 표시 · 상업적 이용 금지 · 변경 금지(재배포 안 함) · 키는 사람마다 · 하루 호출 한도(이해관계자목록 52줄). 수업 프로젝트(비상업)이고 **출처를 적고 값을 가공하지 않으면** 가능한 쪽이다. 단 「변경 금지」 때문에 등락률 같은 계산값을 낼지는 판단 거리다. KIS 시세는 약관 제5조③(개인 업무 한정 · 제3자 제공 금지)이라 쓰지 않는다.

※ 공공데이터포털 데이터 페이지의 이용허락범위 칸은 스크립트로 그려져 이번에 원문을 다시 읽지 못했다(같은 계열 「채권시세정보」 는 제4유형으로 보임). 기록(이해관계자목록)을 따르되 구현 전에 눈으로 한 번 더 확인한다.

## 설계안
- 새 **공개 읽기 전용** 길(가칭 `GET /api/public/index-closes` · 인증 없음): 수집 DB 에서 지수 몇 개의 **가장 최근 거래일 종가**와 기준일 · 출처 문구를 준다. 응답은 `{as_of, source, items: [{name, close}]}` · 서버 캐시 · 요청 횟수 제한 · 못 받으면 빈 목록. 이 PC 에서는 수집 DB 를 열지 않고 `collector_db` 서비스로만 읽는다(시험은 합성 고정물).
- 랜딩 소개 화면 첫 영역 아래 한 줄: 「전일 종가 기준 · 기준일 · 출처: 공공데이터포털 금융위원회 지수시세정보(공공누리 제4유형)」. 값을 못 받으면 칸을 통째로 숨긴다. 실시간이 아님을 글로 밝힌다(TC-LND-03 의 「실시간」 금지 규칙과 맞음).
- `/api/stocks/market`(야후 · 헤더 띠)은 건드리지 않는다. 새 줄에 야후를 쓰지 않으므로 TC-YH 기준선은 그대로다.
- 시험: 새 라우트 시험 + TC-LND 단정(「티커의 숫자는 서버 응답 그대로 · 출처와 기준일을 같이 적는다」). 문서: API 명세서 새 ID · UI 명세서 17절 · Figma 「Qurious · 랜딩」.

## 구현 결과(10-30 · S166)
- `GET /api/public/index-closes`(`API-PUBD-01` · `app/routes/public_data.py` · `collector_db.read_latest_index_closes`): 코스피 · 코스닥 가장 최근 거래일 종가를 가공 없이 · 기준일 · 출처 · 로그인 없이 · 서버 캐시 10분 · 분당 30번(429) · 못 읽으면 200 빈 목록. 실행 앱에서 쿠키 없이 200 확인(`as_of` 2026-10-28 · 코스피 · 코스닥 종가).
- 랜딩 소개 화면 한 줄(`landing.js` `setupTicker` · 쿠키를 보내지 않음 · 못 받으면 숨김) · Figma 「Qurious · 랜딩」 네 프레임에도 그림 · 시험 `TC-PIX` 6건(합성 수집 DB 픽스처) · 문서(API 명세서 v0.49 · 3차 UI 명세서 17.3 · RTM v1.64 · 시험 계획서 v1.77).
- 야후 참조는 늘리지 않았다(TC-YH 기준선 그대로). 헤더 지수 띠(`/api/stocks/market`)는 건드리지 않았다.
- **구현 뒤 눈으로 확인할 것**: 공공데이터포털 금융위원회 지수시세정보 데이터 페이지의 이용허락범위 칸(이번에는 스크립트로 그려져 원문을 못 읽었다 · 기록은 이해관계자목록 52줄의 제4유형).
