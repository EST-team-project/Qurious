강민석 님, 코인 모의매매 화면(`paper-crypto`)을 정직한 표시 중심으로 고쳤고, 그 과정에서 서버 쪽 한 가지를 확인해 알려 드립니다.

### 서버에서 확인한 것 — `app/services/paper_trading.py` `upbit_tickers`
- 시세를 5초(`_UPBIT_TICKER_TTL`) 동안 저장하고, 업비트 호출이 실패하면 `except Exception: pass` 로 **실패를 삼킨 뒤** 저장해 둔 값을 **나이와 상관없이** 그대로 돌려줍니다(`return [_UPBIT_TICKER_CACHE[c]["data"] …]`).
- `upbit_trade_price` → `crypto_buy` · `crypto_sell` 이 그 값을 체결 가격으로 씁니다. 응답에 받은 시각 칸이 없어 화면도 알 수 없습니다.
- **재현**(가짜): 한 시간 전에 받은 것으로 `KRW-BTC` 1억원을 저장해 두고 `httpx.AsyncClient` 를 실패하게 바꾼 뒤 `upbit_tickers(["KRW-BTC"])` → 1억원이 그대로 나오고 `upbit_trade_price` 도 1억원입니다.
- 제안(고침은 담당 몫): ① 저장 값이 일정 시간(예: 30초)보다 오래되면 「현재가를 가져오지 못했습니다」 로 거절하거나 ② 응답에 받은 시각(`asOf`)을 넣어 화면이 보이게.

### 제가 화면에서 한 것(프런트만 · 서버 응답 꼴은 그대로)
1. 시세 밑 한 줄 — 「출처: 업비트 공개 시세 · 약 5초까지 저장해 둔 값 · 받은 시각은 표시되지 않음 — 시세를 받지 못하면 마지막으로 받은 값이 나올 수 있습니다.」
2. 주문 칸 위 — 「이 앱의 모의 장부에만 기록 · 업비트로 주문이 나가지 않음 · 현재가로 수수료 · 슬리피지 없이 즉시 체결(실제 거래소 수수료 미반영)」 — `crypto_buy` · `crypto_sell` 에 수수료 · 슬리피지가 없는 것을 코드로 확인한 글입니다.
3. 시세 아래 최근 120일 **일봉 차트** — 기존 `GET /api/paper/crypto/{code}/candles`(업비트 일봉)를 그대로 불러 화면에만 그립니다(저장하지 않음).
4. **실시간(S172)** — 현재가와 차트의 오늘 봉이 업비트 공개 WebSocket(`wss://api.upbit.com/websocket/v1` · 인증 없음)으로 체결마다 움직입니다. **브라우저가 직접 연결**해 서버 요청 한도를 쓰지 않고 앱에는 저장하지 않습니다. 시각은 응답의 체결 시각(`trade_timestamp`)입니다. 끊기면 늘려 가며 다시 연결하고, 탭이 숨겨지거나 화면을 떠나면 닫습니다.
5. **주문에 쓰이는 가격을 실시간 값 옆에 따로** 보입니다 — 화면이 5초마다 `GET /api/paper/crypto/ticker` 로 서버가 쓰는 값을 확인해 「98,115,000원 · 14:02:30 확인」 처럼 보이고, 실시간 값과 0.5% 이상 다르거나 확인이 30초를 넘으면 「화면 가격과 주문 가격이 N% 다릅니다. 주문은 아래 가격으로 체결됩니다.」 경고를 띄웁니다(기준은 제안값). 위 서버 문제(오래된 값)가 있으면 **이 경고로 화면에서 드러나지만, 서버가 고쳐진 것은 아닙니다.**
- 새 파일 `public/js/coinview.js` · `paper.js` 에는 시세를 그릴 때 부르는 줄과 실시간 연결 묶음 · `app.html` 에 칸 · 시험 `tests/test_coinview_screen.py`(TC-CRY 6건).

### 확인 부탁
1. 위 서버 동작이 의도인지(의도라면 화면 글을 「오래된 값이 나올 수 있음」 으로 유지하면 됩니다).
2. 수수료 · 슬리피지를 모의 장부에 반영할 계획이 있는지(생기면 화면 글을 바꿔야 해서 알려 주세요).
3. `GET /api/paper/crypto/ticker` 응답에 값을 받은 시각(체결 시각 또는 서버가 받은 시각)을 넣어 주실 수 있는지 — 지금 화면의 「확인 시각」 은 화면이 서버에 물어본 시각이라 값 자체의 나이를 모릅니다. 넣어 주시면 화면이 값의 나이를 그대로 보일 수 있습니다.
4. 가격 경고 기준(0.5% · 30초)이 모의 장부 쪽 판단과 맞는지.

되돌리는 법: `public/js/paper.js` 의 `coinview` import · `pcDrawChart` · `cryptoTicker` 안 줄과 「코인 실시간」 묶음(`pcStartLive` 외), `app.html` 의 `pc-live-badge` · `pc-source-note` · `pc-chart-wrap` · `pc-gap-warn` · `pc-order-price` · `pc-order-note` 를 지우면 옛 화면입니다.
