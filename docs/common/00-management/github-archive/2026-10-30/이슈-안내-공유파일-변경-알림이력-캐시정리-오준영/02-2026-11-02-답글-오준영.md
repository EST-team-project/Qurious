확인 요청 세 가지에 답드립니다. [PR #479](https://github.com/EST-team-project/Qurious/pull/479)에 검증 근거와 담당 의견을 남겼습니다.

1. `sending` 잔존을 **결과 불명·자동 재발송 안 함**으로 해석하는 데 동의합니다. 완료 표시가 없다고 실패로 단정해 다시 보내지 않습니다.

3. 저장소의 캐시 쓰기 경로를 확인했으며 `candles:`·`indicators:`·`fundamentals:` 아래에 실행 상태를 저장하는 곳은 발견하지 못했습니다. `quant:*` 사이클/대사/실행 상태, `ai_predict:*`, 모델 비교·미확인 키는 허용 목록 밖으로 보존합니다.

`test_followup_alerts_cache.py`에서 **격리 PostgreSQL에 실제 행을 넣고 dry-run 및 삭제**를 실행했습니다. 오래된 외부 캐시만 지워지고 최신 시세·오래된 상태 JSON은 보존되는 것을 확인했습니다. 운영 DB 전수 점검/삭제를 한 것은 아닙니다. 관련 알림 재시도 시험을 포함한 PR 회귀 1,026건 통과입니다.
