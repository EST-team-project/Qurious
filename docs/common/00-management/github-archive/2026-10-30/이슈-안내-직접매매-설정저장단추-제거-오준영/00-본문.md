오준영 님, 직접매매 › 주문/매매 화면의 오른쪽 카드 「증권사 API 연동 (Mockup)」 를 정리했습니다. 증권사 연동 설정(마이페이지)과 닿아 있어 미리 알립니다.

### 무엇이 문제였나(코드 읽기)
`public/js/trading.js` 의 「설정 저장」 단추(`trading-broker-save`)는
1. 증권사를 **주문 칸의 선택값**(`ord-broker` — 기본 「가상 매매」 → `mock`)에서 읽고,
2. 키 · 시크릿 · 계좌 · 모의 여부를 키움 칸이 비어 있으면 **마이페이지 입력칸**(`broker-app-key` · `broker-app-secret` · `broker-account` · `broker-paper`)에서 읽어
3. `POST /api/broker/settings` 로 보냈습니다.

서버 `app/routes/stocks.py` `_apply_credentials` 는 `broker == "mock"` 이거나 관리형(KIS)이면 **저장된 `app_key · app_secret · account_no` 를 비웁니다**(`row.app_key = row.app_secret = row.account_no = ""`). 그래서 주문 화면에서 기본값 그대로 「설정 저장」 을 누르면 마이페이지에 저장해 둔 증권사 설정이 말없이 mock 으로 돌아갈 수 있었습니다. 토스증권 칸은 읽는 코드조차 없었습니다. 토스트는 늘 「설정 저장 완료」 였습니다.

### 이동원이 바꾼 것(HTML · 프런트 JS 만)
- `app.html`: 키 · 시크릿 입력칸과 「설정 저장」 단추를 없애고 「이 화면의 주문은 어디로 가나」 안내 + 읽기 전용 연동 상태(`trading-broker-status` 유지) + 「마이페이지 › 증권사 연동」 링크로 바꿨습니다.
- `trading.js`: 저장 핸들러 삭제(읽기 `GET /api/broker/settings` 는 그대로) · 주문 토스트를 「주문 완료 (kis)」 → 「기록 완료 (앱 안 기록 …)」 로 · 포트폴리오에 현재가 기준 안내 한 줄과 불러오기 실패 문구.
- 시험: `tests/test_trading_order_screen_honest.py`(TC-TOS 4건).

### 확인 부탁(오준영 님 · 강민석 님)
1. 증권사 설정은 마이페이지에서만 바꾸는 것이 맞나요? (이 카드를 없앤 근거입니다.)
2. `POST /api/orders` 는 증권사를 부르지 않고 `Order(status="filled")` 로 앱 안에만 기록합니다. 그런데 **「가상 매매」 가 아닌 증권사를 고르면 현금은 안 움직이고 보유만 바뀝니다**(`stock.py` `place_order` — 현금은 `broker == "virtual"` 분기에서만). 의도인가요, 빠진 건가요? 화면에는 지금 있는 그대로를 적었습니다.
3. **개인 KIS 모의계좌로 실제 주문을 내는 길(`POST /api/broker/order` · `manual_broker_order` · 10-30 `58d8cbf`)은 화면이 없습니다**(`public/` 에서 부르는 곳을 찾지 못함). 안내 글은 이 길을 말하지 않고 「앱 안 모의 계좌 주문은 국내주식 모의주문 · 전략 자동 실행은 자동매매」 로만 적었습니다(국내주식 모의주문 화면은 앱 안 모의 계좌 `PaperAccount` 입니다). 이 길을 직접매매 화면에 연결할 계획이 있나요? 있으면 안내 글을 그때 고치겠습니다.
4. 마이페이지의 「Mockup」 낱말(`app.html` 「비워두면 Mockup 데이터로 동작합니다」 · `Mockup (테스트)` 옵션 · `settings.js` 「Mockup 모드」)은 건드리지 않았습니다. 실제로 mock 브로커로 동작하는 경로라 틀린 말은 아니지만, 정리하고 싶으시면 알려 주세요.
