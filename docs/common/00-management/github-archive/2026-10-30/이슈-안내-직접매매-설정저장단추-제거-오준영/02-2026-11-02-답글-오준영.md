닫힌 뒤에도 남아 있던 2번의 현금/보유 불일치를 확인해 PR #477에서 수정했습니다.

1. 증권사 설정은 마이페이지에서 변경하는 경로가 맞습니다. #436의 주문 화면 설정 저장 제거는 유지합니다.
2. 비가상 broker를 골랐을 때 현금은 그대로이고 보유만 변하던 것은 장부 불일치였습니다. `POST /api/orders`는 앱 장부 전용 `virtual`만 받고, 화면도 동일하게 맞췄습니다. 방향·양수 정수 수량·유한 양수 가격을 검증하고 계좌 잠금 안에서 현금·보유·비용을 함께 기록합니다.
3. 보유 2주에 동시 매도 2건을 보내도 1건만 성공하고 나머지는 400, 현금은 한 번만 적립되는 실제 PostgreSQL 회귀 시험을 추가했습니다. 입력/UI 시험 19건과 장부 회귀를 통과했습니다.

기존 잘못된 장부를 추정해 재작성하지 않았고, 실제 KIS 수동 주문 UI 연결은 이번 수정 범위에 포함하지 않았습니다. [PR #477](https://github.com/EST-team-project/Qurious/pull/477)에 코드·검증 근거를 올렸으며 아직 main 병합·운영 배포 전입니다.
