고정 카드의 CRLF 해시 문제를 수정해 PR #477에 올렸습니다.

- 해시 검사 전 `raw.replace(b"\r\n", b"\n")`만 적용합니다. 카드 내용·다른 공백을 재작성하지 않으며, 내용이 바뀌면 계속 거절합니다.
- LF/CRLF 카드와 내용 변조를 함께 검사하고, 카드 조회·설정 저장·공급원 고정 동작을 검증했습니다. 관련 `test_strategy_loader.py` / `test_fixed_test_strategy.py` **24건 통과**입니다.
- 이번 확인은 Linux 격리 환경에서 실제 LF/CRLF 바이트를 넣은 회귀 시험입니다. Windows PC에서 직접 실행했다고 기록하지는 않습니다.

[PR #477](https://github.com/EST-team-project/Qurious/pull/477)은 검토 대기이며 main 병합·운영 배포 전입니다.
