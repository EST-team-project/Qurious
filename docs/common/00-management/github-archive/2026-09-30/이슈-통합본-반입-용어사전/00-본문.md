## 2. 용어사전 — 서버 쪽

```mermaid
flowchart LR
  S["자료 넷<br/>단어장 · 용어집 · 강의 용어 · 화면 용어"] --> B["빌드<br/>scripts/glossary_build.py"]

  API -.->|"다음 작업"| UI["화면"]
```

|---|---|:-:|
