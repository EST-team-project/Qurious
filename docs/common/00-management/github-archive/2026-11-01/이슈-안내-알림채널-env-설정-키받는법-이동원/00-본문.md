# [안내] 알림 채널(.env) 설정 방법과 키 받는 법 — 디스코드 추가

매매 성공 · 실패 알림(`app/services/notification.py`)을 받으려면 채널 하나 이상을 설정해야 합니다. **키 · 토큰 · 비밀번호는 이슈 · 댓글 · 채팅 · 커밋에 붙이지 않습니다**(`.env` 는 `.gitignore` 에 있습니다).

## 1. 어디에 쓰나

| 방법 | 어디 | 누구에게 | 비고 |
|---|---|---|---|
| 글로벌 | 저장소 루트 `.env` | 사용자 설정이 없는 모든 사용자 | 앱 다시 시작 필요. 개발 앱은 `.env` 가 있으면 그것을, 없으면 `.env.dev` 를 읽는다(`scripts/personal/dev.ps1`) |
| 사용자별 | 앱의 마이페이지 → 알림 설정(알림 동의 필요) | 그 사용자 | 있으면 글로벌보다 먼저 쓴다. 응답에서는 비밀 칸을 가려 돌려준다 |

둘 다 비어 있으면 알림은 조용히 건너뜁니다. 채널을 켠 뒤에는 알림 설정 화면의 「테스트 알림」(`POST /api/notification/test`)으로 한 번 확인합니다.

## 2. `.env` 에 넣을 줄(필요한 채널만)

```ini
# 텔레그램
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
# 슬랙
SLACK_WEBHOOK_URL=
# 디스코드(2026-11-01 추가)
DISCORD_WEBHOOK_URL=
# 이메일(Gmail 예)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=
SMTP_PASSWORD=
SMTP_FROM=
SMTP_TO=
# 문자(CoolSMS) — 카카오 알림톡도 같은 API 키를 쓴다
COOLSMS_API_KEY=
COOLSMS_API_SECRET=
SMS_FROM=
SMS_TO=
```

값 뒤에 `# 설명` 을 붙이지 않습니다(`.env.example` 에는 일부 줄에 붙어 있습니다 — 복사한 뒤 지웁니다).

## 3. 키 받는 법

| 채널 | 받는 법 | 켜지는 조건 |
|---|---|---|
| 텔레그램(가장 쉬움 · 무료) | ① 텔레그램에서 `@BotFather` → `/newbot` → 이름과 사용자명을 정하면 토큰이 나온다 ② 만든 봇에게 아무 말이나 보낸다 ③ 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열어 `"chat":{"id": …}` 의 숫자가 `TELEGRAM_CHAT_ID`(그룹은 음수) | 토큰 + 채팅 ID |
| 슬랙(무료) | https://api.slack.com/apps → Create New App(From scratch) → Incoming Webhooks 켜기 → Add New Webhook to Workspace → 채널 고르기 → `https://hooks.slack.com/services/…` 복사 | 웹훅 주소 |
| 디스코드(2026-11-01 추가 · 무료) | 서버 설정(또는 채널 편집) → 연동 → 웹훅 → 새 웹훅 → 채널을 고르고 「웹훅 URL 복사」(`https://discord.com/api/webhooks/…`)를 `DISCORD_WEBHOOK_URL` 에. 주소를 아는 사람은 누구나 그 채널에 글을 올릴 수 있으니 비밀로 두고, 노출되면 웹훅을 지워 새로 만든다 | 웹훅 주소(디스코드 주소 모양이 아니면 보내지 않음) |
| 이메일(Gmail) | 구글 계정에서 2단계 인증을 켠 뒤 「앱 비밀번호」(myaccount.google.com/apppasswords)를 만들어 16자리를 공백 없이 `SMTP_PASSWORD` 에. `SMTP_USER` · `SMTP_FROM` 은 같은 Gmail, `SMTP_TO` 는 받을 주소. 계정 비밀번호는 쓰지 않는다 | 호스트 · 사용자 · 비밀번호 · 받는 주소 |
| 문자(CoolSMS) | https://coolsms.co.kr 가입 → 콘솔의 API Key 관리에서 키 · 시크릿 생성 → 발신번호 등록(본인 인증) → 잔액 충전. 80자까지 보낸다(넘으면 잘림) | 키 · 시크릿 · 발신 · 수신 번호 |
| 카카오 알림톡 | 카카오 채널 개설 + 알림톡 템플릿 심사 + 발신 프로필 키가 필요 — 연습용으로는 번거로워 권하지 않는다 | `KAKAO_SENDER_KEY` · `KAKAO_PHONE` 까지 |

## 4. 확인

1. `.env` 를 저장하고 앱을 다시 시작합니다.
2. 알림 설정 화면에서 「테스트 알림」을 누르면 켠 채널로 메시지가 옵니다. 안 오면 앱 로그의 「알림 실패」 줄을 봅니다.
3. 실패한 채널은 자동 재시도 정책이 있고(연결 거절 · DNS 오류에 한해), 같은 사건은 자동 재발송하지 않습니다.

## 5. 디스코드 구현 범위와 다른 채널 제안

**디스코드는 이번에 구현했습니다**(`send_discord()` · `.env` 의 `DISCORD_WEBHOOK_URL` · 기본 채널 · 시험 TC-NR-07 · 08). 범위는 **전체 공용 주소**입니다 — 알림 설정 화면에는 Discord 체크 상자와 「웹훅 주소 받는 법」 안내를 더했고(켜고 끄기만 · 주소는 서버 관리자가 `.env` 에), **사용자별 주소 칸은 아직 없습니다**. 사용자별 주소를 받으려면 설정 표에 새 칸(마이그레이션) · 화면 칸 · 동의문 범위 확인이 필요해 따로 정합니다. 보낼 때 `@everyone` · `@here` 가 사람을 부르지 않게 막고, 실패 로그에는 주소(비밀 토큰)를 남기지 않으며, 글은 2,000자에서 줄입니다.

아래는 많이 쓰는 나머지 채널을 조사한 **추가 후보**(코드에는 아직 없음)이고, 구현은 채널마다 `.env` 한 줄 + `send_<채널>()` 함수 하나 + (사용자별 설정을 쓰면) 알림 설정 표 칸 추가입니다.

| 후보 | 어떻게 보내나 | 키 받는 법 | 비용 · 주의 | 확인 |
|---|---|---|---|---|
| 마이크로소프트 팀즈 | 「Workflows」 앱의 웹훅 흐름에 POST | 팀즈에서 Workflows → 「웹후크 요청을 받으면 채널에 게시」 템플릿으로 만들고 생성된 URL 복사 | 옛 Office 365 커넥터(Incoming Webhook)는 종료되어 새로 만들 수 없다고 안내됨(종료 날짜는 출처마다 달라 공식 문서 확인 필요) | 종료 사실만 확인 |
| 라인 | Messaging API(공식 계정 필요) | LINE Developers 에서 채널 · 토큰 발급 | **LINE Notify 는 2025-03-31 에 서비스가 끝났다** — 옛 글의 Notify 방법은 쓰지 않는다 · 월 무료 메시지 수 제한 | 종료 사실 확인 · 나머지는 공식 문서 필요 |
| 푸시오버(Pushover) | `https://api.pushover.net/1/messages.json` 에 토큰 + 사용자 키로 POST | 사이트에서 애플리케이션 토큰 · 내 사용자 키 | 앱이 유료(일회성)인 것으로 알려짐 — 확인 필요 | API 주소만 확인 · 나머지 확인 못 함 |
| ntfy | 주제(topic) 주소로 평문 POST | 키 없이 주제 이름만 정함(공개 서버는 이름이 곧 비밀 — 길고 무작위로) · 자체 서버도 가능 | 무료 · 휴대폰 앱으로 받음 | 확인 못 함 — 공식 문서 필요 |
| 구글 챗 | 스페이스 웹훅 주소에 POST | 스페이스 → 앱 및 통합 → 웹훅 | 구글 워크스페이스 계정이 있어야 할 수 있음 | 확인 못 함 |

권장 순서: 팀즈(회사형) → 푸시오버 · ntfy(휴대폰 푸시). 라인은 공식 계정이 필요해 개인 판 후보입니다. **어느 채널을 먼저 구현할지**는 이 이슈에서 정해 주세요.

## 보고식 알림(11-01 개편)

같은 날 알림 모양이 바뀌었습니다 — 알림 한 건이 **사건 · 이유 · 항목 · 위험 · 다음 행동 · KST 시각 · 모의투자 표시**를 갖추고, 채널마다 다른 모양으로 갑니다(디스코드 카드 · 슬랙 블록 · 이메일 표 · 텔레그램 접기). 알림 설정 화면에서 **사건 11종마다 켜기 / 조용히 / 끄기**를 고르고 **조용한 시간**(기본 꺼짐 · 켜면 21~08시 한국 시간)을 정할 수 있습니다. 조용히는 텔레그램 · 디스코드의 알림음만 끄고, 슬랙 · 이메일은 그대로이며, 카카오 · SMS 는 보내지 않습니다. 긴급(비상 정지)은 끌 수 없습니다. 「설정 화면 → 알림 시험」 단추로 모양을 확인할 수 있습니다.

일일 수집 회차(12:30)가 끝나면 운영자 `.env` 채널로 **수집 보고**가 한 번 갑니다(`.env` 의 `COLLECT_REPORT_NOTIFY=false` 로 끔). 자세한 내용은 [안내 — 보고식 알림](../이슈-안내-알림-보고식-호출부값-오준영-강민석/00-본문.md).
