# [안내] 클릭 점검이 찾은 화면 결함을 화면 JS 로만 고쳤습니다

10-31 ~ 11-01 화면 클릭 점검(버튼을 하나씩 눌러 보는 점검)이 찾은 결함 가운데 **화면 JS 만으로 고칠 수 있는 것**을 이동원이 고쳤습니다. 백엔드 · 서버 응답은 건드리지 않았고 시험(관련 162건)은 통과했습니다. 아래 파일이 주담당 화면에 닿으므로 알려 드립니다 — 의견이 있으면 댓글로 주세요.

| 화면(주담당) | 파일 | 무엇을 고쳤나 |
|---|---|---|
| 커스텀 인디케이터(신장환 님) | `public/js/indicator.js` | 단기 −5 · RSI 9999 같은 칸 범위(`min`/`max`) 밖 숫자로도 Pine · 파이썬 코드가 만들어지던 것을 막고 칸 이름을 알림 · 인디케이터 이름의 따옴표가 코드 글자 상자를 깨던 것을 바꿈 |
| 자산배분 · 최적화(오준영 님) | `public/js/robo.js` | 투자 금액 0 → 5,000 · −100 → 100 으로 조용히 보정되던 것을 「100 ~ 10,000,000만원」 안내로(빈칸은 5,000만원으로 계산한다고 알림) |
| LEAN 백테스트(강민석 님) | `public/js/paper.js` | 결과를 다시 그릴 때 콘솔에 나던 `translate(NaN, 0)` 오류 — 옛 차트를 자리(innerHTML)를 바꾸기 전에 없앰 |
| 공용(전원) | `public/js/common.js` | 서버 422 의 영어 기본 문구(「Input should be greater than or equal to 1」)를 한국어로 — 표준 제약 종류만 바꾸고 서버가 한국어로 보낸 글은 그대로. 칸 이름은 `FIELD_KO` 표에 있어 새 칸은 한 줄 더하면 됨 |

이동원 몫(모델 비교 · TradingView 연동 · 교재 링크)도 같은 점검에서 고쳤습니다.

**하지 않은 것(서버라서)** — 감사 로그 사용자 ID 필터 · 음수 주문 · 코인 최소 금액은 #462 에 따로 올렸습니다.

확인: `docs/_local` 의 점검 스크립트로 같은 조작을 다시 해서 토스트 · 안내가 뜨고 서버로 요청이 가지 않는 것을 봤습니다.
