# [안내] 알림 설정에 내 디스코드 웹훅 주소 칸 · 동의문 판 n0.2 · 시험이 실제 알림 채널로 보내지 않게 막음

@신장환 @오준영 @강민석 — 이동원 몫 알림 쪽 변경이라 알립니다. 읽고 할 일은 아래 3절뿐입니다.

## 1. 무엇이 바뀌었나

- **알림 설정 화면에 「내 디스코드 웹훅 주소」 칸**이 생겼습니다(`notification_settings.discord_webhook_url` · 마이그레이션 `0036`). 비워 두면 서버 공용 채널(`.env` 의 `DISCORD_WEBHOOK_URL`)로 갑니다. 지금 공용 채널은 **팀 테스트 디스코드**입니다 — 사용자 없는 알림(일일 수집 보고)과 자기 주소를 안 넣은 사람의 알림이 이리로 옵니다.
- 주소는 비밀값이라 `GET /api/notification/settings` 에서 `****` 로 가려지고, 저장할 때 디스코드 주소 모양이 아니면 422 입니다. 새 주소를 채우는 것은 알림 연동 **선택 동의**가 먼저입니다. 동의문 판이 `2026-10-29-n0.1` → `2026-11-01-n0.2` 로 올랐습니다(항목에 디스코드 웹훅 주소를 더함 · 이미 동의한 사람의 상태는 그대로).
- API 명세서 v0.56 · ERD v1.15 · 데이터 사전 v1.16 에 반영했습니다.

## 2. 시험이 실제 알림 채널로 보내지 않게 막았습니다

공용 칸에 팀 채널 주소가 들어가면서, 알림 코드를 지나가는 시험이 `.env` 의 실제 채널로 글을 올릴 수 있게 됐습니다(S183 에 수집 보고로 한 번 샐 뻔했습니다). 그래서 `tests/conftest.py` 에 `_no_real_alert_channels`(autouse)를 더해 **텔레그램 · 슬랙 · 디스코드 · SMTP · 문자 설정을 모든 시험에서 빈 값으로 시작**하게 했습니다. `TC-NR-13` 이 이것을 지킵니다.

## 3. 팀원이 할 일

1. `git pull` 뒤 앱을 다시 켜면 개발 앱이 마이그레이션 `0036` 을 자동으로 올립니다(자동이 꺼진 환경은 `alembic upgrade head`).
2. **알림 채널을 `.env` 값으로 시험하던 자기 시험이 있다면** 시험 안에서 `monkeypatch.setattr(settings, "…", 값)` 로 값을 넣고 가짜 전송 함수를 쓰세요(`tests/test_notification_retry.py` 의 `TC-NR-08` 이 본보기). 값을 안 넣으면 채널이 비어 있어 건너뜁니다.
3. 팀 테스트 디스코드로 실제 알림을 받아 보고 싶으면 이동원에게 따로 말해 주세요 — 주소는 공개 저장소 · 이슈에 쓰지 않습니다.
