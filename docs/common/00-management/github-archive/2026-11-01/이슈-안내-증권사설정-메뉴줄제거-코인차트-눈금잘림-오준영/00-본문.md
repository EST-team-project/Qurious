# [안내] 「증권사 API 설정」 메뉴 줄을 뺐고 코인 차트 눈금 · 알림 설정 · 「종가 반영 전」 표시를 고쳤습니다

사용자(이동원) 화면 피드백과 11-01 결정을 반영했습니다. 아래 표의 앞 두 줄은 **화면 JS 만**, 뒤 두 줄은 서버 한 곳(이동원 몫 파일)을 고쳤습니다.

| 화면(주담당) | 파일 | 무엇을 고쳤나 |
|---|---|---|
| 증권사 API 설정(오준영 님) | `public/js/core.js` | 왼쪽 「전체 메뉴」 의 「내 계정 › 증권사 API 설정」 줄을 뺐습니다. 그 줄을 누르면 마이페이지의 「증권사 연동」 구역이 열리는데, 왼쪽 트리의 불은 「내 정보 (마이페이지)」 에 들어와 **두 줄이 같은 화면을 가리켰기** 때문입니다. 설정은 마이페이지 안으로 들어와 있습니다(10-29 결정). |
| 코인 모의매매(`paper-crypto`) | `public/js/paper.js` | 일봉 차트의 위쪽 가격 눈금(「120,000,000」)이 가장자리에서 반쯤 잘려 보이던 것을 가격 · 시간 두 축에 `ensureEdgeTickMarksVisible` 을 켜서 온전히 보이게 했습니다. |
| 알림 설정 화면 | `public/app.html` · `public/js/settings.js` · `app/services/alert_prefs.py` · `app/services/notification.py` | ① 디스코드 칸에 「내 주소가 없으면 서버 공용 채널로 보내기」 체크 상자(기본 꺼짐)를 더했습니다 — 자기 주소가 없는 사람의 체결 · 잔고 알림이 팀 채널로 새지 않게. 켜지 않으면 알림이 어느 채널로도 가지 않습니다(수집 보고 같은 사용자 없는 운영 알림은 그대로 공용). 값은 `preferences.discord_use_shared` 라 마이그레이션이 없습니다. ② 390 폭에서 「받는 방식」 칸이 좁아 「조용히」 가 잘리던 것을 최소 너비 96px 로 고쳤습니다. |
| 종가 「반영 전」 표시(공용) | `app/services/quote_now.py` · `app/services/stock_hub.py` · `public/js/stockdrawer.js` · `public/js/stockcard.js` | 수집 DB 종가의 날짜가 마지막으로 장이 끝난 거래일보다 오래되면 현재가 라벨이 「10월 29일 종가 · 10월 30일 종가는 반영 전」 이 되고, 종목 허브 가격 칸에도 같은 한 줄이 붙습니다. 판정은 평일 + 내장 2026 휴장 달력(수집 DB 를 열지 않음)입니다. 라벨을 그대로 보이는 팀원 화면은 코드를 바꾸지 않았습니다. |

## 바뀌지 않은 것 — 그대로 쓰셔도 됩니다
- 화면 키 `settings` 와 `#settings` 주소 · 다른 화면의 「증권사 API 설정으로」 링크 · 서버 안내 문구의 「증권사 API 설정」 이름은 **그대로**입니다. 마이페이지 구역 제목이 같은 이름이고, 링크는 같은 구역을 엽니다.
- 「알림 설정」 · 「Open API · 외부 연동」 줄은 아직 별도 화면이라 메뉴에 남겼습니다.

## 확인해 주실 것
- `core.js` 에서 `VIEW_PARENT` 에 `"settings": "mypage"` 한 줄이 늘었습니다(메뉴 줄이 없는 화면이 마이페이지 줄을 따르게). 메뉴 줄이 없는 화면을 더 만들 때 같은 곳에 적습니다.
- 메뉴 항목은 73 → 72 입니다(`scripts/view_scan.py` 로 센 값). 시험 TC-NV-06 · TC-CLV 의 단언을 새 구조에 맞게 고쳤습니다.

시험: TC-ARP-06 · TC-ADI-11(공용 채널 옵션) · TC-QUOT-11 · TC-HUB-25(반영 전) · TC-NV-06 · TC-CLV(메뉴).

확인: 실제 앱(1280)에서 `#settings` 로 들어가면 마이페이지의 「증권사 연동」 구역이 열리고 트리 불은 「내 정보 (마이페이지)」 한 곳에만 들어옵니다. 코인 차트는 위 눈금이 「119,750,000」 으로 온전히 보입니다.
