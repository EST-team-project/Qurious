# [안내] 알림이 보고식으로 바뀌었습니다 — 주문·자동매매 쪽에서 넘겨 주시면 더 자세해지는 값 (이동원)

**대상**: 오준영 님(`auto_trade.py` · 자동매매) · 강민석 님(`routes/stocks.py` · 주문) · 신장환 님(참고) — **답글은 필수가 아닙니다.** 코드는 제가 건드리지 않았고(백엔드 로직 금지 규칙), 값을 넘기는 일은 각자 판단해 주세요.

## 무엇이 바뀌었나 (2026-11-01 · S183)

- 알림 한 건이 **보고식**이 됐습니다: 사건 · 이유 · 항목 · 위험 · 다음 행동 · KST 시각 · 모의투자 표시. 채널마다 모양이 다릅니다(디스코드 카드 · 슬랙 블록 · 이메일 표 · 텔레그램 접기).
- 알림 설정 화면에 **사건별 켜기 · 조용히 · 끄기**와 **조용한 시간**(기본 꺼짐)이 생겼습니다. 긴급(비상 정지)은 끌 수 없고 조용한 시간에도 바로 갑니다.
- 호출하는 쪽의 **함수 이름 · 인자는 그대로**입니다(`notify_*`, `dispatch`). 그래서 아무것도 안 고쳐도 동작합니다.
- 새로 열어 둔 것: `notify_auto_trade_executed(..., details=[(라벨, 값), ...], risk_note="...")` — 선택 인자입니다. 넘기면 알림 항목에 그대로 붙습니다.

## 값을 넘기면 좋아지는 곳 (원하시는 만큼만)

| 위치 | 지금 알림에 빠진 값 | 넘기는 방법 |
|---|---|---|
| `auto_trade.py` 자동매매 가상 체결(`notify_auto_trade_executed` 호출) | 수수료 · 거래세(`trade["cost"]`) · 체결 후 현금 · 신호 점수 · 위험 한도 사용률 · 당일 손익 | `details=[("수수료·세금","105원 · 0원"), ("체결 후 현금","9,299,895원"), ...]` · `risk_note="일손실 한도(-3%)까지 여유 …"` |
| `auto_trade.py` 위험관리로 주문 생략(`notify_risk_skip`) | 신호 점수 · 한도 사용률 | (인자 추가 필요 — 원하시면 알려 주세요, 제가 헬퍼에 열겠습니다) |
| `routes/stocks.py` 주문 접수 · 오류 · 예수금 부족 | 주문번호 · 주문 전 잔고 · 오류 코드 | 같은 방식(요청하시면 헬퍼에 인자를 열겠습니다) |

## 알아 두실 점

- **외부에서 들어온 글**(증권사 오류 문구 · TradingView 코멘트)은 알림 만들 때 채널별로 이스케이프합니다 — `<` `&` 가 텔레그램 오류를 내던 문제가 사라집니다.
- 「위험관리로 주문 생략」은 같은 시간대에 여러 건이 오면 **2분 안에 1건(요약)으로 합쳐** 갑니다. TradingView 신호는 지연 없이 바로 갑니다.
- **기본 받는 방식이 달라진 사건**: 「위험관리로 주문 생략」 · 「자동매매 시작 · 중지」 는 기본이 **조용히** 입니다 — 텔레그램 · 디스코드는 알림음 없이, 슬랙 · 이메일은 그대로, **카카오 · SMS 로는 가지 않습니다**(켜기로 바꾸면 이전처럼). 주문 생략은 같은 시간대 여러 건을 2분 동안 모아 한 건으로 보냅니다.
- 앱이 켜질 때 **보관 알림 풀기 작업**(60초마다)이 함께 시작됩니다(`app/main.py` lifespan · `start_alert_flusher`). 보관한 알림이 없으면 아무 일도 하지 않습니다.
- 일일 수집 회차(12:30)가 끝나면 운영자 `.env` 채널로 **수집 보고**가 한 번 갑니다(`.env` 의 `COLLECT_REPORT_NOTIFY=false` 로 끔).
- DB 마이그레이션 `0035`(새 칸 2개 — `notification_settings.preferences` · `notification_log.payload`)가 들어갑니다. 팀 브랜치에 `0035` 번호가 겹치면 알려 주세요.
