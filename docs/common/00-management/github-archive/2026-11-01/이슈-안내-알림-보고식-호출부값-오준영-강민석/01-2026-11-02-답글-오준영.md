선택 항목을 실제 기록에서 연결했습니다. [PR #479](https://github.com/EST-team-project/Qurious/pull/479)입니다.

- **가상 체결:** 위탁수수료·유관기관 비용·거래세·농어촌특별세·정산금액·체결 후 가상 현금, 비용 기준을 전달합니다.
- **직접 KIS 접수:** 확인된 주문번호를 전달하며 체결 미확인 표시는 유지합니다.
- **위험 생략:** 회차 기준 당일 손익과 생략 시점에 다시 읽은 일 주문 수/상한을 전달합니다. `notify_order_placed`·`notify_risk_skip`은 기존 호출을 유지하는 선택형 `details` 인자를 추가했습니다.
- 값이 없는 신호 점수/한도 사용률을 추정해 채우지 않습니다.

추가로 **알림 예외가 이미 commit된 가상 체결을 실패/unknown으로 바꾸던 경로**를 격리했습니다. 알림 실패는 종류만 로그에 남기고 확정된 장부 상태를 유지합니다. 비용 0과 값 없음, 선택 필드 전달, 알림 실패 시 체결 보존을 시험했습니다.

검증은 PR 전체 관련 회귀 1,026건 통과·실패 0건입니다(Chrome 환경 1건·실제 수집 DB 2건은 건너뜀). 이번 후보의 운영 배포·실제 주문·외부 알림 발송은 하지 않았습니다.
