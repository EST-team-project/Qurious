### 무엇이 끊겼나
누적 수익률 −0.00% · MDD 0.00% 인데 「Sharpe −442.121」 · 「Sortino −15.865」 · 「Sterling −1,438.458」 · 「Calmar −1,438.458」 이 뜬다. 거래가 거의 없어 변동성이 0 에 가까울 때 나오는 값이라 사용자에게는 「크게 망했다」 로 읽힌다. 성과 칸 첫 줄이 「Khushi (2026) 참조」 · 「QFRS」 같은 논문 이름이고, 자산 추이 그림 축은 「9999.9만」 만 되풀이된다.

### 재현
1. 모의투자 › 모의계좌 현황(또는 로보 어드바이저 › 모의 투자 의사결정 아래 성과 칸).

### 기대
기록이 적거나 변동성이 거의 0 이면 숫자 대신 「아직 판단할 만큼 기록이 없습니다(스냅샷 12개 · 거래 n건) — 모의 주문을 더 해 보세요」. 축은 금액이 바뀌는 만큼 보이게(원 단위 또는 %).

### 실제
- `GET /api/paper/performance/metrics` 200 — 위 값 그대로(스냅샷 12개 기준)
- 같은 칸 「🧪 데모 데이터」 단추(제목 「데모용 15일치 데이터 생성」)가 실제 계좌 성과 옆에 있다 — 누르면 내 성과 기록에 섞이는지 확인 필요(이번 점검에서는 누르지 않음).
