**주담당** 강민석 @rkdalstjr · **우선** 🟡 불편 · **화면** 국내주식 모의주문(`paper-stock`) · 모의계좌 현황(`paper-dashboard`) 「최근 체결」

### 무엇이 끊겼나
국내주식 모의주문의 「주문 내역」 과 모의계좌 현황의 「최근 체결」 에 「매수 신한지주 3주 · 출처 QUANT」 같은 자동매매 줄이 보인다. 그런데 바로 위 「보유 종목」 은 「보유 종목이 없습니다」 이고 현금도 줄지 않았다. 그 매수는 다른 장부(퀀트 가상계좌 1천만 원)에 들어갔기 때문이다. 사용자는 「샀는데 보유가 없다」 로 읽는다.

### 재현
1. 자동매매가 한 번 돈 계정으로 모의투자 › 국내주식 모의주문을 연다.
2. 「주문 내역」 의 출처 칸(QUANT)과 「보유 종목」 · 「보유 현금」 을 견준다.

### 기대
모의투자 계좌(1억 원) 화면에는 그 계좌의 주문만 보인다. 자동매매 장부 거래는 「자동매매 장부」 로 따로 보이거나, 출처 거르기 + 「다른 장부」 표시가 있다.

### 실제
- `GET /api/paper/stocks/orders/history` → `source: "QUANT"`, `broker: "quant_ai"` 줄 3건(11:55)
- `GET /api/paper/stocks/positions` → `[]`, `GET /api/paper/account` → `stockEval: 0`
- 대시보드 탭에서는 모의투자 계좌(약 1억 원)와 퀀트 가상계좌(약 1천만 원)가 따로 보인다 — 화면마다 장부 경계가 다르다.

### 제안
- 두 화면의 목록 조회에 장부(PAPER) 거르기를 넣는다 — 서버에서 `source != "QUANT"` 또는 화면에서.
- 자동매매 거래는 자동매매 현황 · 의사결정 화면에서 보이니, 여기에는 「자동매매 거래는 자동매매 현황에서 →」 링크 한 줄.
