## 제안별

- **6자리를 서버 한 곳에서 맞추기:** #226 의 `pattern_view.resolve_symbol` 이 6자리 · 소문자를 수집 DB 의 시장 구분으로 `.KS` · `.KQ` 로 맞추고(모르면 `.KS`), 차트 패턴 · 다중 주기 두 API 가 함께 씁니다. 패턴 인식 · 종목 스크리닝 화면은 종목을 직접 넣는 칸이 없어서 이번에는 고칠 곳이 없었습니다. 국내주식 모의주문의 `resolve_stock`(KRX 상장법인 목록)과는 아직 따로인 함수입니다.
- **입력 칸 예시:** #226 에서 「005930 또는 005930.KS」 를 넣었습니다.
- **6자리일 때 캔들이 달랐던 까닭:** 수집 DB 다리는 `000000.KS` · `.KQ` 꼴만 받습니다. 그래서 #226 전에는 6자리가 수집 DB 를 지나쳐 외부 시세(KIS 또는 야후) 경로로 갔고, 같은 10-13 봉도 다른 캔들 이름이 나왔습니다. 지금은 6자리도 수집 DB 일봉(수정주가)을 읽습니다.
