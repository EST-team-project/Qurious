**주담당** 강민석 @rkdalstjr · **같이** 오준영 @GoonGuMa(자동매매 현황 같은 꼴) · **우선** 🟡 불편 · **화면** 모의 투자 의사결정(`robo-decision`)

### 무엇이 끊겼나
한국 시각 11시 55분에 나간 자동매매 주문이 로그에는 「2026-10-16 02:55:24」 로 보인다. 같은 목록 아래쪽 줄은 「2026-10-16T02:55:30.563353+00:00」 같은 원문 꼴이다. 같은 회차가 화면마다 다른 시각으로 보인다 — 자동매매 현황 「마지막 사이클 2026-10-16 03:20:43 UTC」, 증권사 API 설정 「마지막 실행: 10. 16. 12:20」.

### 재현
1. 자동매매가 한 번이라도 돈 계정으로 로보 어드바이저 › 모의 투자 의사결정을 연다.
2. 로그 줄의 시각과 지금 시각을 견준다.

### 기대
모든 시각이 KST 「10월 16일 11:55」 꼴 하나로 보인다.

### 실제
- (10-16 다시 봄) 같은 회차(12:40 KST)를 증권사 API 설정 화면은 「마지막 실행 10. 16. 12:40」, 자동매매 현황은 「마지막 사이클 2026-10-16 03:40:43 UTC」 로 보입니다.
- `GET /api/quant/auto/status` → `logs[].time: "2026-10-16 02:55:24"`(UTC · 표시 없음), 체결 줄은 ISO `+00:00` 그대로
- `public/js/quant.js` 119행은 같은 값을 「… UTC」 로 붙여 보인다 — 화면마다 다르게 처리
