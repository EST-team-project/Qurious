열어 두었던 **자동 ETF 선정·편입 편집안**을 구현했습니다. [PR #479](https://github.com/EST-team-project/Qurious/pull/479)입니다. 자동 주문을 켜는 기능이 아니라, 사용자가 확인하고 저장하는 목표 편집안입니다.

- 리밸런싱의 ‘국내 상장 ETF 후보로 채우기’를 선택하면 저장 배분의 해외주식·국내채권·대체자산 비중별로 후보 1개를 연결합니다. 국내주식과 원래 현금 비중은 보존합니다.
- 상품 안내와 같은 수집 자료/분류를 쓰며 거래 가능·20개 관측일 자료·단순 구조 후보를 **20일 평균 거래대금→순자산→코드** 순으로 고릅니다. 선정 근거·기준일을 확인 창과 편집안에 표시합니다. 상품명/기초지수 분류이므로 적합성·수익 추천으로 표시하지 않습니다.
- 후보가 없으면 해당 비중은 현금으로 남고, 마지막 확정 거래일까지 자료가 없으면 오류를 안내하며 기존 목표를 보존합니다.
- 조회/취소/실패는 플랜·예약·주문을 바꾸지 않습니다. 확인하면 편집안의 자동 실행을 끄고, 저장 전 미리보기/예약 실행을 막습니다. 서버의 기존 플랜·예약은 실제 저장 전까지 유지됩니다.

실제 수집 스키마·자산군별 비중 합계·동점 결정·부적합/오래된 자료·본인 저장 결과·JS 취소/오류/저장 전 차단을 시험했습니다. 기존 안 B 안내도 유지합니다. #479 검토·반영 후 이 남은 항목을 정리할 수 있습니다.

검증은 PR 전체 관련 회귀 1,026건 통과·실패 0건입니다(Chrome 환경 1건·실제 수집 DB 2건은 건너뜀). 이번 후보의 운영 배포·실제 주문·외부 알림 발송은 하지 않았습니다.
