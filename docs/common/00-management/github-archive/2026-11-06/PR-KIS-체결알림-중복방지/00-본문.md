# fix: KIS 체결 확인의 동시 호출·재조회 알림 중복 방지

- 상태: 사용자 승인으로 일반 PR 게시 준비. 브랜치 `fix/kis-fill-notice-dedupe-20261106`.
- 대상: `EST-team-project/Qurious`, 기준 브랜치 `main`.
- 담당: 오준영, P02-⑤-1~3 증권사 체결 추적·운영 알림.
- 선행: #583은 main에 병합됐다. 최신 main `d828759a`를 기준으로 KIS 변경분만 올린다.

정기 체결 확인과 수동 복구 조회가 동시에 같은 체결을 확인하면 동일 주문의 알림이 두 번 전송됐습니다. KIS 모의 3종목 검증 중 삼성에스디에스 매수 10주에서 관측했으며, 중복 주문은 없었습니다.

두 경로가 동일한 `client_order_id`를 알림 참조로 전달하고, 기존 PostgreSQL `(user, kind, ref)` 선점으로 체결 알림을 한 번만 발송하도록 수정했습니다. 같은 종목이라도 다른 주문의 알림은 각각 발송합니다.

## 변경 범위

- `auto_trade.confirm_live_fills`, `kis_recovery_session.refresh`와 `notification.notify_order_filled`의 주문 참조 연결.
- 실제 PG 동시 호출·재조회·전달 실패·다른 주문 구분 시험, 호출자의 참조 전달 확인.
- 운영 시험의 합성 Slack 주소 전송만 로컬 수신기로 연결. 제품 URL 검증 유지, 실제 Slack 호출 없음.
- 전체 검증·모의 주문 결과·담당별 오류 처리 기록과 #579 게시 원본 보관.

## 검증

- 최종 담당 범위 회귀 **244통과·실패/건너뜀 0**. 신규 동시 발송 시험 2건 포함.
- 실제 Beat·worker·Redis·PG·로컬 HTTP 운영 시험 **5시나리오 통과**.
- 전체 원본과 Windows·선택 의존성 보충을 시험별로 대조한 고유 집계 **4,481통과·2실패·3건너뜀**. 이는 중복 실행을 더한 수치가 아닙니다.
- 홈페이지 진단 후 하나금융지주·S-Oil·삼성에스디에스 각 10주, 총 30주 모의 매수·전량 매도, 6건 모두 FILLED. 기존 삼성전자 1주 보존, 시험 잔량/미체결 0.
- 11/6 10:05 KST 최종 운영 이미지 반영. 세 서비스 각각 712파일 일치·HTTP 11경로·새 heartbeat·설정/장부 보존 확인. 수정 후 추가 모의 주문은 보내지 않았고 알림 중복 방지는 격리 PG에서 검증했습니다.

남은 pytest 실패는 강민석 담당 수수료 계약(#579)과 이동원 담당 키 도구 인코딩입니다. 공통 화면 시험의 옛 기대값도 담당 검토로 남깁니다. 수수료 판정은 ‘불일치’로 유지하며 타 담당 구현·시험은 이 PR에서 수정하지 않습니다. 백업·계좌 식별자·원본 주문 저널·인증 정보는 포함하지 않습니다.

최신 main `d828759a`의 팀 변경을 보존했습니다. 이 PR의 제품·시험 파일은 244건 검증본과 동일합니다. 전체 회귀 수는 `fe3ad02f` 기반 당시 결과이며 이후 팀의 카드 화면 변경을 다시 전체 시험한 수치가 아닙니다.
