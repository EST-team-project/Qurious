# [시험 계약] 같은 수수료율·다른 거래 총액의 대사 결과를 ‘불일치’로 유지

- 상태: **사용자 승인 후 [#579](https://github.com/EST-team-project/Qurious/issues/579) 게시 완료**. 아래는 승인 전 초안이며 실제 게시문은 [01-게시본](01-2026-11-06-게시본.md)에 보관한다.
- 작성: 오준영 · 2026-11-06
- 담당: 강민석(P02-④-1·④-3 비용 모델·LEAN 대사), 확인 지원: 오준영
- 관련: ERR-037, PR #534

전체 회귀에서 `test_judge_fee_uses_top_level_lean_fills_and_compares_rates`가 실패한다. 저널 거래대금 1,000·수수료 10, LEAN 거래대금 2,000·수수료 20은 수수료율이 모두 100bp지만 거래대금과 수수료 총액이 다르다. 구현은 `불일치`, 기존 시험은 `참고용(요율)`을 기대한다.

2026-11-06 오준영 확인: **총액이 다르면 ‘불일치’ 판정을 유지한다.** 이 결정을 이유로 현재 구현을 완화하지 않는다. 타 담당 영역이므로 이번 작업에서는 구현·시험 기대값을 수정하지 않고 초안으로 남긴다.
