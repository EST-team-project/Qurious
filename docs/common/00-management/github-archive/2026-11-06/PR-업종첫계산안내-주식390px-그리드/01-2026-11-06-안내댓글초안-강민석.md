강민석 님, 모의투자 주식 화면(`paper-stock`)의 `public/app.html` 에 **클래스 하나**를 더했습니다. 서버 코드와 `paper.js` 는 바꾸지 않았습니다.

**무엇이 보였나**: 390px 폭에서 「주문 입력」 · 「스탑(감시) 주문」 카드의 오른쪽 끝이 392px 로 창 밖(390px)에 걸쳤습니다. 원인은 카드를 감싼 그리드(`grid md:grid-cols-2`)가 좁은 화면에서 열 규칙이 없어, 칸이 내용의 최소 폭(357px)으로 늘어나 부모(320px) 밖으로 37px 삐져나온 것이고, 바깥 `main`(overflow hidden)이 마지막 2px 를 잘랐습니다. 문서 가로 폭은 390 이라 가로 스크롤은 생기지 않았습니다.

**고친 것**: 그 그리드에 `grid-cols-1` 을 더했습니다(`class="grid grid-cols-1 md:grid-cols-2 gap-4 mb-4"`). 768px 이상에서는 그대로 두 칸입니다. 같은 측정으로 다시 재니 카드 폭이 357 → 320 으로 부모와 같아졌습니다.

1. 화면에서 카드가 어색하게 보이는 곳이 있으면 알려 주세요(390px 에서만 확인했습니다).
