오준영 님, #586 에서 오준영 님 몫에 걸린 확인 두 가지를 부탁드립니다. 답이 늦어도 판 올림은 이미 끝났고, 아래는 **다음 판에 반영할 것**입니다.

**1. `kis-results` 기능 완성도 — 제가 매긴 초안입니다**

기능 완성도 점검표에 `kis-results`(KIS 모의투자 결과)가 없어서 배점표로 한 줄 더했습니다. 오준영 님 화면이라 점수는 **확정하지 않았고**, 화면 배지에도 반영하지 않았습니다(`배지반영 = 아니오`).

| 칸 | 점수 | 근거 |
|---|:-:|---|
| UI | 16 / 20 | 상태 열 개 표 · 시간 · 질의 · CSV · 쪽 · 빈 상태. 시험은 가짜 DOM |
| 서버 | 26 / 30 | 기존 `/api/quant/kis/orders` 하나만 부름 |
| 연동 | 15 / 25 | 증권사 실제 왕복은 키가 있는 환경에서만 확인 |
| 시험 | 20 / 25 | 화면 TC-KR 10건 · 서버 `test_kis_monitor_route`(사용자/봇 구분) |
| 합계 | **77** | 부분 검증 |

- 점수와 근거가 맞는지, 올리거나 내릴 칸이 있는지 알려 주세요. 실제 KIS 모의 계좌 기록으로 화면을 눌러 본 기록이 있으면 UI · 연동 칸이 달라질 수 있습니다.
- 맞다고 하시면 다음 판 올림에서 배지(`teamcompletion.js`)에도 반영하겠습니다.

**2. 시험 파일 둘의 묶음 이름**

시험-요구 대장은 시험을 `TC-…` 묶음 이름으로 모으는데, 아래 두 파일은 이름이 없어서 대장 밖에 있습니다(RTM · 테스트 계획서 표 5 에 안 잡힘). 이름을 정해 주시면 대장에 올리겠습니다.

| 파일 | 건수 | 내용 | 제안(이름은 정해 주세요) |
|---|:-:|---|---|
| `tests/test_strategy_v2_corporate_action.py` | 8 | #561 조정일 실행 누락 · 보류 지속 · 알림 경계 | `TC-SV2CA` |
| `tests/test_credential_storage_logs.py` | 4 | 운영 로그 검사가 stderr 오류 · 조회 실패를 정상으로 보지 않음 | `TC-CSL` |

- 요구 ID(`P0x-…`)도 아시면 같이 알려 주세요. 제가 짐작해서 채우지 않았습니다.

**3. 표 속성 대장에 제가 적은 오준영 님 몫 표 세 개**

ERD · 데이터 사전을 올리다가 아래 앱 표가 표 속성 대장에 없다는 경고가 떠서, 모델 코드의 주석과 `ON DELETE CASCADE` 에서 읽을 수 있는 것만 적어 등록했습니다. 보존기간 같은 정책 칸은 정해진 것이 없어 「정하지 않음」 으로 두었습니다. 틀린 칸이 있으면 알려 주세요.

| 표 | 제가 적은 것 |
|---|---|
| `broker_cancel_requests` | 개인 KIS 모의 주문을 취소할 때 전송 전에 한 줄 · 주문(`live_orders`)을 지우면 함께 지워짐 |
| `rebalance_target_changes` | 국면에 따라 목표 비중이 바뀔 때 한 줄(변경 전후 비중 · 근거) · 사용자나 계획을 지우면 함께 지워짐 |
| `execution_risk_stops` | 진입한 포지션마다 한 줄(손절 계산 기준) · 사용자를 지우면 함께 지워짐 |

(`paper_snapshot_price_audits` 는 강민석 님 표라 따로 알립니다.)
