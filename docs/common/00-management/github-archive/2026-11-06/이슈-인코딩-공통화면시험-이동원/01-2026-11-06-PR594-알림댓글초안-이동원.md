「알림 키 교체 도구 인코딩과 공통 화면 시험 기대값」 보관 초안의 네 건은 모두 제 담당 파일이라 직접 재현한 뒤 고쳤고, PR #594 가 머지됐습니다(`dc64c877`).

- 알림 키 교체 도구(`scripts/rotate_notification_credentials.py`): `main()` 이 콘솔 인코딩과 상관없이 UTF-8 로 출력합니다. 줄표 출력 시험이 통과합니다.
- `tests/e2e/smoke_views.py`: 마이페이지로 옮겨 간 설정·알림·모의 별칭을 `MYPAGE_HOSTED` 에서 읽어 마이페이지 안의 구역으로 확인합니다.
- `tests/e2e/gnb_widths.py`: 메뉴 묶음 기대값을 13개에서 12개로 맞췄습니다.
- `tests/e2e/learn_inapp.py`: 학습 홈의 세 갈래 → 개발 개념 → 부 목차 → 장 순서로 동선을 따라갑니다.

실제 앱에서 돌린 결과는 스모크 77화면 문제 0, 메뉴 폭 12곳과 추가 훑기 83건 문제 0, 학습 동선 ①~⑦ 통과입니다. 스모크는 점검 계정(`E2E_EMAIL=smoke-check@example.com`)으로 돌려야 하고, 기본 계정으로 돌리면 77화면이 모두 실패로 보입니다.
