11/3 오전 KIS 모의 재주문 시험 진행 상황입니다.

- 09:10:10 Windows 예약은 종료 코드 1로 끝났고 시험 시작 기록·신규 주문은 없었습니다. 예약 당시 상세 표준출력이 보존되지 않아 최초 실패 원인은 확정하지 않았습니다.
- 사용자 수동 시작 요청에 따라 시험을 재개했습니다. 주문 전 KIS HTTP 조회 오류와, 별도 사전 조회 직후 주문 준비 잔고 조회의 `BALANCE_RATE_LIMIT`을 확인했습니다. #505에서 명시적 당일 수동 시작, 일시적인 GET만 제한 재조회, 주문 단계 사이 호출 간격을 보완했습니다. POST는 재전송하지 않습니다.
- 09:17 첫 시험용 매도 1주는 KIS 모의에서 취소 전에 체결됐습니다. 따라서 `parent_filled_without_retry`로 종료했고 잔량 재주문은 없었습니다. 기존 전략 1주는 보존됐고 원래 위험 설정도 유지했습니다.
- 사용자가 새 모의 1주로 추가 시험 1회를 별도 승인했습니다. 09:21 새 매수 1주 체결과 전략별 보유(기존 1 + 시험 1)를 확인했습니다. 같은 요청 번호를 사용했고 조회 단계에서 차단된 요청은 실제 주문·의도 기록이 없음을 확인한 뒤에만 이어갔습니다.
- 추가 실행기 PID와 대기 기록을 확인했습니다. 기존 매도의 30분 대기 후 **09:47:40~09:49:40 KST**에 새 원 매도·취소를 시작하고, 다시 30분 뒤 **10:17 이후**에 기존 원 지정가·가격 이탈 1% 조건에서 재주문 1회를 시험합니다. 임시 허용 창 45분은 원복하며 기존 전략 1주를 보존합니다. 첫 시험 기록은 보존하고 추가 시도도 1회만 허용합니다.

검증: 네트워크 없는 Docker 시험 41 passed / DB 연동 6 skipped, diff 검사 통과. 이번 실행기는 Docker 영구 데이터 경로에 커밋 소스와 SHA-256을 대조해 반영했습니다. 앱 이미지 전체 교체는 하지 않았습니다.

**C5 실제 잔량 재주문 접수·체결 성공은 아직 대기이며, C4 증권사 상주 감시도 완료로 처리하지 않습니다.** 결과가 나오면 이 댓글을 갱신하겠습니다.
