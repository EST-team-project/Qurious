11/3 C4 증권사 상주 감시 후속 확인입니다. 담당은 오준영(P02-⑤ 증권사 연동)이며, 현재 C4 연동은 미구현 상태입니다.

오늘 확인 범위를 공개 API 목록·샘플에서 공식 FAQ와 실제 문의 경로까지 넓혔습니다.

- KIS 공식 FAQ의 공개 목록 173건(100+73)을 확인했습니다. 공식 검색 API에서 `감시`, `스탑`, `STOP`, `자동주문`을 제목·본문으로 검색한 결과는 각각 0건입니다. 이것만으로 기능 미지원이라고 단정하지 않습니다.
- 공식 `koreainvestment/open-trading-api` 저장소의 Issues와 Discussions가 모두 비활성 상태임을 확인했습니다.
- 현재 KIS FAQ 페이지의 문의 안내는 **한국투자증권 홈페이지 로그인 후 ‘고객의 소리’에서 접수**하는 경로입니다. 개발자 포털 로그인이나 증권사 주문용 앱키가 곧 고객센터 접수 권한을 의미하지 않습니다.
- 접수 가능한 문의문을 작성했습니다. 현재 연결된 도구에는 해당 홈페이지 로그인 세션 접근 기능이 없어 문의는 아직 발송하지 않았고, 사용자에게 이 접수 단계와 답변 전달을 요청했습니다.

문의 내용:
1. 개인 Open API에서 HTS [0954]와 같은 증권사 서버 감시 조건 등록·중지·삭제·조회 지원 여부 및 공식 URL/TR ID.
2. Open API 모의투자(Testbed/VTS) 지원 여부. 실전·HTS 전용이면 해당 제한.
3. 조건 ID·버전·유효기간·만료·삭제·발동을 구분하는 응답과 종료 이력 조회.
4. 조건 ID·발동 이력과 실제 주문번호·주문일·주문조직번호의 연결, 이후 체결·취소 조회.
5. 응답 유실·재접속 시 중복 등록 방지 및 기존 조건 조회. 조건 삭제와 발동 주문 취소의 구분.

서버를 끈 상태에서도 증권사가 감시하는 기능에 대한 문의입니다. 거래소 스톱지정가(22), 조건검색, 예약주문, 우리 서버 주기 판단으로 C4 구현을 대체하지 않습니다. 현재 `monitoring=server_polling`, `broker_hosted_stop=false`를 유지하며 확인되지 않은 경로로 주문/등록을 보내지 않았습니다. C5 모의 재주문 시험과 구분합니다.
