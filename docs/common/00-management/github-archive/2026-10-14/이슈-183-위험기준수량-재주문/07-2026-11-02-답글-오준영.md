C2 보완 의견(수량을 제한한 이유, 진입 기준 고정, 기존 보유의 전환 고정, 신규 ATR 기본값)을 PR #477에 구현했습니다.

- 신규 위험 모드는 **마지막 확정 일봉의 공통 Wilder ATR(14) × 2**를 기본값으로 제시합니다. 기존에 저장된 % 손절 의미는 유지합니다. 수정 OHLC의 ATR을 해당 일자의 누적 조정계수로 원주가 거리로 환산하며, 자료가 없거나 단위가 맞지 않으면 진입을 보류합니다.
- 주문 전 진입 가격·손절 종류/설정·ATR 기준일·손절선을 OrderIntent에 기록하고, 확정 체결 평균가로 보유 회차의 기준을 고정해 저장합니다. 재시작·부분 매도·설정 변경 뒤에도 같은 기준을 읽고, 실제 주문 직전에도 다시 검사합니다.
- 진입 근거가 없는 기존 보유는 첫 위험 판정 때 **‘전환 시 고정’**으로 남깁니다. 진입 당시 값을 복원한 것으로 표시하지 않습니다.
- 고정 손절이 있는 보유는 고정 예산 모드로 바꿔도 추가 매수를 막습니다. 평균가가 외부 변경으로 달라졌다면 자동으로 손절선을 넓히지 않고 확인을 요구합니다. 전량 청산 뒤 새 진입은 다른 회차입니다.
- 위험·현금·1회 예산·비중·증권사 가능 수량·요청 수량 중 실제 수량을 제한한 항목을 응답/화면에 표시합니다. 기존 예산과 공통 위험 관문을 유지합니다.

실제 PostgreSQL에서 진입/전환 기준, 재시작·부분 매도·모드/전략 설정 변경, KIS 모의 응답의 부분 체결 후 잔량, 주문 직전 손절 경계 전송/차단을 검증했습니다. `test_risk_stops.py` + `test_order_pricing.py` 17건 통과, 전체 결과는 [PR #477](https://github.com/EST-team-project/Qurious/pull/477)에 있습니다.

DB 이전 `0038_risk_stops`가 필요하며 아직 main 병합·운영 적용 전입니다. 갭·슬리피지·미체결로 실제 손실이 예상치를 넘을 수 있다는 안내는 유지합니다. C4 상주 감시나 C5 실제 재주문 체결 실측을 이번 검증으로 완료 처리하지 않습니다.
