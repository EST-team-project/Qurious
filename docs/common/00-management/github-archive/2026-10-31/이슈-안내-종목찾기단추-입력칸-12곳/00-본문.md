종목 코드를 직접 치던 입력칸 12곳 옆에 돋보기 단추(「종목 찾기」)를 달았습니다. 칸에 직접 치는 방식은 그대로이고, 단추를 누르면 이미 있던 「종목 검색」 창(`stock-search-modal` · `/api/stocks/search`)이 열려 이름이나 코드를 치면 관련 종목이 뜹니다. 고르면 칸이 채워집니다. 사용자가 「입력을 유지하되 검색 창으로 관련 기업명을 띄워 달라」 고 해서 정했습니다.

### 바뀐 칸 (칸 id · 화면)
| 화면 | 칸 | 넣는 값 |
|---|---|---|
| 주문/매매 | `ord-symbol`(+ `ord-name` 종목명도 함께) | 기호 |
| 모의투자 · 종목 | `ps-symbol` · `ps-stop-symbol` | 기호 |
| 퀀트 · LEAN | `ql-ticker` | 기호 |
| 미국 차트 · 주문 | `us-symbol` · `us-ord-symbol` | 기호(해외는 `AAPL` 꼴) |
| 지표 · 자유 산식 | `fx-symbol` | 기호 |
| 지표 · TradingView | `pc-symbol` · `tvc-ticker` | 6자리 코드 · 기호 |
| 리밸런싱 | `rb-add-symbol` · `rb-cf-symbol` | 기호 · 6자리 코드 |
| 패턴 분석 | `pt-symbol` | 기호 |

### 이동원이 바꾼 것 (HTML · 프런트 JS · CSS 만)
- `public/js/stockfind.js`(새 파일) · `public/css/stockfind.css`(새 파일) · `public/app.html`(칸 12곳에 `data-stock-find` 속성) · `public/js/company.js`(검색 창 열기 `openStockSearch` 내보내기만) · `public/js/main.js`(단추 달기 한 줄).

- 좁은 칸(폭 약 100px 이하)에서는 단추가 칸 아래로 내려갑니다.

### 확인 부탁
1. 위 화면들에서 칸 값이 **기호 형식**(`005930.KS`)으로 들어가도 괜찮은가요? 6자리만 받는 칸이 있으면 알려 주세요(지금은 `pc-symbol` · `rb-cf-symbol` 만 6자리로 넣습니다).
2. 해외 종목(`AAPL`)을 국내 전용 칸에서 고르면 그대로 들어갑니다 — 화면의 검증 문구가 막는지 봐 주세요.
3. 이 단추를 원치 않는 화면이 있으면 칸에서 `data-stock-find` 속성만 지우면 됩니다.
