## 무슨 일인가

모의투자 → **모의계좌 현황**(`app.html#paper-dashboard`)을 열면 개발자 도구 콘솔에 `GET /api/paper/performance/backtest-100d/exists 500 (Internal Server Error)` 가 찍힙니다. 같은 커밋에서 생긴 **두 곳**이 모두 `NameError` 로 500 이 납니다.

| # | 라우트 | 원인 | 위치 |
|---|---|---|---|
| 1 | `GET /api/paper/performance/backtest-100d/exists` | `Order` 를 import 하지 않았다 — `from app.models import ApiKey` 뿐 | `app/routes/paper.py:551` · `:552`(세 곳) |
| 2 | `GET /api/paper/performance/benchmark` | `get_benchmark_series` 가 `.limit(limit)` 을 부르는데 이 함수에는 `limit` 인자가 없다(바로 위 `get_allocation_history` 에서 복사된 줄로 보인다) | `app/services/performance_service.py:413` |

재현(개발 앱 컨테이너 · 사용자 4명 중 첫 사용자):


## 고치는 방법(제안 — 한 줄씩)

1. `app/routes/paper.py` 의 `from app.models import ApiKey` → `from app.models import ApiKey, Order`
2. `app/services/performance_service.py` 413 줄의 `.limit(limit)` 삭제 — `efcccd4` 이전 판은 행 수 제한이 없었다(`.order_by(snap_date.asc())` 로 끝).
