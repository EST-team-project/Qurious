## 판단 · 원칙

- **SSoT** — 리허설 판정 규칙 · 기록은 `scripts/hf_dataset.py` 한 곳, 날 수 · 상태 글은 서버 `rehearsal_view` 한 곳. 주간 스크립트는 차례대로 부르기만 하고, 화면은 서버 글을 싣기만 한다. 12:30 앞뒤 셈은 러너 `guard_window` 를 그대로 쓴다.
- **말없는 fallback 금지** — 판정 기록에 리허설 칸이 없으면 「없음」 이 아니라 「모름」 이다(개발 앱에서 「리허설 없음」 으로 잘못 보여 고침). 실패한 옛 기록을 성공으로 쓰지 않는다.
- **원자성 · 멱등성** — 상태 파일은 덮어쓰기 전에 합치고, 같은 날 다시 돌려도 결과가 같다. 다른 실행이 잠금을 쥐고 있으면 기다리지 않고 75 로 끝낸다.
- **경계** — 팀원 화면은 프론트만 고쳤고, 조각마다 「지우면 원래대로」 주석과 칸이 없으면 건너뛰는 길을 두었다.
