# [Bug] HF 원장 Pull 시 파일 지문 불일치 오류 재발

## 문제 설명
2026-10-29 `python scripts/daily_lean_reconcile.py` 실행 시 HF 원장 Pull 단계에서 파일 지문 불일치 오류가 재발했습니다. 동일한 문제가 2026-10-28에도 발생했으며, 당시 `git pull origin main` 실행 후 해결되었습니다. 그러나 하루 뒤 동일한 파일에서 같은 오류가 다시 발생했습니다.

일시적인 코드 동기화 문제인지, HF 원격 저장소의 원장 파일과 지문 목록(manifest) 간 불일치인지 원인 확인이 필요합니다.

## 실제 결과
```
    🚀 2026-10-29 대조 시작 (v4)
    ▶ [1/4] HF 원장 pull 중...
       (HF 로그인 캐시에서 토큰을 자동으로 불러왔습니다)

    RuntimeError: Pull 실패(종료코드 4):
    [실패] 원장을받지 못했다 — ValueError:
    원장 파일이 지문 목록과 다르다 —
    rows/auto_default/v1/2026-09-01.parquet
```

## 발생 이력
- **2026-10-28:** 동일한 파일에서 지문 불일치 오류 발생.
- **2026-10-28:** `git pull origin main` 실행 후 문제가 해결됨.
- **2026-10-29:** 동일한 명령어 실행 시 동일한 파일에서 오류 재발.

## 예상 결과
HF 원장 다운로드 및 지문 검증이 정상적으로 완료되고, 이후 LEAN 재실행과 일일 대조 단계가 진행되어야 합니다.

## 확인 요청 사항
1. 어제 `git pull origin main` 실행 후 문제가 해결된 원인을 확인합니다.
2. 현재 로컬 코드가 원격 `main` 브랜치의 최신 코드와 일치하는지 확인합니다.
3. `rows/auto_default/v1/2026-09-01.parquet` 파일과 manifest에 기록된 지문이 불일치하는 원인을 확인합니다.
4. 코드 버전 불일치, HF 원격 저장소의 파일 갱신, 캐시 또는 다운로드 과정 중 어떤 요인이 문제를 재발시키는지 확인합니다.
5. 근본 원인을 해결하고 동일한 문제가 반복되지 않도록 검증 및 회귀 테스트를 보완합니다.

## 완료 기준
- HF 원장 Pull이 정상 완료됩니다.
- 원장 파일과 manifest 간 지문 불일치의 근본 원인이 규명됩니다.
- `git pull origin main`을 반복적으로 실행하지 않아도 정상 동작합니다.
- 기존 원장 무결성 검증을 유지하면서 재발 방지 테스트를 통과합니다.

## 참고 정보
- 발생 일자: 2026-10-28, 2026-10-29
- 스크립트: `scripts/daily_lean_reconcile.py`
- 실패 단계: `[1/4] HF 원장 pull`
- 종료 코드: `4`
- 문제 파일: `rows/auto_default/v1/2026-09-01.parquet`

## 주의 사항
현재 확인된 사실은 동일한 오류가 재발했다는 점과, 전날 `git pull origin main` 실행 후 문제가 해결되었다는 점입니다. 코드 버전 불일치가 근본 원인인지는 아직 확인되지 않았으므로, 원인을 조사한 뒤 수정해야 합니다. 원장 무결성 검증을 우회하거나 비활성화하는 방식은 해결책으로 인정하지 않습니다.
