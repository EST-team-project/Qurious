오준영 담당 범위 처리 결과 공유드립니다. 본문의 선택지 중 **① 저장 시 암호화**를 적용했습니다. **10/29 14:27 KST 운영 DB 전환과 배포를 완료했고, 14:49에는 승인된 과거 평문 백업 정리까지 마쳤습니다.**

### 처리 내용

- **API 키·비밀키·계좌번호**를 AES-256-GCM으로 암호화 저장합니다. 사용자별 자격증명 소유 구조는 유지하고, 암호화 키는 DB·소스·이미지와 분리해 앱·worker·beat에 읽기 전용으로 제공합니다.
- DB 마이그레이션 `0031`에서 기존 값을 일괄 암호화하고 평문 쓰기를 제한했습니다. 키 누락·복호화 실패 시 평문으로 우회하지 않고 요청을 차단합니다.
- 설정 조회 응답의 계좌번호를 마스킹했습니다. 기존 마스크를 그대로 재저장해도 원래 값은 보존됩니다.
- 키 교체·암호화 백업 복원 절차와 함께 **약관 v0.3 / 개인정보 처리방침 p0.2**에 실제 보호 범위를 반영했습니다.

### 검증 및 백업 정리

- 배포 후보 **617건 통과**. Node 미설치로 건너뛴 렌더링 1건은 Chrome에서 별도 확인했습니다. 암호문 변조, 키 누락 시 503, 키 교체, 마이그레이션 실패 시 원상 복구와 기존 값 보존을 검증했습니다.
- 운영 사본 복원과 기존 57개 표의 보존 대조 후 DB를 전환했습니다. 전환 뒤 실제 KIS 모의 **잔고·시세·주문 가능 수량 조회가 성공**했으며 주문은 보내지 않았습니다.
- 기존 평문 DB 백업 **19개는 암호화 사본의 원본 일치 및 최신 사본의 실제 DB 복원을 검증한 뒤, 사용자 승인에 따라 삭제**했습니다. 암호화 사본 19개와 별도 키는 보존했습니다. 이번 목록에 대한 일회성 정리이며 향후 파일 자동 삭제 규칙은 추가하지 않았습니다.

### 현재 상태

**증권사 자격증명 관련 수정·운영 반영·승인된 백업 정리는 완료**했습니다. 자동매매·실전 허용은 OFF입니다. 알림 설정의 토큰·SMTP 비밀번호·전화번호 암호화는 이번 변경에 포함되지 않은 별도 담당 범위입니다.
