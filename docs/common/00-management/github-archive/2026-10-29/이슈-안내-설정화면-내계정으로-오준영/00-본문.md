### 앞으로 (2단계 — 설계 끝 · 아직 구현 전 · 의견 부탁)
사용자가 「설정은 전부 마이페이지로」 라고 결정했고, [마이페이지 화면 설계 v0.1](docs/phase-3/02-design/ui/마이페이지-화면설계.md)(Figma 포함)에서 **마이페이지 안에 왼쪽 구역 목록**(내 정보 · 보안 · 증권사 연동 · 알림 · 외부 연동 · 화면 설정 · 투자 성향 · 위험 구역)을 두기로 했습니다(사용자 결정 10-29). 일은 둘로 나누고 **둘 다 11-05 전**에 합니다. 화면(HTML · 프런트)만 건드리고 서버 로직은 안 건드립니다.
- **1차**: 구역 틀 + 기존 카드 재배치. 증권사 연동 구역은 **요약 + 「증권사 API 설정 열기」 링크**만 — `settings` 화면과 칸은 그대로 둡니다(위험 거의 없음).
- **2차**: 증권사 설정 **본체를 구역 안으로** 옮깁니다. 오준영 님 화면에 닿는 것은 아래입니다.
1. **S1 증권사 API 설정(`settings`)**: 칸 id 는 그대로 두고 view 위치만 옮깁니다. 숨은 의존 — `trading.js:148-154` 가 `broker-app-key` · `broker-app-secret` · `broker-account` · `broker-paper` 를 읽고, e2e `tests/e2e/kis_modes.py` · `broker_feedback.py` 가 `[data-view="settings"]` 를 강제로 보이게 해서 씁니다 → 옮길 때 이 선택자도 같이 고칩니다. `#settings` 딥링크는 살립니다(빈 껍데기 + 마이페이지 「증권사 연동」 구역으로 보내기).
2. **S4 증권사 API 자동화(`indicator-api`)**: S1 과 **같은 서버 설정 행**(`/api/broker/settings`)을 쓰는 복사본이라, 「증권사 API 설정으로」 링크로 바꾸고 싶습니다. 이 화면이 3차 발표 데모 이름(⑤ 증권사 API 연동 자동화)이라면 알려 주세요 — 그러면 두겠습니다.
3. **S8 투자성향 진단(`robo-portfolio`)**: 사용자가 **옮기지 않기로** 했습니다(설문은 자산배분이 씀). 마이페이지 「화면 설정」 구역에 현재 값 한 줄 + 링크만 둘 수 있는지 — 읽을 수 있는 값이 있으면 알려 주세요(없으면 링크만).
