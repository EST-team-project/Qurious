### 처리 내용

| 본문 요청 | 반영 결과 |
|---|---|
| S1 · 증권사 API 설정 통합 | 기존 설정 본체를 **내 계정 → 증권사 연동**으로 옮겼습니다. 기존 입력 ID와 `#settings` 바로가기를 유지해 매매 화면의 설정 참조와 기존 링크가 계속 동작합니다. |
| S4 · 자동화 화면의 중복 입력 | **증권사 API 자동화 화면과 안내는 유지**하고, 중복 키 입력·저장 폼은 「증권사 API 설정 열기」 링크로 교체했습니다. |
| S8 · 투자성향 요약 | 진단은 기존 로보 포트폴리오에 유지하고 내 계정에는 요약과 이동 링크를 연결했습니다. 현재 계정·브라우저에 저장된 진단만 표시하며 서버 저장·기기 간 동기화 기능은 아닙니다. |

- 실제 Chrome에서 넓은/좁은 화면의 바로가기, 설정 불러오기·저장, 재진입 시 중복 저장 방지, 계정별 투자성향 분리를 확인했습니다.
- #397을 포함한 배포 후보 시험은 **617건 통과**했습니다. Node 미설치로 건너뛴 렌더링 1건은 Chrome에서 별도로 확인했습니다.
- **우리 담당 변경은 main 병합 및 운영 반영 완료**입니다. 자동매매·실전 허용은 OFF를 유지했습니다. 알림·OpenAPI 설정 본체 이동은 별도 담당 범위입니다.
