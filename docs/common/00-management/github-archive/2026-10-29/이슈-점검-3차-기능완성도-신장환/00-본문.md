### 2-2. 알림 — 이동원이 만든 길 (생성기는 안 고쳤습니다)
`pine_strategy.py` 가 CLI 뿐이라 화면에서 쓸 수 없어서, 이동원이 **새 라우트 파일 `app/routes/strategy_cards.py`** 를 만들어 생성기를 **부르기만** 합니다(`app/services/pine_strategy.py` 는 한 줄도 안 바꿨습니다).
- `GET /api/strategy-cards` — `docs/phase-3/02-design/system/예시/strategy-card-*.json` 목록 + 각 카드를 `generate()` 로 만들 수 있는지(`GenerationError` 까닭을 그대로).
- `GET /api/strategy-cards/{id}/pine` — `generate()` 결과(`code` · `sha12` → `fingerprint` · `warnings` · `skipped_v2`)와 `read_back()` 값을 그대로 돌려줍니다. 숫자 범위만 서버에서 막습니다(기준가 > 0 등). 코드는 저장하지 않습니다.
- 화면: 대사 화면(`indicator-tradingview`) 위에 「카드 → Pine 내려받기」 카드. 시험 `TC-SCA` 5 · `TC-PCD` 5.
- **부탁**: 생성기 시그니처(`generate(spec, symbol, ref_price, mintick, fee_pct, sell_tax_pct, slippage_bp, initial_capital)` · `PineResult` · `read_back`)나 `GenerationError` 를 바꾸실 때 이 라우트와 시험이 같이 깨질 수 있으니 알려 주세요. 카드 JSON 이름 규칙은 `strategy-card-*.json` 입니다.
