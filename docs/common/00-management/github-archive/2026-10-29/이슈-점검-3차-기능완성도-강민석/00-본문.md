### 3. 시험 확인 하나 (점검표와 별개)

### 3-2. 알림 — 이동원이 고친 화면 (서버는 안 건드렸습니다)
TradingView ↔ LEAN 대사 화면(`public/js/tradingview.js` · 새 `public/js/comparelayers.js` · `app.html` 안내 문구)을 이동원이 고쳤습니다. **`app/` 서버 코드는 한 줄도 바꾸지 않았고**, 강민석 님이 만든 응답(`signal_comparison` · `fill_comparison` · `performance_comparison`)을 화면이 층별로 읽도록만 했습니다.
- 맨 위 「일치 / 부분 일치」 배지(서버 `verdict`, 수익률 · MDD 차이 3%p / 10%p)를 없애고, **신호 · 체결 층마다 배지 하나**(신호 = 날짜별 진입 · 청산 상태 정확 일치 / 체결 = 날짜 · 방향 정확 일치). 성과 숫자는 「참고」 로 내렸고 색 기준도 뺐습니다. 팀 이슈 원칙 「수익률 유사성만으로 통과시키지 않는다」 를 따른 것입니다.
- LEAN 이 안 돌아 pandas 로 대체되면(`lean.lean_ok == false`) 맨 위에 「비교 불가」 를 크게 띄웁니다.
- 이력 표의 옛 `verdict` 는 성과 비교 결과 그대로 두고 「성과 차이 판정(참고)」 중립 글씨로만 보입니다(DB · API 변경 없음).
- **부탁 하나**: 체결가 · 성과의 **허용 오차 값**을 정해 주세요. 정해질 때까지 화면은 「기준 미정」 으로 숫자만 보입니다. 서버 `verdict` 의 3%p / 10%p 를 바꾸시거나 층별 판정을 서버가 주도록 하시려면 서버 몫이라 이동원은 건드리지 않았습니다.
- **부탁 둘째 — 구간별 판정**: 그림자 일지 ↔ LEAN 대조(v4)의 층별 판정은 **사후 봉인 시험 35일(9/1 ~ 10/25 — 규칙 등록 전 날짜)과 봉인 구간 2일(10/26 ~ 27)을 섞은 값**입니다. 신호 37/37 일치도 35일은 사후 계산이라 전진 기록이 아닙니다. 이동원은 신뢰성 화면에서 이 사실을 글로 적고(사용자 결정 10-29), **구간별로 따로 낸 판정(JSON 이든 보고서 표든)** 을 강민석 님께 부탁드립니다. 서버(대조 스크립트) 몫이라 이동원은 건드리지 않습니다. 화면 설계는 `docs/phase-3/02-design/ui/전략신뢰성-대사-화면설계.md` · Figma 「03 설계」 페이지입니다. 보유 불일치 4일 원인 확인은 #314 11번 답글 초안에 있습니다.
- 대사 층 배지 이름은 서버 · 보고서가 쓰는 말에 맞춰 「일치 · 불일치」 로 통일했습니다(사용자 결정 10-29).
- 되돌리려면 `public/js/tradingview.js` 의 `renderLayers` 호출 한 줄과 `comparelayers.js` import 를 지우면 됩니다. 시험 `TC-CLY`(5건)가 새로 생겼습니다.
