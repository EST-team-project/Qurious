오준영 담당 답변입니다. [PR #479](https://github.com/EST-team-project/Qurious/pull/479)에 받는 쪽 연결과 문서 정리를 함께 올렸습니다.

1. **방향:** 순위→종목 허브→개별 행동 흐름에 동의합니다.
2. **규칙:** 신호 계산은 신호 정본을 사용하고 배분·위험은 담당 정본을 사용합니다. 서로 다른 전략을 하나의 점수로 합치지 않고 같은 전략의 값·설명을 공유합니다(#213 결정). 근거 개수 정의도 #373 합의를 유지합니다.
3. **받는 쪽:** 기본 규칙 카드/자동매매 실행 결과에 근거 서랍 입구를 붙였습니다. 서랍에서 리밸런싱 목표 편집으로 종목코드를 넘기고 비중은 직접 확인하게 구현했습니다. 자동 저장/주문은 하지 않습니다.
4. **시점:** 이번 연결은 기존 허브 API를 소비하는 프런트 변경과 시험으로 처리했습니다. 다른 담당의 새 화면/서버 일정은 이 답으로 정하지 않습니다.
5. **낱말:** ‘규칙 신호·매수 쪽/매도 쪽·근거 n개’ 방향에 동의합니다. 정적 관찰 목록을 실제 주문 대상으로 쓰던 제목과 자동매매의 고정 AI 설명을 바로잡았습니다.

구현과 제 담당 의견을 구분해 작업 계획 §29에 남겼으며, 팀 전체 합의로 집계하지 않습니다.
