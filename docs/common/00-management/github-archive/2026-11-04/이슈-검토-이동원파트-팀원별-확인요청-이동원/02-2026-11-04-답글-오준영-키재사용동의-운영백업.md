## 1. 키 파일 — 기존 구성 재사용으로 진행 가능합니다

- 기존 증권사 암호문 형식·필드 인증값·키 ID는 유지하고, 알림용 암호문 식별자와 `notification_settings.<필드명>` 인증값을 별도로 사용

- 대상은 토큰·웹훅·SMTP 비밀번호·카카오/문자 API 키·시크릿·카카오 발신 프로필 키 등 비밀 필드. 주소·전화번호 같은 개인정보의 추가 암호화 범위는 별도 명시

- 키 누락·변조·복호화 실패 시 평문 저장/발송으로 우회하지 않음
