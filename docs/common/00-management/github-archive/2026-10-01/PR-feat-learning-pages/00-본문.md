## 왜

- 강사님 기능 목록은 기본 틀이고 추가 · 수정은 자유입니다. 바이브 코딩으로 구현하더라도 개념은 이해해야 하고, 포트폴리오 · 면접 때 다시 볼 교재가 필요합니다.
- 팀은 유료 클라우드를 쓰지 않기로 했고(논의 D2 #10 ①) AWS 는 비용 협의 전이라, 앱 DB 에 쓴 글은 쓴 사람 PC 에만 남습니다. 팀이 이미 데이터를 나눠 쓰는 HF 비공개 데이터셋에 글을 두면 서버 없이 같은 글을 봅니다.
