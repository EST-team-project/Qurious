오준영 님 현황 대조(03)와 PR #481 보고(05) 감사합니다. 두 가지를 바로잡고, 구현과 제 설계를 견준 결과와 남은 하나를 적습니다.

**정정**

1. **③ 체결 → 알림** — 본문에 「수동 모의주문과 KIS 실행에는 알림 호출이 없다」 고 썼는데, **KIS 쪽은 틀렸습니다.** 증권사 주문의 FILLED 전환 때는 이미 체결 알림이 나가고, 실제 빠진 곳은 모의주문 장부의 수동 · 스탑 체결이었으며 #481 이 그것을 채웠다고 이해했습니다.
2. **② 신호 → 주문의 「위험 기준 수량이 채워진」** — 본문 시나리오의 이 말은 자동매매 쪽 수량을 그대로 넣는다는 뜻으로 읽힐 수 있었는데, #481 처럼 **장부가 다르면 모의주문 장부의 평가액 · 현금으로 다시 계산**하는 것이 맞습니다.
3. **① 지금 종목 공유** — 신호 카드의 서랍 입구는 #479, 모의주문 단추 · 신호 순위 연결은 #481 이라 **신장환 님이 맡기로 한 카드 서랍 · 모의주문 단추는 중복 작업하지 않으셔도 됩니다.**
4. **11-04 같이 눌러 보기** — 일정 확정이 아니라 제안이었고, 다른 담당자의 일정을 확약한 것으로 읽지 않습니다.

**제 설계를 #481 구현에 맞췄습니다 (Figma 종목 허브 08 쪽 · 보기 전용)**

주담당인 오준영 님의 구현을 따르기로 했습니다. 제가 처음 그린 안과 달랐던 두 곳을 구현대로 고쳤습니다.

- 계산한 수량은 「수량에 적용」 단계 없이 **수량 칸에 바로 채웁니다**(서랍에서 「PAPER 모의주문으로」 를 누르면 계산도 자동으로 돕니다).
- **이미 보유한 종목은 계산을 보류**하고 직접 검토를 안내합니다(추가 매수 계산 상태는 그림에서 뺐습니다).
- 같은 점: 종목만 넘기고 PAPER 장부 기준으로 다시 계산 · 주문 · 스탑을 자동 등록하지 않음 · 손절 기준과 가정을 화면에 보임 · 계산 못 하면 보류.
- 실제 화면과의 대조(수량 칸 · 입력 칸 배치 · 390 폭)는 #481 병합 뒤에 합니다.
