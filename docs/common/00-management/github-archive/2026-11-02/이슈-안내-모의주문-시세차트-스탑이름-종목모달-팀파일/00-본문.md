# [안내] 모의주문 화면 — 시세 조회에 일봉 차트 · 스탑 칸에 종목 이름 입력 · 스탑가 자동 채움 빼기 · 「근거 · 차트 크게 보기」 모달

@강민석 @오준영 @신장환 — 이동원이 모의주문 화면(`public/js/paper.js` · `public/app.html` 의 국내주식 모의주문)을 고쳐서 알립니다. 주담당은 강민석 님(UI 명세서 화면 17)이라 서버 쪽은 건드리지 않았습니다. 읽고 할 일은 아래 3절뿐입니다.

## 1. 무엇이 바뀌었나(화면 · 프런트 코드만 · 서버 변경 없음)

- **시세 조회 결과 아래 일봉 차트** — 수집 일봉(`/api/data/ohlcv`)을 그립니다(기간 1개월 · 3개월 · 1년). 새 서버 길도 야후 참조도 늘리지 않았습니다.
- **스탑 칸에 이름을 쳐도 됩니다** — 「삼성전자」 를 치고 시세 조회를 누르면 이름으로 찾아 하나면 채우고, 여럿이거나 없으면 종목 찾기 창을 그 글자로 열어 줍니다. 전에는 칸 글자를 그대로 서버에 보내 「지원하지 않는 종목입니다」 가 나왔습니다. 시세 조회 · 미리보기 · 주문 · 스탑 등록이 같은 길을 씁니다(`js/stockfind.js` 의 `resolveSymbolInput`).
- **스탑가 자동 채움 삭제** — 시세를 조회하면 스탑가 칸에 현재가를 넣어 두던 것을 뺐습니다. 그대로 매도 스탑을 등록하면 서버가 「현재가 ≤ 스탑가」 로 보고 다음 1분 점검에서 바로 체결하기 때문입니다. 대신 현재가와 견준 방향 안내 · 빠른 단추(−3% · −5% · −10%) · 차트의 스탑가 점선을 둡니다. 이미 닿은 스탑을 등록하려 하면 한 번 더 확인합니다.
- **「근거 · 차트 크게 보기 →」 단추** — 시세 조회 결과에 달았습니다. 종목 서랍을 거치지 않고 바로 가운데 모달이 열려 큰 일봉 차트와 허브 일곱 칸을 아래로 내리며 봅니다. 서랍에도 같은 차트와 「크게 보기」 가 생겼습니다. (#476 이음새 ① 로 제안한 「주문 화면 근거 단추」 를 이번에 이동원이 먼저 달았습니다 — 오준영 님 · 강민석 님이 따로 달 필요는 없습니다.)

설계: Figma 「Qurious · 종목 허브」 07 쪽(안 C · 안 D · 2026-11-02 결정).

## 2. 확인한 것 · 확인하지 못한 것

- 화면 · 순수 함수는 시험으로 지킵니다(TC-SCH · TC-SFD-04 · 05 · TC-SDR-07 · 08). 이름 풀기는 실제 브라우저 클릭 확인을 아직 다 하지 못했습니다.
- 모의주문의 시장가 · 스탑 서버 로직은 바꾸지 않았습니다.

## 3. 요청(서버 쪽 — 강민석 님 몫이라 고치지 않고 알립니다)

1. **장 시간 판정** — 안내 문구는 「장 시간에만」 인데 `paper_trading.check_stop_orders` 에는 장 시간 판정이 없습니다. 문구를 고치거나 판정을 넣어 주세요.
2. **방향 검증** — 등록 시 스탑가가 현재가의 어느 쪽인지 서버가 검사하지 않습니다. 화면은 경고만 합니다.
3. **체결 알림** — 스탑이 발동해 체결돼도 알림을 부르지 않습니다(`notify_order_filled` 는 `auto_trade.py` 한 길뿐). #476 이음새 ③ 과 같은 일입니다.

답은 꼭 필요하지 않고, 위 셋 중 맡을 분이 있으면 알려 주세요.
