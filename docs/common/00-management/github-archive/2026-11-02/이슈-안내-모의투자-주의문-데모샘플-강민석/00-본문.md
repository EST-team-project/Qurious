# [안내] 모의투자 화면 3곳에 「가상 매매 기준 · 참고용 · 데모 데이터는 샘플」 주의문 한 줄을 더했습니다 (public/app.html · public/js/dashboard.js)

> 초안 — 이슈 번호 없음 · 게시 전. 작성 2026-11-02 (S193 · 할 일 ②-29 S17). 사용자 결정(11-02): 「데모 데이터 표시를 넣고, 화면/카드의 가장 아래에 둔다」 로 고쳤다.

## 무엇을 바꿨나

`public/app.html` 에 **HTML 한 줄씩 두 곳**, `public/js/dashboard.js`(내 파일)에 **상수 하나 + 한 줄**입니다.
`paper.js` · `robo.js` · 서버 · CSS 는 손대지 않았습니다.

| 화면 | 위치 | 더한 것 |
|---|---|---|
| `paper-dashboard` (모의투자 계좌 현황) | **화면의 맨 아래** — 「최근 체결」 카드 바로 뒤, `space-y-4` 의 마지막 자식 | `<p … data-paper-notice>` 한 줄 (KPI · 자산 추이 · 체결 전부가 가상 매매 기준이라 카드 안이 아니라 화면 끝에 둠) |
| `robo-decision` (AI 모의 투자 의사결정) | 「모의 투자 성과 분석」 카드의 **맨 아래** — `#robo-metrics-table` 의 형제(안이 아님. 안에 두면 `robo.js` 가 `innerHTML` 을 바꿀 때 지워짐) | `<p … data-paper-notice>` 한 줄 |
| 대시보드 「로보 모의계좌」 탭 (내 파일) | 탭 패널의 맨 아래 한 줄 (숫자가 보이는 경우에만) | 상수 `PAPER_NOTICE` 한 곳에서 그림 |

세 곳에 같은 글을 씁니다.

> 가상 매매 기준 · 실제 돈이 오가지 않는 참고용 결과이며 투자 권유가 아닙니다. 관리자가 시연용으로 만드는 데모 데이터는 임의로 만든 샘플이며 모의투자 결과가 아닙니다.

(처음엔 앞 문장만 「QFRS 성과 지표」 카드 아래 · 「모의 투자 성과 분석」 카드 위 · 「모의계좌 총 자산」 곁 note 에 두었다가, 위 표의 자리로 옮기고 데모 데이터 문장을 더했습니다.)

좁은 화면(390px)에서는 `text-xs` 그대로 두 줄 안팎으로 줄바꿈됩니다(`nowrap` 없음 · 전체가 단어 단위 줄바꿈).

## 왜

수익률 숫자 곁에 「이 숫자가 가상 매매 기준이다」 라는 말이 두 화면에 없었습니다
(대사 화면의 LEAN 안내 · 학습 화면 `NOTICE_LINE` 에는 이미 비슷한 말이 있습니다).
글은 코드로 확인한 사실만 썼습니다 — 성과 지표가 모의 계좌 스냅샷(`PaperAccountSnapshot`)에서 나온다는 것, 앱 약관의
「모의 계좌는 실제 돈이 오가지 않는다」 문구, 그리고 `POST /api/paper/performance/simulate`(관리자 전용 · 랜덤 워크 15일치 시연용)가 만드는 값은 임의 샘플이라는 것.
**수수료 · 세금 · 슬리피지 반영 여부는 일부러 쓰지 않았습니다**
(주식 모의 체결은 비용을 떼는 것을 확인했지만, 코인 · 대체자산 · 슬리피지는 확인하지 못해 한 줄로 단정할 수 없었습니다).

## 되돌리는 법

`public/app.html` 에서 `data-paper-notice` 가 든 `<p>` 두 줄을 지우고, `public/js/dashboard.js` 의 `PAPER_NOTICE` 상수와 마지막 조각(`data-paper-notice`) 한 줄을 지우면 됩니다. 다른 곳은 영향이 없습니다.

```
grep -n "data-paper-notice\|PAPER_NOTICE" public/app.html public/js/dashboard.js
```

## 의견을 구합니다 (강민석 님)

1. **`pd-backtest-card` 의 자리** — `paper.js` 1300행 `view.appendChild(card)` 가 100일 백테스트 카드를 `paper-dashboard` 뷰 **맨 끝**에 붙입니다.
   그래서 화면에서는 위 주의문 **아래**에 이 카드가 옵니다. 주의문이 정말 맨 아래가 되려면 이 카드를 주의문 앞에 끼워 주시면 됩니다
   (예: `const notice = view.querySelector('[data-paper-notice]'); notice ? notice.before(card) : view.appendChild(card);`). 한 줄입니다.
2. **「🧪 데모 데이터」 단추가 만든 값이 성과 화면에 안 나오는 것 같습니다** — 코드 읽기로 확인한 내용입니다(단추를 눌러 보지는 않았습니다).
   - `POST /api/paper/performance/simulate`(`app/routes/paper.py` 584행 · 관리자 전용)는 `PaperAccountSnapshot` 15행을 넣는데 `origin` · `completeness` 를
     정하지 않아 모델 기본값 `unknown` 으로 들어가고, `position_count=3` 인데 `price_metadata=[]` 입니다.
   - `valid_daily_row()`(`paper_snapshot_service.py` 209행)는 `complete` + `daily` + 가격 메타 일치만 통과시켜 이 행은 거짓입니다
     (DB 없이 같은 속성으로 만든 객체로 `valid_daily_row(…) == False` 를 확인). `get_robo_metrics` · `get_daily_returns` · 배분 추이 · 벤치마크가 이 행을 모두 거릅니다.
   - 반면 같은 호출은 그 계정의 **기존 스냅샷을 전부 지웁니다**(607행) — 진짜 일일 행도 함께입니다. 단추의 확인 창은 「기존 스냅샷을 지우고 15일치 데모 데이터를 생성합니다」 라고만 합니다.
   - 의도하신 동작인지 알려 주세요. 데모 값을 화면에서 보이게 하려는 거라면 데모 행을 `origin='simulation'` 으로 저장하고 조회가 따로 보이게 하는 방법이 있고,
     아니라면 확인 창에 「성과 지표에는 나타나지 않습니다」 를 더하는 방법이 있습니다.
   - 그래서 주의문의 데모 문장은 「화면에 채운 값은 샘플」 이 아니라 「데모 데이터는 임의 샘플이며 모의투자 결과가 아니다」 라고만 썼습니다(지금 코드에서 참인 말).
3. **데모 데이터를 쓰는 중일 때만 화면에 「데모 데이터」 배지를 띄우는 한 줄을 `robo.js` 에 넣어 주실 수 있나요?**
   `robo.js` · `paper.js` 는 강민석 님 파일이라 제가 직접 넣지 않았습니다. 다만 배지가 뜻을 가지려면 2번이 먼저 정리되어야 하고
   (데모 행이 화면에 보여야 함), 배지를 띄울 신호(예: `/api/paper/performance/metrics` 응답의 `demo: true`)가 서버에서 와야 합니다 — 2번 방향을 알려 주시면 맞춰 보겠습니다.
4. `paper.js` 가 그리는 KPI 카드(`pd-kpis` · 총 수익률 등)와 `robo.js` 가 그리는 성과 카드(`robo-metrics-*`) 숫자 **바로 곁**에도 같은 글을 쓰는 게 좋을까요?
   지금은 화면 · 카드 맨 아래 안내 줄에만 있습니다. JS 쪽 숫자 곁은 강민석 님 몫이라 손대지 않았습니다.
   하게 되면 같은 글을 그대로 쓰면 좋겠습니다(시험 `tests/test_s14_s17_copy.py` 가 세 곳의 글이 같은지 봅니다 — 글을 바꾸면 알려 주세요).
