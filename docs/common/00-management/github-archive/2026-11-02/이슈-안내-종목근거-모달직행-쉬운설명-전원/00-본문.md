# [안내] 「종목 근거」 입구가 서랍이 아니라 큰 모달로 바로 열립니다 · 모달 안 쉬운 설명 · 신호 근거 응답에 key 칸

@강민석 @오준영 @신장환 — 이동원이 종목 근거 화면(`public/js/stockdrawer.js` · `public/js/stockplain.js` · `public/css/stockdrawer.css`)을 고쳐서 알립니다. **여러분 화면의 단추 줄은 고치지 않았습니다.** 그런데 `data-hub-open` 단추의 동작이 바뀌어서(서랍 → 모달) 화면이 달라 보일 수 있습니다. 읽고 할 일은 3절뿐입니다.

## 1. 무엇이 바뀌었나

- **입구가 모두 큰 모달 직행입니다.** 퀀트 대시보드 신호 카드 · 신호 순위 · 자동매매 결과 · AI 상담 카드 · 리서치 종목 칩의 `data-hub-open` 단추가 옆 서랍이 아니라 가운데 큰 모달(큰 일봉 차트 + 근거 일곱 칸을 내리며 읽음)을 바로 엽니다. 사용자 피드백(11-02: 「처음부터 모달로 크게」)입니다. 서랍은 남겨 두었고, 서랍이 꼭 필요한 입구는 단추에 `data-hub-mode="drawer"` 를 달면 됩니다.
- **서랍에 있던 두 이동 단추를 모달로 옮겼습니다** — 「PAPER 모의주문으로 →」(오준영 님 PR #481 의 이동 · 수량 계산 연결을 그대로 씀) · 「리밸런싱 목표 편집으로 →」(PR #479). 종목 코드가 6자리일 때만 보입니다.
- **모달 안 쉬운 설명** — 칸마다 「이 칸 읽는 법」 한 줄, 신호 근거마다 「쉬운 뜻 · 조심할 점 · 규칙 점수」, 모달 머리 아래 시장 맥락 한 줄(수집 DB 지수 일봉 · 기준일), 맨 아래 「내 판단 정리 틀」(이미 보인 사실만 채운 글을 복사 · 목표가 · 손절가는 만들지 않고 비워 둠). 새 계산이나 한 줄 결론은 없습니다. 설계: Figma 「Qurious · 종목 허브」 10 쪽.
- **서버 응답에 칸 하나 추가(기존 칸은 그대로)** — `GET /api/stock-hub` 의 신호 칸 `reasons[]` · `counter_reasons[]` 항목에 규칙 이름 `key`(예 `ma_down` · `macd_up`)가 더해졌습니다. 화면이 쉬운 풀이를 찾는 열쇠이고, 모르는 `key` 면 서버 글만 보입니다.

## 2. 확인한 것 · 확인하지 못한 것

- 시험: TC-SDR-09(입구는 기본이 모달 · 팀 파일의 단추 줄은 그대로) · TC-SDR-10(읽는 법 · 쉬운 풀이 · 이동 단추 · 정리 틀) · TC-SDR-11(규칙 열한 가지가 서버 규칙표와 같음 · 금지 낱말 없음). 개발 앱(8966)에서 신호 카드를 눌러 모달이 바로 열리고 근거 다섯 줄 풀이 · 시장 맥락 · 글 복사가 되는 것을 직접 확인했습니다.
- 못 한 것: 신호 순위 · 자동매매 결과 · AI 상담 카드 · 리서치 칩 입구를 각각 눌러 보는 확인은 다 하지 못했습니다(모두 같은 `data-hub-open` 처리 한 곳을 지납니다). 390 폭은 신호 카드에서 열어 가로 넘침이 없고 이동 단추 둘이 보이는 것까지 확인했습니다. 신호 순위 화면은 아직 app.html 에 붙어 있지 않아 눌러 보지 못했습니다.

## 3. 요청

1. 위 화면의 담당이신 분은 **한 번씩 눌러 보시고** 서랍이 필요한 입구가 있으면 알려 주세요(그 단추에 `data-hub-mode="drawer"` 를 달거나, 이동원에게 말해 주세요).
2. PR #481 이 main 에 들어간 뒤 모달의 「PAPER 모의주문으로 →」가 오준영 님 수량 계산 화면으로 이어지는지 같이 확인해 주세요(이동원이 병합 뒤 확인합니다).

3. **오준영 님 — `tests/e2e/paper_flow.js`(PR #481)가 「신호 카드 → 서랍 → 크게 보기 → 서랍 다시 → PAPER 모의주문으로」 순서를 전제합니다.** 입구가 바로 모달로 열리게 바뀌어, 그 줄들(`#hub-drawer` 기다림 · `[data-hub-expand]` 클릭)이 맞지 않습니다. 이동원이 #481 을 받은 뒤 「카드 단추 클릭 → `#hub-modal [data-hub-go="paper-stock"]` 클릭」 으로 고치려 하는데, 이 시험은 실제 Chrome · 격리 DB 가 있어야 돌아 **이동원 쪽에서는 돌려 볼 수 없습니다.** 고친 줄은 한 번 돌려 확인해 주세요(또는 직접 고쳐 주셔도 됩니다).

답은 꼭 필요하지 않습니다.
