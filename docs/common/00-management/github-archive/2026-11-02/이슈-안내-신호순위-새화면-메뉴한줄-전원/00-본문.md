# [안내] 로보 어드바이저 메뉴에 「신호 순위」 새 화면을 더합니다 · 공용 파일 세 곳에 한 줄씩 · 순위 응답 줄에 이름 칸

@GoonGuMa @janghwan-god @rkdalstjr — 이동원이 신호 순위 화면을 새 화면으로 붙이려고 공용 파일을 고쳐서 먼저 알립니다. 여러분 화면 · 서버 로직은 고치지 않았습니다. 읽고 할 일은 3절뿐입니다.

## 1. 무엇이 바뀌나

- **메뉴**: 로보 어드바이저의 「패턴 인식·종목 스크리닝」 바로 아래에 **「신호 순위」** 가 한 줄 늘어납니다(화면 키 `signal-rank`). 기록된 규칙 신호(매수 쪽 · 중립 · 매도 쪽)를 종목 전체(약 3,950종목)에서 종합 점수 순으로 보여 주고, 종목을 누르면 오른쪽에 서랍(신호 기준 종가 · 지금 가격 · 근거)이 겹쳐 열립니다. 새로 계산하지 않고 `GET /api/stock-hub/signal-rank` 가 읽는 기록을 그대로 그립니다.
- **자리 결정**: 처음에는 「스크리닝에 탭을 더하기」(안 B)로 제안했는데, 순위 대상이 401종목에서 약 3,950종목으로 늘어 「종목 전체를 훑는 화면」 에 가까워져 **새 화면(안 A)** 으로 정했습니다. 두 안을 나란히 그린 Figma(보기만): https://www.figma.com/design/t2BVPRrfnaJI3yfcymkeEq
- **공용 파일에 한 줄씩**:
  - `public/js/core.js` — `GNB_MENUS.agent.items` 에 항목 한 줄 + `VIEW_GUIDES` 에 안내 글 한 줄
  - `public/app.html` — `data-view="signal-rank"` 화면 칸 하나(`#sr-root`) + CSS 링크 한 줄
  - `public/js/main.js` — `import` 한 줄 + `if (view === "signal-rank") onSignalRankViewActivated();` 한 줄
  - 새 파일 `public/js/signalrankview.js` · `public/css/signalrankview.css` (판단 · 그리기는 기존 `public/js/signal-rank.js` 를 그대로 씁니다)
- **서버 — 신장환 님 파일**: `app/services/stock_hub.py` 에 함수 `attach_names` 를 **따로** 더했고 `app/routes/stock_hub.py` 의 `signal-rank` 라우트 끝에 한 줄(`return stock_hub.attach_names(out)`)을 붙였습니다. 순위 줄마다 종목 이름을 한 번의 읽기 연결로 붙이는 것이고, **새 칸 `rows[].name` 하나만 더해집니다(기존 칸 · 순서 · 값은 그대로)**. `signal_rank` 함수 본문은 건드리지 않았습니다 — #487 에서 신장환 님이 `load_day` 읽는 양을 줄이며 고치실 부분과 겹치지 않게 하려고요.
- `signal_explain` · `stock_hub` 의 `_universe()` 는 그대로입니다(#487 03 에서 신장환 님이 대상 목록 기준으로 맞추시기로 한 것 — 대상 목록 `targets` 는 앱이 부를 수 있는 `app/services/signal_targets.py` 로 옮겨 두었습니다).

## 2. 왜 먼저 알리나

메뉴 항목이 늘면 화면 수와 IA · UI 명세서 숫자가 바뀌고, 세 공용 파일은 여러분 PR 과 같은 줄에서 겹칠 수 있습니다. 모두 **한 줄 추가**라서 겹치면 3-way 로 쉽게 합쳐지지만, PR 을 만들기 전에 알립니다.
