## 댓글 본문

@rkdalstjr 강민석 님, 이 글 본문이 「시작 금액이 아직 한 값이 아니다 — 비교 API 기본값 10,000」 이라고 적었는데 **고쳤습니다**(2026-10-29).

- `POST /api/tradingview/compare` 의 `initial_cash` 기본값을 **10,000 → 10,000,000** 으로 바꿨고, 화면의 초기 자금 칸과 스크립트의 빈 값 대체도 같은 값입니다. 이제 TradingView(Pine 설정 1,000만 원 — #335 답) · LEAN 정산(`daily_lean_reconcile.py`) · 모의(`auto_trade`)와 같은 1,000만 원입니다.
- 비교 응답의 `reconcile_table.header.engine_settings` 에 세 엔진의 시작 금액 · 통화 · 비용(수수료+세금 왕복 · 슬리피지)이 한 표로 실리고 어긋난 항목은 `mismatches` 로 나옵니다. 대사표 자체(줄 단위 · 원인 코드)는 `compare_fills` 를 건드리지 않고 새 키로 붙였습니다.
- 허용 오차 숫자는 코드에 넣지 않았습니다(요청 칸 `tolerance` 로 받고, 없으면 「기록만」). 사전등록 기준의 최종 판은 강민석 님 PR 로 확인한다는 10-27 정리 그대로입니다.
