1. **`app/services/signal_explain.py`** — 순위 화면이 부를 함수 둘.
   - `load_day(session, on=None, symbols=None)` — 지금 정의 판에서 종목마다 `on` 이전(포함) 가장 최근 줄. 허브가 한 종목을 읽는 `load_snapshot` 과 같은 규칙이라 허브와 순위가 같은 값을 보입니다. 정렬은 종합 점수 → 신뢰도 → 종목코드(내림 · 내림 · 오름). `symbols` 를 주면 그 종목만 보고, 줄이 하나도 없는 종목은 `missing` 에 허브와 같은 두 갈래(`not_universe` 매일 기록하는 종목 밖 · `none` 기록 없음)로 돌려줍니다 — 안내 문장은 허브의 것을 쓰시면 됩니다.
   - `side_counts(snapshot)` — 설명 창 근거 표의 줄마다 기여도 부호를 세어 `buy` · `neutral` · `sell` 개수와 `components`(강사님 퀀트 대시보드 근거별 점수의 `reason` · `points` 에 `timeframe` · `contribution` 을 더한 꼴)를 돌려줍니다. 순위 표의 「매수 쪽 근거 n개」 와 설명 창 근거 표가 같은 수를 말합니다.
