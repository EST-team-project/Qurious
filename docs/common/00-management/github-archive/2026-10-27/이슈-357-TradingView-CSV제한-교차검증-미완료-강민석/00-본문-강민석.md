# [P02-④-3] TradingView 무료 플랜의 CSV 제한에 따른 실제 교차검증 미완료 및 후속 조치

## 배경

P02-④-3 TradingView ↔ LEAN 교차검증을 진행하고 있으나, 현재 사용 중인 TradingView 무료 Basic 플랜에서는 차트 데이터 CSV 내보내기를 사용할 수 없어 동일 조건의 실제 TradingView 데이터를 확보하지 못했습니다.

공식 안내:
- 요금제 및 기능 비교: https://www.tradingview.com/pricing/
- 차트 데이터 CSV 내보내기 방법: https://www.tradingview.com/support/solutions/43000537255-how-to-export-chart-data/

이는 비교 코드의 오류가 아니라 실제 검증 입력 데이터를 확보하지 못한 제약입니다.

## 완료한 항목

- TradingView 거래 목록 CSV 파서 개선
- LEAN 체결 이벤트 추출 및 신호 데이터 반환
- 신호 발생 비교와 체결 비교 분리
- 체결 날짜·방향·가격 차이 비교 기능 구현
- 관련 테스트 51건 통과
- 관련 Python 컴파일 검사 및 `git diff --check` 통과

위 결과는 기능 및 테스트 검증 결과이며, 두 엔진의 실제 결과가 일치한다는 의미는 아닙니다.

## 미완료 항목

- 동일 종목·기간·전략 조건의 실제 TradingView CSV와 LEAN 결과 비교
- 실제 신호 일치율 및 체결 날짜·방향·가격 차이 산출
- 실제 비교 결과에 기반한 수익률·MDD·Sharpe 등 성과지표 차이 및 불일치 원인 분석

## 후속 조치

1. CSV 내보내기가 가능한 팀원에게 동일 조건의 TradingView 차트 데이터 또는 전략 체결 내역 CSV 제공을 요청합니다.
2. 데이터를 확보하면 LEAN 결과와 비교하고, 종목·기간·전략 조건·비용 가정·비교 결과를 기록합니다.
3. 데이터를 확보하지 못한 동안은 기능 테스트 결과와 실제 데이터 교차검증 결과를 명확히 구분합니다.
4. 실제 비교가 끝나기 전까지 TradingView와 LEAN이 일치한다고 판정하지 않습니다.

## 완료 기준

- 실제 TradingView CSV를 이용한 비교 결과 또는 데이터 확보 실패 사유가 기록되어 있을 것
- 신호 비교와 체결 비교 결과가 구분되어 있을 것
- 성과 차이를 검증하지 못한 경우 그 사실과 제한사항을 명시할 것
