## 무엇을
1. **거래 0회 (#245):** 성과 검증 · 커스텀 인디케이터 모두 `trade_count` 가 0 이면 수익률 · 샤프 · 최대 낙폭 · 승률 카드 대신 대시보드와 같은 「신호 없음 — 이 기간에 한 번도 사고팔지 않아 … 같은 기간 매수 후 보유 수익률은 N% 입니다」 를 보입니다. 성과 검증 표의 수익률 · 승률 칸은 「-」, 「비교에 추가」 요약은 「거래 0회 · 신호 없음 · 매수 후 보유 N%」 입니다.
2. **계산 종목 (#245):** 커스텀 인디케이터 결과 위에 「계산 종목: 삼성전자(005930) — 성과 검증 화면에서 고른 종목」 한 줄을 넣었습니다.
3. **자료 줄 (#250):** 두 화면 결과 아래에 응답의 `data_note` 를 「자료: 수집 DB 일봉(수정주가) · 2020-01-02 ~ 2026-10-15 종가」 처럼 그대로 보입니다(전략 분석과 같은 꼴).
4. **부제 (#250):** 성과 검증 부제 「… 10년 성과를 검증합니다」 를 「… 성과를 최근 10년 안의 일봉으로 검증합니다. 실제 자료 기간은 결과의 『자료』 줄에 적힙니다.」 로 바꿨습니다.
5. **「🧠 설명」 창 (#269):** 머리는 「5일 수익률 예측(회귀 · 모델 이름) n%」, 본문은 「방향 판단(LightGBM 분류 · …) — 아래 배지의 확률과 SHAP 기여도가 이 판단의 것입니다」 로 나눴습니다. 두 모델을 반반 섞은 `confidence`(「신뢰도」)는 머리에서 뺐고, 배지 아래에 「배지의 % 는 모델의 분류 확률이며 실제 수익이 날 확률은 아닙니다」 한 줄을 넣었습니다(#274 와 같은 말). 이 한 줄은 `renderXaiBlock` 의 선택 인자 `probNote`(기본 꺼짐)로 넣어, 자산배분 카드의 같은 블록은 그대로입니다.

서버(`app/`)는 바꾸지 않았습니다. 성과 계산 · 모델 · 응답 꼴 모두 그대로입니다.
