## 무엇이 보이나

종목 줄의 「🧠 설명」 을 누르면 열리는 「AI 판단 근거」 칸에 모델 이름이 두 개 나옵니다.

| 자리 | 화면 글 | 어디서 오나 |
|---|---|---|
| 칸 머리 오른쪽 | 「5일 예측 n% · 모델 GradientBoosting · 신뢰도 n」 | 응답 `prediction.model` — `app/services/investment_research.py` 의 수익률 **회귀**(`GradientBoostingRegressor`) |
| 칸 본문 첫 줄 | 「판단 = 학습 모델(LightGBM · 2년 일봉으로 5거래일 뒤 방향을 예측 …)」 | 화면 글(`public/js/robo.js` 「🧠 설명」 칸) |
| SHAP 기여도 | LightGBM 분류의 기여도(TreeSHAP) | 응답 `explanation` |

같은 응답(`GET /api/ml/explain`)이 **수익률을 맞히는 회귀 모델**과 **방향을 가르는 분류 모델**의 결과를 함께 돌려주는데, 화면에는 둘이 다른 모델이라는 구분 없이 붙어 있어 「이 판단은 GradientBoosting 인가 LightGBM 인가」 로 읽힙니다. 발표 영상에 이 칸이 나와 질문을 받을 수 있습니다.

## 제안 (정하는 것은 주담당)

- 머리 글을 둘로 나눠 이름을 붙입니다 — 예: 「5일 수익률 예측(GradientBoosting 회귀) n%」 · 「방향 판단 근거(LightGBM 분류 · SHAP)」.
- 또는 한 칸에 한 모델만 보이고, 다른 하나는 접힌 줄로 둡니다.
- 서버 응답 꼴(`prediction` · `explanation`)은 그대로 두고 화면 글만 바꿔도 됩니다.
