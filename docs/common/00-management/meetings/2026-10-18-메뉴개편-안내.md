--- 메시지 1 ---

[안내] 위 메뉴가 「고정 탭 여섯 + 왼쪽 전체 메뉴 트리」 로 바뀝니다 — 이동원

- 바뀐 것: 위 탭은 늘 보이는 여섯(로보 어드바이저 · 투자 인디케이터 · 모의투자 · 퀀트자동매매 · 학습 · 데이터)만 둡니다. 폭이 좁아져도 탭을 하나씩 숨기지 않고, 다 안 들어가면 탭 줄을 통째로 접습니다. 「더보기 N ▾」 와 오른쪽 서랍 「전체 메뉴」 는 없어집니다.
- 왼쪽: 지금 묶음만 보이던 왼쪽 메뉴가 묶음 13개 · 메뉴 74개(앱 화면 70 · 새 창 링크 4)를 모두 담은 「전체 메뉴」 트리가 됩니다. 지금 묶음만 펼치고, 다른 묶음은 눌러 펼칩니다. 긴 이름은 자르지 않고 두 줄로 접고, 넓은 화면(1920)에서는 트리가 288px 까지 넓어집니다.
- 「학습」 탭 = 금융 필수 지식(누르면 강의실) + 개념 학습(트리 바로 아래 묶음). 이름은 증권 · 투자 서비스들이 위 메뉴에 두는 「Learn」 을 우리말 명사로 옮긴 것입니다.
- 좁은 화면(768 아래): ☰ 가 같은 트리를 왼쪽에서 엽니다(바깥 누름 · Esc · 메뉴 고름이면 닫힘).
- 그대로인 것: 화면 키(#agent-chat 같은 주소) · 각자의 화면 파일 · 서버는 그대로입니다. 메뉴 셸(app.html 머리 · core.js 메뉴 · gnbmore.js · qurious.css)만 바뀝니다.
- 글자 대비: 지금 탭 · 지금 항목 파란 글, 트리 소제목 회색, 「전체 메뉴」 제목 주황을 조금 진하게 했습니다(대비 4.5 기준).
- 부탁 1: UI 명세서의 「들어가는 길」 이 「위 메뉴 › …」 · 「더보기 › …」 로 적힌 화면은 「왼쪽 전체 메뉴 › 묶음 › 화면」 으로 바뀝니다 — 이번 PR 에서 함께 고칩니다. 다르게 적고 싶은 곳이 있으면 알려 주세요.
- 부탁 2: 시연 영상 일곱은 머리 · 왼쪽 메뉴가 모든 장면에 보여 새 메뉴로 다시 찍습니다(10-19 장중 · 이동원). 자기 영상을 직접 다시 찍을 분은 장면 파일(docs/발표/영상/장면/)을 그대로 쓰면 됩니다.
- 반대하시거나 고칠 점이 있으면 이 글에 답 주세요 — 머지 전이면 그대로 반영합니다.
