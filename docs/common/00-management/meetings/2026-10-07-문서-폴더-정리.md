--- 메시지 1 ---

**docs 폴더를 종류별로 정리했어요 — 머지 뒤 git pull 한 번 부탁드려요**

문서마다 판 파일이 쌓여 찾기 어려워서(테스트 계획서 16판 · RTM 13판 · 시험 폴더 한 곳에 32파일) 정리했어요. 종류 폴더 맨 위 파일이 166개 → 52개예요.

- **문서마다 이름 하나** — `테스트계획서.md` 처럼 판 번호 없는 이름이 늘 최신이에요(판은 머리표에).
- **지난 판은 `지난판/`** — `지난판/테스트계획서_v1.14.md` 처럼 그대로 남아요.
- **표 대장은 `대장/`, 평가셋은 `시험/평가셋/`, docx 는 `계획서/내보내기/`**, 문서 작성 기준 · 그림 지침은 `docs/문서기준/` 이에요.
- **판을 올릴 때** — `python scripts/docs_scan.py --bump docs/<종류>/<이름>.md` 로 지금 판을 지난판에 사본으로 남기고, 같은 파일을 고쳐 머리표 판을 올려 주세요. 손으로 복사하면 사본 속 링크가 한 단계씩 어긋나요. 다른 문서의 링크는 고치지 않아도 돼요.
- 링크 · 스크립트 · 시험 속 경로는 함께 고쳤어요. GitHub 에 이미 올린 글 속 옛 주소는 열리지 않을 수 있으니 `docs/README.md` 의 「옮긴 자리」 표에서 찾아 주세요.
- 본인 문서: 신장환 님 `설계/목표기능2-패턴예측-XAI-설계.md`(v0.1 은 지난판/) · 오준영 님 `설계/목표기능3-리밸런싱-설계.md`.
- docs 를 고치는 브랜치가 있으면 main 을 받아 합치면 git 이 이름 바꿈을 따라가요. 겹치면 말씀해 주세요.
