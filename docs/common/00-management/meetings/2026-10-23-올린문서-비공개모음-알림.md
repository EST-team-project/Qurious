AI 투자 상담에서 올린 문서가 **다른 사람의 채팅 근거 · 문서 검색에 그대로 나오고, 탈퇴해도 조각이 남아 계속 보이던** 결함(DF-146)을 고쳤습니다. 일회용 계정 둘로 재현 · 확인했습니다.

**바뀐 것**
- 올린 문서 조각은 사람마다 따로 보이는 비공개 모음(`user_docs`)에만 들어갑니다. 채팅 근거는 「공용 크롤 조각 + 내가 올린 문서」 만 씁니다.
- 탈퇴 · 문서 지우기는 조각부터 지우고, 못 지우면 멈추고 「잠시 뒤 다시」 를 알립니다.
- 그래프 API(`/api/graph/*`)는 이제 로그인해야 하고, 그래프 다시 채우기(`/seed`)는 관리자만 됩니다.

**부탁 하나** — 각자 PC 의 벡터 DB 에 예전에 올린 문서가 남아 있을 수 있습니다. pull 뒤 앱이 다시 뜨면 한 번만 확인해 주세요.
```
docker exec fin-ai-app python -m app.services.user_docs migrate
```
`"found": 0` 이면 할 일 없습니다. 0 이 아니면 `--apply` 를 붙여 한 번 더 돌리면, 지금 있는 계정의 문서는 비공개 모음으로 옮기고 탈퇴한 계정의 조각은 지웁니다.

**알아 두실 것** — 이 고침의 시험(TC-DI · 채팅 · RAG 저장)은 호스트 파이썬에 벡터 DB 라이브러리가 없어 `test.ps1` 에서 건너뜁니다. 앱 이미지 컨테이너로 돌리는 명령은 테스트 계획서 TC-DI 줄에 있습니다.
