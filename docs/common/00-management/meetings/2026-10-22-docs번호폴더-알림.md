📁 **docs 폴더 번호 매김 — PR 머지됨**

강사님 피드백(「일반인은 업무 순서를 모르니 폴더에 번호를 · 분석 · 설계 · 테스트 밖은 합쳐 7 ~ 8개로」)에 따라 docs 를 다시 묶었습니다.

**새 모양**
- `docs/phase-3/` — 3차에 고치는 문서(판을 여기서 이어 올림)
- `docs/phase-2/` — 2차 최종 판(얼림)
- `docs/common/` — 회의 · github-archive · ADR · TIL · 영상 같은 기록

각 폴더 안은 같은 번호입니다.
`00-management`(계획서 · 문서 기준) · `01-analysis`(요구사항 · 조사) · `02-design`(설계 · 데이터 · 화면 · API) · `03-development`(코딩 표준 · 수집 안내) · `04-testing`(시험) · `05-deployment`(배포) · `06-retrospective`(발표 · 영상 · TIL)

**부탁 셋**
1. pull 한 번 받아 주세요 — git 이 파일을 새 자리로 옮깁니다.
2. 새 문서는 새 자리에 만들어 주세요. 예: 오준영 님 설계 → `docs/phase-3/02-design/system/`, 테스트 계획서 → `docs/phase-3/04-testing/`. 옛 자리(`docs/3차/…`)에 두면 `python scripts/docs_scan.py --check` 가 알려 줍니다.
3. 열린 브랜치에서 옛 자리 문서를 고치고 계셨다면 대개 그대로 합쳐지지만, 머지가 막히면 알려 주세요.

옛 주소 → 새 주소 표: `docs/README.md` 7절
