## 배운 것

- **완성된 화면 이미지를 통째로 올리지 않고 `generate_figma_design` 으로 캡처해 보관한다.** 이미지 한 장은 Figma 안에서 글자 · 칸이 하나도 안 잡히지만, 캡처는 편집 가능한 레이어로 들어온다. 같은 화면을 다시 찍지 않게 **화면마다 파일**을 따로 두었다(00 표지 + 01 지금 화면 · 폭 1920). 한 파일에 묶자는 처음 제안은 사용자 피드백으로 철회했다.
- **옛 판의 화면은 그 태그 코드를 풀어 별도 포트에 띄워 찍는다.** `git archive` 로 2차 태그(`phase2-final-2026-10-21`)를 따로 푼 폴더에 두고 8967 포트로 띄우되, 화면 마크업 · 스크립트는 태그 것을 쓰고 `/api` 요청만 개발 앱으로 넘겼다. 작업 트리를 `git checkout` 으로 되돌리지 않아도 「그때 화면」 이 나오고, 지금 코드와 섞이지 않는다.
- **소급 절에서는 「화면에 있지만 동작하지 않는 칸」 을 코드로 찾는다.** 2차 기본 인디케이터 전략 화면의 체크박스 여섯 가운데 MA 60 · MACD · 볼린저 셋은 `indicator.js` 가 읽지 않아 눌러도 결과가 안 바뀌고(`useMA5` · `useMA20` · `useRsi` 만 읽음), 표의 볼린저 줄은 실제 밴드가 아니라 당일 등락 ±2 % 로 가른 대용값(`chgPct>2`)이었다. 화면만 보면 칸이 다 일하는 것처럼 보인다 — 3차의 「여섯 모두 읽는다」 와 「실제 밴드」 가 왜 의미 있는 변화인지는 이 둘을 적어 두어야 보인다. 신장환 님의 의도였는지는 확인하지 않았다.
- **서버 값이 섞이는 화면 문장은 지금 서버가 아니라 태그 시점의 서버 코드로 확인한다.** 커스텀 인디케이터의 비용 라벨 「왕복 대칭 15bp (실제 국내주식 비용이 아니다)」 는 서버 응답(`cost.label`)이 만드는 글이다. 2차 소급 절에 쓰기 전에 태그의 `trading_cost.py` 에서 같은 문구가 있는지 확인했다.
- **장식 움직임은 접근성과 한 쌍이다.** 움직임 줄이기 설정에서는 인트로를 건너뛰고 모든 애니메이션을 끄되 **차트 선은 다 그려진 채** 남겨야 한다(숨겨 두었다가 애니메이션으로 드러내는 방식이면 움직임을 끈 사람에게는 선이 아예 없다). 또 장식 차트에 글자 · 숫자를 넣지 않는다는 시험을 따로 둔다 — 시세처럼 읽히는 숫자 흉내는 「실시간」 금지 · 약관 문구와 부딪힌다.
- **시험 「번호」 와 「건수」 는 다른 숫자다.** 변경 노트에 「TC-QUAL 6 → 8」 이라 적었지만 스캐너(`rtm_scan --json`)가 센 `test_data_quality.py` 는 7 → 9 였다. 번호는 01 ~ 06 → 01 ~ 08 이고, TC-QUAL-05 와 05b 가 함께 있어 건수가 하나 더 많다. 판에 적는 숫자는 번호가 아니라 스캐너가 센 건수로 한다.
- **2차를 얼린 규칙과 소급 절은 어긋난다.** docs README 3.3절은 2차 문서를 「바로잡기만」 허용하고 판을 올리지 않게 하는데, 소급 16장은 새 절이다. `docs_scan --bump` 도 2차에는 얼린 자리라는 경고를 낸다. 사용자 결정(10-29)에 따라 v0.29 → v0.30 으로 올리고 개정 이력에 어긋남을 밝혔다. README 에 예외를 더할지는 사용자 결정 거리로 남겼다.
