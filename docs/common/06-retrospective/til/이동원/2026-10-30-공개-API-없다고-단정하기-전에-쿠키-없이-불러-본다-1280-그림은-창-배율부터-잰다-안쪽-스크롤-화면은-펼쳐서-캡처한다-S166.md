## 배운 것

- **「공개 API 가 없다」 고 적기 전에 쿠키 없이 불러 본다.** S165 에 지수 티커를 보류한 까닭으로 「공개 지수 API 가 없음」 을 적었는데, `GET /api/stocks/market` 은 로그인 없이 `200` 이다(API 명세서 인증 칸도 「없음」). 정말 걸리는 것은 API 가 아니라 **원천의 이용 조건**이었다 — 그 API 의 값은 야후(수집 원천으로는 닫고 앱은 참조를 늘리지 않기로 봉인한 출처 — 「수집에만 배제」 라는 기억도 절반만 맞았다)였고, 대안인 수집 DB 지수 일봉은 공공누리 제4유형(출처 표시 · 비상업 · 변경 금지)이다. 근거가 되는 한 줄은 쿠키 없는 `curl` 한 번이었고, 이 한 번으로 팀원 이슈 초안이 이동원 몫 판단 메모로 바뀌었다.
- **1280 폭 그림은 창 배율부터 잰다.** 이 PC 의 Playwright 창은 화면 배율(`devicePixelRatio`)이 0.667 로 고정돼 CSS 폭이 1920 이었다(`setViewportSize` · CDP 덮어쓰기 모두 듣지 않음). 번호 그림은 배율 1 로 1280 × 700 이 되는 chrome-devtools 브라우저로 찍었고, Figma 캡처는 1920 폭 그대로 두었다. 같은 도구에서 폭이 안 맞으면 도구를 바꾸는 편이 빠르다.
- **안쪽 스크롤 화면은 펼쳐서 캡처한다.** 앱의 `#main-content` 는 `overflow: auto` 라 첫 캡처가 창 높이(1050)에서 잘렸다. `#main-content` · `#app-wrapper` · `#app-shell` 의 높이를 `auto` · `overflow: visible` 로 풀고 다시 캡처하자 전체(1362)가 들어왔다. 문서용 번호 그림도 같은 방법으로 찍었다.
- **「눈에는 안 보이지만 키보드로는 닿는」 막대는 투명 + `pointer-events: none` + `:focus-within` 이다.** `display: none` 은 키보드 사용자에게서 건너뛰기를 빼앗는다. 다만 건너뛰기에 미리 초점을 두면 숨긴 막대가 나타나므로 미리 초점 주기는 걷었다.
- **「이 탭에서 한 번만」 은 개발 · 시연에서 불편하다.** 인트로를 다시 보려고 탭을 닫아야 했다. 상태 저장(`sessionStorage`)을 읽는 곳 · 쓰는 곳 둘 다 걷고, 시험은 「저장하지도 읽지도 않는다」 로 바꿨다.
- **도구 메모를 먼저 읽는다.** 학원 PC 는 앱을 `-NoCelery` 로 켠다(자동매매 겹침 방지). 이번에 빼먹어 beat 가 30초 떠 있었다(작업 수신 없음 · 바로 중지).
- **CRLF 파일의 여러 줄 패치는 줄 끝을 맞춘다.** 시험 파일 전체가 CRLF 라 `\n` 으로 적은 여러 줄 닻이 0번 맞았다. 패치 스크립트에서 닻과 바꿀 글의 `\n` 을 파일의 줄 끝으로 바꾼 뒤 찾는다(한 줄 닻은 영향이 없어 처음엔 눈치채지 못했다).
