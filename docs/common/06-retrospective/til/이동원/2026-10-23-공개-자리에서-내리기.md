## 한 일

- 학습의 한 갈래와 그 장 8편 · 그림 13장을 공개 자리에서 내렸다. 화면 키 · 메뉴 · 서버의 섹션 값 · 차례 꼴 · 시험 셋이 한 갈래에 엮여 있어 **낱말 하나로 전수(grep)한 뒤** 파일마다 닻이 정확히 한 번인 곳만 바꾸는 도구로 고쳤다.
- 지운 것이 다시 들어오지 않게 **지킴이 단언**을 넣었다 — 지운 화면 키가 메뉴 · html 에 없고, 옛 차례 꼴을 서버가 거부한다. 장 수(72 → 64)도 시험이 센다.
- 기초 코드 지킴이를 넓혔다. 강사님 판에서 메뉴 묶음이 충돌 표시 없이 지워지는 일이 세 번(직접매매 · 미국주식 · 크롤링) 이어져, 지킬 메뉴 키를 묶음째 넣고 html 넷에 글자 줄이기 스크립트가 없는지도 본다. **강사님 판으로 돌려 깨지는 것까지** 확인했다.

## 배운 것

- **지우기는 「찾기 → 보관 → 지우기 → 막기」 순서.** 보관은 git 밖(무시 목록)에 두고, 마지막에 시험이 그 자리를 지킨다. 막기가 없으면 다음 병합에서 조용히 돌아온다.
- **이력은 고치지 않았다.** 팀 공용 저장소라 강제 push 는 팀원 사본을 깨고, 계정 위험도 크다 — 앞으로 공개 자리에 없게 하는 것까지가 이번 몫이다.
- **닻이 두 번 나오면 멈추는 도구가 맞다.** 개정 이력 줄과 「최근 개정」 칸에 같은 글이 들어가 두 곳이 되자 도구가 멈췄다 — 둘 다 바꿀 곳이었지만, 멈추지 않았다면 한쪽만 바뀐 채 지나갔을 것이다.
