## 배운 것

- **합계는 세 덩어리가 맞아떨어질 때까지 센다.** 표 5 합 3,322 + 대장에 없는 파일 171 + 컨테이너 50 = 전체 시험 3,543. 한 번에 3건이 모자랐을 때 어느 줄이 빠졌는지 찾으면 표 밖 파일이 보인다.
- **`--assign` 은 새 ID 가 없어도 파일을 다시 쓴다.** 줄끝이 LF 로 바뀌어 전체가 바뀐 것처럼 보였다. 실행 뒤 `git diff --numstat` 로 확인하고 CRLF 로 되돌렸다.
- **새 테스트가 첫 실행에 통과하면 일부러 틀려 본다.** 요약 숫자를 99 로 바꾸자 카드 글의 `41 / 110` 이 사라져 시험이 실패할 것을 확인했다.
- **전체 시험의 실패는 환경과 코드로 가른다.** 12건 중 5건은 UTF-8 모드에서 통과하는 cp949 문제였다.
- **긴 표 칸은 읽는 사람에게 부담이다.** 사용자 피드백(10-31)에 따라 새 줄은 한두 문장으로 쓰고 세부는 변경 노트로 뺐다.
