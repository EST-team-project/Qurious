## 1. 무엇을 했나

- docs 를 업무 순서 번호 폴더로 옮겼다. 뿌리는 `common` · `phase-2`(2차 얼림) · `phase-3` 이고, 그 아래가 `00-management` ~ `06-retrospective` 일곱 묶음이다. 여러 종류를 합친 묶음은 옛 종류를 하위 폴더로 뒀다(예: `02-design/` 아래 `system` · `data` · `ui` · `api`).
- 옮김 1,676 · 고친 파일 594 · 링크 7,491 · 글 속 경로 459 · 절대 주소 31 · 코드 속 경로 조각 37. 사본 리허설에서 새로 깨진 링크는 0 이었고, 작업 트리에 적용한 결과는 사본과 2,074 파일이 바이트까지 같았다.
- `docs_scan.py` 의 종류를 「차수 폴더 바로 아래 한 칸」 에서 「번호 폴더 기준 경로 한두 칸」(`04-testing` · `02-design/ui`)으로 바꾸고, 옛 차수 이름(`docs/2차` · `docs/3차`)에 문서가 남으면 잡게 했다. 시험 TC-DV-10 을 더했고, 깨 보기 둘(종류 깊이 · 옛 차수 이름 검사)은 모두 시험이 잡았다.

## 2. 왜 했나

- 강사님 피드백(2026-10-22): 처음 보는 사람은 업무 순서를 모르니 폴더에 번호를 매기고, 분석 · 설계 · 테스트 밖의 자료 성격은 합쳐 7 ~ 8개로 줄일 것.
- 사용자 결정: 일곱 묶음(안 A · 합친 곳은 하위 폴더) · 이름은 실무에서 가장 많이 쓰는 꼴 · 뿌리 기록 폴더까지 전부.

## 3. 배운 것

- **이름은 관행에서 고른다.** Google 개발자 문서 스타일 가이드의 파일 이름 규칙(소문자 · 하이픈 · ASCII), 대학 연구 자료 관리 지침의 0 채운 번호(`01` · `02` 가 글자 순서로도 바로 선다), macOS 의 한글 이름 정규화 문제(NFD · NFC — 같은 글자가 다른 바이트 경로가 된다)를 근거로 삼았다. 영어는 번호 폴더와 바로 아래 종류까지만 쓰고, 지난판 · 대장 같은 더 아래 폴더와 파일 이름은 그대로 뒀다.
- **옮기기는 도구로 한다.** 링크는 옛 자리로 풀어 새 자리로 다시 쓴다. 손으로 옮기면 1,676 개 가운데 어디서 틀렸는지 알 길이 없다. 같은 도구를 다시 돌려 0곳이 나오면 끝난 것으로 본다(멱등성).
- **사본 리허설 → 적용 → 바이트 대조.** 첫 리허설에서 「새로 깨진 링크」 둘이 잡혔는데, 원래 깨져 있던 지난판 링크의 글자만 바뀐 것이었다. 지난판 · 얼린 2차 · 기록은 그때 쓴 글이라 글 속 경로는 그대로 두고 링크만 고치게 도구를 고쳤다.
- **리허설 사본은 경로가 길다.** 사본을 스크래치 폴더에 두니 Windows 의 260자 한도를 넘는 경로가 생겨 긴 경로 접두사(`\\?\`)로 다뤘다. 저장소 안 새 경로는 가장 긴 것이 119자다.
- **무거운 리허설은 단계로 쪼갠다.** 한 번에 돌리면 끊길 때 처음부터 다시 해야 한다. 사용자 요청대로 단계마다 상태 파일을 남기고, 끊기면 그 단계부터 이어 돌게 했다.
- **git 은 이름 바꿈을 1,000 개까지만 찾는다**(`diff.renameLimit` 기본값). 넘으면 지운 파일 + 새 파일로 보인다. 커밋 스크립트는 한도를 5,000 으로 올려서 본다.
- **무시 파일은 두 겹으로 막는다.** 역량지도처럼 커밋하지 않는 파일은 `.gitignore` 에 새 자리 줄을 더하고, 그 줄이 main 에 들어가기 전까지는 `.git/info/exclude` 로 막는다.
- **종류는 이름 목록이 아니라 경로 조각으로 본다.** 차수 폴더와 파일 이름 사이를 이어 붙여 목록과 견주면, 한 칸 종류와 두 칸 종류를 한 규칙으로 읽는다.

## 4. 막힌 것 · 남은 것

- 세션이 두 번 끊겼다. 무거운 배경 에이전트와 큰 문서 편집의 편집기 진단이 겹쳤다 — 큰 md 는 파이썬 패치로 고치고, 배경 일은 하나씩 돌렸다.
- 셸 heredoc 이 백슬래시를 줄이는 함정이 다시 나왔다. 백슬래시 · 백틱이 든 스크립트는 파일로 써서 돌린다.
- 전체 시험(79차)에서 TC-VX-09 가 실패했다. 덱 영상 주소 앞머리를 글자(`../../영상/파일/발표/`)로 들고 있던 단언이라, 도구의 코드 경로 찾기가 놓친 것을 전체 시험이 잡았다. 새 자리(`../../common/06-retrospective/videos/파일/발표/`)로 고치고 그 파일 등 30건을 다시 돌려 통과했다.
- 머지 뒤 팀원은 `git pull` 하고, 옛 주소는 docs 폴더 지도 7절의 옮긴 자리 표로 찾는다.
