## 개념 정리

### 1. 조립기는 「세 사람이 같은 형식」이라는 가정 위에 서 있었다

이동원 · 신장환 · 오준영 님 덱은 고정 크기(1280×720), `aside.notes`, `<span class="pg">` 형식이었다. 강민석 님 덱은 셋 다 달랐고, 그래서 **같은 증상이 세 곳에서** 났다.

| 가정 | 강민석 덱의 실제 | 증상 | 고친 곳 |
|---|---|---|---|
| 노트는 `aside.notes` 나 대본 md | 스크립트의 `const notes = ['…']` 배열 | 14장 전부 「노트 없음」 | 배열을 읽어 장 순서대로 넣음 |
| 쪽번호는 `.pg` 칸 | `<div class="foot"><span>…</span><span>04 / 13</span>` | 옛 번호가 그대로 | 풋터 마지막 칸을 덱 전체 번호로 |
| 규칙은 `.slide`·`body` 아래 | 전부 `#qurious-kms-deck .slide` · 크기는 `clamp(…vw)` | **스타일이 하나도 안 입혀짐** | 루트 id 걷기 · 원본 크기 1440×810 · `.active` 부여 |

CSS 는 조립기가 「가두지 않은 선택자 0개」라고 통과시켰지만 화면은 깨져 있었다. **점검이 통과해도 눈으로 한 장은 본다** — 루트 id 를 접두어로 붙이는 바람에 어떤 요소와도 맞지 않는 선택자가 「가둔 것」으로 세어졌다.

### 2. 합친 결과는 「그 파일만」 따로 열어 확인해야 한다

한 파일 판을 만든 뒤 저장소 안에서 열면 상대 경로로 그림과 영상이 **우연히** 찾아져 문제가 가려진다. 그래서 그 파일 하나만 빈 폴더에 복사해 서버로 열고 세 가지를 센다.

- 영상 8편의 `readyState` 가 4(재생 가능)이고 길이가 읽히는가
- 그림 8장의 `naturalWidth` 가 0 이 아닌가
- `src` · `href` 중 `data:` · `blob:` · `#` 이 아닌 외부 참조가 0개인가

사용자 피드백(「발표 자료만 받아도 영상과 이미지가 나와야 한다」)은 이 검사가 곧 수용 기준이다. 덱을 다시 만들 때마다 같은 검사를 되풀이한다.

### 3. 화면과 자막의 숫자가 다르면 자막을 화면에 맞춘다

영상 D 의 새로고침 장면은 「위 10종목에 지금 가격을 붙입니다」라고 말하는데 화면에는 「위 **7**종목에 지금 가격을 붙임」이 떴다. 시세를 못 받은 종목은 건너뛰기 때문이다. 말을 화면에 맞춰 「위쪽 종목(최대 10개)」로 고치고 건너뛴다는 사실을 한 줄 더했다. 미리 적어 둔 값이 아니라 **그날 화면이 정답**이다.

### 4. 자막 읽을 시간 점검은 한 번 고치면 다시 어긋난다

`subtitle_sync pad` 가 pause 를 늘리면 영상 길이가 바뀌어 다른 줄의 노출 시간이 달라진다. 고친 뒤 **다시 녹화해서 다시 점검**해야 통과했다(두 번 돌았다). 문장을 줄이는 쪽이 더 빠를 때도 있다(42자 → 35자).

### 5. 시간 배정은 글자 수로 센 추정이라는 표시를 단다

강민석 님 노트 2,577자는 5.5자/초 기준 약 7분 50초(범위 7.2 ~ 8.6분)다. 이동원 영상은 실측 합계 2분 44초(가정은 2분 50초)였다. 표 6-2 의 합계는 약 38분 15초로 목표 50분 안이다. 추정과 실측을 칸에서 구분해 적었다.
