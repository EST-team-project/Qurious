## 1. 무엇을 했나

- **구현하기 전에 읽는 교재를 앱에 붙였다.** 강사님 기능 목록은 틀이고 추가는 자유다. 바이브 코딩으로 만들더라도 RAG · 임베딩 · 배치 같은 개념을 모르면 면접에서 한 문장도 못 한다. 그래서 장 34편(완성 2 · 뼈대 32)을 깔고, 장마다 구현 묶음(W2~W8) 직전에 채우기로 했다.
- **글 쓰는 법부터 조사했다.** MDN · Google ML 단기 과정 · Diátaxis · Hugging Face 강좌는 모두 「무엇을 배우나」 를 먼저 말하고, 그림과 실행되는 예로 설명하고, 확인 문제나 요약으로 닫는다. 위키백과의 「AI 문체의 표지」 목록은 피할 것 표가 됐다 — 과장된 의의, 막연한 출처, 「~뿐 아니라 ~도」, 굵은 글씨 남발, 그리고 **돌리지 않은 출력**.
- **팀 자료는 HF 에 두었다.** 공용 서버가 없어서(유료 클라우드 0원 · AWS 보류) 앱 DB 에 쓰면 쓴 사람 PC 에만 남는다. 팀이 이미 쓰는 HF 비공개 데이터셋 `qurious-quant/learn-pages` 를 글 저장소로 삼고, 앱 편집기의 「저장」 하나가 커밋 하나가 되게 했다.

## 2. 막힌 것 · 알게 된 것

- **같은 질문에 세 번 다른 답이 나왔다.** 「2026년 코스피에서 팔 때 세금은?」 을 이 PC 의 `llama3.1` 에 그냥 물으면 「0.3%」, RAG 로 근거를 주면 「1만분의 5 [출처 2]」, 검색어를 법령 용어로 넓혀 근거 둘을 다 주면 「1만분의 5, 즉 0.5%」 였다. 맞는 답은 0.05% + 0.15% = 0.20% 다. 두 번째는 검색이 농어촌특별세 조각을 놓쳐서, 세 번째는 근거를 다 받고도 모델이 단위를 열 배 틀리게 바꿔서 틀렸다. **세 번째 답은 출처 번호 검사를 통과했다** — `[출처 1]` 은 실제로 넘긴 번호였으니까. 번호가 맞는 것과 내용이 맞는 것은 다른 검사다. 「근거에 없는 숫자」 를 찾는 열 줄짜리 검사가 0.5% 를 잡았다. 그래서 설계 원칙이 하나 늘었다 — **숫자는 코드가 계산하고, 언어 모델은 근거를 읽어 설명한다**(0.20% 는 이미 `trading_cost.py` 가 계산한다).
- **뜻 검색도 「코스피」 와 「유가증권시장」 이 같은 줄 몰랐다.** bge-m3 는 「팔 때 내는 세금」 과 「양도에 대하여 과세」 를 이어 줬지만(해시 임베딩 5위 → 2위), 정답 조문은 4위였다. 법령은 코스피를 「유가증권시장」 이라 부른다. 이 간극을 메우는 재료가 용어사전(①-1)이다 — RAG 와 용어사전이 따로 노는 기능이 아니었다.
- **빈 목록 줄이 제목이 됐다.** 편집기의 「장 틀」 에 `> [!GOAL]` 아래 빈 목록 줄(`> - `)을 두었더니, 미리보기에서 `[!GOAL]` 이 큰 제목으로 보였다. 마크다운에서 글 한 줄 바로 아래의 `-` 한 줄은 **제목 밑줄**(setext)이다. 시험(TC-LN-17)으로 막았다.
- **고친 화면이 옛것으로 보였다.** 서버가 캐시 지시를 주지 않으면 브라우저는 어림짐작으로 옛 HTML 을 쓴다. 학습 사이트의 HTML 만 「바뀌었는지 매번 묻기」(no-cache)로 내주고, js · css 에는 `?v=` 를 붙였다. 바뀌지 않았으면 304 라 비용은 거의 없다.
- **412 재시도는 실전에서 거의 안 난다.** 다른 팀원이 HF 에 직접 커밋한 뒤 저장해 보니 412 없이 성공했다 — 저장 직전에 최신 커밋을 받아 오기 때문이다. 412 는 「받아 온 순간과 커밋 순간 사이」 의 아주 짧은 경합에서만 난다. 그래서 그 경로는 실제 저장소가 아니라 가짜 HF 시험으로 확인했다. 시험을 돌리기 전에 「이 실행이 정말 그 경로를 지나는가」 를 따져야 했다.
- **HF 의 `blob_id` 는 git 블롭 해시였다.** 로컬에서 `sha1("blob <길이>\0" + 내용)` 을 계산한 값이 HF 파일 목록의 값과 같았다(README 로 대조). 덕분에 서버에 따로 묻지 않고 「내가 연 판이 아직 최신인가」 를 비교한다.
- **스캐너가 또 거짓 흔적을 셌다.** 교재 예제의 `check_citations` 가 RAG 구현 흔적으로, `normalize_body` 가 「지표 정규화」 흔적으로 잡혔다. 용어사전 때와 같은 일이라 같은 방법(흔적 한정)으로 막았다.
