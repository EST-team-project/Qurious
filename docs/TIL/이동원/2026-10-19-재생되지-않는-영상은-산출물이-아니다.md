## 1. 무엇을 했나

- **영상을 발표 자료에서 바로 재생되게 했다 — 파일은 git 밖.** 사용자 피드백 「yaml 뿐 아니라 실제 비디오로 재생할 수 있어야」 에 따라 녹화본(webm · VP8)을 H.264 mp4 로 바꿔 `docs/발표/영상/파일/` 에 내보낸다 — 사용법 판 · 발표 판(편마다 10 MB 안). 영상에 공식 자료 화면이 찍혀 있어 mp4 · 그림은 공개 저장소에 두지 않고(`.gitignore` · 출처 대장의 이용 조건), 장면 YAML 과 목록만 넣는다. 도구 `tools/demo/export_mp4.py` 는 녹화 뒤 장면이 바뀐 영상을 내보내지 않고(장면 지문), 다시 돌리면 0편이며, 목록(`목록.json`)과 README <표 6> 을 채운다.
- **발표 자료도 판 관리 문서가 됐다.** `docs_scan.py` 가 `docs/발표/<묶음>/` 의 HTML 도 판을 올리고(지난판/ 사본의 영상 경로를 한 칸 아래 자리에 맞춤), 판은 `<meta name="doc-version">` 에서 읽는다. 발표 자료 v0.2 는 영상 칸 넷이 발표 PC 에 내보낸 mp4 를 재생한다(파일은 git 밖).
- **장중 영상을 두 판으로 찍었다** — 국내 모의 체결까지(V04) · 모의 계좌(V06) · 지수 · 금리 · 산업(F06) · 주가 차트와 시세 시각(F07) · 통합 대시보드(F08). 리밸런싱 주문 산출(V05 · P-V05)은 #277 이 바꾼 화면으로 다음 세션에 찍는다.
- **개념 학습 아래 띠는 관리자 몫으로.** 일반 사용자에게 팀 자료 저장소 이름 · 개발 낱말 · 「새로 받기」 가 보이던 것을, 서버가 응답에서 빼고(`_team_view`) 새로 받기는 403 으로 막았다(사용자 결정).
- **거시 · 산업 화면에 출처 줄** — 서버가 이미 주던 `note`(야후 지연 시세)를 화면이 그대로 그린다.
- **개념 학습 팀 자료 쓰기를 없앴다(D133 · 사용자 결정).** 가입만 하면 누구나 서버의 쓰기 토큰으로 팀 저장소를 쓰고 · 고치고 · 지울 수 있었다 — 라우트 셋(`API-LRN-03 · 04 · 05` 폐기) · 저장소 쓰기 함수 · 화면 편집기와 쓰기 시험 다섯을 지우고, 팀 자료는 이동원이 HF 에서 직접 고친다. 앱은 받아 읽기만 하고, HF 주소는 관리자에게만 낸다.
- **UI 명세서 그림 둘을 다시 찍고, 팀원 PR 열하나(#267 · #268 · #271 ~ #279)를 세 번에 나눠 받았다** — 겹친 공용 문서 셋(RTM · 시험-요구 대장 · API 명세서)은 세 갈래 병합.

## 2. 막힌 것 · 알게 된 것

- **공개 범위는 저장 방식보다 먼저 이용 조건으로 정한다.** 처음엔 「저장소에 mp4」 로 정했다가, 영상에 금융위원회 시세 · 야후 · OpenDART · 용어 풀이 화면이 찍혀 있어 출처 대장의 「다시 나눠 주지 않음 · 비공개로만」 과 어긋나는 것을 PR 본문을 쓰다 짚었다 — 올리기 전에 다시 물어 git 밖으로 바꿨다(한 번 올리면 이력에서 지우기 어렵다). GitHub 저장소 화면은 어차피 영상을 재생하지 않는다(문서 「Working with non-code files」).
- **녹화기의 ffmpeg 은 VP8 만 된다.** Playwright 가 함께 주는 ffmpeg 에는 H.264 인코더가 없어 imageio-ffmpeg 를 썼다 — 없으면 도구가 「무엇을 깔라」 까지 말하고 멈춘다(막다른 길 금지).
- **녹화 중에 `app/` 을 고치면 녹화가 깨진다.** 개발 앱은 `app/` 을 지켜보다 다시 뜨므로, 녹화 중 서버 파일을 고치자 예약 주문 요청이 사라졌다 — 녹화와 코드 고침을 시간으로 나눈다.
- **CRF 28 · 정지 화면 맞춤이면 2분 영상이 28 MB → 5.5 MB 여도 글자가 읽힌다** — 10 MB 를 넘으면 CRF 를 31 · 34 로 올리고, 그래도 넘으면 멈춘다.
- **`git pull` 은 받으면서 원격을 새로 읽는다.** 병합본을 만든 기준(`faeb653`)보다 한 걸음 더(#272) 받아, 겹친 파일이 그 사이 바뀌지 않았는지 다시 봤다(바뀌지 않음).
- **시험을 억지로 늘리지 않는다**(사용자 피드백) — 고친 파일의 시험만 돌리고 전체 시험은 한 번, 깨 보기는 하지 않았다. 전체 시험의 실패 일곱은 모두 알려진 것(DF-110 · DF-135)이었다.

## 3. 원칙으로 다시 보기

- **한 곳(SSoT)** — 영상 길이 · 크기 · 지문은 `목록.json` 한 곳, README 표 · 발표 자료 부록 표는 그 파일에서 만든다.
- **멱등** — 내보내기 · 문서 고침 스크립트는 다시 돌리면 0곳(옛 꼴이면 마지막 꼴로, 이미 마지막 꼴이면 건너뜀).
- **최소 공개** — 개발 낱말 · 저장소 이름은 관리자에게만, 서버가 뺀다(화면이 숨기는 것이 아니라). 공식 자료 화면이 찍힌 영상은 공개 저장소 밖.
- **말없는 fallback 금지** — 장면이 바뀐 녹화 · 10 MB 를 넘는 영상 · 인코더 없음은 조용히 넘어가지 않고 멈춘다.
