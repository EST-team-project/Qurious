## 1. 무엇을 했나

- **장면 파일(YAML) 하나에서 영상 · 자막 · 장 파일이 나오는 녹화기를 만들었다.** 단계는 장 제목 · 자막 · 화면 이동 · 누르기 · 쓰기 · 고르기 · 기다리기 · 강조 열세 가지. 커서 · 누른 자리 물결 · 강조 테두리 · 자막 띠 · 장 제목 카드는 앱 글꼴로 화면에 얹는다.
- **2차 로보 어드바이저 여정을 영상 일곱 편으로 찍었다**(V01 성향 진단 · 배분 → V07 근거 상담 · 각 34 ~ 68초 · 콘솔 오류 0). 시연 전용 로컬 계정 · 가상 돈 · 장이 닫힌 토요일이라 국내 주문은 미리 보기까지, 미국은 예약 → 취소.
- **영상은 git 이 아니라 HF 비공개 데이터셋**(`qurious-quant/demo-videos`)에 올렸다. 장면 파일만 저장소에 두고, 화면이 바뀌면 그 장면만 다시 찍는다(강사님 「영상은 바뀌면 늘 최신화」).
- **2차 발표 자료를 HTML 한 파일(22장)로 만들고 Figma 로 옮겼다**(Qurious 폴더 「Qurious · 2차 발표 자료」). 팀원 칸은 「채울 칸 · 누가 · 언제」.
- **금융 필수 지식의 교재 단원을 정리했다.** 강사님 원천에서 지난 판이 된 옛 10단원을 「회사 구조 · 세무회계」 화면에서 걷어내고, 본문과 어긋난 2 · 3 · 4단원 이름을 본문 첫 절에 맞췄다(산업 분석과 공시 · 기술적 분석 · 재무제표 · 퀀트 사례 · 배당 · ETF). 교재 원본은 고치지 않고 빌드에서 바로잡는다.

## 2. 막힌 것 · 알게 된 것

- **녹화 API 의 기본이 화질을 깎는다.** Playwright 1.59 Python 의 `page.screencast` 는 프레임을 800×450 으로 줄이고 크기 인자가 없다. 크롬 DevTools 의 `Page.startScreencast` 를 직접 불러 1920×1080 을 받았다. 프레임은 화면이 바뀔 때만 오므로 마지막 프레임을 이어 써서 25fps 시간표를 만들고, 인코딩은 녹화가 끝난 뒤에 한다(실시간 인코딩이 밀리면 길이가 어긋난다).
- **기다림은 자르되 밝힌다.** AI 답(48초 안팎)을 기다리는 동안 시간표를 멈추고, 이어 붙인 자리에 「기다린 n초를 줄였습니다」 를 띄운다. 답 자체는 바꾸지 않는다.
- **이 PC 의 ffmpeg 는 WebM 만 만든다**(Playwright 에 딸린 최소판 — VP8). 그래서 발표 자료는 PPTX 가 아니라 WebM 을 바로 재생하는 HTML 로 정했다.
- **400 의 범인이 내 도구였다.** 리밸런싱 「저장한 배분 가져오기」 는 브라우저 확인 창으로 적용을 묻는데, 녹화기가 기본으로 「취소」 를 눌러 목표 비중이 빈 채 「주문 산출」 이 400 이 됐다. 팀원 화면 결함으로 적기 전에 내 도구의 기본값부터 의심해야 했다 — 장면마다 `dialogs: accept` 를 두게 고쳤다.
- **긴 답은 가운데로 굴리면 요점이 화면 밖으로 나간다.** 강조할 때 요소를 가운데로 굴렸더니 출처 번호가 달린 답 문장이 위로 사라졌다. 화면보다 긴 요소는 머리부터 보이게 고쳤다.
- **「최신이 반영되지 않았다」 의 실체는 반입이 아니라 우리 쪽 낡은 곳이었다.** 강사님 강의 본문은 반입 뒤 바뀌지 않았고, 바뀐 껍데기(푸터 · 바깥 CSS)는 들이면 면책 문구가 지워져 오히려 해롭다. 고칠 곳은 우리가 붙여 둔 옛 단원과 어긋난 제목이었다.
- **「다른 영역은 고치지 않는다」 는 팀 합의가 아니었다.** 찾아보니 내 작업 규칙(9월 28일)이었다. 팀 결정으로 「화면만 잠정 반영 · 미리 알림 · 반대하면 되돌림」 을 정하고, 바뀐 것을 팀 안내 이슈로 알린다.

## 3. 원칙으로 다시 보기

- **한 곳(SSoT)** — 장면 파일 하나가 영상 · 자막 · 장 제목의 원천이다. 화면이 바뀌면 파일 한 곳을 고치고 다시 찍는다.
- **말없는 대체 금지** — 줄인 기다림은 화면에 밝히고, 녹화가 중간에 멈춘 판(`ok: false`)은 올리기 도구가 거절한다. 공개 저장소에는 올리지 않는다(비공개인지 확인한 뒤에만 올림).
- **멱등성** — 번호 채우기 · 대장 고침 도구는 다시 돌리면 0곳이다.
