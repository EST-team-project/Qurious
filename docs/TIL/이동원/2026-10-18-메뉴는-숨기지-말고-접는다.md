## 1. 무엇을 했나

- **위 메뉴를 고정 탭 여섯 + 왼쪽 「전체 메뉴」 트리로 바꿨다(D129).** 탭 열 개를 폭에 들어가는 만큼만 보이던 것을, 로보 어드바이저 · 투자 인디케이터 · 모의투자 · 퀀트자동매매 · 학습 · 데이터 여섯으로 고정했다. 모든 묶음 13 · 항목 74(앱 안 화면 70 · 새 화면 링크 4)는 왼쪽 트리에 있고 지금 묶음만 펼친다. 「더보기」 와 오른쪽 서랍은 없앴다.
- **탭 줄은 하나씩 숨기지 않고 통째로 접는다.** 다 안 들어가면 로고 부제 → 탭 아이콘 → 탭 줄 차례로 접는다. 실제 글꼴로 재니 1280 이상은 모두, 1024 는 부제 · 아이콘만 접히고, 940 아래는 탭 줄이 접혀 트리가 메뉴를 맡는다.
- **좁은 화면은 ☰ 가 같은 트리를 연다.** 300px 로 열리고, 어두운 막 · Esc · 메뉴 고름 · 화면 바뀜이면 닫히며 초점은 ☰ 로 돌아온다. 메뉴가 위 「더보기」 와 ☰ 두 곳에 두 꼴로 있던 것이 한 벌이 됐다.
- **메뉴 글 대비 셋을 고쳤다.** 지금 탭 · 지금 항목 파란 글 4.37 → 5.66, 트리 소제목 2.56 → 4.75, 「전체 메뉴」 제목 3.19 → 5.02. 화면에서만 숨기는 글(`.sr-only`)이 CSS 에 없어 옛 서랍의 「(새 화면)」 이 보이던 것도 함께 정의했다.
- **트리 글은 자르지 않고 너비는 화면에 맞췄다.** 긴 이름은 두 줄로 접고, 트리 너비는 240 ~ 288px(화면 폭의 15%)로 늘어난다.
- **Figma 를 디자이너 차례로 짰다.** 브리프 → 지금 화면(문제 지점 번호) → 정보 구조 → 토큰(앱 CSS 변수 이름 그대로) · 컴포넌트(상태 변형) → 폭 · 상태별 시안 → 설계 주석 → 결정 → 구현 대조.

## 2. 막힌 것 · 알게 된 것

- **`font: inherit` 는 크기까지 물려받는다.** 트리 항목을 키보드로 닿는 `button` 으로 바꾸며 단추 기본 글꼴을 지우려고 `font: inherit` 를 줬더니, 본문의 18px · 줄 높이 1.65 를 물려받아 항목이 묶음 머리보다 커졌다. 시험은 구조 · 글만 봐서 통과했고 사용자 화면에서 찾았다. 글꼴 집만 물려받게(`font-family: inherit`) 고치고, 그 약속과 「글을 자르지 않는다」 를 시험으로 묶었다. 크기 · 높이는 브라우저에서 재야 보인다.
- **캡처 글꼴이 숫자를 바꾼다.** Figma 에 제품 글꼴(Pretendard)이 없어 Noto Sans KR 로 바꿔 찍었더니 글자가 넓어 1280 에서 탭이 실제보다 둘 더 숨어 보였다. 설계 파일의 폭 판단은 제품 글꼴로 해야 한다 — Figma MCP 는 PC 에 깐 글꼴이 아니라 계정에 올린 글꼴만 본다.
- **「이미 했나」 를 옛 닻으로 보면 두 번 들어간다.** 줄을 뒤에 붙이는 고침의 둘째 미리 보기가 1곳을 또 보였다. 새 글이 옛 닻을 품기 때문이다 — 「새 글이 이미 있나」 로 바꿔 0곳을 확인했다.
- **이름은 조사로 정한다.** 「배우기」 · 「학습」 · 「금융 필수 지식」 가운데, Schwab · Webull · Coinbase 가 위 메뉴에 두는 「Learn」 을 확인하고 다른 탭처럼 명사이면서 두 묶음(금융 필수 지식 · 개념 학습)을 다 덮는 「학습」 을 골랐다.
- **좁은 화면은 한 번 더 누르는 대신 찾는 곳이 하나다.** 묶음 첫 화면만 보면 ☰ 트리가 한 번 더 누르지만, 첫 화면이 아닌 화면은 덜 누르고 메뉴가 한 벌이다 — 숫자로 견준 표를 정보 구조 쪽에 두었다.

## 3. 원칙으로 다시 보기

- **한 곳(SSoT)** — 위 탭 차례(`MENU_TOP`)와 트리 차례(`MENU_TREE`)는 `core.js` 한 곳, 메뉴 글은 `GNB_MENUS` 한 곳. 탭 줄 접기 셈은 `fitGnbTabs` 한 곳이다.
- **숨기지 않는다** — 데스크톱에서 숨긴 메뉴는 덜 쓰인다(NN/g). 다 안 들어가면 반만 보이지 않게 통째로 접고, 같은 메뉴가 늘 트리에 있다.
- **접근성은 의미부터** — 묶음은 `details` · `summary`, 항목은 `button`, 지금 화면은 `aria-current`, ☰ 는 `aria-expanded` · `aria-controls`, 글 대비 4.5.
- **디자이너 · 개발 흐름** — 시안이 먼저, 구현 뒤에는 같은 폭으로 찍어 시안 옆에 두고 어긋남을 적는다(이번에는 항목 높이 2px · 로고 부제 대소문자).
