## 1. 무엇을 했나

- **지킴이 여섯을 받기 전에** — 완성도 배지의 강사님 점수 = 점검표 · html 넷에 바깥 공통 CSS 없음 · 푸터의 투자 권유 고지 · 자동매매 주기 문구 = 설정값 · 게이트웨이 없이 한글 종목 검색 · 사용자 주문은 그 사용자 키로만. 지금 코드에서 통과하고, 강사님 판을 넣은 사본 열 곳에서 모두 실패하는 것을 본 뒤에 받았다.
- **결정 없는 작은 묶음만** — Pine v6 서버 셋 · 판단 불가 둘 · KIS 일봉 둘 · 패턴 캐시 하나 · 공통 API 하나 + `stock.py` 의 `get_candles` 구간. 우리 판 = 기준인 일곱은 강사님 판 그대로(바이트까지 같은지 확인), 하나는 3-way 깨끗, 하나는 충돌 하나를 둘 다 두기로, 구간은 그 세 곳만. 결정은 스크립트(`resolve.py` · `apply.py`)로 남겨 다시 돌려도 같은 결과인지 봤다.
- **받은 시험의 빈 곳을 메움** — 내보내기 라우트가 변환 오류를 422 로 바꾸는 줄을 지키는 시험이 없어 TC-PE 를 썼다.
- **기준점 두 줄** — th06 을 서버(`e815be3`) · 화면(`9478811`)으로 나누고, 변경 추적 스캐너가 줄마다 그 경로를 건드린 커밋만 센다(TC-LS).
- **실제 확인** — 개발 앱에서 Pine 내보내기 `//@version=6` · 중첩 식 422 · 국내 일봉 수집 DB · 다중 시간대 신호가 캐시를 건너뜀(두 번 1.3초 · 1.1초). 전체 시험 1286 통과.

## 2. 막힌 것 · 알게 된 것

- **받은 시험은 우리 구조를 모른다.** 강사님 새 KIS 시험은 `get_candles("005930.KS", max_age_hours=0)` 이 KIS 로 간다고 본다. 우리 판은 국내 일봉을 수집 DB 에서 먼저 읽으므로, 그대로 받으면 수집 DB 가 있는 PC(데이터 담당)에서만 실제 수집 DB 를 읽고 `source` 가 collector 가 되어 실패한다 — 다른 PC 에서는 통과해 안 보인다. 우리 KIS 시험과 같은 꼴로 수집 DB 를 비우는 한 줄을 더하고, 가짜 수집 DB 를 둔 사본에서 그 줄을 빼면 실패하는 것까지 봤다.
- **강사님 시험은 함수를 보고 라우트를 안 본다.** 변환 함수 시험(TC-FM) 15건은 라우트의 `except FormulaError → 422` 를 지워도 모두 통과했다. 화면이 받는 것은 라우트의 답이라, 라우트를 DB 없이 직접 부르는 시험을 따로 썼다.
- **깨 보기의 닻이 여러 번이면 「못 찾음」 이다.** 같은 `except … 422` 꼴이 그 파일에 다섯 번 있어 첫 바퀴에서 바꾸지 못했다 — 「잡음」 으로 세지 않고, 그 함수의 `return` 줄까지 넣은 닻으로 다시 깼다.
- **`-x` 로는 다른 시험이 먼저 멈출 수 있다.** 강사님 3-way `auto_trade.py` 를 넣은 사본에서는 그 파일의 야후 언급 한 줄 때문에 야후 봉인 시험이 먼저 멈춰, 겨눈 지킴이까지 가지 않았다. 지킴이 하나만 겨눠 다시 돌렸다.
- **없는 함수를 지키려면 규칙을 지킨다.** 강사님 수동 주문 함수는 우리 판에 아직 없다 — 행동 시험은 지금 건너뛸 수밖에 없어서, 코드 전체에 「인자 없는 경로 해석은 시스템 배치만 · 서버 계좌는 `is_managed` 갈래 안에서만」 이라는 정적 규칙 둘을 두었다. 지금 통과하고 강사님 판에서 두 규칙이 각각 실패한다.
- **야후 봉인은 호출이 아니라 줄을 센다.** 내가 쓴 독스트링의 낱말 하나와 강사님의 출처 이름표 한 줄이 「24 → 26」 으로 잡혔다. 낱말은 빼고, 이름표는 호출 0 이라 까닭을 적고 25 로 열었다.

## 3. 원칙으로 다시 보기

- **SSoT** — 배지 점수의 정본은 점검표 TSV 다. 강사님 표가 45 → 90 으로 바꿔도 점검표를 먼저 고치기 전에는 실패한다(팀원 PR 이 깨지지 않게 이동원 · 주인 없는 줄만).
- **최소 권한** — 사용자 주문은 그 사용자 키로만. 서버 계좌 하나로 모든 사용자가 주문하는 길을 「없는 함수」 까지 코드 전체 규칙으로 막았다.
- **말없는 fallback 금지** — 모르는 부분 이름은 저장소 전체로 바꾸지 않고 상태 글로 · Pine 으로 못 옮기는 식은 깨진 코드 대신 422 + 까닭.
- 숫자 — 깨 보기 스물여섯 곳 가운데 스물둘을 시험이 잡았다. 못 잡은 넷(게이트웨이 갈래 둘 · 다중 시간대 캐시 · 화면 요청 취소)은 시험이 없는 곳으로 적어 다음 판에 넘겼다.
