## 1. 무엇을 했나

- **「금융 필수 지식」 · 「개념 학습」 두 묶음을 「학습」 하나로 합쳤다.** 위 탭 「학습」 → 학습 홈(네 갈래 카드) → 금융 필수 지식(강의실) · 개발 개념 · 파이썬 중급 · 특강. 목차의 금융 장과 강의실이 두 곳에 보이던 것은 강의실 아래 「보충 장」 하나로 모았다.
- **갈래 화면을 강의실과 같은 꼴로 맞췄다.** 부(특강은 날짜) 카드 — 번호 · 제목 · 분량 · 한 줄 · 장 둘 · 막대 · 읽은 장 — 를 누르면 부 목록이 열리고, 장을 누르면 읽는다. 부가 하나뿐인 파이썬 중급은 강의실 「교재」 카드처럼 장마다 카드로 바로 읽는다. 메뉴의 「장 읽기」 줄은 뺐다.
- **특강 1일차(10-19) 여덟 교시를 장으로 넣었다.** 강의 자료의 그래프 · 수치는 공식 자료(한국은행 · FRED · 공정위 · DART 등)와 맞대어 다시 그렸고(그림 13장), 다르게 적은 곳은 장마다 표로 밝혔다. 서버 장 규칙에 섹션 `special` · 차례 `S.<일차><교시>` 를 더했다.
- **사용법 영상 목록 화면을 열었다.** 왼쪽은 지금 편(영상 · 장 단추 · 「이 화면 열기」 · 「다음」), 오른쪽은 차례(로보 어드바이저 여정 · 기능 영상). 영상 파일을 받지 않은 PC 에서는 메뉴 줄째 숨긴다.
- **「시작하기 전에」 고지를 한 곳에 두었다** — 할 수 있는 것 · 하지 않는 것 · 숫자의 날짜 · 판단은 이용자 몫.
- **개념 학습을 72편으로 넓혔다** — 파이썬 중급 여섯 · 저장소 다섯과 포트 · 어댑터 · 팀원 기능의 개념(에이전트 · 신호와 설명 · 백테스트와 성과 · 자산배분과 주문 · 머신러닝 모델) · 특강 여덟. 내부 번호 · 문서 이름 163곳을 실제 서적 · 공식 문서 꼴로 고쳤다.
- **사용법 글의 「실시간」 셋을 고쳤고, README 첫 줄 밑에 머리 그림을 넣었다.**

## 2. 막힌 것 · 알게 된 것

- **함수 이름이 겹치자 API 명세서가 바뀌었다.** 화면 구조 스캐너는 화면과 API 를 함수 이름으로 잇는다. 새 파일의 `load` · `render` · `onClick` 이 상품 차트 파일의 같은 이름과 겹쳐, 상품 차트 API 를 「사용법 영상」 화면이 부른다고 적혔다. 맨 위 함수 이름을 파일마다 다르게(`hvLoad` 등) 바꾸자 검사가 다시 같아졌다.
- **CSS 클래스 이름도 겹쳤다.** 부 목록 머리의 번호 배지를 `.cl-badge` 로 지었더니 파랑이 아니라 연노랑으로 나왔다. 수집 화면(`collect.css`)이 같은 이름을 먼저 쓰고 있었다 — 앱 전체가 한 문서라 CSS 는 이름 하나를 함께 쓴다. `.cl-part-no` 로 바꾸고, 새 클래스는 넣기 전에 `public/css` 전체에서 이름을 찾는다.
- **메뉴에 줄이 없는 화면은 「어디 아래인지」 를 따로 알려야 한다.** 「장 읽기」 줄을 빼자 장 화면의 머리 경로에 화면 키(`learn-page`)가 그대로 나왔다 — 머리 경로 · 왼쪽 트리 · 위 탭이 모두 메뉴 줄에서 이름을 찾기 때문이다. 메뉴 줄이 없는 화면 → 따를 줄 표(`VIEW_PARENT`)를 두고, 장의 갈래는 목록을 받아야 알므로 화면이 그린 뒤 `showUnder` 로 「학습 › 특강」 처럼 바꾼다.
- **같은 주소로 다시 오면 해시 이벤트가 나지 않는다.** 부 목록을 갈래 화면 안에 그리면 「← 개발 개념」 을 눌러도 주소가 같아 아무 일도 없다. 장 화면과 같은 방식으로 부 목록에 화면 키(`#learn-part`)를 따로 주고, 어느 부인지는 기록 칸(`history.state`)에 둔다 — 뒤로 가기도 그 부로 돌아온다.
- **영상에서 성향이 「진단 전」 으로 보였다.** 투자 성향은 브라우저에 계정별로만 저장된다. 녹화는 편마다 새 브라우저라, 장면 파일에 성향을 적으면 녹화 도구가 녹화 전에 넣어 두게 했다.
- **줄을 지우는 고침은 「이미 했나」 검사가 틀린다.** 새 글이 옛 글 안에 들어 있어(줄 하나를 뺀 글) 늘 「이미 함」 으로 보였다. 지울 줄의 다음 줄까지 닻으로 잡아 새 글을 고유하게 만든다.
- **시험이 주석 글자에 두 번 속았다.** 「실시간 낱말이 없다」 를 파일 전체 글자로 찾자 그 규칙을 설명하는 주석에 걸렸다. 머리 주석을 빼고 글 · 값만 본다.

## 3. 원칙으로 다시 보기

- **한 곳(SSoT)** — 영상 한 편의 꼴은 `videoById` 하나, 고지 글은 `learnnotice.js` 하나, 카드 꼴은 강의실의 `fl-course` 하나(갈래 화면이 그대로 쓴다).
- **일관성** — 같은 일(과정 고르기 → 목록 → 읽기)은 같은 꼴로. 금융 필수 지식만 깔끔하고 나머지가 다르면 사용자는 다른 서비스로 읽는다.
- **말없는 fallback 금지** — 영상 표가 비면 메뉴 줄을 숨기고 화면에는 까닭을 보인다. 찾는 부 목록이 없으면 「찾는 목차가 없습니다」.
- **이름은 찾기 쉽게 고유하게** — 함수 이름도, CSS 클래스도. 도구와 브라우저는 이름으로 잇는다.
