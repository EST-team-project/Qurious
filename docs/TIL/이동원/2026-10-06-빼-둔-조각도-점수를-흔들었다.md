## 1. 무엇을 했나

- **섹터 법령은 섹터 질문일 때만 찾게 했다.** 섹터 법령 2026 판(114문서 · 9,725조각)을 근거 DB 에 넣고, 질문에 그 법의 정식 이름 · 약칭 · 업 이름(은행업 · 보험업 · ISA …)이 있을 때만 후보로 둔다. 벡터는 실험 컬렉션에서 그대로 옮겼다(다시 만들면 42분 · 코사인 1.0 확인). 같은 날 두 길을 재니 섹터 질문 18 은 정답 0 → 15, 낱말을 굳힌 뒤 새로 쓴 표본 밖 14 는 정답 0 → 7, 기존 검색 50 · 근거답 15 는 글자까지 같았다.
- **일정 2판 화면을 만들었다.** 칸에는 종류별 개수, 날짜를 누르면 그날 목록을 50건씩. 3월(3,532건)도 잘리지 않는다(DF-66 닫힘). 같은 날 안 차례는 화면 칩 차례로 맞췄다.
- **리서치 화면을 바꿨다.** 「AI RAG로 검색」 이라 적고 글자 찾기 5건을 주던 화면을, 공시 · 정책뉴스 · 기사 제목을 찾고 거르는 수집 자료 검색 화면으로(DF-61 닫힘).
- **시스템관리에 API 문서를 더했다(요청).** 목록 · 거름은 우리 디자인으로, 고른 API 하나만 Swagger UI 로 펼쳐 시험 호출. 로그인 쿠키로 실제 실행되니 쓰기 API 는 켤 때만.
- **주주총회 과거분 2020 ~ 2023 을 받았다** — 해마다 3월 주총이 늘었다(2,010 → 2,647).

## 2. 막힌 것 · 알게 된 것

- **거름으로 빼 둔 조각도 점수를 흔들었다.** 섹터 조각을 근거 문서와 같은 낱말 색인(SQLite FTS5)에 넣고 「섹터 질문이 아니면 후보에서 뺀다」 로 막았는데, 섹터를 끈 길의 기존 검색이 R@5 0.940 → 0.900 으로 떨어졌다. bm25 는 **표 전체**의 조각 수 · 평균 길이 · 낱말이 든 조각 수로 점수를 매겨서, 결과에서 빼도 남의 점수에는 들어간다. 따로 된 색인으로 옮기자 문항별 순위까지 같아졌다(DF-70). 「안 보이게」 와 「영향이 없게」 는 다른 일이다.
- **같은 날 세 번이 달랐던 것은 답 모델이 아니라 GPU 였다.** 표본 밖 셋째 회의 마지막 문항이 미룸 → 발췌로 바뀌어 「같은 날이면 같은 답」 이 깨진 줄 알았는데, Ollama 로그에 그 순간 `device lost on Vulkan0` 이 있었다. 회차를 비교할 땐 글자보다 오류 수를 먼저 본다.
- **늦게 온 응답이 지금 화면을 덮었다.** 달을 빠르게 넘기면 앞 달 응답이 늦게 와 지금 달을 덮고, 날짜를 누르자마자 그날 목록이 0.2초 뒤 사라졌다(늦게 온 카드가 옆 칸을 덮음). 브라우저로 직접 눌러 보고서야 보였다(DF-71).
- **시험이 글자만 찾으면 주석에도 속는다.** 마운트 줄을 주석으로 막아도 시험이 통과했다 — 글자는 남아 있으니까. 깨 보기 열아홉 곳 중 두 곳이 이렇게 빠져나갔고, 둘 다 「모양」 까지 보게 고쳤다.
- **보조 파일이 지워지자 앱이 근거 DB 를 못 열었다.** 마무리 점검에서 근거 찾기 · 답이 500 이었다. 근거 DB 가 WAL 이라 이 PC 의 마지막 연결이 닫히며 -shm · -wal 이 지워졌고, 읽기 전용으로 붙은 도커 앱은 그것을 만들 수 없었다. 이틀 전 검색 색인에서 같은 일을 겪고 「근거 DB 는 -shm 이 남아 있어 열릴 뿐」 이라고 적어 두었는데 그대로 일어났다 — 롤백 저널로 바꿨다(DF-74). 수집 DB 도 아직 WAL 이다.
- **팀원 시험이 처음 들어왔는데 우리 절차에서 실패했다.** 리밸런싱 정책 시험 11건이 표 없는 새 시험 DB 에서 실패하고, 표를 만든 DB 에서는 통과했다. 고치지 않고 이슈 초안으로 넘겼다(DF-73).
- **「따로 있어서」 가 아니라 「달라 보여서」 였다.** 개념 학습 · API 문서를 앱으로 합칠지 조사하니, 실제 서비스는 독자별로 자리를 나누되 머리글 · 토큰은 한 제품처럼 맞췄다(조사서 · 안 C 추천).
