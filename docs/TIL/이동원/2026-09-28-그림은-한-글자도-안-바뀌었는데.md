## 1. 무엇을 했나

- **ERD v1.1 · 데이터 사전 v1.1** — 10-06(화) 오전 칸 전에 다시 쟀다. v1.0 은 이력으로 둔다.
- **`docs/회의/`** 를 만들고 일일 스크럼 · 퇴근 전 보고 **양식 v0.1(제안)** 과 팀 제안 글을 두었다. 저장소 밖에 두던 09-23 글도 옮겼다.
- 산출물목록 v1.5 · S56 PR 번호 #30 채움.

## 2. 왜 했나

- 강사님 일정표의 10-06 오전 칸이 IA · 와이어프레임과 함께 ERD 를 본다. ERD 는 09-21 에 쓰고 한 번도 다시 재지 않았다.
- 유의사항 ⑤⑥(매일 스크럼 · 보고)은 10-01 부터다. 규칙은 분배안에 있는데 **남길 칸**이 없었다. 사용자가 팀 글을 저장소 밖에 둘 이유가 없다며 `docs/` 아래 회의 폴더로 들이자고 했다.

## 3. 어떻게 했나 — 고른 것과 버린 것

- **고른 것 — 그림을 손으로 옮기지 않는다.** 스캐너 출력과 v1.0 그림을 비교해 같을 때만 옮기는 조립 스크립트를 썼다. diff 0줄. 스키마가 그대로라는 것이 그 자체로 발견이었다.
- **고른 것 — 앱 DB 를 실제로 올려 본다.** v1.0 은 마이그레이션 파일의 `op.create_table` 글자를 셌다. 이번엔 빈 Postgres 에 0001 → 0003 을 올리고 `alembic check` 로 모델과 대조했다. 4곳이 어긋났고, 9월 20일에 같은 검사로 찾은 4곳과 같았다 — 여드레 동안 그대로였다.
- **고른 것 — 일일 기록은 주 1회 PR 로 묶는 안.** 하루 한 PR 이면 한 달에 20건이 넘는 GitHub 쓰기다. 이 저장소는 계정 정지를 두 번 겪었다.
- 버린 것 ① **v1.0 을 고쳐 쓰기** — 「09-21 에는 두 DB 가 이어져 있지 않았다」 가 사라진다. 판 관리 규칙대로 새 파일.
- 버린 것 ② **양식을 확정해서 내기** — 팀 공용 장치다. ADR-0003 의 교훈(만들고 나서 논의하면 뒤집힌다)대로 제안으로 낸다.
- 버린 것 ③ **모델 ↔ 마이그레이션 4곳을 고치기** — 표마다 주담당 파트가 다르다. 동작 영향이 없어서 급하지도 않다. 문서에 「autogenerate 를 돌리면 인덱스 4개를 지우는 마이그레이션이 생긴다」 는 함정만 적었다.

## 4. 어떻게 확인했나

- 스캐너 요약 — 표 · 칸이 v1.0 과 같고 행 수만 늘었다(13,431,190 → 13,462,818). 시세 세 표가 4,472,185 로 **같아졌다** — v1.0 때 원본이 2,869행 많던 것은 파생을 아직 안 만든 며칠이었다. 일일 갱신(S53)이 셋을 같이 돌린다.
- DF-01 을 옛 `#55` 의 값 그대로 다시 떴다 — 052670 2026-02-06 조정 종가 2,080 → 02-09 625,000. 그리고 그날 **포털 등락률도 +29,948%** 였다. 포털이 기준가를 조정하지 않았으니 등락률과 수정주가가 함께 틀린다. 주식 수로 전 종목을 훑어 같은 모양을 하나 더 찾았다(086460).
- 스캐너를 두 번 돌려 `cmp` — 처음엔 다른 줄 7개(메모리 주소). 고친 뒤 같음(코드 PR).

## 5. 막힌 것 · 남은 것

- **데이터 사전의 앱 DB 주석 비율이 일주일간 한 칸도 안 늘었다**(15/259). v1.0 의 처방은 「표를 손대는 김에 주석을 단다」였는데, 그 사이 모델 파일을 연 커밋(I14)은 **표 설명**만 달았다 — 스캐너는 칸 주석만 센다. 김에 하는 일은 안 된다. 따로 잡아야 한다.
- DF-01 수정(전처리) · 일일 기록 양식 확정(팀 논의) · 모델 4곳(팀 결정).
- `quant_virtual_accounts` 는 쓰는 코드가 0곳인데 ERD 에는 `users` 에서 뻗는 선이 그대로 있다. 선은 「쓰인다」가 아니다.

## 6. 배운 것

- **스키마가 그대로여도 ERD 는 낡는다.** 바뀌는 것은 표 사이의 길(다리)과 값(오염)이다. 그림만 보면 「바뀐 것 없음」이다.
- **같은 검사를 다시 돌리는 것만으로 「아직 그대로」를 증명할 수 있다.** 9월 20일의 4곳 · 9월 21일의 300배가 그대로였다. 적어 두지 않았다면 「고쳐졌겠지」가 됐을 것이다.
- **규칙이 있어도 남길 칸이 없으면 증빙은 0 이다.** 칸을 만드는 것도 산출물이다.
