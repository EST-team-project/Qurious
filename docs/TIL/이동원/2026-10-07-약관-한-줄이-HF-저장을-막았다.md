## 1. 무엇을 했나

- **크롤링 세 화면의 Figma 결정을 문서에 옮겼다.** 자동 · 수동 크롤링 · 데이터 인제스트를 관리자 화면 셋(수집 일정 · 단계 · 자료 직접 받기 · 적재 · 백업)으로 바꾸는 결정을 IA · UI 명세서 · 할 일 문서에 넣고, Figma 의 결정 기록 · 버린 안 · 프레임 이름을 맞췄다.
- **「신용평가 CSV 인제스트」 가 무슨 기능인지 조사했다.** 누가 읽나 · 자료가 있나 · 강사님 요구인가 · 우리 로보 어드바이저에 맞게 고칠 수 있나를 보고 조사서로 냈다. 사용자는 고쳐 쓰는 안(화면 둘을 상품 안내 · 재무 · 신용 위험으로)을 골랐다.
- **주인 없는 화면 22개를 이동원 몫으로 2차 · 3차에 나눴다.** 사용자가 역할을 다시 확정하며 정한 규칙(주인 없거나 요구 밖인 화면은 이동원 · 로보 어드바이저 먼저)대로.
- **강사님 원본(th01 · th07)이 바뀔 때 금융 필수 지식을 따라가는 법을 조사했다.** 다른 곳 다섯 갈래(번역 · 벤더링 · 갱신 봇 · 교과서 · 데이터 판 관리)를 보고 우리 안 다섯과 추천(E — 감시 + 출처 기록부터)을 조사서로 냈다. 사용자는 E 와 C 를 융합하기로 했다 — 연 · 날짜별 판 보관을 1단계로 당기고, 그 판 ID 를 출처 기록과 합치기의 바탕으로 쓴다.

## 2. 막힌 것 · 알게 된 것

- **화면이 있다고 기능이 있는 것은 아니었다.** 「데이터 인제스트」 가 넣는 표 넷은 모두 0행이었고, CSV 묶음은 이 PC 에도 강사님 저장소의 어느 판에도 없었다 — 우리 `.gitignore` 가 처음부터 그 폴더를 막아 두고 있었다. 화면 · 코드를 읽기 전에 그 표의 행 수부터 봤으면 더 빨랐다.
- **단추 이름은 지우는 범위를 말하지 않았다.** 「DB 초기화」 는 화면 글로는 인제스트한 자료를 지우는 단추로 읽히지만, 서버 목록(`USER_MODELS`)을 열어 보니 모든 사용자의 주문 · 포트폴리오 · 증권사 설정 · 감사 로그까지 지운다. S95 에 이 단추를 「위험 구역 — 표 비우기」 로 옮기는 그림을 그렸는데, 옮기기 전에 서버 쪽 목록을 읽었어야 했다.
- **약관 한 줄이 우리 기본 방식을 막았다.** 사용자 메모는 「데이터는 HF 에 데이터셋을 파서 저장해도 된다」 였지만, 금감원 「금융상품 한눈에」 오픈 API 이용약관 제9조는 「실시간으로 제공되는 정보를 이용자의 서비스와 연동할 수 있을 뿐이며, 정보를 복제 또는 저장하거나 전송할 수 없습니다」 다. 쪽 요약도 같은 말을 했지만, 설계를 뒤집는 조항이라 쪽을 파이썬으로 받아 조 번호까지 원문으로 옮겼다. 그래서 상품 안내의 예금 · 적금 금리는 부를 때마다 받아 보여야 한다.
- **「요구인가, 남은 옛 기능인가」 는 두 곳을 함께 봐야 갈린다.** 강의 4일차 프로젝트 쪽에는 신용 CB · 상품 추천 요구가 없고(신용평가모형은 개념 · XAI 예시로만), 기초 코드 최신판도 이 기능을 한 줄도 고치지 않았다. 둘 다 봐야 「빼도 되는 옛 기능」 인지, 「주인 없는 화면」 이라 고쳐 써야 하는지 나눌 수 있었다.
- **수집 DB 는 이 PC 에서 열지 않았다.** 재무 칸을 보려고 `market.sqlite3` 을 열면, 앱이 읽기 전용으로 붙여 쓰는 WAL DB 의 마지막 연결을 이 PC 가 닫게 될 수 있다(DF-74 와 같은 꼴). 데이터 사전의 칸 표로 대신 봤다.
- **커밋 제목은 내용이 바뀌었는지 말해 주지 않았다.** 기록된 판 뒤로 들어온 원본 커밋 29개 가운데 금융 내용 경로를 건드린 것은 하나였는데, 그 제목이 「Refactor code structure…」 였다. 제목으로 거르면 바로 그 하나를 놓친다 — 경로(허용 목록)와 blob 으로 걸러야 한다. 또 출처 기록이 원본마다 커밋 하나라 파일의 실제 바탕과 어긋나, 교재 10단원은 원본에서 이미 지워진 옛 파일과 글자까지 같은 본문을 달고 있었다(제목과 본문이 맞지 않는다).
- **화면 설계 프레임을 문서 그림으로 쓸 때 번호 상자는 PNG 에 그렸다.** Figma 화면 안에 주석을 넣지 않는다는 규칙을 지키려고, 요소 위치를 Figma 에서 프레임 기준 좌표로 읽어 내보낸 PNG 위에 빨간 상자를 그렸다.
