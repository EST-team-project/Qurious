## 1. 무엇을 했나

- **「현재가」 를 한 곳에서 받게 했다.** 투자 인디케이터의 삼성전자 「현재가」 가 210,000 인데 실제는 217,000 이었다 — 화면이 수집 DB 의 마지막 종가(공공데이터는 다음 영업일에 공개)를 「현재가」 로 보였다. 서버 함수 하나(`app/services/quote_now.py` · `GET /api/quote/now`)가 「내 증권사 키 → 지연 시세(약 20분) → 지난 종가」 차례로 값을 찾고, 값마다 출처와 시각 한 줄(「장 마감 · 지연 시세(약 20분) · 15:19 체결」)을 짓는다. 고친 뒤 같은 화면은 218,000 이었다(10-19 장 마감 뒤).
- **모의 주문은 체결 직전에 다시 받는다.** 국내 주문 · 미리보기 · 손절 · 익절이 같은 함수로 확인하고, 그 사람의 증권사 키가 있으면 그 자리에서 받은 값으로 체결한다. 자동매매 체결가는 엔진 몫이라 고치지 않고 이슈 초안으로 넘겼다(오준영 님).
- **판단은 저장 자료 그대로 둔다.** 기능을 「같은 자료로 다시 돌려 같은 답이 나와야 하는 것」(백테스트 · 학습 · 정산 · 근거 답)과 「지금 값이 틀리면 손해나 환각이 생기는 것」(「현재가」 · 체결가 · 손절 · AI 가 가격을 말할 때)으로 나눴다.
- **개념 학습을 앱 안 화면으로 합쳤다.** 위 탭 「학습」 을 눌러도 개념 학습만 다른 페이지로 나가던 것을, 「전체 목차」 · 「장 읽기」 두 화면으로 앱 안에 넣었다(주소 `#learn/<장>` · 뒤로 가기는 앞 장).
- **발표 자료 v1.0 을 새로 썼다** — 개발자 발표 꼴 45장 · 시스템 구성 v2.1 · 완성 그림 넷(손 SVG + 구운 PNG) · 질의응답 39문항은 덱 밖 별도 파일. 루트 README 도 v2.0(판 = 프로젝트 단계)으로 다시 썼다.

## 2. 막힌 것 · 알게 된 것

- **「현재가」 라는 이름이 값의 출처를 숨겼다.** 서버 응답에는 기준일(`as_of`)과 출처가 이미 있었는데 화면이 버렸다. 이름을 고치는 것만으로는 부족하고, 글을 서버 한 곳에서 지어야 화면마다 다르게 말하지 않는다.
- **「실시간」 은 계약이 있어야 쓰는 말이다.** 실제 서비스는 거래소 · 코스콤 계약이 있을 때만 「실시간」 이라 쓰고 나머지는 「20분 지연」 처럼 밝힌다. 증권사 키로 받은 시세도 그 사람의 화면에서만 쓸 수 있다(약관 제5조 3항) — 그래서 서버 공용 키로 모두에게 보이지 않는다.
- **거래일 달력을 열면 수집 DB 를 연다.** 장 상태를 공휴일까지 보려다, 읽기 전용으로 붙은 SQLite 를 시험 · 이 PC 에서 열면 앱이 멈춘 결함(DF-81)과 같은 길이 생겨 요일 · 시각으로만 판정했다(공휴일은 3차).
- **지난 날 체결 시각만 보이면 오늘 값처럼 읽힌다.** 미국 종목이 「05:00 체결」 로 나왔는데 실제는 이틀 전 값이었다 — 체결 날짜가 오늘이 아니면 날짜를 붙였다.
- **봉인 시험은 글자를 센다.** 출처 이름을 `yahoo` 로 지었더니 야후 봉인 시험의 기준선이 늘었다 — 공급자 상표 대신 `delayed` 로 지어 원래 실패(DF-110)에 몫을 얹지 않았다.
- **시험을 억지로 늘리지 않았다**(사용자 피드백) — 고친 파일 시험 · 닿는 묶음만 돌리고, 깨 보기는 핵심 둘(체결 직전 확인 빼기 · 「실시간」 낱말 넣기)만. 전체 시험은 다시 돌리지 않았다.

## 3. 원칙으로 다시 보기

- **한 곳(SSoT)** — 값 찾는 차례와 출처 글은 `quote_now` 한 곳, 화면은 이스케이프해 보이기만.
- **말없는 fallback 금지** — 증권사 → 지연 시세 → 지난 종가로 넘어갈 때 까닭(`fallback`)을 응답에 남긴다.
- **최소 공개 · 이용 조건 먼저** — 실시간 값은 저장 · 백업하지 않고(10초 메모리), 그 사람의 키 값은 그 사람에게만.
- **재현성과 시의성을 나눈다** — 판단은 다시 돌릴 수 있는 저장 자료, 실행 직전 확인과 표시만 지금 값.
