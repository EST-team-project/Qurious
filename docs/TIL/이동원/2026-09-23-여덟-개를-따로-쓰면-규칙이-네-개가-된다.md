## 3. 어떻게 했나 — 고른 것과 버린 것

**처음 방식 — 8건을 따로 썼다.** 논의마다 초안을 쓰고, 검증을 세 갈래(투표 귀속 · 규칙·상태 · 사실·코드·형식)로 돌렸다. 검증 지적이 **61건** 나왔다. 대부분은 틀린 사실이 아니라 **논의끼리 서로 다르게 쓴 것**이었다.

| 같은 사실 | 초안들이 쓴 방식 |
|---|---|
| D0 ② (72시간 규칙) 가 3/4 로 미확정 | **네 가지** — "전체 잠정" / "확정 유지" / "꼬리표만" / "D0 ② 따라 바뀜" |
| 조건부 찬성(✅ᶜ) | 한 곳은 n/4 에 넣고, 두 곳은 뺐다 |
| 민석님의 "1차 비용 4수준을 그대로" | 두 곳이 **서로 다른 4단계로 "보정"** 했다 |
| #6 답글의 한 줄 정정 | 세 초안이 서로 다른 문장으로 고치려 했고, 하나는 사실이 틀렸다 |

**고친 방식 — 세는 법을 먼저 정했다.** 공통 기준 U1~U14 를 만들고 **정본 문장**을 글자 그대로 옮겼다.

- 범례: "n/4 는 제안과 ✅ 만 센다"
- D0 ② 미확정: "D0 ② 잠정 위의 확정"
- 전원 찬성이 모자랄 때: "09-27 에는 잠정(미합의)으로 2차를 시작하고 … 무응답을 찬성으로 세지 않는다"

8건을 이 기준으로 **한 건씩** 고쳐 올렸다.

```
처음                             고친 뒤
─────────────────────────        ─────────────────────────
8건을 따로 쓴다                   기준(정본 문장)을 먼저 쓴다
→ 같은 규칙이 네 가지로 적힘      → 8건이 같은 글자로 적힘
→ 검증이 "서로 다르다"를 61건     → 스캐너가 64행을 한 표로
```

## 4. 어떻게 확인했나

- **팀원 발언은 답글까지 전수로 셌다.** 이슈 41 + PR 23 에는 팀원 댓글이 0건이었다. 그래서 반환된 댓글 58건의 작성자를 확인했다 — 전부 나였고, 잘린 곳도 없었다. 조회 오류가 아니라 **실제로 0건**이다.
- 스캐너 첫 실측값은 손으로 센 값과 **전부 같았다**(D0 4 · D1 3 · D2 2 · D7 2 · D4 2 · #29 1).
- 게시하기 전에 새 본문마다 스캐너로 결론표를 읽어, 8열이 깨지지 않았는지와 상태 기호가 맞는지 봤다. 게시한 뒤 한 번 더 실측했다 — 64행 · 경고 0.
- **"그대로"를 원본으로 확인했다.** 1차 `COST_PRESETS` 는 `etf` 0.05 · `stock_min` 0.23 · `stock_slip` 0.30 · `stress` 0.50%다. 주석에는 "왕복"이라고 적혀 있다. 그런데 `run_backtest` 는 이 값을 **매수·매도 양쪽에** 뗀다(`backtest_strategies.py:353-382`). 그러니 1차 민감도는 **라벨의 2배 비용**으로 계산된 것이다. 🔴
- **"고치기 전에" 법령을 다시 봤다.** D4 초안은 본문의 "2026 매도세 0.15%"를 코드 값 0.20% 로 "정정"하려 했다. 법령 DB 현행 시행령 제5조(2026-01-02 시행판)는 코스피 영(零)·코스닥 0.15% 였다. 코드가 인용한 "제36001호"는 조회되지 않았다. 고쳤다면 **맞는 문장을 틀리게** 만들 뻔했다. → 🟡 재대조로 두고 숫자를 단정하지 않았다.

## 6. 배운 것

1. **여럿으로 나눠 쓰기 전에, 세는 법과 정본 문장을 먼저 쓴다.** 같은 사실이 여덟 곳에 들어가면 여덟 번 다르게 적힌다. 검증이 잡은 61건의 대부분이 그 "다르게"였다.
2. **"그대로"는 원본을 열어 보라는 뜻이다.** 두 초안이 좋은 뜻으로 "보정"했는데, 원본을 여니 1차에 2배 오류가 있었다. 말한 사람의 단어를 지키면 버그가 보인다.
3. **고치기 전에, 고칠 근거의 근거를 본다.** 코드가 법령보다 새로우면 맞을 것 같지만, 코드도 누가 옮겨 적은 것이다. 원천(법령 DB)이 다르게 말했다.
4. **규칙은 자기 자신을 통과시킬 수 없다.** 규칙이 없는 곳에 규칙을 제안할 때, 그 제안까지 "반대 없으면 통과"로 두면 무응답이 확정이 된다.
5. **밝힐 것은 먼저 밝힌다.** 원자료를 결론 전에 올린 일, 그날 답글이 사실과 달랐던 일을 결론 절 맨 앞에 적었다. 숨긴 채 "원래 A 로 되돌리자"고만 쓰면 추인을 몰래 받는 것이 된다.
