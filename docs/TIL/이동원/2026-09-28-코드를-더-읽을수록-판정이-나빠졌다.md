## 1. 무엇을 했나

- v0.1 이 미뤄 둔 7개 화면(W6~W12)을 그려 **주 경로 12개를 다 그렸다.** 틀을 흐름 순서(규칙 → 검증 → 기록 → 연결)로 다시 묶었다.
- 그리려고 화면 코드를 읽다가, **다른 파트 영역의 결함 18건**을 파트별 체크리스트 이슈 초안으로 모았다. 코드는 고치지 않았다.
- IA v0.2 의 판정 정정 7건을 변경 노트로 모았다(IA v0.3 에서 한 번에 고친다).

## 2. 왜 했나

- 강사님 일정표 2차 5번째 칸(10-06(화) 오전)이 「IA·와이어프레임」이다. v0.1 은 대표 5장뿐이었다.
- 이 작업은 사용자와 기다리는 시간을 나눠 한 것이다. 일일 갱신 12:30 회차를 확인하는 사이에 했다.

## 3. 어떻게 했나 — 고른 것과 버린 것

- **스크린샷만 보고 그리지 않았다.** 「지금」 칸마다 그 화면을 그리는 코드를 열었다. 그랬더니 스크린샷으로는 멀쩡하던 화면이 셋이나 뒤집혔다.
  - `indicator-strategy` 🟢 → 🔴: 「볼린저밴드 ±2σ」 행이 **하루 등락률 ±2%** 로 판정하고, 체크와 상관없이 늘 붙는다(`app.html:3295`). S52 의 「매수 우위」 중 매수 1개가 이것이었다.
  - `robo-screening` 🟢 → 🟡: 「LightGBM」은 합산 점수다. 서버 코드 주석이 스스로 그렇게 말한다(`investment_research.py:124`).
  - `quant-lean`: 「초과 수익」이 **서로 다른 기간을 뺀 값**이다(`lean_backtest.py:204`).
- **다른 파트의 코드는 고치지 않았다.** 사용자 지시(S54)다 — 데이터 파트는 자기 영역을 고치고, 다른 파트가 작업할 때 오류를 덜 겪게 **찾아서 알린다.** 파트는 역할 분배안 v1.0 기준으로 나눴고 담당(Assignee)은 비웠다.
- 버린 것 ① **결함마다 이슈 하나(18개)** — GitHub 쓰기가 한꺼번에 몰린다. 파트별 체크리스트 한 개로 모았다. 각 파트가 자기 줄을 떼어 가면 된다.
- 버린 것 ② **IA v0.2 를 지금 고치기** — 작업 중에는 문서를 버전업하지 않는다. 정정은 변경 노트로 모으고 v0.3 에서 한 번에 고친다.

## 4. 어떻게 확인했나

- 인용한 줄은 모두 기준 커밋 `e764e5f` 에서 `sed -n` 으로 다시 열어 봤다. `stock.py:82-83` · `:327` · `:330` · `lean_backtest.py:35-40` · `:204` · `:212` · `paper_trading.py:194-200` 등이다.
- 7절에 적은 재사용 합계(✅ 21 · 🟡 17 · 🔴 1 · 🟢 2)는 표를 스크립트로 세어 맞췄다. 처음에 「41줄」이라고 적었는데, 판정 없는 「—」 줄이 하나 더 있어 42줄이었다.
- 이슈 초안은 `post_check` 로 길이(7천여 자)와 링크(전부 절대 주소 · 커밋 고정)를 확인했다.

## 5. 막힌 것 · 남은 것

- **내 관찰 하나가 틀렸을 가능성**이 있다. IA v0.2 에 「빈 종목이면 아무 안내가 없다 🟢」라고 적었는데, 코드에는 4초짜리 토스트가 있다. 나는 버튼을 누르고 12~30초 뒤에 찍었다. 고정 대기 뒤의 스크린샷은 **잠깐 떴다 사라지는 것**을 못 본다.
- 데이터 파트 몫 A1 — `get_quote` 가 전일 종가를 받으면서도 등락률을 **늘 `None`** 으로 돌려준다(`stock.py:82-83`). 스크리닝 표의 `+0.00%` 가 여기서 나온다. 다음 작업 후보다.
- 모바일 본문 배치는 v0.2 에서도 못 했다. N2 는 D5 뒤로 미룬다.

## 6. 배운 것

- **에러 0건은 「맞다」가 아니다.** 12개 화면 모두 에러가 없었지만, 코드를 읽을수록 판정은 🟢 4 → 2 로 줄고 🔴 3 → 4 로 늘었다. 화면이 「틀렸다」고 말하지 않는 결함은 로그에도 안 남는다.
- **이름이 계산을 보증하지 않는다.** 「±2σ」「LightGBM」「신뢰도 65%」 — 셋 다 글자와 계산이 달랐다. 화면을 볼 때는 숫자 옆 글자가 아니라 그 숫자를 만든 줄을 본다.
