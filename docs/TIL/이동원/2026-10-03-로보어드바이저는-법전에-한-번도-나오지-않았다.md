## 1. 무엇을 했나

- **법령 근거를 찾는 API 둘을 만들었다.** 받아 둔 법령 10 · 감독규정 4 에서 기준일에 시행 중인 판의 조문만 찾는다 — 낱말 검색과 벡터 검색을 순위로 합치고(RRF), 질문에 「세율 · 원천징수」 가 있으면 세법, 「주주총회 · 자기주식」 이면 상법, 「투자권유 · 공매도」 면 자본시장법 쪽 후보를 한 번 더 센다. 벡터 쪽이 꺼져도 낱말로 답한다.
- **조각 첫 줄에 편 · 장 경로를 붙였다.** 「상법 > 제4편 보험 > 제1장 통칙 > 제651조(…)」. 받아 둔 원문으로 다시 쪼개는 명령(2.8초 · 네트워크 없이)을 만들어 4,067조각을 다시 만들고, 두 모델로 다시 임베딩했다(이 PC CPU 로 nomic 59분 · bge-m3 86분 — 같이 돌렸다).
- **검색 평가셋 v0 을 만들었다.** 질문 38개마다 정답 조문을 적고, 조문 글을 하나씩 열어 확인했다.
- **용어사전 후보 용어 일곱 가운데 다섯을 공개했다.** 보험 넷 중 둘은 「리서치해서 고르라」 는 말을 받아, 법령에 나오는 쪽(보장성 · 저축성)을 골랐다.
- **사용자가 찾은 결함 하나를 고쳤다(DF-44).** 용어사전 분류 카드를 누르면 오류가 났다.
- **문서를 따라잡았다** — 설계서 · 테스트 계획 · API 명세서 · RTM · IA · 결정 대장의 변경 노트, 개념 학습 3.4 장 본문, 어제 쓰지 못한 TIL.

## 2. 막힌 것 · 알게 된 것

- **「로보어드바이저」 는 근거 문서 4,067조각에 한 번도 나오지 않는다.** 법의 이름은 「전자적 투자조언장치」(자본시장법 시행령 제2조 제6호)다. 낱말 검색은 이 질문을 영원히 못 찾는다 — 사람이 쓰는 말과 법이 쓰는 말이 다르다. 용어사전의 동의어로 검색어를 넓히는 것이 다음 후보다.
- **같은 숫자를 두 번 재야 머리의 효과를 말할 수 있었다.** 머리를 바꾸기 전에 낱말 검색 점수를 먼저 재 두었다(Recall@5 0.684 · MRR@10 0.470). 바꾼 뒤 MRR 은 0.487 로 올랐지만 회사법 질문은 0.89 → 0.78 로 내려갔다 — 머리의 「회사」 「주식회사」 가 회사편 모든 조각에 붙어 낱말 점수를 흐렸다. 머리의 효과는 벡터 쪽에서 봐야 한다.
- **nomic-embed-text 는 한국어 질문을 거의 못 찾았다.** 벡터만으로 Recall@5 0.053(38개 중 2). 조각 글을 그대로 검색어로 넣으면 자기 자신을 1위로 찾으니 길은 맞다 — 같은 뜻을 다른 한국어로 물으면 못 맞힌다. 섞어 찾기에 넣으면 오히려 낱말 검색만보다 나빠졌다(0.684 → 0.526). 다국어 모델 bge-m3 는 벡터만으로 0.816, 낱말과 합치면 0.868 이었다 — 기본 모델을 bge-m3 로 정했다. 앱의 문서 · 채팅 근거 색인도 nomic 이라 같은 문제가 있을 수 있다.
- **정답을 조문 글로 확인하지 않았으면 틀린 정답을 적을 뻔했다.** 「적합성 원칙」 은 자본시장법 제46조라고 기억했지만, 그 조는 2021년 금융소비자보호법이 생기며 지워졌다. 정답은 금융소비자보호법 제17조다. 정답을 조각 ID 가 아니라 「문서:조」 로 적은 것은, 쪼개기 규칙을 바꿔도 정답이 흔들리지 않게 하려고서다.
- **「고쳤다」 와 「막힌다」 는 다르다.** #88 답글은 「/simulate 는 운영에서 관리자만」 이라고 했지만, 코드는 dict 에 `getattr(user, "roles")` 를 써서 늘 빈 목록이었고, 환경 변수를 정하는 곳이 없어 늘 「개발」 로 보였다. 둘이 겹쳐 지금은 누구나 부른다.
- **화면은 그날 눌러 본 곳만 확인된다.** 분류 카드는 화면을 만든 날부터 `limit=200` 을 보내 서버 상한(100)에 막혔는데, 그날 브라우저 확인은 검색 · 용어 한 장 · 서랍만 눌렀다. 화면의 모든 `limit=` 을 상한과 대조하는 시험을 붙였다.
- **글자 충돌이 없어도 위험한 병합이 있다.** 강사님 기초 코드의 새 KIS 게이트웨이는 우리 실거래 차단 관문을 거치지 않는다. git 은 충돌로 알려 주지 않는다 — 반영은 그 관문 시험부터 하기로 했다(다음 세션).
