## 1. 무엇을 했나

- **사용법 창에 「영상으로 보기」 칸을 열었다(D132 첫 단계).** 그 화면의 영상이 있으면 윗줄에 「▶ 영상 길이」, 창 안 요약 아래에 칸이 생기고, 누르면 그 자리에서 튼다. 여러 화면에 걸친 영상은 그 화면이 처음 나오는 장부터 튼다(차트 패턴 = 신호로 종목 살피기 장 2 · 0:15). 장 단추 · 「② / 3」 장 표시 · 창 바닥 고지를 더했다.
- **영상 표는 영상 곁에 두었다.** 화면 키 → 영상 · 장 표는 녹화 기록(단계 시각 · `go` 화면 키)과 장 파일에서 도구(`tools/demo/help_videos.py`)가 만들어, 영상과 같은 로컬 폴더(`data/help/` — git · 이미지 밖)에 둔다. 영상을 다시 찍어도 git 을 고칠 일이 없고, 영상이 없는 PC 는 표도 없어 칸이 저절로 숨는다. 앱은 로그인한 사람에게만 `/help/videos.json` · `/help/media/{이름}` 으로 낸다.
- **화면을 옮기면 내용 칸을 맨 위로 되돌린다(DF-134).** 앞 화면에서 내려간 자리를 물려받아 새 화면 중간에 떨어지던 것을 메뉴 셸 한 곳에서 고쳤다(같은 화면을 다시 부르면 자리를 둔다).
- **새 메뉴로 영상을 다시 찍고, 기능 영상을 새로 찍고, 발표 영상을 따로 만들었다.** 사용법 영상은 편마다 1분 안팎(앱 창에서 보기 좋게), 발표 영상은 같은 기능 15편을 편마다 2 ~ 3분으로 더 자세히(강사님 「각 3분 내외」). 장중 · 회차 뒤가 필요한 편(국내 체결 · 계좌 숫자 · 리밸런싱 주문 산출 · 거시 · 차트)은 다음 날로.
- **시세가 나오는 장면에 출처 한 줄을 넣었다(D54)** — 화면이 실제로 읽는 자료대로. 수집 DB 의 수정주가로 계산한 화면에만 D54 문구를 쓰고, 지금 시세를 증권사 → 야후로 받는 모의 주문 · 계좌에는 넣지 않았다.

## 2. 막힌 것 · 알게 된 것

- **녹화 「성공 · 콘솔 오류 0」 은 자막이 맞다는 뜻이 아니다.** 확인 프레임을 한 장에 모아 보니 세 편이 어긋났다 — 통합 대시보드는 자막이 「총 자산」 을 말하는데 화면은 「자료 없음」, 리밸런싱은 저장이 막혀 주문이 안 나왔는데 자막은 「주문을 계산」, 성향 진단 결과에는 서버 낱말 「moderate」 가 그대로. 앞 둘은 화면을 고치거나 찍는 때를 옮겼고, 마지막은 화면 글을 고쳤다(오준영 님 화면 — 프론트만 잠정 반영 · 사전 알림). 발표 판은 그림을 두 줄로 크게 모아 보니 넷이 더 나왔다 — 「표로 보기」 를 눌렀는데 표가 창 아래에 생겨 안 보임 · 이 화면에 없는 기능 이름 · 화면 글과 다른 따옴표 이름(「모델 성능 경고」 ↔ 화면 「모델 성능 기준선 미달」) · 창 머리와 본문의 모델 이름 엇갈림. 작은 그림으로는 글자를 맞대지 못한다.
- **404 도 콘솔 오류다.** 영상이 없는 PC 를 404 로 두었더니 화면을 열 때마다 브라우저가 오류를 찍었다(녹화 기록 「콘솔 오류 2」). 영상 표만은 빈 표(200)를 주게 바꿨다.
- **같은 「시세」 라도 출처가 화면마다 다르다.** 차트 · 배분은 수집 DB 수정주가, 모의 주문은 증권사 → 야후, 리밸런싱은 전 거래일 원 종가, 계절성 지수는 한국은행 ECOS. 출처 문구를 하나로 붙이면 틀린 이름이 된다.
- **장면을 고치면 옛 녹화 기록과 단계 차례가 어긋난다.** 출처 줄을 끼우자 옛 기록으로는 화면을 이을 수 없었다 — 기록에 화면 키를 남기게 하고, 옛 기록은 장면 파일과 같은 앞쪽까지만 쓴다.
- **OpenAPI 는 `{경로:path}` 를 `{경로}` 로 적는다.** 한 라우트로 두었더니 명세서 대조가 갈렸다. 파일은 한 폴더뿐이라 라우트를 둘로 나누니 경로 검사도 단순해졌다(이름에 「/」 가 들어갈 수 없다).
- **굴러가는 칸은 창이 아니었다.** 앱은 머리 · 왼쪽 메뉴를 고정하고 내용 칸(`#main-content`)만 굴린다. 그래서 녹화기의 「창을 N 만큼 굴림」 은 아무 일도 하지 않았고(장면 일곱 곳이 빈 걸음), 앱도 화면을 옮길 때 그 칸을 되돌리지 않아 앞 화면에서 내려간 자리에서 새 화면이 시작됐다(DF-134). 발표 장면 초안을 밟던 배경 작업이 그림으로 찾았다 — 화면 바꾸기(`navigate`)에 「다른 화면이면 맨 위로」 한 줄 · 시험 하나(TC-NV-16)를 더하고, 녹화기는 그 칸을 굴리게 고쳤다.

## 3. 원칙으로 다시 보기

- **한 곳(SSoT)** — 영상 표는 녹화 결과 한 곳에서 만든다. 손으로 쓰지 않고 git 사본도 두지 않는다.
- **말없는 fallback 금지** — 옛 기록이 장면 파일과 어긋나면 「그 앞 화면만 잇는다」 고 알리고, 화면 글에 편 번호 · 파일 이름이 들어가면 도구가 멈춘다.
- **멱등** — 같은 파일은 다시 옮기지 않고, 표는 파일을 다 옮긴 뒤 마지막에 바꾼다(화면이 반쯤 옮긴 표를 보지 않게).
- **최소 공개** — HF 비공개 자료라 로그인한 사람에게만 · 우리 폴더의 정해진 꼴만 낸다.
