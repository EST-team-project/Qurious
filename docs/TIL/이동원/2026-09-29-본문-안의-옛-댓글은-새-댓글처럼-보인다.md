## 1. 무엇을 했나

- 다시 올린 옛 글 **23건**(논의 9 · 이슈 14)의 새 번호를 기록 색인 3절 · 갱신 대장 1절에 채웠다. 짝은 S60 이 목록 페이지로 맞춘 표에서, 이슈 6건(#38 · #40 · #41 · #43 · #44 · #45)은 이번 검색에서 새로 찾았다.
- 논의 9건은 페이지를 한 건씩 열어 **갱신 댓글이 9/9 붙은 것**을 확인했다. D3 는 끝 문단(①④⑦⑧ 을 v2 에서 다시 묻자는 제안)을 **그대로** 올렸다.
- 옛 인덱스를 대신할 **인덱스 v2** 본문과 #4 닫기 댓글을 썼다 — 새 번호 목록 · 공식 일정 · 분석 A1~A17 한 줄 현황 · **닫는 조건**.
- 갱신 대장 **6절 「닫아도 되는 글」** 을 새로 두었다(사용자 요청) — 지금 2 · 기한 뒤 논의 9 · 다시 올리지 않을 옛 글 6(권장). 세션 끝 확인에 ⑦ 닫기 점검을 더했다.

## 2. 왜 했나

- 옛 번호와 새 번호가 숫자로 겹친다 — 옛 `#8` · `#9` · `#13` 은 우연히 새 번호도 같지만, 옛 `#11`(A8)은 새 #17 이고 새 #11 은 D1 논의다. 09-30 기한 전에 팀원이 「D4 가 몇 번이지」 를 한 표에서 찾을 수 있어야 한다.
- 「작업하다 보면 끝나는 글이 생긴다 — 닫아도 되는 걸 알려 달라」(사용자). 열린 글이 쌓이면 어느 것이 살아 있는 일인지 안 보인다.

## 3. 어떻게 했나 — 고른 것과 버린 것

- **고른 것 — 페이지 읽기는 한 건씩, 로그인 없이.** 토큰 API 는 쓰지 않았다. 같은 페이지를 다시 물을 땐 도구 캐시(15분)를 써서 GitHub 에 새 요청이 가지 않게 했다.
- **고른 것 — 새 댓글은 「제목 + 끝 문단」 으로 가린다.** 갱신 댓글은 「올린 뒤 바뀐 것 N가지」 로 시작하고 N 이 글마다 다르다. 끝 문단까지 로컬 파일과 맞으면 그 댓글이다.
- **고른 것 — #4 닫기 댓글에 번호 자리를 비워 두지 않는다.** v2 번호는 올려야 생긴다. 자리 채우기(S51 `#번호` 사고) 대신 **제목 검색 링크**와 「v2 가 #4 를 가리켜 타임라인에 참조가 생긴다」 는 점을 썼다.
- **고른 것 — 올리자마자 닫을 글은 올리지 않는 쪽을 권장.** S58 은 6건을 「올린 뒤 닫기」 로 적었다. 본문 + 댓글 + 닫기면 쓰기 2~3건씩인데, 읽는 사람이 얻는 건 기록 파일과 같다. 닫힌 7건(2.2)과 같은 논리다. 결정은 사용자 몫으로 남겼다.
- **고른 것 — 절 번호는 그대로.** 다른 문서가 「갱신 대장 3절 순서」 를 가리켜서, 닫기 점검은 6절로 뒤에 붙였다.
- 버린 것 — **이슈 페이지를 더 열어 보기.** 로그인하지 않은 화면엔 이슈 댓글이 아예 없다. 더 열어도 같은 답이 나온다.

## 4. 어떻게 확인했나

- 첫 이슈 목록 답이 12건에서 끊겼다. 머리글의 「Issues 17」 이 열린 이슈 수(#4~#9 · #14 · #17 · #18 · #26 · #35 · #37 · #38 · #40 · #41 · #43 · #44)와 맞아서, 목록이 잘린 것이지 이슈가 없는 게 아니라고 판단했다.
- 이슈 5건을 한 건씩 열면 「댓글 없음」, 검색 `comments:>0` 은 같은 5건을 「있음」 으로 돌려줬다. #7 을 열어 보니 도구가 받은 페이지에 **댓글 구역 자체가 없었다** — 비로그인 이슈 화면은 댓글을 그리지 않는다. 그래서 이슈는 🟡(있음까지)로만 적었다.
- 23줄을 채운 스크립트는 줄마다 「옛 값이 정확히 이것일 때만」 바꾸게 했다(개수가 다르면 멈춤).

## 5. 막힌 것 · 남은 것

- 이슈 댓글 **내용**은 확인하지 못했다 — 사용자가 화면에서 본 것으로 바꿔 적는다.
- 09-28~29 에 쓰기가 약 25건 붙었다 🟡(논의 댓글 9 · 이슈 본문 6 · 이슈 댓글 최대 10). 페이지 날짜가 UTC 라 KST 하루치는 모른다 — 남은 글은 하루 5건으로 되돌린다.
- 09:06 일일 갱신은 사용자가 아니라 **작업 스케줄러가 띄웠다**(마지막 실행 09:06:48 · 로그 09:06:56). 트리거는 12:30 하나뿐이라 그 시각에 돈 이유는 못 찾았다 🟡.
- 남은 일: v2 게시 → #4 · #40 닫기 · D8 본문 + 댓글 · #5 · #6 갱신 댓글 · 6.3 권장 결정.

## 6. 배운 것

- **다시 올린 본문 안의 옛 댓글은 도구에게 새 댓글로 보인다.** D7 은 「2건 · 답글 3건」 으로 읽혔지만 전부 본문 속 기록이었다. 「언제 · 누가 올린 것만」 으로 걸러야 한다.
- **보이지 않는다와 없다는 다르다.** 비로그인 이슈 화면의 「댓글 없음」 은 「안 그렸음」 이었다. 두 방법이 엇갈리면 어느 쪽이 무엇을 못 보는지부터 잰다.
- **닫기도 쓰기다.** 닫을 글을 고르는 일은 「몇 건을 줄일 수 있나」 와 같은 질문이다.
