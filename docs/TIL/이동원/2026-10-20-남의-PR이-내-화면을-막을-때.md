## 2. 막힌 것 · 알게 된 것

- **머지 뒤 검사가 내 PR 이 아닌 곳에서 멈췄다.** 학습 PR 보다 팀원 PR 다섯이 먼저 머지돼 RTM 표 한 줄이 어긋났다. RTM · 표 5 · API 명세서는 대장 + 코드를 함께 세는 생성물이라, 누가 무엇을 머지했든 main 이 바뀌면 다시 채운다.
- **글로 걱정하던 회귀가 머지 뒤 실제가 됐다.** 해외 종목 매도 500 을 막으려던 가드(#286)가 원화가 아닌 종목을 미리 보기 · 주문 · 체결 세 곳에서 모두 막아, 같은 길을 쓰는 미국 주문 화면이 400 이 됐다. 미리 보기는 장부를 바꾸지 않아 확인용으로 안전하다.
- **핫픽스가 반쪽이었다.** PR 글에는 「매수면 통과」 가 있었는데 커밋에는 서명 한 줄만 있었다. PR 글이 아니라 커밋의 바뀐 줄(`git show`)과 개발 앱 호출로 확인해야 한다 — 그리고 화면이 보내는 값(`side: "BUY"`) 그대로 부른다.
- **두 장부가 열쇠 하나를 나눠 썼다.** 패턴 화면의 위험 관문은 1억 모의 계좌로, 자동매매는 1천만 장부로 같은 「당일 시작 자산」 열쇠를 썼다. 그날 먼저 부른 쪽이 기준이 되어 자동매매가 첫 바퀴에 −89.65% 로 멈췄다. 기능을 하나씩 재는 시험은 두 길이 만나는 차례를 못 잡았고, 영상처럼 흐름을 끝까지 밟는 확인이 잡았다.
- **회차 중에 찍으면 배지가 남는다.** 12:30 회차가 도는 동안 찍은 16편에 「자료 10-16 · 확인 필요」 가 찍혀, 회차가 끝난 뒤 다시 찍었다.
- **관리자 화면은 관리자 계정으로.** 데이터 관제의 수집 화면은 관리자 전용이라 시연 계정으로는 403 · 타일이 비어 녹화가 멈췄다. 계정은 파일에 쓰지 않고 환경 변수로만 넘긴다.
- **「git 밖」 은 팀원에게는 「없음」 이다.** 발표 자료가 이 PC 의 mp4 를 가리키면 팀원 PC 에서는 영상 칸이 빈다. 공유할 자료는 공유되는 곳에 둔다.

## 3. 원칙으로 다시 보기

- **생성물은 다시 채운다(SSoT)** — 손으로 맞추지 않고 도구로.
- **말없는 fallback 금지** — #286 전의 미국 주문은 국내 수수료로 말없이 계산됐다. 거부로 바꾼 것은 옳은 방향이고, 막힌 길은 비용 모델로 되살린다.
- **증거는 커밋과 실측으로** — PR 글이 아니라 바뀐 줄 · 개발 앱 응답 · 시각 · 커밋 해시.
- **자막 = 동작** — 영상이 말하는 것은 화면 글자뿐 아니라 그 뒤의 동작(키 있음 · 없음)까지 맞아야 한다.
