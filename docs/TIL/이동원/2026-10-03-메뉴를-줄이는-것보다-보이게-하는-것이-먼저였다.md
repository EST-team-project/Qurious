## 1. 무엇을 했나

- **강사님 `9478811` 의 화면 쪽(파일 여섯)을 받았다.** 로그인 첫 화면이 「투자 대시보드」 가 되고, 위 메뉴 · 더보기 · 증권사 API 설정이 바뀌었다. 이걸로 `9478811` 묶음을 다 받아 강사님 자료 추적 기준점을 `289bfb5` → `9478811` 로 옮겼다(th06 줄만 — 다른 폴더는 아직 분석만 한 상태라 그대로).
- **받기 전에 Figma 로 견줬다.** 지금 화면과 강사님 새 판을 **같은 계정 · 같은 데이터**로 찍으려고, 강사님 화면 파일을 우리 서버 API 에 붙이는 작은 중계 서버를 scratchpad 에 띄웠다. 캡처 9장을 나란히 두고 정할 것 셋 × 세 안(A 새 기본안 · B 지금 · C 맞춤)을 그려 사용자가 골랐다 — ① C · ② 융합안 D · ③ C.
- **② 는 사용자가 「A + B + C 를 리서치해서 융합」 이라고 답했다.** 리서치로 「우선순위대로 들어가는 만큼 보이기(Priority+) + 더보기 = 전체 메뉴」 를 만들고, 실제로 잰 폭으로 그림을 그려 해석을 다시 확인받은 뒤 만들었다.
- **새 시험 TC-NV 7건** — 커밋된 트리 복사본에서 7건 모두 실패하는 것을 먼저 봤다. 전체 668 → **675 통과**.
- **문서 판** — IA v1.0(첫 화면 · 위 메뉴 구조가 바뀐 Major) · 와이어프레임 v0.5 · API 명세서 v0.3 · 테스트 계획서 v1.5 · RTM v1.3 · 결정 대장 v1.2 · 갱신 대장 v0.4.

## 2. 막힌 것 · 알게 된 것

- **「위 메뉴 둘」 이 정답처럼 보였지만 연구는 반대쪽을 가리켰다.** 지금 위 메뉴는 아홉 개인데 1280 폭에서 세 개 반만 보였다(탭 칸 334px). 강사님 판은 둘로 줄였다. 그런데 NN/g 의 실험(2016)에서 데스크톱의 숨긴 메뉴는 27% 만 쓰였고 보이는 메뉴는 48% 였다 — 줄여서 숨기면 덜 쓰인다. 그래서 「줄이기」 대신 「들어가는 만큼 보이기」 를 골랐다. 1280 에서 셋째 탭(금융 필수 지식)이 들어가도록 오른쪽(환율 · 로그아웃 글자)을 조금 줄였더니 탭 칸이 480px 이 됐고, 폭별 탭 수가 그림과 똑같이 나왔다(1280 셋 · 1600 다섯 · 1920 여덟).
- **강사님 「더보기」 는 우리 메뉴를 몰랐다.** 강사님 빌더는 메뉴 묶음 둘을 빼고 모든 항목을 화면 단추로 그린다. 우리 「금융 필수 지식」 에는 클릭되지 않는 소제목이 있고 「개념 학습」 은 바깥 주소다 — 그대로 받으면 소제목은 `undefined` 라는 단추가, 개념 학습은 없는 화면으로 가는 단추가 된다. 3-way 병합은 이걸 충돌 없이 합친다. 코드로 읽어 받기 전에 우리 빌더로 바꿨다(TC-NV-03).
- **서버 글도 화면이다.** 화면 파일만 보면 안 보이는 결함이 서버 응답의 글자 칸에 있었다 — 「종목 선정」 화면으로 가라는 안내(그런 메뉴는 없다 · 지난 세션에 내가 옮긴 문구), 탭 이름의 옛 서비스 이름 넷, 서버 설정 이름, 어느 판에도 없는 `#paper-account` 링크. 화면은 서버 글을 그대로 보여 준다. 탭을 하나씩 눌러 읽지 않았으면 못 봤다.
- **같은 데이터로 띄우니 0% 의 정체가 보였다.** 강사님 대시보드의 기본 전략(삼성전자 · 1년 · RSI)이 수익률 · 샤프 · 낙폭 · 승률을 모두 0 으로 보였다. 이 기간에 한 번도 사고팔지 않았기 때문이다 — 0 은 결과가 아니라 「매길 수 없음」 이다. 「신호 없음」 과 같은 기간 보유 수익률(98.3%)로 바꿨다.
- **잠겨 있어도 잠겨 보이지 않았다.** 키가 없어 「KIS 모의투자 시작」 은 `disabled` 였는데 초록 단추 그대로였다. 앱 전체에 잠긴 단추 모양이 한 줄도 없었다. 서랍을 연 채 주소로 화면을 바꾸면 서랍이 남는 것, 기능 완성도 배지가 서랍 위에 뜨는 것도 단추를 하나씩 눌러 보다 찾았다.
- **브라우저 캐시가 확인을 속였다.** CSS 를 고치고 1초 뒤 연 창이 옛 CSS 를 기억에 들고 있어 「안 고쳐졌다」 고 읽혔다. 서버 파일과 창이 읽은 규칙을 따로 대조하고서야 알았다.
