## 1. 무엇을 했나

- **「신용 리스크 분석」 을 「재무 · 신용 위험」 으로 바꿨다.** 옛 화면은 개인 · 기업 CB 조건을 글로 만들어 범용 대화 API 에 물었다. 대화 도구가 비어 있는 CB 표를 되풀이 읽어 답이 약 2분 걸렸다. CB 원자료는 신용정보회사 것이라 모을 수 없다.
- **회사 쪽은 우리 전자공시 재무로(`API-RISK-01`).**
  - 숫자 넷: 유동비율 · 부채비율 · 자기자본비율 · 자본잠식률.
  - 점검 일곱: 질문 꼴이고, 답은 「그렇다 · 아니다 · 자료 없음」 이다.
  - Altman Z'': 점수 · 구간 · 해마다 막대 · 한계 문장.
  - 판 고르기는 데이터 API 와 같은 함수 한 곳(접수일 다음 거래일부터 쓴 판)이다.
- **시장 쪽은 한국은행 ECOS 시장금리로(`API-RISK-02`).** 국고채 3년 · 회사채 AA- · BBB- · CD · CP 를 매일 받는 수집기를 새로 만들었다. 스프레드 셋과 「지난 10년 하루값 가운데 아래에서 몇 %」 를 보인다.
- **화면은 설계 D 다.** Figma 에 세 안(A 한 장 두 단 · B 탭 둘 · C 점검 먼저 + 시장 신용 띠)을 실제 앱에 띄워 캡처했다. 사용자가 「B 와 C 를 잘 융합」 을 골라, 위 띠 + 탭 둘 + 점검 먼저인 D 로 만들었다.
- **대화 쪽 도구도 바꿨다.** 강사님 대화 에이전트의 옛 CB 도구 두 줄을 새 도구 둘(재무 건전성 · 신용 스프레드)로 갈았다. 같은 도구를 되풀이 고르면 답으로 끝낸다(약 2분 → 두 번째 추론).
- **시험 여섯 묶음 · 깨 보기.** 서버 TC-FH 17 · TC-MC 8 · 수집기 TC-ECS 11 · 대화 도구 TC-AGR 7 · 화면 TC-FRS 5 · DART 키 가림 TC-DK 6. 화면 시험은 사본에서 열한 곳을 깨 기대한 시험만 잡았다.

## 2. 막힌 것 · 알게 된 것

- **없는 항목 코드도 「자료 없음」 으로 온다.** ECOS 는 오류도 HTTP 200 으로 주고, 틀린 항목 코드에도 주말 창과 같은 INFO-200 을 준다. 그래서 거래일이 들어 있을 10일 넘는 창이 비면 실패로 센다.
- **키가 주소에 들어가면 오류 글로 샌다.** ECOS 는 키를 주소 경로에, DART 는 쿼리 문자열에 넣는다. 연결 시간 초과 글에는 주소가 그대로 실린다. DART 쪽은 그 글이 수집 기록 표(HF 로 백업됨)에까지 들어가는 길이었다. 공용 요청 함수에서 키를 가린 같은 종류의 예외로 다시 던지게 했다.
- **새 표는 옛 코드를 멈추게 할 수 있다.** 수집 DB 에 표가 생긴 뒤 옛 main 이 회차를 돌면, 백업 대조가 「모르는 표」 로 멈춘다. 그래서 이 PR 은 다음 회차 전에 머지해야 한다.
- **약관 날짜는 원문 끝에서 읽는다.** 머리말에 시행일을 2014-11-07 로 적었는데, 받아 둔 원문의 부칙은 2020-11-05 였다. 시험이 그 틀린 날짜를 「있어야 할 글」 로 지키고 있었다.
- **시험이 실제 DB 를 열고 있었다.** 재무 시험이 회사 이름을 읽을 때 이 PC 의 수집 DB 를 읽기 전용으로 열었다. 앱이 읽기 전용으로 붙인 WAL DB 라 규칙상 열면 안 된다. 없는 경로를 주는 autouse 장치를 두었다.
- **화면이 서버 숫자를 다시 적으면 둘이 갈린다.** Z'' 경계(1.10 · 2.60)와 「10년」 을 화면 글에 적어 두었다. 응답에서 읽게 바꾸고, 화면에 그 숫자가 없는지 시험으로 지킨다.

## 3. 원칙으로 다시 보기

- **판정하지 않는다** — 거래소 자본잠식 50% 같은 선을 화면에 그리지 않고, 「자본잠식이 없나」 사실만 답한다. 구간 이름도 「안전 · 부실」 이 아니라 「높은 · 가운데 · 낮은」 이다.
- **말없는 fallback 금지** — 금융회사는 유동비율 대신 까닭을 보인다. 연결 재무가 없어 별도로 바꾸면 그 사실을 글로 남긴다. 키가 없으면 수집기는 78(설정 결함)로 끝난다.
- **숨기지 않는다** — 자료가 없는 점검 둘(이자보상 · 영업현금흐름)도 빼지 않고 「자료 없음」 + 까닭으로 둔다.
- **SSoT** — 재무 판 고르기는 `data_financials` 한 곳, 항목 코드 표는 수집기 한 곳(앱 사본은 시험으로 맞춤), 표 정의는 `collector/db.py` 한 곳이다.
- **권한 나누기** — 수집 · 설정 문제의 할 일(명령)은 관리자 응답에만 싣는다. 일반 사용자는 글만 본다.
