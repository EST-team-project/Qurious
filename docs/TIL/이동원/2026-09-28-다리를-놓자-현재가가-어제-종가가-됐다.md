## 1. 무엇을 했나

- `get_candles` 가 국내 주식 일봉을 **수집 DB 에서 먼저** 읽게 했다. 새 파일 `collector_db.py` 가 SQLite 를 읽기 전용으로 열어 옛 경로와 같은 모양으로 돌려준다. 값은 수정주가이고 `source` · `as_of` 칸이 더 붙는다.
- 쓸 수 없는 요청(지수 · 환율 · 해외 · ETF · 주봉 · DB 없음)은 예외 없이 `None` → 옛 경로.
- 시험 22건 — 카카오 5:1 분할 골든 픽스처 + 31종목 전 기간 대조. 스키마 스캐너 재현성 시험 2건과 합쳐 전체 102건.
- 다리 때문에 뜻이 바뀐 칸 5곳을 파트별 이슈 초안으로 모았다.

## 2. 왜 했나

S42 의 ERD 가 처음 드러낸 것이 「두 DB 는 이어져 있지 않다」 였다. 1,343만 행을 모았는데 화면은 한 줄도 읽지 않았다. 옛 `#61` 이 이 다리를 P1-1 로 꼽았고, 테스트계획서 v1.0 · v1.1 모두 골든 픽스처를 다음 일로 적어 두었다. S56 의 A1(등락률)을 끝낸 다음 차례였다.

## 3. 어떻게 했나 — 고른 것과 버린 것

- **고른 것 — 정답지를 다른 길로 만든다.** 골든 픽스처의 기대값은 `price_adjusted` 가 아니라 `price_daily` 의 **원래 값 × 계수**로 계산했다. 어댑터가 읽는 표에서 정답지를 뽑으면, 그 표가 틀려도 시험은 통과한다.
- **고른 것 — 어댑터 밖의 숫자로 잰다.** 수정 종가의 하루 수익률은 거래소가 준 등락률(`flt_rt`)과 같아야 한다. 픽스처 12봉뿐 아니라 실제 DB 의 31종목 전 기간(2020~)에서 확인하는 통합 시험을 하나 두었다. 분할 14건이 전부 이어져 있었다.
- **고른 것 — 거래가 없던 날은 평평한 봉.** 시가 · 고가 · 저가가 0 으로 오는데, 비워 두면 `quant_pipeline` 의 ATR 이 실수 변환에서 NaN 을 만든다. 그날 종가는 전일 종가 그대로라 시가 = 고가 = 저가 = 종가가 사실과 같다.
- **고른 것 — compose 를 고치지 않는다.** 앱 컨테이너가 이미 `./data` 를 `/app/data/csv` 에 읽기 전용으로 붙이고 있었다. 그 안의 경로를 후보로 두면 된다. 이미지에 `collector/` 패키지가 없어서 어댑터는 `collector` 를 import 하지 않는다.
- 버린 것 ① **실시간 시세도 수집 DB 로** — 수집기는 다음 날 낮에 전일 값을 받는다. 장중 가격을 대신하면 거짓이다.
- 버린 것 ② **DB 가 오래되면 옛 경로로 되돌리기** — 배제한 출처로 조용히 돌아간다. 대신 `as_of` 로 기준일을 보인다.
- 버린 것 ③ **자동매매 체결가를 직접 고치기** — `auto_trade.py` 는 P-E 영역이다. I14 때는 사용자가 맡긴 예외였다. 이번엔 이슈 E-1 로.

## 4. 어떻게 확인했나

- **어댑터만 만들고 잇기 전에** 새 시험을 돌렸다 → 2 실패 · 20 통과. 실패한 둘이 정확히 다리 계약(외부 차트 호출 · 빈 캔들)과 지표의 기준일 칸이었다. 이은 뒤 22 통과.
- 수집 DB 의 09-23 종가(삼성전자 285,500 · 카카오 33,450)가 S56 에 외부 출처에서 잰 「전일 종가」와 같았다. 두 출처가 서로를 확인했다.
- **도커에서 읽기 전용 마운트 + WAL** 로 열리는지 걱정했다. SQLite 는 WAL 모드에서 공유 메모리 파일을 쓰려 한다. 이미 받아 둔 이미지의 파이썬으로 같은 마운트를 흉내 내 보니 열렸다(SQLite 3.46).
- Postgres 를 잠깐 띄워 전체 102 통과 · 컨테이너 삭제.
- 같은 세션에 ERD 를 다시 재다가 **스키마 스캐너가 돌릴 때마다 다른 사전을 낸다**는 것을 찾았다. 함수 기본값을 메모리 주소째 적고 있었다. 「다시 돌리면 된다」는 약속이 7줄에서 깨져 있었는데, 한 번만 돌리면 보이지 않는다. 두 번 돌려 `cmp` 하는 것이 재현성 시험의 가장 싼 형태다.

## 5. 막힌 것 · 남은 것

- **`current_price` 의 뜻이 바뀌었다.** 코드는 한 줄도 안 바뀌었는데 「지금 가격」이 「어제 종가」가 됐다. 이 값을 자동매매가 **체결가**로 쓴다. 옛 경로도 6시간 캐시라 원래 틈이 있었지만, 연휴 뒤 첫날(09-28)이면 삼성전자가 −4.2% 벌어진다. 이슈 E-1.
- 「10년」 백테스트가 6.7년이 됐다. 수집 DB 가 2020-01-02 부터다. 이슈 D-1.
- 봉인 시험(TC-YH)은 줄을 센다. 이번에 줄어든 두 줄은 설명문이고, 진짜로 줄어든 것은 **호출**이다. 줄 수는 진척을 잘못 보여 줄 수 있다.
- 호출하는 곳이 옛 `#61` 의 11곳에서 14곳으로 늘어 있었다. 옛 숫자를 옮겨 적었다가 다시 셌다.
- **「어댑터 밖의 숫자」가 완전히 밖은 아니었다.** 등락률도 수정주가도 같은 포털 값(`vs`)에서 나온다. ERD 를 다시 재다가 DF-01(052670 300배)이 **아직 그대로**인 것을 봤는데, 그날 포털 등락률도 +29,948% 였다 — 둘이 함께 틀려서 내 대조를 통과한다. 같은 유형이 086460 에 하나 더 있었다. 주식 수라는 다른 칸으로 한 번 더 보게 했다. 고치는 것은 전처리(다음 일).

## 6. 배운 것

- **다리를 놓으면 값의 뜻이 바뀌는 칸이 생긴다.** 모양 시험(계약)은 통과해도 뜻은 바뀔 수 있다. 그런 칸은 응답에 기준일을 싣고, 기대던 곳을 찾아 알린다.
- **정답지는 검사 대상과 다른 길로 만든다.** 같은 표에서 뽑은 기대값은 거울이다. 길만이 아니라 **출처**까지 달라야 한다.
- **남의 숫자는 다시 잰다.** 11곳은 일주일 전(09-21)의 사실이었다.
