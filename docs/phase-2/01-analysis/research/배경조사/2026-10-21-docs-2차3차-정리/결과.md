## 요약 (다섯 줄)

> 3 ~ 7절과 이 요약은 배경 에이전트가 세션 재시작으로 멈춘 뒤 **메인이 1 · 2절의 실측으로 채웠다**(2026-10-21 10:3x).

1. **추천은 안 A — 옮기지 않는다.** 차수 폴더(`docs/2차/`)로 옮기면 상대 링크 1,875 곳을 다시 써야 하고 이미 올린 GitHub 글 속 주소 204 곳(지금 열리는 것)이 404 가 된다. 지금 규칙(판 없는 이름 + `지난판/`)은 옮기지 않는 한 판을 올려도 링크가 깨지지 않는다.
2. **2차 경계는 태그 하나와 표 하나로 남긴다** — 2차 최종 커밋에 주석 달린 git 태그(저장소의 첫 태그 · 영구 주소) + 산출물목록 0.1절에 「2차 최종 판」 칸(문서마다 2차를 닫은 판 · 그 판의 지난판 사본 링크).
3. **3차는 같은 파일에서 판을 이어 올린다** — 살아 있는 문서 56개는 자리 그대로, 2차 전용(`발표/2차/`)만 얼리고 3차 발표는 `발표/3차/` 를 새로 둔다(도구 손볼 곳 0 — `NESTED_DIRS` 가 묶음 이름을 가리지 않음).
4. **사용자 손은 명령 두 줄**(태그 만들기 · push) — S131 PR 머지 뒤. 파일 옮기기(`git mv`)는 0.
5. 정할 것: ① 안 A ② 태그 이름 ③ 이번 세션에 「2차 최종 판」 으로 올릴 문서 범위(6절 1층 아홉 · 2층은 3차 첫 주) ④ 태그 시점.
