## 4. D115 — 증권사 현재가의 「전일 대비」 부호

- 고른 종목: 신한지주(055550) — 10-16 에 내림. 근거 앱 응답 `/api/stocks/quote?symbol=055550.KS`(12:37:25): `price 93,400 · prev_close 94,200 · change_pct −0.85 · as_of 2026-10-16 15:30`(수집 DB 는 열지 않음).
- 호출: `GET /api/broker/price?symbol=055550.KS` **한 번**(12:43:00 · 앞 증권사 호출 12:41:54 에서 66초) → **200**

```json
{"symbol": "055550.KS", "name": "", "current": 93800.0, "open": 96000.0, "high": 97400.0, "low": 92700.0,
 "volume": 1311344, "change": -400.0, "change_pct": -0.42}
```

- 판정: `change` −400 · `change_pct` −0.42 **둘 다 음수 → 「부호 있음 — 결함 아님」.** KIS 가 `prdy_vrss` 에 부호를 붙여 준다(`app/services/brokers/kis.py:113` 은 그대로 받아도 된다 · 확실도 높음 — 내린 종목 하나로 본 결과).
- 관찰(결함 판정 아님 · 확실도 낮음): KIS 모의 현재가가 실제 마지막 종가와 다르다 — 신한지주 93,800(전일 94,200 − 400) vs 야후 10-16 종가 93,400(+400원), 삼성전자 연결 테스트 「현재가: 217,000원」(12:56:51) vs 야후 10-16 종가 215,500(+1,500원). 같은 때 대시보드 KIS 탭 잔고 평가는 신한지주 3주 280,200원(= 93,400 × 3 · 12:41:56)이라 같은 KIS 모의 서버 안에서도 현재가 조회와 잔고 평가가 다르다. 시간외 단일가 등 다른 값일 수 있다 — 까닭 미확인. 실시간 칸(D109)의 시세 출처를 고를 때 「모의 서버 현재가 = 실제 시세」 로 보지 말 근거가 된다. `name` 칸이 빈 글(`hts_kor_isnm` 없음)인 것도 함께 적는다.
- 응답에 계좌 · 키는 없었다.
