> **실행하는 사람(에이전트)에게:** 이 계획은 `docs/phase-3/06-retrospective/이동원/30분-발표-재구성-설계.md`(사용자 승인 2026-11-11)를 구현한다. 단계는 체크박스(`- [ ]`)로 따라간다. **AI 는 git 을 쓰지 않는다**(전역 10절) — 각 작업 끝의 「커밋」 칸은 쓰지 않고, 마지막 작업 9 에서 `git-handoff` 로 사용자가 돌릴 블록을 만든다.

**목표:** 이동원 파트를 약 8분으로 줄이기 위해, 통합 덱의 영상 장 두 곳(영상 E · 영상 C)에 「자막 없는 영상 + 겹침 층(자막 · 카드 · 말풍선 · 멈춤)」을 만든다.

**구조:** ① 녹화 도구가 자막만 숨긴 「깨끗한 영상」과 장 · 자막 · 강조(좌표 포함)의 기록(`events.json`)을 만든다. ② 큐 파일(YAML)이 기록의 순번에 멈춤 · 카드 · 말풍선을 묶는다. ③ 조립기가 영상 장에 겹침 층 마크업과 JSON 을 넣고 플레이어 JS 가 재생 시각(`currentTime`)으로 자막을 띄우고 큐에서 멈춘다. ④ 번들러가 이미지 · 영상을 한 파일에 넣는다(기존 기능).

**기술:** Python 3.13(`C:\workspace\venvs\demo\Scripts\python.exe`, 스크립트는 `-I`) · Playwright · PyYAML · pytest(`C:\workspace\venvs\qurious\Scripts\python.exe -m pytest`) · 순수 JS(덱 스크립트).

**설계 문서:** `docs/phase-3/06-retrospective/이동원/30분-발표-재구성-설계.md`

## 전역 제약 (설계에서 그대로)

- **영상 길이를 줄이지 않는다**(영상 E 약 2분 2초 · 영상 C 약 55초). 장면 파일의 동작 · `pause` · `say` · pace(E 1.5 · C 1.4)는 고치지 않는다.
- **슬라이드 내용(`이동원/발표자료.html`)을 고치지 않는다.** 덱 조립에서만 뺀다.
- **한 파일 판(`전체-발표자료.html`)만 내려받아도 이미지와 영상이 정상으로 보여야 한다**(사용자 11-11 강조): 영상 · 슬라이드 그림 · **카드 이미지** · 큐 데이터가 파일 안에 있고 외부 요청 0.
- 멈춤 후 이어가기는 키(사용자 선택): 멈춤 중 →·PageDown·스페이스 = 이어서 재생(장 안 넘어감) · 재생 중 →·PageDown = 무시 · 재생 중 스페이스 = 일시정지 · 영상이 끝난 뒤 →·PageDown·스페이스 = 다음 장 · ←·PageUp = 항상 이전 장.
- 강조 박스(ring) · 클릭 물결 · 커서 · 배지는 영상에 남기고, **큰 제목 카드(`#__demo-chap`)와 하단 자막(`#__demo-sub`)만** 숨긴다.
- **녹화는 12:30 수집 회차 전에 끝낸다**(회차 뒤 일지 47행). 수집 회차(12:30~13:10)에는 녹화 · 시험 · 8966 요청을 하지 않는다.
- 문서 · 주석 한국어, 들여쓰기 2칸, 긴 Python 은 파일로(`python -I`).
- 물러서는 시점: **오늘 15:00 까지 한 파일 판 단독 검증을 통과하지 못하면** 설계 7절의 물러서는 길로 간다.

- 큐: 직전 시각 `last` 와 현재 `now` 에서 `last < cue.t <= now` 이고 `now - last < 1.0`(건너뛰기가 아닌 자연 재생)일 때만 `video.pause()` + 카드/말풍선 표시. `enabled:false` 는 건너뜀. 이미 띄운 큐는 다시 안 띄움(되감기 후 다시 지나가면 다시 띄움).
- 말풍선 위치: `rect`(녹화 좌표 `vw×vh`)를 영상 표시 크기로 환산해 옆에 놓되 영상 밖으로 나가면 안쪽으로 밀어 넣는다(검토 초점 5).
- 키 규칙: 전역 제약의 표 그대로. 처리한 키는 `e.preventDefault(); e.stopImmediatePropagation()`.
- 영상 로드 실패(`.nofile`)면 큐를 동작시키지 않는다.
