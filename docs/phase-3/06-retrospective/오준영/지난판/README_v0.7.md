담당 발표는 4~5분, 별도 시연은 3~4분을 제안한다. 팀 전체 시간 배정은 아직 확정하지 않았다. 발표자료의 도식은 동작 설명이며 실제 화면 캡처가 아니다. 실제 KIS 완료 결과는 확인한 과거 기록으로 설명한다.

11/4 기술 시연 확인: 최신 #543 앱과 격리 PostgreSQL·Redis에서 실제 화면→API→DB의 A 흐름 14개, 조회·과거 KIS 근거 전환의 B 흐름 5개를 통과했다. 국면 전환은 시험용 과거 상태와 기준시각을 사용했다. 운영 장부는 보존했으며 이번 시연의 신규 KIS 주문은 0건이다. 사람의 발표 시간 측정·팀 리허설·인수자 실습·영상 제작은 아직 수행하지 않았다. [완료 기록과 화면](../../../04-testing/운영마감-시연검증-2026-11-04.md).

11/4 초안·오후 사실 갱신 → 11/5 기능·자료 1차 확정 → 11/6 팀 통합·대체 영상 → 11/9~10 연습 → 11/11 최종 리허설 → 11/12 오전 발표를 목표로 한다. 팀원의 검토·참석을 대신 확약하지 않는다.

0.6은 **11/6 KIS 모의 3종목 각 10주 매수·매도, 체결 알림 중복 방지, DB0044 운영 전환**을 반영했다. 전체 고유 시험 4,486건 중 4,481통과·2실패·3건너뜀이며, 수정 관련 244통과는 중복 합산하지 않는다. 앱·worker·beat는 10:05 검증 당시 각각 712파일이 일치했다. #583·#584는 main에 병합됐다. 이후 팀 문서 변경을 포함한 현재 main 전체를 다시 시험한 결과로 확대하지 않는다.

자료 검증 결과와 작업환경 정리는 [11/6 발표 마감 기록](../../../04-testing/작업환경-발표마감-2026-11-06.md)에 기록한다. 이전 본문과 PDF는 `지난판/` 및 `내보내기/`에 보존했다. 발표 목표는 4분 20초이며 사람의 낭독·팀 검토·인수자 실습은 아직 미확인이다. 인터넷·앱 연결이 끊기면 이 HTML·PDF·설명 영상의 날짜가 명시된 근거로 설명한다. 자료 검사 9개·PDF 6쪽 통과, 영상 1초·55초·107초 이동 및 재생을 확인했다.


팀 통합 연결: #572의 [전체 발표 초안](../../전체-발표-초안.md)과 [배분 모델 장면](../../videos/장면/V-오준영-A-배분모델.yaml)을 확인했다. 팀 문서는 이동원 PC의 발표용 47초·사용법 103초 영상 제작을 보고하며, A와 다른 담당 편의 최종 MP4는 아직 포함하지 않는다. #619의 B·C는 이 저장소의 [재생 페이지](../영상.html)에서 발표용·사용법용을 각각 볼 수 있다. 시험 입력과 검증 범위는 [영상 검증 기록](../영상-검증기록.md)에 명시한다. 사람의 발표 시간 측정과 팀 리허설은 남는다.
