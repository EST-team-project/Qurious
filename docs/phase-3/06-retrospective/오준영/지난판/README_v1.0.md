담당 발표는 **5분 40초(실측 전)**, 별도 시연은 3~4분을 제안한다. 팀 전체 시간 배정은 아직 확정하지 않았다. 발표자료의 도식은 동작 설명이며 실제 화면 캡처가 아니다. 실제 KIS 완료 결과는 확인한 과거 기록으로 설명한다.

11/11 09:19 병합된 PR #638(59장)을 기준으로 다시 생성했다. 발표자료·대본 **v0.9**는 7장에 사용자 제공 **11/9 매수·매도·비상정지 Discord 알림**의 핵심 문구와 수치를 카드로 재구성했다. 접수와 체결 확정의 시각·가격·금액을 구분하고, 정지 이유와 다음 행동을 보여 준다. 원본 이미지 삽입이 아닌 내용 재구성임을 장 하단에 표시했다. 비상정지 해제 시점은 캡처에 없어 연속된 정지·재개 검증으로 설명하지 않는다. 통합 덱은 총 60장, 오준영 파트는 31~38장, 새 알림 사례는 **37장**이다. 기존 운영·인수 장은 개인 8장·통합 38장으로 이동했다.

이전 발표자료·대본 **v0.8**은 발견한 오류를 **5장 체결 알림 중복(ERR-044)**과 **6장 긴급정지의 KIS 미체결 취소 누락(ERR-051)**으로 나누어 각각 현상·원인·수정·검증을 설명했다. 244건은 체결 알림 신규 2건을 포함한 담당 범위 회귀이고, 300건은 긴급정지 관련 회귀다. KIS 미체결 5주 취소는 별도 실연동 근거다. 11/6 전체 회귀와 11/9 배분 설명 170건은 대본의 질문용 참고와 [검증 근거](검증근거.md)에 남기며 중복 합산하지 않는다. 독립 경보 완료와 실행 조건은 현재 마지막 8장에서 설명한다.

v0.9 자료 검증(11/11): 최신 PR #638 기준으로 통합 원본·한 파일 판을 재생성했다. Windows Chrome에서 오준영 31~38장 표시·넘침·발표자 노트, 이미지와 내장 영상 7편 로드를 확인해 **21개 검사 통과·JavaScript 예외 0건**이었다. 새 37장을 화면으로 검수했다. 다른 담당자와 영상의 50프레임은 쪽번호 참조를 제외하고 최신본과 같으며, 영상 7프레임의 내용도 동일하다. 비공개 근거는 `.codex-work/presentation-alerts-20261111/exports/`와 `scope-check.json`에 보관한다.

v0.8 자료 검증(11/10): Windows Chrome에서 개인 7장·통합본 47~53장의 표시·넘침·발표자 노트, 버튼·키보드·작은 창 맞춤, PDF 7쪽의 **18개 검사 통과·JavaScript 예외 0건**을 확인했다. 새 오류 두 장을 화면으로 검수했고 PDF는 182,282바이트다. 다른 담당자 장과 영상 장의 본문, 영상 관련 파일은 변경하지 않았다. 비공개 근거는 `.codex-work/presentation-errors-20261110/exports/`에 둔다.

이전 v0.7 자료 검증(11/10): Windows Chrome에서 개인 자료 6장·통합본 47~52장의 표시와 넘침, 방향키/버튼, 작은 창 맞춤, 발표자 노트 연결·토글, PDF 6쪽의 **16개 검사 통과·JavaScript 예외 0건**을 확인했다. PDF v0.7은 164,824바이트다. 비공개 렌더링 근거는 `.codex-work/presentation-refresh-20261110/exports/`에 보존한다.

11/4 기술 시연 확인: 최신 #543 앱과 격리 PostgreSQL·Redis에서 실제 화면→API→DB의 A 흐름 14개, 조회·과거 KIS 근거 전환의 B 흐름 5개를 통과했다. 국면 전환은 시험용 과거 상태와 기준시각을 사용했다. 운영 장부는 보존했으며 이번 시연의 신규 KIS 주문은 0건이다. 사람의 발표 시간 측정·팀 리허설·인수자 실습·영상 제작은 아직 수행하지 않았다. [완료 기록과 화면](../../04-testing/운영마감-시연검증-2026-11-04.md).

11/4 초안·오후 사실 갱신 → 11/5 기능·자료 1차 확정 → 11/6 팀 통합·대체 영상 → 11/9~10 연습 → 11/11 최종 리허설 → 11/12 오전 발표를 목표로 한다. 팀원의 검토·참석을 대신 확약하지 않는다.

0.6은 **11/6 KIS 모의 3종목 각 10주 매수·매도, 체결 알림 중복 방지, DB0044 운영 전환**을 반영했다. 전체 고유 시험 4,486건 중 4,481통과·2실패·3건너뜀이며, 수정 관련 244통과는 중복 합산하지 않는다. 앱·worker·beat는 10:05 검증 당시 각각 712파일이 일치했다. #583·#584는 main에 병합됐다. 이후 팀 문서 변경을 포함한 현재 main 전체를 다시 시험한 결과로 확대하지 않는다.

자료 검증 결과와 작업환경 정리는 [11/6 발표 마감 기록](../../04-testing/작업환경-발표마감-2026-11-06.md)에 기록한다. 이전 본문과 PDF는 `지난판/` 및 `내보내기/`에 보존했다. v0.6 당시 발표 목표는 4분 20초였으며 사람의 낭독·팀 검토·인수자 실습은 아직 미확인이다. 인터넷·앱 연결이 끊기면 이 HTML·PDF·설명 영상의 날짜가 명시된 근거로 설명한다. 자료 검사 9개·PDF 6쪽 통과, 영상 1초·55초·107초 이동 및 재생을 확인했다.


팀 통합 연결: #572의 [전체 발표 초안](../전체-발표-초안.md)과 [배분 모델 장면](../videos/장면/V-오준영-A-배분모델.yaml)을 확인했다. 팀 문서는 이동원 PC의 발표용 47초·사용법 103초 영상 제작을 보고하며, A와 다른 담당 편의 최종 MP4는 아직 포함하지 않는다. #619의 B·C는 이 저장소의 [재생 페이지](영상.html)에서 발표용·사용법용을 각각 볼 수 있다. 시험 입력과 검증 범위는 [영상 검증 기록](영상-검증기록.md)에 명시한다. 사람의 발표 시간 측정과 팀 리허설은 남는다.
