담당 발표는 4~5분, 별도 시연은 3~4분을 제안한다. 팀 전체 시간 배정은 아직 확정하지 않았다. 발표자료의 도식은 동작 설명이며 실제 화면 캡처가 아니다. 실제 KIS 완료 결과는 확인한 과거 기록으로 설명한다.

11/4 자료 확인: Chromium에서 6장 표시·넘침, 키보드/버튼 이동, 작은 화면 배율, PDF 6쪽 출력을 포함한 9개 검사를 통과했다. 0.2에서는 변경 문서의 상대 링크를 기존판과 대조해 새 오류 0건을 확인했다. 전체 시연 시간 측정과 인수자 실습은 아직 수행하지 않았다.

11/4 초안·오후 사실 갱신 → 11/5 기능·자료 1차 확정 → 11/6 팀 통합·대체 영상 → 11/9~10 연습 → 11/11 최종 리허설 → 11/12 오전 발표를 목표로 한다. 팀원의 검토·참석을 대신 확약하지 않는다.

0.2는 11/4 실제 KIS 모의 매수·매도, 오전 전체 회귀와 오후 변경분 시험, 11/3 자료 준비, #537 배포를 반영했다. [오후 운영 결과](../../../04-testing/운영최신화-2026-11-04.md)의 실패 2건과 미관측 범위를 포함한다. 지난판은 `지난판/`, 이전 PDF는 `내보내기/발표자료-v0.1.pdf`에 보존했다.
