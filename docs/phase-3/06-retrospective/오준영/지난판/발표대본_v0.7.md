## 1장. 판단을 계획·실행·기록으로 연결 (35초)

“제 담당은 자산배분·리밸런싱과 증권사 연동 자동화입니다. 배분 계산 결과를 사용자가 확인한 계획으로 저장하고, 전략 주문은 위험 검사를 거쳐 결과가 기록되도록 연결했습니다. 앱의 PAPER·QUANT 가상 장부와 KIS 모의계좌는 별도로 관리합니다.”

## 2장. 배분을 계산해도 주문은 바로 나가지 않음 (50초)

“성향별 배분에 리스크 패리티, 최소분산, Black–Litterman, 국면 배분을 추가했습니다. 계산 기준일과 입력 조건을 함께 남깁니다. 저장한 배분을 가져오고 목표와 국면 연결 설정을 확인한 뒤 플랜을 저장합니다. 국면 자동 갱신은 사용자가 따로 켜서 저장해야 하며, 자동 주문 예약과도 별도입니다. 기본 가져오기는 국내주식 부분만 쓰고 나머지를 현금으로 남깁니다.”

## 3장. 전략 주문 앞뒤를 확인 (45초)

“자료 준비와 전략 판단 뒤 중복·손실 한도·비상 정지를 검사하고, 접수된 주문은 번호로 체결을 추적합니다. 비상 정지는 자동매매 계열과 개인 KIS 모의 주문에 적용합니다. 웹 직접매매·일반 PAPER·외부 Open API는 적용 밖이며, 보유 종목을 자동 청산하지 않습니다. QUANT 판 2에서 조정 사건을 감지해 보류하면 자동 손절·익절도 중단됩니다. 수량·가격의 자동 교정과 보류 해제는 아직 지원하지 않습니다.”

## 4장. KIS 모의 체결과 긴급정지 취소 확인 (45초)

“11월 6일 시험 진단의 추천 목록에서 세 종목을 각 10주씩 KIS 모의계좌로 매수하고 전량 매도했습니다. 여섯 주문 모두 체결됐습니다. 11월 9일에는 긴급정지 API만으로 미체결 5주가 취소되는 것을 확인했습니다. 반복 정지는 취소를 다시 보내지 않았고, 정지 중 신규 매수·매도·자동 시작도 차단됐습니다. 두 시험 모두 기존 삼성전자 1주와 위험 설정을 보존했습니다. 이는 가상 자금의 기능 검증이며 전략 수익성 검증은 아닙니다.”

## 5장. 시험 결과와 발견한 오류 (45초)

“11월 6일 전체 시험은 당시 4,481건 통과, 2건 실패, 3건 건너뜀이었습니다. 이후 수수료·인코딩·공통 화면 시험 수정이 병합됐지만 과거 실행 결과는 그대로 남겼습니다. 11월 9일에는 긴급정지 관련 300건과 성향 설명·배분 관련 170건을 각각 통과했습니다. 이 묶음들은 중복 합산하지 않습니다. 체결 알림 중복도 주문 식별자로 발송 권한을 선점하도록 수정했습니다. 이 결과를 최신 main 전체가 통과했다는 뜻으로 확대하지 않습니다.”

## 6장. 운영 조건과 남은 확인 (40초)

“알림 암호화는 11월 6일 전환했고, 11월 9일에는 DB0046과 세 서비스의 717파일 일치를 확인했습니다. Windows에서 5분마다 실행하는 독립 경보도 설치했고 Discord 연결 시험의 실제 수신을 확인했습니다. 다만 로그인 중에 실행하므로 로그아웃·절전 중 감시를 보장하지 않습니다. 주문 알림의 읽음 확인과 경보 수신은 구분합니다. 인수자의 새 PC 복원 실습과 PAPER 보유 자산의 자연 평가는 남아 있습니다.”

발표 직전에 마지막 장의 관측 날짜를 확인한다. 11/5 현금 스냅샷·11/6 및 11/9 운영 점검을 발표 당일의 성공으로 확대하지 않는다. 11/9 배분 설명 수정의 170건은 수정 후보 검증이며 운영 배포 완료를 뜻하지 않는다.

| 시험을 통과했으면 프로젝트 오류가 없나요? | 코드·환경·범위별 근거다. 11/6 당시 2실패·3건너뜀 기록은 보존한다. 수수료·인코딩·공통 화면 시험은 후속 수정이 병합됐고 11/9 관련 회귀도 별도로 통과했지만, 최신 main 전체 무결함을 뜻하지 않는다. 영상 미검증은 별도로 기록한다. |
| 독립 경보는 언제 실행되나요? | Windows 사용자 로그인 중 5분 간격으로 Docker 상태·암호화 오류 로그를 검사한다. Discord 연결 시험과 실제 수신을 확인했지만 로그아웃·절전 중 24시간 감시나 실제 키 훼손 시험을 완료한 것은 아니다. |

| 국내주식 15%면 나머지도 모두 매수하나요? | 기본 가져오기는 나머지 85%를 현금으로 남긴다. ETF 포함 경로는 별도 선택·확인한다. |
| 원격 합격 전략이 연결됐나요? | 정식 공급원 연결은 별도다. 명시적 고정 시험 전략과 본인 전략 실행 경로를 구분한다. |
