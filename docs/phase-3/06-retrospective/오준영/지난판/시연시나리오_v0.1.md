두 흐름을 총 3~4분으로 제안한다. 자산배분→리밸런싱과 전략→증권사 주문은 서로 다른 실행 경로로 보여 준다. 리밸런싱이 KIS 계좌를 직접 매매한다고 설명하지 않는다.

## 1. 시연 전 준비

1. 발표용 계정과 자료 기준일을 정한다. 계산·저장·국면 연결 조작은 운영 계정과 분리한 시험 환경에서 진행한다.
2. 화면의 계좌·개인 정보는 시험용 값이나 마스킹된 값만 보이게 한다. 알림 원문과 개발자 도구의 세션 값은 띄우지 않는다.
3. 자료 준비 상태를 확인한다. 당일 자료가 준비되지 않았으면 대기 화면의 정상 차단을 보여 주고 날짜를 적은 이전 검증 근거로 이어간다.
4. 자동 주문·KIS 시험 명령은 시연 시작 동작에 포함하지 않는다. 과거 실제 모의 체결 결과와 현재 화면 조회를 구분해 설명한다.

## 2. 흐름 A: 배분과 리밸런싱 (약 2분)

| 순서 | 조작 | 보여 줄 결과·설명 |
|---|---|---|
| A1 | `app.html#robo-portfolio`에서 성향·기간·배분 모델 선택 | 리스크 패리티·최소분산·BL·국면 중 목적에 맞는 계산. 기준일과 입력 조건 확인 |
| A2 | 시험 계정에서 계산·저장 | 자산군별 비중과 저장 결과. 저장만으로 주문하지 않음 |
| A3 | `app.html#robo-rebalance`에서 저장한 배분 가져오기 | 기본 국내주식 목표와 현금, 적용하지 않은 자산군을 읽어 줌. 별도 ETF 포함 경로는 선택했을 때만 설명 |
| A4 | 시험 환경에서 국면 자동 갱신 체크→저장→새로고침 | 명시적으로 켠 상태만 보존. 자동 예약은 별도 설정 |
| A5 | 준비된 격리 전환 이력 또는 날짜가 적힌 검증 근거 열기 | 합성 과거 상승 상태→11/2 실제 자료의 하락·고변동: 국내 목표 33%→15%, 현금 67%→85%인 국내주식 전용 사례. 운영 자연 전환으로 설명하지 않음 |

오늘 11/4 오전의 실제 자료는 아직 11/2까지다. 자료 대기 때문에 저장·연결 조건을 충족하지 못하면 우회하지 않는다. 먼저 A1의 기준일과 대기 이유를 보여 주고, A4~A5는 검증 자료 설명으로 대체한다. 녹화본 준비 여부는 완료 표에 따로 기록한다.

## 3. 흐름 B: 전략 실행과 모의 주문 추적 (약 1~2분)

| 순서 | 조작 | 보여 줄 결과·설명 |
|---|---|---|
| B1 | `app.html#quant-auto`에서 전략·판·계좌·위험 설정 확인 | 시험 전략과 개인 전략, QUANT 가상 장부와 KIS 모의계좌 구분 |
| B2 | 판단·실행 기록과 거부 사유 조회 | 같은 신호 중복, 손실 한도, 비상 정지, 자료 미준비가 주문을 막는 위치 |
| B3 | 날짜가 적힌 KIS 모의 성공 근거 열기 | 11/3 취소 확정 1주→잔량 재주문 1주 체결, 시험 보유 0주·기존 전략 보유 보존·설정 원복 |
| B4 | 마스킹한 알림 기록·주문 연결 설명 | 주문 접수와 체결 완료를 구분. 서버가 계속 실행돼야 주기 감시와 추적이 동작 |

실시간 KIS 신규 주문·30분 대기·취소·재주문을 발표 중 재현하는 구성은 채택하지 않는다. 11/3에 확인한 완료 결과를 설명하고 질문이 나오면 재현 절차와 제한을 보여 준다.

## 4. 실패하면 전환할 화면

| 상황 | 조치 |
|---|---|
| 최신 일봉 없음 | 자료 기준일·대기 이유 표시 후 이전 날짜가 명시된 근거 설명 |
| 로그인·네트워크 장애 | 로컬 발표자료의 흐름도와 검증 표로 전환. 준비된 경우 녹화본 사용 |
| 새 국면 변화 없음 | 같은 국면에서는 목표를 유지하는 정상 동작 설명. 변화를 만들려고 운영 상태를 변경하지 않음 |
| 예기치 않은 주문/보유 | 시연 조작 중단, 해당 계좌의 기존 주문과 자동 설정부터 확인 |
