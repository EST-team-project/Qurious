## 1장. 판단을 계획·실행·기록으로 연결 (35초)

“제 담당은 자산배분·리밸런싱과 증권사 연동 자동화입니다. 배분 계산 결과를 사용자가 확인한 계획으로 저장하고, 전략 주문은 위험 검사를 거쳐 결과가 기록되도록 연결했습니다. 앱의 PAPER·QUANT 가상 장부와 KIS 모의계좌는 별도로 관리합니다.”

## 2장. 배분을 계산해도 주문은 바로 나가지 않음 (50초)

“성향별 배분에 리스크 패리티, 최소분산, Black–Litterman, 국면 배분을 추가했습니다. 계산 기준일과 입력 조건을 함께 남깁니다. 저장한 배분을 가져오고 목표와 국면 연결 설정을 확인한 뒤 플랜을 저장합니다. 국면 자동 갱신은 사용자가 따로 켜서 저장해야 하며, 자동 주문 예약과도 별도입니다. 기본 가져오기는 국내주식 부분만 쓰고 나머지를 현금으로 남깁니다.”

## 3장. 전략 주문 앞뒤를 확인 (45초)

“자료가 준비됐는지 확인한 다음 전략을 평가하고, 중복·손실 한도·비상 정지·귀속 보유를 검사합니다. 증권사 접수 성공과 실제 체결은 다른 상태이므로 주문 번호로 추적합니다. 현재 감시는 우리 서버가 주기적으로 판단하는 방식이며, 서버가 꺼져도 증권사가 대신 감시하는 기능은 이번 완료 범위가 아닙니다.”

## 4장. 취소 확인 뒤 남은 수량만 재주문 (45초)

“취소 요청을 받았다는 응답만으로 재주문하지 않습니다. 실제 체결량과 취소 확정량, 남은 수량을 대조합니다. 11월 3일 KIS 모의계좌에서 원 주문 1주의 취소와 잔량 1주의 재주문 체결을 확인했습니다. 시험 보유를 정리하고 기존 전략 보유를 보존했으며 임시 위험 설정도 원복했습니다. 11월 4일에는 별도 수동 API로 모의 1주 매수·매도도 확인했습니다. 실제 모의 환경 검증이며 전략 수익성을 입증하지는 않습니다.”

## 5장. 시험 종류별로 확인 범위를 구분 (45초)

“11월 4일 오전 전체 시험은 환경별 중복을 제외해 4,253건 통과, 3건 건너뜀이었습니다. Linux의 Windows 경로 시험 실패 7건은 동일 소스를 Windows에서 확인했습니다. 오후 #543 기준 변경분은 224건 통과했고 비용 판정 기대값 시험 1건은 다른 담당의 확인이 남았습니다. Yahoo 표기 기준선은 후속 PR에서 수정돼 통과했습니다. 실제 화면과 API·DB를 잇는 기술 시연은 19항목을 통과했습니다. 앱·worker·beat는 각각 701파일이 병합본과 일치하며, 운영 조회와 장부 보존을 확인했습니다.”

## 6장. 운영 조건과 남은 확인 (40초)

“자료가 오래됐거나 갱신 완료 기록이 없으면 판단을 보류합니다. 11월 4일 오전의 자료 대기와 오후 11월 3일 일봉 준비 완료를 각각 확인했습니다. 오늘 15시 40분 현금 계좌 3개의 일일 스냅샷은 자연 실행을 확인했지만, 보유 자산의 운영 자연 평가는 별도입니다. 인수인계에는 정상 확인 순서와 장애·복원 절차, 이 한계들을 함께 남깁니다.”

발표 직전에 마지막 장의 날짜·자료 상태를 다시 확인한다. 11/4 15:40 현금 스냅샷 성공을 다른 날짜나 보유 계좌 평가에 확대하지 않는다.

## 예상 질문

| 질문 | 답변 요점 |
|---|---|
| 실제 돈으로 주문했나요? | KIS 모의투자와 앱 가상 장부로 확인했다. 실전 투자 검증이 아니다. |
| 국면이 바뀌면 바로 매매하나요? | 명시적으로 켠 플랜의 목표 갱신이며 기존 승인·예약·가격 검증을 따른다. |
| 서버가 꺼져도 손절되나요? | 현재는 우리 서버 주기 감시다. 증권사 상주 감시를 제공한다고 설명하지 않는다. |
| 시험을 통과했으면 프로젝트 오류가 없나요? | 코드·환경·범위별 근거다. 오후 #543 변경분 시험에는 비용 판정 기대값 실패 1건이 남아 있으며 미시험·보류도 구분한다. |
| BL의 시장 균형은 어떻게 얻나요? | 성향 또는 사용자 기준 비중이다. 시가총액 시장 비중을 자동 수집한 모델이 아니다. |
| 국내주식 15%면 나머지도 모두 매수하나요? | 기본 가져오기는 나머지 85%를 현금으로 남긴다. ETF 포함 경로는 별도 선택·확인한다. |
| 원격 합격 전략이 연결됐나요? | 정식 공급원 연결은 별도다. 명시적 고정 시험 전략과 본인 전략 실행 경로를 구분한다. |
