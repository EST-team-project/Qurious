## 1장. 판단을 계획·실행·기록으로 연결 (35초)

“제 담당은 자산배분·리밸런싱과 증권사 연동 자동화입니다. 배분 계산 결과를 사용자가 확인한 계획으로 저장하고, 전략 주문은 위험 검사를 거쳐 결과가 기록되도록 연결했습니다. 앱의 PAPER·QUANT 가상 장부와 KIS 모의계좌는 별도로 관리합니다.”

## 2장. 배분을 계산해도 주문은 바로 나가지 않음 (50초)

“성향별 배분에 리스크 패리티, 최소분산, Black–Litterman, 국면 배분을 추가했습니다. 계산 기준일과 입력 조건을 함께 남깁니다. 저장한 배분을 가져오고 목표와 국면 연결 설정을 확인한 뒤 플랜을 저장합니다. 국면 자동 갱신은 사용자가 따로 켜서 저장해야 하며, 자동 주문 예약과도 별도입니다. 기본 가져오기는 국내주식 부분만 쓰고 나머지를 현금으로 남깁니다.”

## 3장. 전략 주문 앞뒤를 확인 (45초)

“자료가 준비됐는지 확인한 다음 전략을 평가하고, 중복·손실 한도·비상 정지·귀속 보유를 검사합니다. 증권사 접수 성공과 실제 체결은 다른 상태이므로 주문 번호로 추적합니다. 현재 감시는 우리 서버가 주기적으로 판단합니다. QUANT 판 2는 보유 중 가격 조정 사건을 감지하면 추가 진입·자동 청산을 보류합니다. 보류 중에는 자동 손절·익절도 실행되지 않고, 수량·평단·손절·익절선의 자동 교정과 보류 해제는 아직 지원하지 않습니다.”

## 4장. KIS 모의 3종목 매수·매도 확인 (45초)

“11월 6일 홈페이지 시험 진단의 추천 목록에서 하나금융지주·S-Oil·삼성에스디에스를 각 10주 골라 KIS 모의계좌로 매수하고 전량 매도했습니다. 여섯 주문 모두 체결됐고 시험 잔량과 미체결은 0이며 기존 삼성전자 1주와 위험 설정은 보존했습니다. 11월 3일에는 취소 확정 뒤 남은 1주만 재주문하는 경로도 별도로 확인했습니다. 가상 자금을 쓰는 모의 주문 기능 검증이며 전략 수익성 검증은 아닙니다.”

## 5장. 시험 결과와 발견한 오류 (45초)

“11월 6일 전체 시험은 환경별 보충을 같은 사례끼리 대조해 4,481건 통과, 2건 실패, 3건 건너뜀입니다. 같은 체결을 두 경로가 확인해 알림을 중복 전송하던 담당 오류를 주문 식별자 선점으로 수정했고 관련 244건을 통과했습니다. 주문 자체의 중복은 없었습니다. 10시 5분 운영 검증에서 세 서비스 각각 712파일이 일치했습니다. 수수료 판정과 키 교체 도구 실패는 담당자의 후속 확인 대상으로 남겼습니다.”

## 6장. 운영 조건과 남은 확인 (40초)

“알림 암호화는 11월 6일 DB0044로 전환했고 기존 키·설정·장부를 보존했습니다. 이후 체결 알림 수정도 반영했습니다. 주문 알림의 전달 성공 기록과 사용자가 직접 읽었다는 확인은 구분합니다. 상시 경보 연결과 인수자의 복원 실습은 남아 있습니다. 자료가 준비되지 않으면 판단을 보류하며, 보유 자산의 자연 스냅샷은 해당 계좌가 없어 아직 관측하지 못했습니다.”

발표 직전에 마지막 장의 관측 날짜를 확인한다. 11/5 현금 스냅샷·11/6 운영 점검을 이후 날짜의 성공으로 확대하지 않는다.

## 예상 질문

| 질문 | 답변 요점 |
|---|---|
| 실제 돈으로 주문했나요? | KIS 모의투자와 앱 가상 장부로 확인했다. 실전 투자 검증이 아니다. |
| 국면이 바뀌면 바로 매매하나요? | 명시적으로 켠 플랜의 목표 갱신이며 기존 승인·예약·가격 검증을 따른다. |
| 서버가 꺼져도 손절되나요? | 현재는 우리 서버 주기 감시다. 증권사 상주 감시를 제공한다고 설명하지 않는다. |
| 조정 사건으로 보류하면 손절은 계속되나요? | QUANT 판 2의 보류 중에는 자동 손절·익절도 실행되지 않는다. 수량·평단·손절·익절선의 자동 교정과 보류 해제는 미지원이다. |
| 시험을 통과했으면 프로젝트 오류가 없나요? | 코드·환경·범위별 근거다. 11/6 고유 집계에 수수료·키 교체 도구 2실패가 남고, 확장 브라우저 시험 실패 3건과 영상 미검증은 별도로 기록한다. |
| BL의 시장 균형은 어떻게 얻나요? | 성향 또는 사용자 기준 비중이다. 시가총액 시장 비중을 자동 수집한 모델이 아니다. |
| 국내주식 15%면 나머지도 모두 매수하나요? | 기본 가져오기는 나머지 85%를 현금으로 남긴다. ETF 포함 경로는 별도 선택·확인한다. |
| 원격 합격 전략이 연결됐나요? | 정식 공급원 연결은 별도다. 명시적 고정 시험 전략과 본인 전략 실행 경로를 구분한다. |

## 리허설 기록
