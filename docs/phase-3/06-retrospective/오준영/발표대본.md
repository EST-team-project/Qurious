## 1장. 판단을 계획으로, 실행을 기록으로 (35초)

“제 담당은 자산배분·리밸런싱과 증권사 연동 자동화입니다. 배분 계산 결과를 사용자가 확인한 계획으로 저장하고, 전략 주문은 위험 검사를 거쳐 결과가 기록되도록 연결했습니다. 앱의 PAPER·QUANT 가상 장부와 KIS 모의계좌는 별도로 관리합니다.”

## 2장. 계산 결과는 사용자의 확인을 거쳐 적용합니다 (50초)

“성향별 배분에 리스크 패리티, 최소분산, Black–Litterman, 국면 배분을 추가했습니다. 계산 기준일과 입력 조건을 함께 남깁니다. 저장한 배분을 가져오고 목표와 국면 연결 설정을 확인한 뒤 플랜을 저장합니다. 국면 자동 갱신은 사용자가 따로 켜서 저장해야 하며, 자동 주문 예약과도 별도입니다. 기본 가져오기는 국내주식 부분만 쓰고 나머지를 현금으로 남깁니다.”

## 3장. 주문 전 검증하고, 접수 후 체결을 추적합니다 (45초)

“자료 준비와 전략 판단 뒤 중복·손실 한도·비상 정지를 검사하고, 접수된 주문은 번호로 체결을 추적합니다. 비상 정지는 자동매매 계열과 개인 KIS 모의 주문에 적용합니다. 웹 직접매매·일반 PAPER·외부 Open API는 적용 밖이며, 보유 종목을 자동 청산하지 않습니다. QUANT 판 2에서 조정 사건을 감지해 보류하면 자동 손절·익절도 중단됩니다. 수량·가격의 자동 교정과 보류 해제는 아직 지원하지 않습니다.”

## 4장. 3종목 30주를 매수하고, 전량 매도했습니다 (35초)

“11월 6일 시험 진단의 추천 목록에서 세 종목을 각 10주씩 KIS 모의계좌로 매수하고 전량 매도했습니다. 앱 기록과 증권사 조회에서 여섯 주문의 체결을 대조했고, 시험 잔량과 미체결은 0이었습니다. 기존 삼성전자 1주와 위험 설정은 보존했습니다. 이 연결 시험에서 찾은 알림 오류와, 이후 긴급정지에서 찾은 취소 누락을 이어서 설명하겠습니다. 가상 자금의 기능 검증이며 전략 수익성 검증은 아닙니다.”

## 5장. 체결은 한 번인데, 알림이 두 번 왔습니다 (45초)

“첫 번째는 체결은 한 번인데 알림이 두 번 온 문제입니다. 삼성에스디에스 10주 매수 때 정기 체결 확인과 복구 조회가 같은 주문을 확인해 2초 간격으로 알림을 보냈습니다. 공통 발송에 주문을 구분할 기준이 없었던 것이 원인입니다. 두 경로가 같은 주문 ID를 전달하고 DB에서 발송 권한을 먼저 확보한 호출만 보내도록 수정했습니다. 실제 DB에서 동시 호출과 재조회를 확인했고 신규 두 시험을 포함한 담당 회귀 244건을 통과했습니다. 주문 자체의 중복은 없었습니다.”

## 6장. 긴급정지에서 KIS 미체결 취소가 빠졌습니다 (45초)

“두 번째는 긴급정지가 신규 주문은 막지만 개인 KIS 모의 주문의 미체결 취소를 건너뛰던 문제입니다. 기존 취소 함수가 직접 KIS 주문을 제외했고, 정지 후 별도 취소 시험으로는 이 연결 누락을 찾지 못했습니다. 수동 정지와 일손실 정지에 기존 KIS 취소 서비스를 연결했습니다. 실제 KIS 모의 미체결 5주를 긴급정지 API만으로 취소했고 반복 취소 전송은 없었습니다. 관련 회귀 300건도 통과했습니다. 취소 요청과 확정은 구분하며 보유 종목을 자동 청산하는 기능은 아닙니다.”

## 7장. 암호화·독립 경보를 운영에 연결했습니다 (40초)

“알림 암호화는 11월 6일 전환했고, 11월 9일에는 DB0046과 세 서비스의 717파일 일치를 확인했습니다. Windows에서 5분마다 실행하는 독립 경보도 설치했고 Discord 연결 시험의 실제 수신을 확인했습니다. 다만 로그인 중에 실행하므로 로그아웃·절전 중 감시를 보장하지 않습니다. 주문 알림의 읽음 확인과 경보 수신은 구분합니다. 인수자의 새 PC 복원 실습과 PAPER 보유 자산의 자연 평가는 남아 있습니다.”

발표 직전에 마지막 장의 관측 날짜를 확인한다. 11/5 현금 스냅샷·11/6 운영 점검을 이후 날짜의 성공으로 확대하지 않는다.

|---|---|
| 실제 돈으로 주문했나요? | KIS 모의투자와 앱 가상 장부로 확인했다. 실전 투자 검증이 아니다. |
| 국면이 바뀌면 바로 매매하나요? | 명시적으로 켠 플랜의 목표 갱신이며 기존 승인·예약·가격 검증을 따른다. |
| 서버가 꺼져도 손절되나요? | 현재는 우리 서버 주기 감시다. 증권사 상주 감시를 제공한다고 설명하지 않는다. |
| 조정 사건으로 보류하면 손절은 계속되나요? | QUANT 판 2의 보류 중에는 자동 손절·익절도 실행되지 않는다. 수량·평단·손절·익절선의 자동 교정과 보류 해제는 미지원이다. |
| 시험을 통과했으면 프로젝트 오류가 없나요? | 코드·환경·범위별 근거다. 11/6 고유 집계에 수수료·키 교체 도구 2실패가 남고, 확장 브라우저 시험 실패 3건과 영상 미검증은 별도로 기록한다. |
| BL의 시장 균형은 어떻게 얻나요? | 성향 또는 사용자 기준 비중이다. 시가총액 시장 비중을 자동 수집한 모델이 아니다. |
| 국내주식 15%면 나머지도 모두 매수하나요? | 기본 가져오기는 나머지 85%를 현금으로 남긴다. ETF 포함 경로는 별도 선택·확인한다. |
| 원격 합격 전략이 연결됐나요? | 정식 공급원 연결은 별도다. 명시적 고정 시험 전략과 본인 전략 실행 경로를 구분한다. |
