## 1장. 판단을 계획·실행·기록으로 연결 (35초)

“제 담당은 자산배분·리밸런싱과 증권사 연동 자동화입니다. 배분 계산 결과를 사용자가 확인한 계획으로 저장하고, 전략 주문은 위험 검사를 거쳐 결과가 기록되도록 연결했습니다. 앱의 PAPER·QUANT 가상 장부와 KIS 모의계좌는 별도로 관리합니다.”

## 2장. 배분을 계산해도 주문은 바로 나가지 않음 (50초)

“성향별 배분에 리스크 패리티, 최소분산, Black–Litterman, 국면 배분을 추가했습니다. 계산 기준일과 입력 조건을 함께 남깁니다. 저장한 배분을 가져오고 목표와 국면 연결 설정을 확인한 뒤 플랜을 저장합니다. 국면 자동 갱신은 사용자가 따로 켜서 저장해야 하며, 자동 주문 예약과도 별도입니다. 기본 가져오기는 국내주식 부분만 쓰고 나머지를 현금으로 남깁니다.”

## 3장. 전략 주문 앞뒤를 확인 (45초)

“자료가 준비됐는지 확인한 다음 전략을 평가하고, 중복·손실 한도·비상 정지·귀속 보유를 검사합니다. 증권사 접수 성공과 실제 체결은 다른 상태이므로 주문 번호로 추적합니다. 현재 감시는 우리 서버가 주기적으로 판단합니다. QUANT 판 2는 보유 중 가격 조정 사건을 감지하면 추가 진입·자동 청산을 보류합니다. 보류 중에는 자동 손절·익절도 실행되지 않고, 수량·평단·손절·익절선의 자동 교정과 보류 해제는 아직 지원하지 않습니다.”

## 4장. 취소 확인 뒤 남은 수량만 재주문 (45초)

“취소 요청을 받았다는 응답만으로 재주문하지 않습니다. 실제 체결량과 취소 확정량, 남은 수량을 대조합니다. 11월 3일 KIS 모의계좌에서 원 주문 1주의 취소와 잔량 1주의 재주문 체결을 확인했습니다. 시험 보유를 정리하고 기존 전략 보유를 보존했으며 임시 위험 설정도 원복했습니다. 11월 5일에는 모의 10주 매수와 4주·6주 분할 매도를 모두 체결 확인했고 기존 전략 1주와 위험 설정을 보존했습니다. 실제 모의 환경 검증이며 전략 수익성을 입증하지는 않습니다.”

## 5장. 시험 종류별로 확인 범위를 구분 (45초)

“11월 5일 오후 가격 조정 사건의 보류 처리와 화면·알림을 포함한 관련 시험 442건이 통과했습니다. 배포한 화면은 데스크톱과 모바일에서 확인했고, 앱·worker·beat 각각 708파일이 배포 커밋과 일치했습니다. 오전 전체 회귀에서 남았던 비용 판정과 환경별 시험 결과는 별도 기록하며, 관련 시험 통과를 프로젝트 전체 무결함으로 설명하지 않습니다.”

## 6장. 운영 조건과 남은 확인 (40초)

“자료가 오래됐거나 갱신 완료 기록이 없으면 판단을 보류합니다. 11월 5일 오전에는 자료를 기다렸고 오후에는 11월 4일 일봉과 수신 검증 기록이 준비됐습니다. 11월 5일 15시 40분 현금 계좌 3개의 스냅샷도 예약 전송부터 저장까지 자연 실행을 확인했습니다. 보유 주식이 있는 PAPER 계좌는 없어 보유 자산 평가는 아직 확인하지 못했습니다. 인수인계에는 정상 확인 순서와 장애·복원 절차, 남은 조건을 함께 기록했습니다.”

발표 직전에 마지막 장의 날짜·자료 상태를 다시 확인한다. 11/5 15:40 현금 스냅샷 성공을 다른 날짜나 보유 계좌 평가에 확대하지 않는다.
