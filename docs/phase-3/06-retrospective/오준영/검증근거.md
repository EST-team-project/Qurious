## 2. 현재 조건과 과거 관측

**11/10 자료 갱신 기준:** 11/9 긴급정지 취소 검증과 DB0046 운영 점검, 성향 설명 수정 후보의 170건 통과를 반영했다. 이 수치들은 기록된 실행 결과이며 발표 준비 중 운영 점검이나 모의 주문을 새로 수행한 결과가 아니다. 호스트 경보 설치와 Discord 연결 시험 수신은 완료됐고, Windows 로그인 중 5분 간격이라는 조건을 함께 설명한다. 인수자 복원 실습·PAPER 보유 자산 자연 평가·사람의 발표 시간 측정은 남아 있다.

**비상 정지 범위:** 자동매매 계열·개인 KIS 수동 모의 주문에 적용한다. 웹 직접매매·일반 PAPER·외부 Open API 주문은 적용 밖이며, 보유 종목 자동 청산을 뜻하지 않는다. [#613 담당 답변](https://github.com/EST-team-project/Qurious/issues/613#issuecomment-6731745075), [작업 계획 §64](../../00-management/plans/오준영파트-할일.md#64-11월-9일--611-투자성향-설명-수정과-613-주문-안전-범위-답변).

**11/6 실패의 후속:** 수수료 시험은 담당자 8건 통과 보고와 #593 병합, 인코딩·공통 화면 시험은 #594 병합이 확인됐다. 당시 전체 2실패를 소급해 0으로 바꾸지 않으며, 11/9의 300건·170건이나 11/6 알림 수정 관련 244건을 전체 고유 집계에 더하지 않는다. [후속 상태 기록](../../04-testing/전체회귀-2026-11-06.md#후속-상태--593594-및-담당-경보).

**아래 11/6·11/5·11/4 문단은 당시 상태를 보존한 기록이다. 완료 여부는 위 현재 조건을 따른다.**

**11/6 10:05 최종 운영 검증:** 모의 30주 왕복을 마쳤고 자동매매 OFF·시험 잔량 0·미체결 0을 확인했다. 추천 모델 기준일은 11/4, 품질 기준 미달로 `관망`이었다. 요청한 주문 기능 검증용 선택이며 투자 권유나 자연 BUY 신호로 설명하지 않는다.
