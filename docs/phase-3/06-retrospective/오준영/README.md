담당 발표는 4~5분, 별도 시연은 3~4분을 제안한다. 팀 전체 시간 배정은 아직 확정하지 않았다. 발표자료의 도식은 동작 설명이며 실제 화면 캡처가 아니다. 실제 KIS 완료 결과는 확인한 과거 기록으로 설명한다.

11/4 기술 시연 확인: 최신 #543 앱과 격리 PostgreSQL·Redis에서 실제 화면→API→DB의 A 흐름 14개, 조회·과거 KIS 근거 전환의 B 흐름 5개를 통과했다. 국면 전환은 시험용 과거 상태와 기준시각을 사용했다. 운영 장부는 보존했으며 이번 시연의 신규 KIS 주문은 0건이다. 사람의 발표 시간 측정·팀 리허설·인수자 실습·영상 제작은 아직 수행하지 않았다. [완료 기록과 화면](../../04-testing/운영마감-시연검증-2026-11-04.md).

11/4 초안·오후 사실 갱신 → 11/5 기능·자료 1차 확정 → 11/6 팀 통합·대체 영상 → 11/9~10 연습 → 11/11 최종 리허설 → 11/12 오전 발표를 목표로 한다. 팀원의 검토·참석을 대신 확약하지 않는다.

0.5는 **#561 조정 사건 보류 경고·알림과 14:56 제품 배포, 관련 442통과, KIS 모의 10주 매수·4/6주 분할 매도**를 반영했다. 11/4 일봉과 수신 검증 기록은 오후에 준비됐으며, 11/5 15:40 자연 실행의 현금 스냅샷 3건도 완전 상태로 확인했다. 오전 전체 회귀 및 기술 시연 19항목은 당시 소스·환경의 근거로 유지한다. 남은 비용 판정 계약과 환경별 실패는 전체 결과에서 구분한다. [오늘 결과](../../04-testing/기능마감-검증-2026-11-05.md). 이전 본문과 PDF는 `지난판/` 및 `내보내기/`에 보존했다.

자료 검증: 0.5의 Chromium 화면·이동·배율·PDF 검사 9개 통과, 콘솔 오류 0·PDF 6쪽. 변경 문서와 지난판의 상대 링크 존재를 확인했다. 사용자 확인(11/5): 아직 발표 연습 전이며, 팀 검토도 미실시다.


팀 통합 연결: #572의 [전체 발표 초안](../전체-발표-초안.md)과 [배분 모델 장면](../videos/장면/V-오준영-A-배분모델.yaml)을 확인했다. 팀 문서는 이동원 PC의 발표용 47초·사용법 103초 영상 제작을 보고하며, 이 저장소에는 장면·도구만 공유되고 mp4는 아직 없다. 이 PC에서 최종 영상 재생·자막 대조를 마친 것은 아니다. 담당 대본·검증 근거를 팀 초안에 연결하고 최종 재생본과 사람의 시간을 확인하는 일이 남는다.
