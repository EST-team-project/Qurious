## 2. 녹화 · 내보내기

앱을 개발 모드로 켠 뒤(`scripts/personal/start.ps1 -Dev -NoBrowser`) 저장소 뿌리에서, 녹화용 파이썬(`C:\workspace\venvs\demo` — playwright · pyyaml · imageio-ffmpeg)으로:

```bash
python tools/demo/record_demo.py --no-video <장면.yaml>              # 단계만 밟아 누를 곳 확인
python tools/demo/record_demo.py --frames <장면.yaml>                # 녹화 + 자막 · 장 순간 프레임(눈으로 확인)
python tools/demo/record_demo.py --inventory <화면키,화면키>            # 화면마다 누를 곳 목록
python tools/demo/export_mp4.py --check                              # 3차 폴더 기준 상태(기본 --phase 3)
python tools/demo/export_mp4.py                                      # 새로 찍은 편만 mp4 로
```

- **진행 속도**: 장면 맨 위 `pace: 1.4` (또는 `--pace`) — 대기 · 이동 · 장 제목 시간이 줄어 2차 영상(1.0)보다 빠르다. 자막 한 줄은 1.5초 아래로는 줄이지 않는다.
- 나머지 단계 · 규칙(`say` · `chapter` · `go` · `click` · `wait` 등)은 [2차 README 2절](../../../phase-2/06-retrospective/videos/README.md)과 같다.

> **#619의 오준영 B·C는 발표용·사용법용 총 4개 MP4와 포스터·자막·목록을 저장소에 포함한다.** [영상 재생 페이지](../오준영/영상.html) · [촬영 조건과 검증](../오준영/영상-검증기록.md). B의 과거 국면은 시험 입력이며 C는 체결 0건인 초기 판단·차단 기록이다. 다른 편의 기존 녹화본과 전체 자료 한 파일 판은 아직 포함하지 않는다.


- 파일: 사용법 `파일/사용법/V-….mp4` · 발표 `파일/발표/P-….mp4` · 같은 이름의 포스터(`.jpg`). H.264 · 1080p · 편마다 10 MB 안.
- **발표 자료 한 파일 판** — `python tools/deck/build_team_deck.py`(담당자 덱 · 장면 파일 → 중간 파일 `../전체-발표자료-원본.html` · git 에 올리지 않음) → `python tools/deck/bundle_deck.py --src ../전체-발표자료-원본.html --out ../전체-발표자료.html`. 영상 · 포스터 · 글꼴을 HTML 안에 넣어, **HTML 하나만 다른 PC 로 옮겨도 재생된다**(영상 파일이 하나라도 없으면 만들기를 거부한다). 크기는 영상 합계에 비례한다(5편 약 20 MB).

재생 서버: 저장소 루트에서 `python tools/demo/serve_videos.py --port 8766` 실행 후 [B·C 영상 페이지](http://localhost:8766/오준영/영상.html)를 연다. MP4 중간 이동을 위한 HTTP 구간 요청을 지원한다.
