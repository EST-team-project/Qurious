## 요약

1. **같은 일을 하는 화면은 없다.** 대사 화면(TradingView ↔ LEAN)은 사람이 CSV를 올릴 때 한 번 비교하고, 신뢰성(그림자 일지 ↔ LEAN)은 매일 쌓인 기록을 층별로 본다. 비교 대상 · 층(4층 대 5층)이 달라 한 화면에 섞으면 헷갈린다.
2. **추천은 안 나 — 퀀트자동매매 묶음의 LEAN 백테스트 아래에 「전략 신뢰성」 화면을 새로 둔다.** 그 화면 안에 층별 판정 · 재현 기록 · 그림자 일지 표를 둔다. TradingView 화면은 이름을 「대사」로 바꾸고 Webhook을 아래로 접는다. 안 가(한 화면에 합침)도 쓸 만하고, 구현 비용 차이는 약 0.25 세션이다(추정). 벤치마킹 ⑤-3의 추천은 가였다 — 결정안의 4층 카드와 일지의 5층 카드가 한 화면에 겹쳐 나로 바꿨다.
3. **대사 배지는 층별 판정만** 쓴다(일치 · 불일치). 성과 · 체결가 · 비용은 「참고」, 비교하지 않은 층은 「제외 — 까닭」. 한 줄 총평 배지는 두지 않는다.
4. **지어내지 않았다.** 그림의 숫자는 층별 보고서 값뿐이다. 보고서에 없는 칸(날짜별 판단 · 비용)은 「응답 뒤 채움」으로 적었다. 보유 불일치 4일의 원인은 **10-29 에 코드와 원장으로 확인했다**(9/29 = LEAN 첫 주문이 증거금 부족으로 거부 · 10/23 ~ 27 = 일지는 청산 신호 중 매일 절반씩 분할 매도, LEAN 은 한 번에 전량 매도 — 코드 오류 아님 · 강민석 님께 보낼 답글 초안은 #314 11번). Figma 그림 글(층 카드 둘 · 주석 하나)도 10-29 에 「원인 확인(10-29)」 로 고쳤다.

## 1. 0단계 — 자리 조사

### 1.1 같은 일을 하는 화면이 있나

| 화면(담당) | 하는 일 | 겹치나 |
|---|---|---|
| TradingView 연동(이동원) | CSV · 성과 입력 → LEAN과 비교(층 카드 셋) · Pine 내려받기 · Webhook | **대사**는 여기. 일지 비교는 없다 |
| LEAN 백테스트(강민석) | LEAN 실행 · 수익률 · MDD · 샤프 | 일지와 맞대지 않는다 |
| 전략 분석(이동원) · 성과 검증 Python(신장환) | 백테스트 | 일지와 무관 |
| 모의 투자 의사결정(강민석) | AI가 모델 결과를 해석한 의사결정 | **이름이 비슷하다.** 일지는 규칙의 가상 기록이라 다른 일이다 |
| 모의계좌 현황(강민석) · 자동매매 현황(오준영) | 장부 · 실행 로그 | 일지는 장부가 아니다(설계 부록 A) |

→ 층별 신뢰성 · 그림자 일지 화면은 **어디에도 없다**(층 결과는 보고서 파일뿐).

### 1.2 자리 세 안

위 메뉴는 여섯 탭 고정이고 왼쪽 트리에는 칸 제한이 없다(IA I11 해소). 그래서 **「메뉴 칸 부족」은 문제가 아니다.** 드는 비용은 인디케이터 묶음이 이미 9줄이라는 것 · 검증 화면이 두 묶음에 나뉘는 것이다.

| | 안 가 — 대사 한 화면에 구역 더하기 | **안 나 — 「전략 신뢰성」 새 화면 (추천)** | 안 다 — 그대로 |
|---|---|---|---|
| 내용 | 인디케이터 묶음의 TradingView 화면 위쪽을 「대사」로 · 층별 신뢰성 · 일지 표를 같은 화면 구역으로 · Webhook 접기 | 퀀트 묶음 LEAN 백테스트 아래 새 메뉴 · 층별 · 재현 기록 · 일지 표 · TradingView 화면은 「대사」로 개명 + Webhook 접기 | 바꾸지 않음 · 층 결과는 보고서 파일 |
| 좋은 점 | 화면 수 그대로 · 고정 문구 한 번 | 비교가 화면마다 하나 · 검증이 LEAN 곁에 모임 | 0 |
| 아쉬운 점 | 비교 둘 · 층 이름 둘(5층 · 4층)이 한 화면 · 길다 | 화면 하나 늘고 오가야 함 | 앱 안에서 못 봄 · 판정 말이 따로 논다 |
| 구현(추정) | 약 2.25 = 배치 0.25 + 층 1.0 + 표 1.0 | 약 2.5 = 틀 · 메뉴 0.25 + 대사 정리 0.25 + 층 1.0 + 표 1.0 | 0 |
| 메뉴 줄(위 탭은 모두 여섯 그대로) | 인디케이터 9줄 그대로 · 이름만 바뀜 | 퀀트 6 → 7줄 · 인디케이터 9줄 그대로 | 그대로 |
| 바뀌는 기존 화면 | TradingView 연동(제목 · 순서 · 접기) | TradingView 연동(제목 · 접기) + 퀀트 메뉴 한 줄(공용 메뉴 파일) | 없음 |

- 층 · 표는 **서버가 층별 JSON을 준 뒤**에야 구현된다(강민석 님 몫 협의). 11-05 전에 하는 것은 그림까지다(0.5).
- 안 나에서 「LEAN 백테스트 화면과 합치기」는 강민석 님 화면이라 **제안 + 안내 필요**다.
- 공용 메뉴 파일을 고치기 직전 공개 PR 목록을 본다(신호 순위 설계와 같은 원칙).

## 2. 1단계 — 지금 화면 (코드 · 문서 읽기)

TradingView 연동 화면은 위에서 아래로 ① Webhook 설정 · 테스트 신호 ② 수신 신호 이력 ③ 카드 → Pine v6 내려받기 ④ Strategy Tester ↔ LEAN 교차 검증(결과 = 층 카드 셋 · 성과 표 · LEAN 곡선 · 차이 이유) ⑤ 이력이다. 층 카드는 신호 · 체결 · 성과(참고)이고 성과에는 배지가 없다(오늘 구현). 결정한 「차트 위 · 대사표 아래」(Figma 「설계 — 결정안」)는 아직 구현 전이다. 일지 · 층별 화면은 없다. **하지 못함**: 앱 화면을 Figma로 가져오기 · 눈 대조(구조 블록만 그렸다).
