## 3. 근거와 제안 — 파트별

### 3.1 강민석 ④ (K1 ~ K4)

**K1. DSR — 연율 샤프 · 시도 50 고정** (높음)
- 코드: `app/services/evaluation_risk.py:162~196` `deflated_sharpe_ratio` 는 표준오차 식을 **관측 주기 단위 샤프**로 계산하는데(`n_observations − 1` 로 나눔), 호출쪽 `calculate_all_metrics`(`:206~246`)는 `sharpe_ratio`(`:68~83`, `× √252` 연율)를 그대로 넣는다. 시도 횟수 `n_trials=50` 은 `:206` · `performance_service.py:56` 기본값이다.
- 재현(`dsr-재현.py` · 합성 수익률 · 일 변동성 1% · N=50 · 300회): **평균 0(알파 없음)** 에서 DSR ≥ 0.95 를 넘은 비율이 T=60 에서 **41.3%** · T=250 에서 **39.0%**. 같은 단순 식을 일 단위 샤프로 쓰면 0.3% · 0.0%.
- 알려진 문제다: `2026-10-20-개념학습-범위문체/결과.md:225` 가 「연환산 샤프를 DSR 식에 넣는다」 고 적었고 개념 학습 장 10.2 는 열흘 표본에서 0.7085(코드) 대 0.0350(일 단위)을 보인다. 그런데 코드는 바뀌지 않았고 3차 할 일 문서에는 이 줄이 없다.
- 특강 근거: DSR ≥ 0.95 가 기준(2일차6 p04 · p07 · 3일차7 p03) · 시도 횟수 N 이 식에 꼭 들어간다(3일차7 p07 퀴즈 1) · N 을 세는 방법이 곧 신뢰도(3일차1 p02).
- 제안: ① 샤프를 일 단위로 넣게 고치고 시험(TC-QFRS)에 「알파 0 에서 통과율이 낮다」 한 건 추가 ② `n_trials` 를 상수가 아니라 신장환 님 시도 기록(T7)의 실제 개수로 ③ 표본이 짧을 때(< 60일) 「참고용」 표시 ④ 정식 DSR(시도들의 샤프 분산 사용)로 갈지 · 단순 식을 유지할지 판단.
- ⚠️ 특강 슬라이드의 DSR **식 그림**(3일차7 p03)은 기호 정의가 없고 3일차8 p05 의 설명과 모양이 달라 **구현에 쓰지 않는다**(원 출처 Bailey · López de Prado 2014 를 따른다).
