## 덩어리마다 하는 일 (1교시에서 쓴 절차)

1. **원본** — `learning/11-special-class/pdf/Day01/N교시. ….pdf`(부모 저장소 · 강의 자료). 문장 · 그림을 저장소에 옮기지 않는다 — 쪽 번호 · 우리 말 요지 · 「」 짧은 인용만. 강사 이름은 적지 않는다.
2. **글자 수** — PyMuPDF `page.get_text()` 로 쪽마다 센다. 1교시는 13쪽 모두 0자(10-20 에서는 8편 모두 0자). 이 PC 에는 OCR 도구가 없다.
3. **쪽 그림** — 1교시는 쪽마다 실제로 그려지는 그림이 JPEG 한 장(2752 × 1536)이었다(나머지 그림은 모든 쪽이 함께 쓰는 자원). 아래 스크립트로 원본을 그대로 뽑고 1600 폭 사본을 Read 로 읽는다. 숫자 · 고유명사 상자는 원본에서 잘라 한 장으로 쌓아 다시 읽는다. 그림 파일은 scratchpad 에만 둔다.
4. **맞대기** — 우리 장과 쪽마다 맞대어 [1교시.md](1교시.md) 꼴로 쓴다: <표 1> 쪽별 대조 · <표 2> 틀린 곳(번호 · 쪽 · 원문 요지 · 무엇이 · 왜 · 맞는 내용 · 근거 실제 주소 · 조회일 · 확실도 · 우리 장) · <표 3> 다듬을 표현 · <표 4> 확인 못 한 것 · <표 5> 우리 장 고칠 곳 · <표 6> 차트(우리 데이터로 그릴 수 있나) · <표 7 · 8> 기능 후보 · <표 9> PNG 실측(같은 구조면 「1교시와 같음」 한 줄).
5. **데이터 확인** — 수집 DB 는 읽기 전용으로만 연다(`sqlite3.connect("file:<경로>?mode=ro", uri=True)`). 날짜 꼴이 표마다 다르다: `ecos_series.date` = `YYYY-MM-DD`, `price_adjusted.bas_dt` = `YYYYMMDD`. 재무 표 `financial_statement` 는 DART 주요계정 32개뿐이다(현금흐름표 · 재고자산 없음).
6. **1차 자료** — 원문 PDF 를 열 수 있으면 WebFetch 로 받은 파일을 PyMuPDF 로 찾아 문장을 확인한다(WebFetch 요약은 PDF 본문을 못 읽는 경우가 많다). github.com 은 긁지 않는다.
7. **끝내기** — 결과 파일을 Write 로 쓰고 <표 1> 상태 · 한 줄 요약을 고친다. 이 폴더 밖 파일은 고치지 않는다. git 은 읽기만.

```python
# python -I extract.py "<PDF 경로>" "<scratchpad 안 출력 폴더>"
# 쪽마다 글자 수를 찍고, 그려지는 원본 그림을 그대로 뽑은 뒤 1600 폭 WebP 사본을 만든다.
import io, os, sys
import pymupdf
from PIL import Image

sys.stdout.reconfigure(encoding="utf-8")
pdfPath, outDir = sys.argv[1], sys.argv[2]
os.makedirs(outDir, exist_ok=True)
doc = pymupdf.open(pdfPath)
for i, page in enumerate(doc, start=1):
  shown = [img[0] for img in page.get_images(full=True) if page.get_image_rects(img[0])]
  print(i, "글자", len("".join(page.get_text().split())), "그려지는 그림", len(shown))
  if len(shown) != 1:
    continue  # 둘 이상이면 page.get_pixmap() 렌더로 대신한다
  info = doc.extract_image(shown[0])
  with open(os.path.join(outDir, f"orig_p{i:02d}.{info['ext']}"), "wb") as f:
    f.write(info["image"])
  im = Image.open(io.BytesIO(info["image"])).convert("RGB")
  small = im.resize((1600, round(im.height * 1600 / im.width)), Image.LANCZOS)
  small.save(os.path.join(outDir, f"w1600_p{i:02d}.webp"), quality=80)
```
