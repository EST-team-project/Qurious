## 2. 고치기 전 / 후 (핵심 표)

식 세 가지를 같은 입력에 놓았다.

- **전**: 연율 샤프를 식에 넣고, 기대 최대 샤프 = z₁ × 표준오차.
- **단위만**: 일 단위 샤프를 넣되 기대 최대 샤프는 옛 식(옛 스크립트의 「일 단위」 열 · 0.0350 의 출처).
- **후**: 지금 `calculate_all_metrics` 가 내는 값(일 단위 샤프 + 3648c6ff 가 함께 바꾼 기대 최대 샤프 근사식).

### 2.4 보충 — 정말 알파 0 전략 50개를 만들어 가장 좋은 것을 골랐을 때 (N=50, 1,000회, 시드 2)

| T | 전 | 후 |
|---|---|---|
| 60 | 100.0% | 0.3% |
| 250 | 100.0% | 0.2% |

「후」 값은 이론 어림과 맞는다. 고친 식의 문턱은 `(1−γ)z₁ + γz₂ + z₀.₉₅ ≈ 2.276 + 1.645 = 3.921` 표준오차이고, 독립인 50개 중 최댓값이 이를 넘을 확률은 약 50 × 4.4×10⁻⁵ ≈ 0.22% 다. 선택 편향(여러 번 시험해 최고 고르기)을 실제로 걸러 낸다는 뜻이다.

## 3. 해석

1. **의미 있게 달라졌다.** 알파 없는 수익률의 「통과」 비율이 약 40% 에서 0% 부근으로 내려갔다. 옛 값 41.3% · 39.0% 의 원인(연율 샤프를 √252 배 크게 넣음)이 해소됐다.
2. **「단위만」 과 「후」 의 작은 차이**는 3648c6ff 가 함께 바꾼 기대 최대 샤프 식(오일러 상수 γ 로 두 분위수를 섞는 근사) 때문이다. 시도 50 에서 기대 최대 샤프가 표준오차의 2.054배(옛 식)에서 2.276배(새 식)로 커져, 같은 샤프에서 DSR 이 더 낮게 나온다(열흘 예 0.0350 → 0.0210).
3. **N=1 이면 DSR 은 PSR(0)과 같은 값**이다(0.5956 은 옛 단위만 식과 동일). 새 식은 N=1 에서 바뀌지 않는다.

## 4. 아직 설명이 필요한 차이 · 남은 문제

- **장 10.2 의 0.0350 은 이제 코드 값이 아니다.** 장은 「연율 → 일 단위 샤프」 만 바꾼 값(0.0350)을 「원 정의 값」 으로 적었는데, 고친 코드는 기대 최대 샤프 식도 바꿔 0.0210 을 낸다. 어느 쪽을 장의 「정답」 으로 할지 정해야 한다(권장: 코드와 맞춰 0.0210).
- **N=50 고정은 그대로다.** 후 표의 매우 엄격한 값(예: 연율 샤프 1.0, 1년 → DSR 0.10, 통과에 연율 샤프 4.0 필요)은 「50개의 독립 시도」 를 가정한 결과다. 실제 시도는 서로 비슷해(상관) 유효 시도 수가 더 적을 수 있고, 실제 시도 횟수를 넣지 않으면 모의계좌 화면 DSR 은 모두 낮게만 나온다. → K1 제안 ②(신장환 님 시도 기록 T7 의 실제 개수 연결)는 아직 남은 일이다.
- **정식 DSR 이 아니다.** 시도들의 샤프 분산 대신 한 전략의 샤프 표준오차를 쓰는 단순 식이다. 이번 확인은 「단위 수정과 근사식 교체의 효과」 까지만 잰다(옛 스크립트 주의와 동일).
- 표본이 짧은 구간(T=60 이하)에서 N=1 이어도 DSR 이 0.6~0.9 에 머문다. 「참고용」 표시(K1 제안 ③)는 코드에서 확인하지 않았다.
- 모의계좌 현황 표의 「DSR 0.95」 기준 글은 이번에 보지 않았다(결과 1일차 문서 140행이 언급). 화면의 DSR 숫자가 낮아져 보일 수 있으니 따로 확인이 필요하다.
