## 0. 요약 다섯 줄 (결론 먼저)

1. **결론 — krx-aggrid 는 「데이터를 받아 오는 길」 로는 쓰지 않는다.** 「코드 꼴(패턴)」 의 참고서로 쓰고, 쓴다면 **키 주인 한 사람이 자기 PC 에서 손으로 돌리는 1회성 교차 대조 도구**까지만 둔다. 수집기 · 앱 DB · 화면 · HF · 알림에는 KRX 값을 한 건도 넣지 않는다(3절).
2. **약관 원문(국문 · 영문, 2025-12-26 시행)을 다시 열어 지난 조사 2.2 의 핵심 셋을 확인했다** — 비상업(제6조②) · 제3자 제공 금지(제11조②) · 키당 하루 10,000회(제8조④). 그 조사에 빠졌던 조항 넷도 더했다: 이용기간 1년(제5조③) · 계약이 끝나면 받아 둔 정보도 못 씀(제11조③) · 정확성 미보장(제12조②) · 계속 제공 미보장(제12조⑤). 「무료」 라는 말은 약관에 없다(2절).
3. **제공 시점은 공식 FAQ 가 「영업일 기준으로 익일 오전 8시」 라고 적어, 우리 포털 회차(대개 다음 영업일 12:30 대)보다 4시간 넘게 이르다** → 「KRX 가 더 늦어 대조 가치가 낮다」 는 반박은 틀렸고, 진짜 반박은 ① 이른 값을 키 주인 화면 밖으로 낼 수 없어(제11조②) 모두의 금요일 공백은 못 메운다 ② 포털 시세도 한국거래소가 원천이라(발췌만) 대조가 잡는 것은 주로 **우리 적재 · 포털 중계 오류**다(5절).
4. **저장소 안에 이미 KRX Open API 코드가 있다** — `rag-lab/app/api/routes/analysis_main.py:1972-2048`(강사님 th01 계열, VKOSPI, 스레드 8개, 임시 파일 캐시). 지금은 앱과 이어져 있지 않다. 그런데 `docs/phase-3/02-design/system/통합본-이식계획.md:656` 이 `/api/market/vix-vs-kospi`(출처 「야후 · KRX · 파일」)를 옮길 목록에 둔다 → 옮길 때 KRX 가지를 빼야 제11조② 충돌이 앱에 들어오지 않는다.
5. **두 사본은 같고(트리 `9148d6a`, 우리가 고친 곳 없음), LICENSE · 저작권 표시가 없다.** NOTICE.md 2절의 구두 허가는 강사님 저장소 **셋**(lumina-invest · domain-rag-lab · investment-analysis)만 적었다 → krx-aggrid 는 「베끼지 않고 우리 말로 다시 쓰는 참고」 까지만 한다. 출처 표기는 이미 있는 관행(`collector/README.md` 4절 「코드 재사용 판정」 표 · 파일 머리 주석)에 맞춘다(4절).

### 4.5 라이선스 없는 공개 저장소를 참고할 때 — 일반 원칙(짧게)

- **공개돼 있다는 것은 허락이 아니다.** 라이선스가 없으면 볼 수는 있어도 복제 · 수정 · 배포 허락은 따로 없다고 보는 것이 안전하다(NOTICE 2절과 같은 판단).
- **「참고」 와 「복사」 를 나눈다.**
  - 참고: 원본을 닫고 우리 구조 · 우리 이름 · 우리 말로 다시 쓴다. 줄 단위로 대응시키지 않는다.
  - 복사: 줄을 옮기거나 거의 그대로 고쳐 쓴다 → 허락과 표기가 다 필요하다.
- **보호 대상은 생각이 아니라 표현이다**(일반론). 「날짜마다 부른다」 같은 방법, API 주소 · 칸 이름 같은 공개 명세는 생각 · 사실 쪽이다. 코드 문장 · 구조 · 주석은 표현 쪽이다. 경계가 애매하면 복사로 치고 허락을 구한다.
- **출처를 밝히는 것과 허락을 받는 것은 다른 일이다.** 표기는 정직의 문제이고, 허락을 대신하지 않는다.
- 짧고 흔한 관용 코드(표준 라이브러리 호출 한 줄 등)도 「어디서 봤는지」 는 적는 편이 정직하다.
- **이 절은 법률 자문이 아니다** — 팀 운영 기준이며, 판단이 필요하면 강사님 · 전문가에게 확인한다.

9. 포털 거래량이 시간외 · 애프터마켓을 포함하는지.
10. KRX 내장 정의의 증권군 코드가 무엇을 뜻하는지 — 코드 이름으로 미루어 본 추정이다.
11. 강사님 구두 허가가 th05 에도 미치는지.
12. KRX 가 「제3자」 를 어떻게 해석하는지(팀원 · 수업 동료 포함 여부), 그리고 제2조② · STEP 04 「대외 서비스 개시」 와 제11조②를 어떻게 맞추는지 — 문의하지 않았다.
13. AG Grid Community 의 현재 라이선스 — 이번에 확인하지 않았다.
14. 저작권 일반론(4.5)은 법률 자문이 아니다.
