# ②-26 (2/3) 성과보고서 · 최종 발표 5단 목차 틀

> **쓰임** — 성과보고서와 최종 발표(11-12 오전)가 같은 5단 뼈대를 쓰도록 맞춘 **빈 틀**이다. 본문은 각 주담당이 채운다.
> **5단의 출처** — 특강 `3일차2 p05`(쪽 번호만 인용 · 문장은 옮기지 않았다). 5단 이름은 이동원의 10-28 점검 결과(`docs/phase-3/01-analysis/research/배경조사/2026-10-28-특강-1-3일차-점검/결과.md` L2)에 적힌 이름을 따른다.
> **확실도** — 🟢 파일에서 확인 / 🟡 제안 / 🔴 확인 못 함. 「채울 재료」 는 파일에서 이름이 확인된 것만 적었고, 없는 것은 🔴 이다.

## 1. 한 장 틀

| 단 | 보고서 장 | 발표 쪽 (제안) | 이 단이 답할 질문 (우리 말) | 채울 재료 (이미 있는 것) | 아직 없는 것 · 확인 필요 | 주 채움 |
|:-:|---|---|---|---|---|---|
| 1 | 요약 | 1 ~ 2쪽 | 무엇을 만들었고, 결과가 한 줄로 어떤가? | 앱 한 줄 소개와 시연 흐름(신호 카드 → 근거 모달 → PAPER 수량 → 주문 → 체결 알림 → 일지 · 이동원파트-할일 11-06 ~ 11-08 줄 🟢) | 핵심 숫자 3 ~ 5개 🔴 (마지막에 다시 잰 값으로) | 이동원 |
| 2 | 경제적 근거 | 1 ~ 2쪽 | 이 규칙은 **왜** 지속될 것이라 보나? | 이동평균 교차 · RSI 등 규칙 설명 · 설계서 「인디케이터-전략-설계」 | 규칙별 「왜 지속되나」 메모 🔴 — 규칙 카드에 근거 칸이 없음(10-28 점검 S2 🟢). 카드 안이 아니라 카드 옆 설명 문서로 둘지는 신장환 님 판단 | 신장환 |
| 3 | 신호와 구조 | 2 ~ 3쪽 | 신호는 어떻게 만들어지고, 시스템은 어떻게 이어지나? | 신호 → 근거 → 주문 흐름 · 판 2 카드 · 웹훅 · 대사 · 수집에서 화면까지의 자료 흐름 | 3차 최종 구조 그림의 판 🟡 | 신장환 · 이동원 · 오준영 |
| 4 | 과적합 방지 검증 | 2 ~ 3쪽 | 우연히 좋아 보인 것은 아닌가? | 사전에 적은 조합표 · 시도 전부 기록(T7) · 기준 전략 110개 시도 합격 0(PR #441, 기억 메모 기준 🟡) · DSR 연율 단위 수정(PR #399, 기억 메모 기준 🟡) · LEAN 대사 · 간격을 둔 시간순 분할 | 강건성 보고서의 최종판 🔴 · 표본 밖 구간 사전 등록 여부 🔴 · 레드펜 9문 점검 결과(03 파일) | 강민석 · 신장환 |
| 5 | 제약과 용량 | 1 ~ 2쪽 | 실제로 쓸 때 막히는 것과 규모의 한계는? | 비용 모델(수수료 · 세금 · 슬리피지 10bp 고정 — 10-28 점검 시점 값이라 지금도 같은지 🟡) · 일일 한도 · 위험 관문 · 롱온리 · 데이터 출처 이용 조건 | 슬리피지 민감도 줄 🔴 · 거래대금 대비 주문 규모 경고 🔴 (10-28 점검 K2) · 한계 절(루트 README 의 「한계」 절이 있다면 맞출 것 — 이 초안에서는 파일을 열어 보지 않음) 🔴 | 강민석 · 오준영 |

쪽 수는 우리 제안일 뿐이다. 강사님 평가표의 쪽 제한 · 배점은 🔴 확인되지 않았다(10-31 점검 4일차10 행: 배점은 슬라이드에 예시인지 실제인지 표시가 없음 🟢 → 실제 평가표가 오면 그대로 따른다).

## 2. 장 안에서 같이 쓸 작은 틀 (제안)

각 단의 첫머리를 아래 세 줄로 시작하면 보고서와 발표가 같은 순서로 읽힌다.

| 줄 | 쓰는 것 |
|---|---|
| 결론 한 문장 | 이 단이 말하는 바를 숫자 포함 한 문장으로 |
| 근거 | 표 · 그림 · 코드 위치(파일 경로 또는 PR 번호) — 직접 다시 확인한 것만 |
| 한계 한 줄 | 이 근거가 말해 주지 못하는 것 |

## 4. 발표와의 관계 (제안)

- 발표 슬라이드 한 쪽은 보고서의 한 단 안에서 한 문장 + 그림 하나로 줄인다. 보고서에 없는 숫자를 발표에 새로 넣지 않는다.
- 시연 영상(11-06 ~ 11-08 만들기)은 1단과 3단 사이에 둔다 🟡.
- 발표 시각은 11-12(목) 오전, 11-11(수)은 리허설 · 자료 동결(이동원파트-할일 일정표 🟢).
