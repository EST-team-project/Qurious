# ②-26 (1/3) 계획서 5.3 에 넣을 「3차 산출물 한 표」 초안

> **쓰임** — `프로젝트계획서.md` 5.3절(3차 — 개요) 끝에 붙일 문단 + 표 초안이다. **계획서 본문은 아직 고치지 않았다**(판 올림은 마일스톤에 모아서). 표 번호는 판 올릴 때 `표 N` 자리에 채운다.
> **확실도** — 🟢 파일에서 직접 확인 / 🟡 제안이거나 팀 확인 전 / 🔴 확인 못 함.

## A. 5.3절에 붙일 문단 (초안)

3차(10-22 ~ 11-11)에도 강사님 일정표는 칸마다 산출물을 나란히 둔다. 2차 5.1절의 표 9 가 25칸이었다면, 3차는 30칸이고 **끝 쪽 두 칸**(강건성 검증 · 인수 · 지식이전)이 보고서 성격의 산출물을 가진다. 표 N 은 「3차에 문서로 내는 것이 무엇이고, 누가, 어떤 모양으로, 무엇이 되면 끝인가」 에 답한다. 담당 · 형식 · 완료 기준은 **제안**이며 팀이 확인하면 🟢 로 바꾼다.
