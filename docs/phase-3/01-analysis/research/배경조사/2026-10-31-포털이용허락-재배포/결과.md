## 0. 한눈에

1. 포털 현재 페이지(수정일 2026-10-28)에 「제4유형 : 출처표시 + 상업적 이용금지 + 변경금지」 와 「제3자 무단 제공 및 재배포가 엄격히 금지」 가 그대로 있다.
2. 같은 문장이 금융위 **지수시세 · 일반상품시세 · 증권상품시세**에도 있고, **기업 재무정보**에는 없다(「이용허락범위 제한 없음」).
3. 이 문장은 2026-09-18 기록(그때 수정일 2026-09-07)에도 같은 글자로 인용돼 있다 → **최근에 들어간 문구가 아니다.** 수정일 2026-10-28 은 기업 재무정보 페이지도 같아서, 문구 추가 시점을 보여 주지 못한다.
4. 공공누리 제4유형 공식 요약은 「비상업 · 변경금지 · 출처표시」 이고, 포털의 「제3자 무단 제공 · 재배포 금지」 는 **공공누리 요약에 없는 따로 적힌 문장**이다. 둘의 우선순위는 공식 안내에서 확인 못 함.
5. 「제3자」 가 팀원을 포함하는지 **원문에 정의가 없다.** 팀의 현재 운영(팀원은 제3자 아님 · private)은 해석이지 원문 근거가 아니다(코드에도 그렇게 적혀 있다).

## 2. 「제4유형」 의 뜻과 포털 문구의 관계

### 2.1 공공누리 제4유형 공식 요약 (표 6 · 열어 읽음 · 요약본)

| 조건 | 공식 안내의 말(요약 인용) |
|---|---|
| 출처표시 | 「출처를 표시해야 하며, 온라인에서 출처 웹사이트 링크를 제공할 수 있으면 링크를 제공해야」 · 후원 · 특수관계로 **오인하게 하는 표시 금지** |
| 상업적 이용금지 | 비영리 목적으로만. 「다만, 별도의 이용허락을 받아 공공저작물을 상업적으로 이용하는 것은 가능합니다.」 · 영리행위와 직접 · 간접으로 관련된 행위에 쓸 수 없음 |
| 변경금지 | 「공공저작물의 변경이 금지」 · 내용뿐 아니라 **형식 변경**과 번역 · 편곡 · 각색 · 영상제작 등 2차적 저작물 작성도 금지 |
| 허용 행위 | 「온라인과 오프라인에서 공유하고 이용할 수 있습니다」 — 요약 쪽에는 **복제 · 배포 · 공연 · 공중송신 개별 목록이 없었다**(확인 못 함) |
| 제3자 권리 단서 | 영문 부속 문서에 「제3자의 저작권이 있는 정보」 등은 이용금지 대상으로 적혀 있다고 열람 도구가 전함. 한글 원문 대조는 못 함 |
| 위반 | 이용허락이 자동 종료 · 이용 중단 · 형사 · 민사 책임 가능 |
| 조건 변경 | 변경 전에 이용을 시작했으면 그 저작물은 용도 변경 없이 계속 이용 가능 |

포털 이용정책(표 7)의 제4유형 풀이: 「Attribution required; non-commercial use only; no derivative works」, 그리고 「Third-party rights in public data require the rights holder's permission.」(열람 도구의 영어 요약).

### 2.2 겹침 · 따로 — 읽기

| 질문 | 근거로 말할 수 있는 것 | 확인 못 함 |
|---|---|---|
| 공공누리 4유형이 「재배포」 를 막나 | 공식 요약은 **비상업이면 공유 · 이용 가능**으로 읽힌다. 「배포 금지」 라는 말은 요약에 없다 | 공식 전문의 행위별 허용 범위 |
| 그럼 포털의 「재배포 엄격 금지」 는 | 공공누리 요약에 없는 **포털이 따로 쓴 문장**이다. 「제3자 권리 포함」 칸 · 「원천 소유자 한국거래소」 문장과 한 묶음으로 읽히며, 공공누리 단서(제3자 권리는 이용허락 대상 밖)와 결이 같다 | 둘이 충돌할 때 어느 쪽이 우선하는지 — 공식 안내에서 못 찾음 |
| 「무단」 의 뜻 | 「무단」 은 허락 없이라는 뜻이라, **허락받은 제공**은 문장 밖일 수 있다. 누가 허락하는지(포털 · 금융위 · KRX)는 적혀 있지 않다 | 허락을 받는 절차 · 문의처 |
| 「제3자」 가 누구 | 정의 없음. 팀원 · 같은 팀 클라우드(HF) 가 들어가는지 원문으로 못 정한다 | 포털 · 금융위 · KRX 의 유권 해석 |
| 화면 표시는 「제공」 인가 | 원문에 화면 표시를 허용 · 금지한다는 말이 **없다** | 같은 이유로 확인 못 함 |
| 지표 계산은 「변경」 인가 | 공식 요약은 「형식 변경 · 2차적 저작물 작성」 까지 변경으로 본다. 통계량 산출이 여기에 드는지는 안내에 없다 | 2026-09 이후 계속 미확정(4.1절) |
| 포털 이용약관은 제3자 제공을 막나 | 약관 제12조(금지행위) · 제14조(제공자의 제공 중지) · 제15조(포털 지식재산권)는 요약상 **데이터 제3자 제공을 직접 막는 조항이 보이지 않는다**. 단 제14조는 이용조건 위반 · 제3자 권리 침해 시 제공자가 제공을 중지할 수 있다고 한다 | 약관 조문 원문 대조(요약 인용만 봄) |

## 7. 사용자가 정할 것 · 확인 못 한 것

### 7.1 사용자가 정할 것

1. **지금의 운영 결정(팀원은 제3자가 아님 · private)을 그대로 두는가**, 아니면 원자료(`raw_response`)만 빼는 쪽으로 좁히는가(A → A').
2. **랜딩의 로그인 전 종가 한 줄**을 유지하는가(B'). 유지하면 UI 명세서 1499 의 「눈으로 확인」 이 이번 조사로 채워졌음을 기록할지.
3. **포털 · 금융위 · 강사님에게 문의할지** (글 · 이슈 작성은 이번에 하지 않음).
4. 앱을 **공개 서비스**로 열 가능성이 있는가 — 있으면 D 는 별도 조사가 필요하다.
5. 모든 시세 화면에 같은 출처 문구를 넣는 작업을 할지(이슈 · 담당은 메인이 정함).
