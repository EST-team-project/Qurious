## 0. 요약 · 사용자가 정할 것

**요약 여섯 줄**

1. **먼저 — 팀 결정과 부딪힌다.** 결정 대장 D6 ⑥ 「수급 데이터 — C, 3차 범위에서 뺀다」 가 **확정**이다(`docs/phase-3/00-management/plans/논의결정대장.md` 122행 · 근거 논의 #20 §2.10 · 2026-09-27 기한 확정). 인디케이터 설계서도 범위 밖으로 적었다(`docs/phase-3/02-design/system/인디케이터-전략-설계.md` 61행). 이번 설계는 **이 결정을 다시 여는 일**이다.
2. **종목별 투자자 매매동향을 무료 · 공식 · 재배포 허용으로 주는 곳은 못 찾았다.** 공공데이터포털 금융위 주식시세에는 투자자 칸이 없고, KRX Open API 서비스 목록 31개에도 투자자별 거래실적이 **없다**(열어 읽음). 공공데이터포털에서 「투자자별」 로 나오는 것은 KOSIS **월간 · 시장 전체** 통계로 이어지는 연계 링크다.
3. **종목별 일 단위를 자동으로 받을 수 있는 무료 경로는 증권사 API 뿐이다**(KRX 정보데이터시스템 화면 · 유료 상품도 종목별 일 단위를 주지만 자동 수집 금지 · 유료 계약이라 이 질문의 경로가 아니다). 한국투자(KIS)는 「주식현재가 투자자」(TR `FHKST01010900`, **모의투자도 같은 TR** · 「당일 데이터는 장 종료 후 제공」)와 「종목별 투자자매매동향(일별)」(TR `FHPTJ04160001`, **모의투자 미지원** · 당일분은 15:40 부터 가집계)을 준다(둘 다 열어 읽음). 장중 「추정가집계」 둘은 외국인 09:30 · 11:20 · 13:20 · 14:30 / 기관 10:00 · 11:20 · 13:20 · 14:30 입력이고 모의 미지원이다.
4. **그러나 증권사 시세는 약관이 「본인 업무 · 제3자 제공 금지」** 라(우리 기록: KIS 고객약관 제5조③ · 코스콤 개인가입자 정책) **서버 키 하나로 모아 모두에게 보이는 「수집」 은 막힌다.** 우리 수집기가 KIS 로 과거 시세를 받지 않기로 한 것과 같은 이유다(`collector/sources/kis.py` 머리말).
5. **pykrx · 네이버 · KRX 웹은 길이 아니다.** pykrx 1.2.9 는 스스로 「KRX 및 Naver 의 데이터를 스크래핑」 한다고 적고 KRX 회원 로그인(`KRX_ID` · `KRX_PW`)을 요구한다(PyPI 열어 읽음 · 로그인 요구는 09-15 우리 기록에도 이미 있다) → KRX 홈페이지 약관 제10조②(자동화 수집 금지) · 제12조②(무단 복제 · 배포 금지)에 걸린다. 네이버 증권 robots.txt 는 `Disallow: /` 다(열어 읽음).
6. **추천(결정은 사용자)**: 지금은 **안 A(수집 안 함 · 모달에 「수급 자료 없음 — 까닭」 · 판단 정리 틀에서 사용자가 직접 적기)**. 사용자가 D6 ⑥ 을 다시 열면 **안 B(로그인 사용자 본인 KIS 키로 그 자리에서 조회 · 저장 안 함 · 신호 점수와 백테스트에 섞지 않음 — `quote_now` 와 같은 원칙)**. 「매일 모아 쌓는」 공용 수집(안 C)은 **약관상 무료 경로가 없어 추천하지 않는다.**

- 비용: API 이용료 없음(PC용 eFriend Expert 안내 「API 사용에 따른 별도 이용료는 없음」 — 검색 발췌 · REST 포털의 같은 문구는 확인 못 함).
- 약관: 1절 표(우리 기록). 투자자 매매동향이 약관의 「시세정보」 에 드는지 따로 적힌 문장은 못 찾았다 — 같은 거래소 원천 자료라 같은 조건으로 보는 것이 안전하다(추정).

## 7. 우리 기록 사이의 어긋남 (메인이 알아 둘 것)

1. **D6 ⑥ 확정 ↔ 이번 요청(「수집 설계를 하자」)** — 1절. 다시 열지는 사용자 · 팀이 정한다.
2. **KRX Open API 조항 번호** — 논의 #20 §2.10(09-17)은 Open API 약관을 「제10조② 자동화 수집 금지 · 제7조⑤ · 제12조①②」 로 적었다. 그런데 10-31 · 11-01 조사가 원문으로 읽은 것은 **Open API = 제6조② · 제11조② · 제8조④**, **홈페이지(data.krx) = 제10조② · 제12조②** 다. 09-17 기록이 두 약관을 섞어 적은 것으로 보인다(결론 「쓰지 않는다」 는 같음).
3. **KIS 유량** — 6절 첫 줄.
4. **「본인 키 · 본인 화면 = 됨」(실시간시세 조사 3.4)** ↔ 약관 문언 「고객이 직접 개발한 프로그램」 — 3절 두 번째 줄. 안 B 를 고르면 같은 해석 위험을 하나 더 지는 셈이다(`quote_now` 와 같은 크기).
