## 6. 읽는 법과 한계

- 글자 수는 머리(front matter) · 코드 블록 · 공백을 뺀 본문이다. 분량이 많다고 정확하다는 뜻은 아니다.
- 미해결 표시는 문자열 검색 결과다. 표시가 0곳이어도 사실 검수가 끝났다는 뜻은 아니다 — 숫자 · 법령 문장은 장마다 따로 대조한다.
- 예제 코드 「있음」은 `public/learn/examples/<장 이름>.py` 가 있다는 뜻이며 실행 결과를 본문 숫자와 대조했다는 뜻이 아니다.
- 이 문서는 `public/learn/content` 를 읽어 만든 값이다. 장 머리의 `status` 를 고치면 이 표도 다시 만든다.
