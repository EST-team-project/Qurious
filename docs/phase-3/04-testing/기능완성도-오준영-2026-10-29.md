## 오래된 설명의 정정

- #390에서 API 설정 메뉴가 「내 계정」으로 이동한 것도 해당 TSV 줄에 반영한다. 화면 키 `settings`는 유지된다.

- 자산배분의 「결과 저장·리밸런싱 전달·비중 함수 공통화」는 현재 코드에 있다. 남은 것은 운영 흐름 대조·응답시간 개선·미적용 자산군의 실행 지원이다. 국내주식만 전달하는 현재 정책을 5자산군 투자 완료로 표시하지 않는다.
- 자동매매의 DF-15 설명을 「수집 DB 마지막 종가로만 체결」에서 #359의 가격 근거·불완전 평가 보류와 남은 fallback/실제 보유 대조 제약으로 갱신한다. 결함대장 전체의 종료 상태를 이번 배지 작업으로 바꾸지는 않는다.
- API 설정의 「요청마다 토큰 발급」은 현행 Redis 공유 구현·시험과 맞지 않는다. 운영 저장소 장애·만료 회차 관측은 후속으로 남긴다.
- #389는 병합됐지만 운영은 담당 계획의 마지막 확인 기준 10/27 이미지·DB 0027이다. 이번 갱신에서 운영 계좌 조회·주문·배포는 하지 않는다. 판 2 실행 지원과 자동매매 재개를 완료로 표시하지 않는다.

## 배지와 확인

다섯 줄은 정본 근거를 줄임 없이 배지로 옮기며 점검일 `10-29`를 지정한다. 기존 줄은 기본값 `10-12`를 유지한다. 관리자에게만 배지를 표시하는 동작은 유지한다. TC-CP는 반영 줄의 집합·점수·이름표·실제 화면 키·점수 산식·점검일·관리자 표시를 확인한다.

검증: 배분 저장/예측 안내·KIS 토큰 공유/주문 결과·설정 보존 **111건 통과**, TC-CP **6건 통과**로 서로 다른 **117건 통과·최종 실패/건너뜀 0**이다. 최초 시험 포장에서 git의 한글 경로 인용 때문에 TSV가 빠져 TC-CP 3건이 파일 없음으로 실패했다. 포장을 고치고 줄별 날짜 인자를 읽도록 TC-CP 파서를 보완한 뒤 해당 6건을 재실행했다. 제품 코드의 오류를 숨기기 위해 시험을 제외한 것은 아니다.

실제 `teamcompletion.js`를 Node로 불러 다섯 점수·10/29 표시·기존 모든 담당 배지 값 보존·관리자 전용 스타일을 확인했다. 브라우저 화면을 새로 실행한 검증은 아니며, UI 가점을 추가하지 않았다. `git diff --check`도 통과했다. 원본 결과는 git 제외 경로 `data/local-run/completion-388-20261029/`에 보존한다.
