## 1. 판정과 원인

**우리 담당 공통 시험 시계에 오류가 있었다.** #554에 보고된 KIS 복구 12건·연결 2건·모의시험 2건의 `STALE_DATA`는 한국 시각 09시 이전에 재현됐다. 신호 필터 변경과 별개이며, 제품의 주문 신선도 검사는 올바르게 불일치 자료를 거부했다.

세 시험 파일은 `tests/test_kis_connection_probe.py`의 `runtime` 시계를 공유한다. 이전 구현은 현재 날짜를 각 시간대에서 구한 뒤 KST는 10시, UTC는 01시로 시각만 바꿨다. 08:50 KST에는 UTC 날짜가 전날이므로 조회 시각과 검사 시각이 하루 어긋난다.

| 실제 실행 시각 가정 | 수정 전 검사 시각 − 조회 시각 | 수정 후 차이 |
|---|---:|---:|
| 11/5 00:05 KST | −86,400초 | 0초 |
| 11/5 08:50 KST | −86,400초 | 0초 |
| 11/5 09:04 KST | 0초 | 0초 |
| 11/5 23:55 KST | 0초 | 0초 |

한국 날짜의 10시를 먼저 만들고 요청된 시간대로 변환하도록 시험 코드만 수정했다. 위 네 시각에서 합성 주문이 한 번 접수되고 두 시간대가 동일 순간을 가리키는 회귀를 추가했다. 운영의 10초 신선도 검사·거래 시간·위험 한도는 바꾸지 않았다.

추가 회귀로 같은 모듈의 시험 DB에 앞선 주문이 남자 기존 dry-run 시험의 “전체 표가 0건” 가정도 실패했다. 실행 전후 네 표의 행 수가 같고 주문 함수가 호출되지 않는지 검사하도록 보완했다. 첫 수정의 75통과·1실패 및 관련 421통과·1실패 로그도 보존한다.

## 2. 검증 결과

**최종 관련 회귀 422건 모두 통과, 실패·건너뜀 0건**이다. 08:50 재현 76건은 관련 422건과 중복되므로 합산하지 않는다.

11초 지난 자료가 주문 전송 전에 차단되는 기존 `test_failures_never_send_or_replay[stale]`도 통과했다. 새 회귀 때문에 발생한 첫 수정의 dry-run 1실패는 실행 전후 기록 보존 검사로 보완한 뒤 두 최종 실행에서 통과했다.

외부 통신이 없는 새 Docker 네트워크와 일회용 PostgreSQL·Redis, 합성 증권사 응답으로 실행했다. 운영 자격증명·DB를 시험에 연결하지 않았다. 실행 환경의 벽시계를 바꾸지 않고 시험 모듈의 시계 입력만 바꿨다.

## 3. 신호 필터·최신 main 영향

- `signal_explain.load_day()`의 새 `signal`, `only_codes` 인자는 기본값이 `None`이다. 기존 호출은 그대로 유효하며 새 응답 `matched`가 추가됐다.
- 필터는 `limit` 전에 적용한다. `total`, `as_of_max`, `computed_at_max`, `older_count`는 필터 전 전체 집계를 유지한다. 실제 호출자는 `stock_hub.signal_rank()`이고, 필터가 없으면 새 인자를 넘기지 않는다.
- `TC-XR-FILTER`와 `TC-HUB-71`을 포함해 신호 조회·순위·카드 화면·비교 화면의 관련 회귀를 확인했다. 이번 main 변경에는 KIS 실행·복구·연결 점검·모의시험 제품 코드 변경이 없다.
- 앞선 전체 회귀에서 실패한 공모 수집 날짜 시험(ERR-041)은 최신 main에서 담당자 수정이 들어왔다. 오늘 관련 시험의 해당 사례가 통과했으며, 이전 전체 결과를 소급해 고치지 않는다.

## 4. 작업 보존·운영 범위

main을 `cb204a99`에서 `a7e18ae5`로 fast-forward했다. 수정·미추적 파일 23개를 먼저 보관했고, 겹친 `docs/산출물목록.md`만 양쪽 내용을 병합했다. 나머지 22개는 최신화 직후 원래 해시를 확인했다. 산출물목록은 upstream v3.14를 지난판에 보존하고 통합본을 v3.15로 올렸다.

운영 앱·worker·beat는 이전 이미지 그대로 실행 중이다. 앞선 모의 매수 10주·매도 4/6주 완료 시점과 주문·의도·설정·가상 장부 지문이 같다. 주문 기록 16건, 미체결 0건, 자동매매 꺼짐이며 이번 검증에서 추가 증권사 주문은 없다. 시험 수정은 로컬 미커밋 상태로, 원격 DF-167을 완료 처리하지 않았다.

이 보고서는 #554와 최신 변경 관련 회귀 결과다. 앞선 [전체 회귀](전체회귀-2026-11-05.md)는 `cb204a99` 기준 기록이며, 최신 main 전체 시험 통과로 바꾸어 해석하지 않는다. 사람의 발표 연습도 아직 전이다.
