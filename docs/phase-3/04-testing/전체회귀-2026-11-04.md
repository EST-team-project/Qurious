## 2. 발견한 문제와 수정

고정된 11/2 자료를 사용하는 국면 브라우저 시험에 기준 시각이 없었다. 11/4 오전의 실제 앱은 `checked=false, reason=data_waiting`을 정상 반환했지만, 시험은 `regime_auto`가 항상 있다고 가정해 `KeyError`로 중단됐다. 최초 실행의 setup 5개·persist 3개는 통과했고 history는 실패했다.

오준영 담당 시험에 전용 시각 진입점을 추가했다. 격리 DB에서 11/3 12:29의 자료 대기 차단과 17:20의 자료 준비 후 변경을 각각 재현한다. 실제 준비 판정·수집 근거·API·계산은 유지한다. 대기 단계에서는 반복 점검이 목표·변경 이력·제안·완료 날짜를 바꾸지 않고 실행 버튼이 차단되는지 확인한다. history 단계는 자료 준비 여부와 자료일·판정일부터 검사한다.

보완 후 14개 흐름과 실제 앱 재시작을 통과했다. 이는 과거 자료와 합성 과거 국면을 사용하는 재현 시험이며 **11/4 자연 국면 전환 성공이 아니다**. 상세 절차는 [국면 실브라우저 통합 검증](국면-실브라우저-통합검증.md)을 따른다. 운영 코드나 운영 시계에는 변경이 없다.
