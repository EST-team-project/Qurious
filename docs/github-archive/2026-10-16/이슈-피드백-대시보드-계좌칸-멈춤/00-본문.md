**주담당** 강민석 @rkdalstjr · **우선** 🔴 시연을 막음 · **화면** 투자 대시보드(`dashboard`)

### 무엇이 끊겼나
대시보드를 열면 위에는 「조회 완료 · 12시 22분 5초」 가 뜨는데, 가운데 「투자 사이트별 현재 투자액」 은 탭 없이 「계좌를 불러오는 중입니다…」 에서 더 나아가지 않는다. 첫 화면에서 내 계좌 숫자를 하나도 볼 수 없다.

### 재현
1. 리밸런싱 플랜에 목표 비중을 저장하지 않은 계정(또는 12:30 데이터 갱신 전)으로 로그인한다 — 이때 `GET /api/rebalance/status` 의 `snapshot` 이 `null` 이다.
2. 로보 어드바이저 › 통합 대시보드를 연다.

### 기대
탭 다섯(KIS 모의투자 · 퀀트 가상계좌 · 모의투자 계좌 · 미국주식 · 로보 모의계좌)과 금액이 보인다. 리밸런싱 자료가 없으면 로보 탭에만 「목표 비중을 저장하면 보입니다」 가 뜬다.

### 실제
탭 줄이 비어 있고 칸은 「계좌를 불러오는 중입니다…」 그대로다(5초 넘게 기다려도 같음).

### 증거
- 캡처: [캡처 B1-대시보드.png](https://github.com/EST-team-project/Qurious/blob/main/docs/%EC%A1%B0%EC%82%AC/%EB%B0%B0%EA%B2%BD%EC%A1%B0%EC%82%AC/2026-10-16-%EB%AA%A8%EC%9D%98%ED%88%AC%EC%9E%90%EC%A0%90%EA%B2%80/%EC%BA%A1%EC%B2%98/B1-%EB%8C%80%EC%8B%9C%EB%B3%B4%EB%93%9C.png) · [캡처 D0-대시보드-계좌칸-멈춤.png](https://github.com/EST-team-project/Qurious/blob/main/docs/%EC%A1%B0%EC%82%AC/%EB%B0%B0%EA%B2%BD%EC%A1%B0%EC%82%AC/2026-10-16-%EB%AA%A8%EC%9D%98%ED%88%AC%EC%9E%90%EC%A0%90%EA%B2%80/%EC%BA%A1%EC%B2%98/D0-%EB%8C%80%EC%8B%9C%EB%B3%B4%EB%93%9C-%EA%B3%84%EC%A2%8C%EC%B9%B8-%EB%A9%88%EC%B6%A4.png)
- 응답: `GET /api/dashboard/accounts` 200(탭 4개가 다 옴) · `GET /api/rebalance/status` 200 이지만 `snapshot: null`, `valuation_error: "12:30 데이터 갱신 이후 자동 점검합니다."`
- 코드: `public/js/dashboard.js` 100–101행 `const { snapshot: s, plan } = robo.value; … number(s.total_asset, …)` — `s` 가 `null` 이면 여기서 멈춰 `renderAccountTabBar()` · `renderAccountPanel()` 까지 가지 못한다. 오류는 화면에도 콘솔에도 나오지 않는다.

### 제안
- `snapshot` 이 없으면 로보 탭 칸만 안내 글(「리밸런싱 목표를 저장하면 보입니다 · 리밸런싱 엔진 →」)로 그리고, 나머지 탭은 그대로 그린다.
- 시험: `snapshot: null` 응답을 끼운 화면 시험 한 줄(탭 수 · 첫 탭 금액이 보이는지).
