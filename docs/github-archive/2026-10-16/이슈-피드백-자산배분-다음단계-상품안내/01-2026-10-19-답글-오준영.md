수정 PR: #275

자산배분 결과의 「리밸런싱으로 이동」 옆에 「자산군별 상품 보기 →」를 추가했습니다. 채권·해외주식·대체자산의 ETF 정보를 볼 수 있고 저장한 배분을 자동으로 불러온다는 안내도 넣었습니다.

실제 Chrome에서 합성 API로 상품 안내 이동 → 저장 배분·투자 기간·비중 순 탭 표시 → 자산배분으로 돌아와 기존 결과 유지까지 확인했습니다. 이 이동에서 API는 조회(GET)만 호출했습니다. 화면 스캐너와 diff 검사도 통과했습니다.

Docker 반영 중이며, 완료 후 localhost:8966 확인 결과를 남기겠습니다. 이슈는 OPEN으로 유지하고 자동 종료 연결을 넣지 않았습니다.
