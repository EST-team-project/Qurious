PR #268 머지로 #212 처리를 완료했습니다. main 반영 커밋은 `7073cd2`입니다.

- KIS 연동 모드에서는 가상 현금·보유·주문을 먼저 기록하지 않습니다. KIS 잔고로 판단하고 조회 실패 시 주문을 보류합니다.
- 가상 체결 / 증권사 접수 / 확인된 일부·전량 체결 / 실패 / 접수 여부 미확인을 화면과 의사결정 로그에서 구분합니다. 과거 가상 기록은 KIS 체결로 표시하지 않습니다.
- 직접 KIS 주문도 전송 전 추적 기록을 저장하고 계좌·환경·일자·주문번호·종목·방향·수량으로 체결을 대조합니다. 응답 불명인 직접 주문은 자동 재전송하지 않습니다.
- Redis 토큰 공유·만료 갱신·동시 발급 제한을 추가했습니다.

검증: 관련 Python 회귀시험 258개 및 JS 렌더러 시험 1개 통과. 격리 PostgreSQL·Redis를 사용했고 주문 HTTP는 시험 대역으로 검증했습니다. API 명세·카탈로그 일치, 문서 규칙 검사도 통과했습니다.

사용자 API 설정 등록 후, 현재 실행 중인 앱에서 실제 KIS 모의계좌 토큰 발급 HTTP 200 및 잔고 조회 HTTP 200 / `rt_cd=0`도 확인했습니다. 주문 요청·자동매매 활성화는 하지 않았습니다. 계좌번호·키·자산 금액은 공개하지 않습니다.

코드는 main에 머지됐으며 실행 중인 앱에는 아직 배포하지 않았습니다. 실제 계좌 연결 확인과 PR 코드 배포 후 주문·체결 검증은 구분합니다. 직접 경로의 미확인 주문·미체결 취소는 KIS에서 수동 확인하며, 기존 가상 장부를 자동 삭제·역분개하지 않습니다.
