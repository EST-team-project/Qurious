## 완료 (PR: #286 )

### 1. 시세 칸 통화 단위 분리 + 환율 출처 노출

**수정 파일**: `public/js/paper.js` (`stockQuote`)

- 기존: `q.price`(원화 환산) + `q.currency` → `16,465.61 USD` (단위 어긋남)
- 변경: 해외 종목이면
  - **크게**: `q.price_local + q.currency` → `12.31 USD`
  - **작게**: `약 won(q.price)` → `약 16,466원`
  - **아래 한 줄**: `q.fx_note` 그대로 → `받은 환율 1 USD = 1,337.58원 · 10-16 15:01 기준`
- 원화 종목(`fx_note` 빈 문자열)은 환율 줄이 **생기지 않음**

| 케이스 | 화면 |
|---|---|
| `F` 시세 조회 | `12.31 USD +2.16%` / `약 16,466원` / `받은 환율 1 USD = 1,337.58원 · 10-16 15:01 기준` |
| `005930` 시세 조회 | `71,200원 +1.23%` (환율 줄 없음) |

### 2. 미지원 시장 명시적 거부 — 500 → 400 (DF-96 방어선)

**수정 파일**: `app/services/trading_cost.py`, `app/services/paper_trading.py`

**원인**:
- `resolve_stock("F")` → `market="NYQ"`, `currency="USD"` (정확히 반환)
- `paper_trading` 이 이 값을 `trading_cost.order_costs(market="NYQ")` 로 전달
- `_market("NYQ")` → `UnsupportedMarketError` raise
- 라우트(`_place_stock`)의 `except pt.PaperTradeError` 가 **못 잡아서 500**

**수정**:
- `trading_cost`: `UnsupportedMarketError` 도입, `cost_rate`/`order_costs` 진입 시 `_market()` 검증
- `paper_trading`:
  - `_ensure_supported_market(info)` 가드 — `currency != KRW` 또는 `market ∉ {KOSPI, KOSDAQ, KONEX}` 이면 `PaperTradeError`
  - `_safe_order_costs` 래퍼 — `UnsupportedMarketError` → `PaperTradeError` 변환
  - 진입점 4곳에 가드: `stock_preview` · `stock_order` · `_fill_stock_order` · `place_stop_order`

**결과**:

| 요청 | Before | After |
|---|---|---|
| `F` 매수 | **500** | **400** `"F 는 해외 종목(USD)입니다. 국내주식 모의주문은 원화 종목만 지원합니다."` |
| `F` 매도 | **500** | **400** 동일 |
| `F` 미리보기 | **500** | **400** 동일 |
| `F` 스탑 등록 | **500** | **400** 동일 |
| `005930` 매수 | 200 | **200** (회귀 없음) |

`market_of("F") = "KOSPI"` 는 **국내 전용 헬퍼의 정상 동작**(docstring: "접미사가 없으면 코스피로 본다")이라 손대지 않았습니다. 실제 원인은 `resolve_stock` 이 반환한 `market="NYQ"` 가 `order_costs` 로 흘러간 것이었습니다.

## 남은 물음 3건 → 후속 이슈

본 PR 은 위 두 건만 포함합니다. 아래 셋은 **정책 결정**이 필요해 별도 이슈로 분리합니다.

### 후속 A — 해외 비용 모델 (DF-96)

`trading_cost.py` 가 국내 3시장만 알아, 해외 종목의 비용 계산이 불가능합니다.
현재는 400 으로 명확히 거부 중.

**결정 필요**:
- 미국 시장 칸: 국내 증권거래세 없음 · 매도 SEC 수수료(100만 달러당 20.60달러) · 증권사 해외 수수료율(어느 증권사 기준?)
- 환율 적용 시점: 주문 시점 vs 체결 시점
- 최소 수수료 여부

### 후속 B — 옛 달러 단가 보유 정리

10-16 이전 미국주식 화면에서 매수한 보유는 평균단가가 달러 그대로 원화 장부에 남아 손익이 맞지 않습니다(예: +133,658%).

**정책**:
- 자동 마이그레이션 하지 않음(매수 시점 환율 근거 없음)
- 미국 포트폴리오 화면의 "모의계좌 초기화로 바로잡을 수 있다" 안내를 구체화
- (선택) `currency != 'KRW' && avg_price < 1000` 같은 감지 배너

### 후속 C — 대체 환율(`fx_source=fallback/missing`) 주문 정책

**결정안**:
- `missing`(환율=1): **차단** (손익이 완전히 엉망)
- `fallback`(1,350 고정): **경고 후 허용** (거래 기회 손실 방지)
- `live`/`last`: 현재대로 허용

백엔드(`missing` 차단) + 프론트(`fallback` 경고 표시) 작업 필요.
