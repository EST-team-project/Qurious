**주담당** 오준영 @GoonGuMa · **우선** 🟢 다듬기(저장 위치는 논의) · **화면** 자산배분·최적화(`robo-portfolio`) 진단 칸

### 무엇이 끊겼나
1. 진단 뒤 「점수 21 / 35 · 시스템 프로파일 **moderate** (자산배분 성향에 반영됨)」 — 사용자 글에 내부 영어 키가 나온다.
2. 진단 결과는 브라우저 저장소(`localStorage` 의 `robo_risk_profile`)에만 있다. 다른 브라우저 · 기기에서는 상품 안내의 성향 칩이 비고, 같은 PC 에서 다른 사람이 로그인하면 앞사람 성향이 그대로 보인다(사용자 구분 없음).

### 재현
1. 자산배분·최적화 › 「설문 펼치기」 → 일곱 문항 → 「진단하기」.
2. 결과 줄을 본다. 다른 브라우저(또는 시크릿 창)로 로그인해 투자 성향별 상품 안내를 연다.

### 기대
「위험중립형 — 자산배분 성향: 중립」 처럼 한국어로. 진단 결과는 로그인한 사람에게 붙는다(또는 브라우저에 남길 때 사용자 구분).

### 실제
- `POST /api/ml/robo/risk-profile` 200 → `risk_profile: "moderate"`, `level: "위험중립형"`, `score: 21` — 서버는 저장하지 않는다.
- 브라우저 저장소 값: `{"level":"위험중립형","risk_profile":"moderate","score":21}`

### 제안
- 표기는 바로 고칠 수 있는 작은 일(성향 이름표는 고르기 칸의 글을 그대로).
- 저장 위치(서버 · 사용자별)는 논의 — 상품 안내 화면(이동원)도 이 값을 읽으므로 바꾸면 같이 맞춘다.
