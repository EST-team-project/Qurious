**주담당** 오준영 @GoonGuMa · **우선** 🟡 불편 · **화면** 증권사 API 설정(`settings`)

### 무엇이 끊겼나
「연결 테스트」 를 누르면 「❌ 연결 실패: 증권사 API 오류: Client error '403 Forbidden' for url 'https://openapivts.koreainvestment.com:29443/oauth2/tokenP' For more information check: https://developer.mozilla.org/…/403」 이 뜬다. 키가 틀렸는지, 잠깐 기다리면 되는지, 무엇을 해야 하는지 알 수 없다.

### 재현
1. 퀀트자동매매 › 증권사 API 설정 › 「연결 테스트」.
2. 자동매매가 켜져 있으면 회차(10분마다) 직후, 아니면 1분 안에 한 번 더 누른다.

### 기대
「증권사가 접속 토큰을 1분에 한 번만 줍니다 — 1분 뒤 다시 눌러 주세요(자동매매가 켜져 있으면 회차와 겹칠 수 있습니다)」 처럼 까닭과 할 일을 한국어로. 원문은 관리자에게만 접어서.

### 실제
- 12:26:06 · 12:30:57 두 번 모두 `GET /api/broker/price?symbol=005930.KS` → 502, 위 영어 원문 그대로.
- 12:30:57 은 자동매매 회차가 토큰을 받은 지 3초 뒤라 1분 제한에 걸린 것으로 보인다. 12:26:06 은 바로 앞 증권사 호출(12:23 대시보드 잔고 — 성공)과 3분 떨어져 있어 까닭을 확인하지 못했다(다른 서버 작업이 토큰을 받았을 수 있음).

- 코드: `app/routes/stocks.py` `broker_price` — 예외 글을 `증권사 API 오류: {e}` 로 그대로 돌려준다.

### 제안
- 403 + `tokenP` 는 「토큰 1분 제한」 안내로, 401 · 키 오류는 「App Key · Secret 확인」 으로, 그 밖은 「잠시 뒤 다시」 로 나눠 보인다.
- 영어 원문과 MDN 링크는 관리자 접기 칸으로.
- 뿌리(요청마다 토큰)는 DF-84 와 같다 — 03 이슈의 3번 제안과 함께.
