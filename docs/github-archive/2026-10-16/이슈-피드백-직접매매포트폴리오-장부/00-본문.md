**주담당** 강민석 @rkdalstjr(제안 — UI 명세서 6절에서 이 화면은 주담당 「—」 · 모의투자 장부(C5) 주인이라서) · **우선** 🟡 불편 · **화면** 포트폴리오(`trading-portfolio`)

### 무엇이 끊겼나
국내주식 모의주문으로 KG모빌리티 1주를 사면 직접매매 › 포트폴리오에도 그 1주가 보인다(같은 장부라 맞다). 그런데 이 화면은 「종목 추가/수정 · 추가 · 삭제」 로 수량 · 평균단가를 손으로 넣고 지울 수 있고, 그 값이 같은 모의투자 장부(PAPER)에 그대로 들어간다 — 현금은 그대로다. 모의투자 계좌 총자산이 실제 주문 없이 늘거나 줄 수 있다. 평가금액(예상) 칸은 「-」 로 비어 있다.

### 재현
1. 국내주식 모의주문에서 1주 매수.
2. 직접매매 › 포트폴리오를 연다 → 평가금액 칸을 본다.
3. (코드로 확인 · 이번 점검에서 누르지 않음) 「추가」 → `POST /api/portfolio` 가 PAPER 장부 행을 upsert, 「삭제」 → `DELETE /api/portfolio/{symbol}` 가 행을 지운다 — 둘 다 현금을 바꾸지 않는다.

### 기대
모의투자 장부는 주문(매수 · 매도)으로만 바뀐다. 이 화면은 보기 전용이거나, 손으로 넣는 「관심 · 실제 보유 메모」 는 다른 장부로 간다. 평가금액은 현재가로 채워진다.

### 실제
- 화면: 「KG모빌리티 003620.KS · 1 · 2,575 · - · 삭제」
- 코드: `app/routes/stocks.py` 244–276행(`book=PORTFOLIO_BOOK_PAPER`), 모의주문 화면 글 「직접매매 포트폴리오·Open API 주문과 같은 잔고를 씁니다」

- 2차: 추가 · 삭제를 숨기거나 「모의 주문으로만 바뀝니다 → 국내주식 모의주문」 으로 바꾼다. 평가금액은 모의계좌 현황과 같은 값(현재가)으로.
