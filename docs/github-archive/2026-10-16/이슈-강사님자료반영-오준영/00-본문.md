## 2. 여쭙는 것

1. 전략설정 꼴(운영 모드 · 칸별 기본값 · 범위 · 프로필)을 「증권사 API 설정」 의 위험 한도 칸 옆에 들일지, 들인다면 3차 증권사 연동 전 · 뒤 중 언제
2. 화면 값이 서버 기본값을 덮는 꼴과, 서버 위험 한도가 늘 이기고 화면은 더 좁게만 고르는 꼴 중 어느 쪽
3. 비상 정지의 자리 — 모든 화면 머리 · 관리자 화면 · 사용자별 정지 중
4. 주문 주체 칸을 리밸런싱 실행 주문에도 붙일지 · IP · 브라우저 정보는 남길지(남긴다면 보관 기간 · 본인에게만) — 수동 주문 쪽은 @rkdalstjr 님과 함께
5. 계약 문서를 v0.7 로 올릴지 · 언제
6. 테마 플랜 보존 원칙이 우리 리밸런싱 목표에도 맞는지 — #153 1절 유니버스 칸과 함께 답해 주셔도 됩니다
