**주담당** 신장환 @janghwan-god · **우선** 🟡 불편 · **화면** 차트 패턴·지지/저항·멀티타임프레임(`robo-patterns`)

### 무엇이 끊겼나
한국 사용자는 종목코드를 「055550」 처럼 6자리로 넣는다. 그러면 다중 주기 칸은 「종목 데이터 없음: 055550」 이 뜨고, 캔들 패턴 칸은 다른 결과를 보인다. 「055550.KS」 로 넣어야 제대로 나온다. 입력 칸에는 예시(placeholder)가 없다. 국내주식 모의주문은 6자리를 받아 .KS 로 바꿔 준다 — 화면마다 입력 규칙이 다르다.

### 재현
1. 로보 어드바이저 › 차트 패턴·지지/저항·멀티타임프레임.
2. 「055550」 입력 → 실행. 다음에 「055550.KS」 입력 → 실행.

### 기대
6자리 · .KS · 종목 이름 어느 꼴로 넣어도 같은 종목 · 같은 결과.

### 실제
| 입력 | 다중 주기 | 캔들 패턴 |
|---|---|---|
| `055550` | 「종목 데이터 없음: 055550」 | 패턴 점수 0.5 (neutral) · 10-13 흑삼병 |
| `055550.KS` | 매도 · 종합 −1.1 · 신뢰도 39% | 패턴 점수 −5 (bearish) · 10-13 도지 |

같은 날짜(10-13) 캔들 이름이 다르다 — 6자리일 때 다른 자료(출처)를 읽는 것으로 보인다(확인 필요).

### 제안
- 서버에서 6자리를 .KS/.KQ 로 맞추는 함수를 한 곳에 두고(모의주문의 `resolve_stock` 과 같은 규칙) 패턴 · 다중 주기 · 스크리닝이 함께 쓴다.
- 입력 칸 예시 「005930 또는 삼성전자」.
- 6자리일 때 캔들이 어디서 왔는지 확인(같은 종목이 출처에 따라 다른 봉이면 수정주가 · 출처 차이).
