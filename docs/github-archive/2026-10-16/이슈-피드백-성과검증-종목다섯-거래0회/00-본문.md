**주담당** 신장환 @janghwan-god · **우선** 🟢 다듬기 · **화면** 성과 검증(`indicator-backtest`) · 커스텀 인디케이터 개발(`indicator-custom`)

### 무엇이 끊겼나
1. **종목을 이어 받지 못한다.** 차트 패턴 · 스크리닝 · 자동매매에서 한 종목(예: 신한지주)을 보다가 그 신호를 성과 검증으로 확인하려 해도, 종목 칸이 고정 다섯(삼성전자 · SK하이닉스 · NAVER · 현대자동차 · LG화학)뿐이라 이어서 볼 수 없다. 커스텀 인디케이터 화면은 종목 칸이 아예 없고, 성과 검증 화면의 칸 값(기본 삼성전자)을 가져다 쓴다 — 무슨 종목으로 계산했는지 커스텀 화면에서는 보이지 않는다.
2. **거래가 없을 때 「0.0%」 로만 보인다.** 커스텀 인디케이터 기본값(RSI + 이동평균 · 매수 기준 35 · 삼성전자 · 10년)으로 백테스트하면 응답이 `trade_count: 0`(한 번도 사고팔지 않음)인데, 화면은 「누적 수익률 +0.0% · 샤프 비율 0.00 · 최대 낙폭 0.0% · 승률 0.0% · 손절/익절 0회 / 0회」 만 보인다. 사용자는 「전략이 본전이었다」 로 읽기 쉽다. 같은 경우 대시보드 카드는 「신호 없음 — 이 기간에 한 번도 사고팔지 않아 수익률 · 샤프 · 최대 낙폭 · 승률을 매기지 않습니다. 같은 기간 매수 후 보유 수익률은 51% 입니다」 로 풀어 준다.

용어 — **거래 0회**: 백테스트 기간 동안 매수 조건이 한 번도 맞지 않아 포지션이 생기지 않은 상태다. 이 글에서는 「수익률 0%」 와 다른 뜻으로 쓴다 — 0% 는 사고팔았는데 본전인 경우도 포함하지만, 거래 0회는 평가할 거래 자체가 없다는 뜻이다.

### 재현
1. 투자 인디케이터 › 성과 검증 — 종목 칸을 연다(선택지 다섯).
2. 투자 인디케이터 › 커스텀 인디케이터 개발 — 값을 바꾸지 않고 백테스트 실행.

### 기대
- 종목 칸이 다른 분석 화면과 같은 종목 찾기(코드 · 이름)이거나, 다른 화면에서 보던 종목을 넘겨받는다. 커스텀 화면 결과에 계산한 종목 이름이 보인다.
- 거래 0회면 대시보드와 같은 「신호 없음」 글 + 같은 기간 매수 후 보유 수익률(응답의 `return_buy_hold`).

### 실제
- 성과 검증 종목 선택지 다섯(`public/app.html` 의 `#ibt-symbol` · 2026-10-16 15:03 확인). 전략 분석(`#bt-symbol`)도 같은 다섯이다.
- 커스텀은 `document.getElementById("ibt-symbol")?.value || "005930.KS"` 로 종목을 정한다(`public/js/indicator.js` 153행).
- 커스텀 기본값 결과 — 응답 `trade_count: 0` · `return_total: 0.0` · `sharpe: 0.0` · `win_rate_pct: 0.0`, 화면은 0 값 카드 여섯(<그림 1> · 2026-10-16 15:04).
