## 무엇
스위치는 **자동매매 현황(퀀트자동매매)** 한 곳에만 두고, 의사결정 화면은 **판단·근거·성과 보기 전용**으로 바꿨습니다.

**app.html** (robo-decision 화면)
- 「▶ 의사결정 시작 · ■ 중지」 버튼 **제거**
- 「▶ 자동매매 켜고 끄기 → 퀀트자동매매 현황」 링크로 교체

**robo.js**
- `/api/quant/auto/start` · `/api/quant/auto/stop` 호출 **삭제**
- 링크 클릭 시 **퀀트자동매매 GNB 로 이동** → 자동매매 현황에서 켜고 끄기

## 확인
- 의사결정 화면: 상태 표시(🟢/⚫) + 이동 링크만
- 자동매매 현황: 여전히 「▶ 자동매매 시작 · ■ 중지」 로 켜고 끔

## 남은 것 (별도 · 3차 후보)
- **설명 글을 모드별로**(가상 체결 / KIS 모의 서버) — 대시보드 KIS 칸 문구 · 모드 안내와 함께
- **대시보드 「KIS 모의투자 시작」** — 설정(live·KIS)까지 바꾸는 특수 스위치라 별개로 유지. 문구를 명확히 하는 건 3차 후보
- 두 API 경로(`/api/quant/auto/start` · `/api/auto-trade/start`)가 같은 함수 호출 — 통합은 API 정리 이슈로 넘김
