**주담당** 강민석 @rkdalstjr · **같이** 오준영 @GoonGuMa · **우선** 🟡 불편 · 논의 · **화면** 모의 투자 의사결정(`robo-decision`) · 자동매매 현황(`quant-auto`) · 대시보드 KIS 칸

### 무엇이 끊겼나
- 모의 투자 의사결정: 「▶ 의사결정 시작 · ■ 중지」 — 설명 「… → 가상 주문 실행 → 성과 기록」
- 자동매매 현황: 「▶ 자동매매 시작 · ■ 중지」 — 설명 「… → 자동 가상 주문」
- 대시보드: 「KIS 모의투자 시작」(설정을 live · KIS 로 바꾸고 켬)

셋 다 같은 자동매매를 켜고 끈다(`/api/quant/auto/start` 와 `/api/auto-trade/start` 모두 `auto_trade.start_auto_trade`). 이름이 달라 사용자는 서로 다른 기능으로 알고, 한쪽에서 끄면 다른 쪽도 꺼지는 것을 모른다. 설명은 둘 다 「가상 주문」 인데 지금 계정은 KIS 모의 서버로도 주문이 나간다.

### 재현
1. 의사결정 화면에서 상태 「🟢 실행 중」 을 본다.
2. 자동매매 현황에서도 「🟢 실행 중」 — 같은 것인지 화면 어디에도 말이 없다.

### 기대
켜고 끄는 단추는 한 화면에만 있고, 다른 화면은 상태와 「자동매매 현황에서 켜고 끄기 →」 링크. 설명은 지금 모드(앱 안 가상 체결 / KIS 모의 주문)를 그대로 말한다.

### 실제
위와 같음. 이번 점검에서는 설정이 「실전투자 (Live)」 로 보여 지시대로 시작 · 중지를 누르지 않았다(자동매매는 점검 전부터 켜져 있었음).
