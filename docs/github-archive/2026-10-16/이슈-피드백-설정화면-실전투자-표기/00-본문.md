**주담당** 오준영 @GoonGuMa · **우선** 🔴 시연을 막음 · **화면** 증권사 API 설정(`settings`)

### 무엇이 끊겼나
대시보드에서 「KIS 모의투자 시작」 을 누른 계정은 증권사 API 설정 화면에서 투자 모드가 **「실전투자 (Live)」**, 「모의투자 (Paper Trading)」 체크가 **꺼짐**으로 보인다. 실제 주문은 한국투자증권 모의 서버(openapivts)로 나가고 응답도 「모의투자 매수주문이 완료 되었습니다」 인데, 화면만 보면 진짜 돈으로 거래하는 것처럼 읽힌다. 시연에서 이 화면이 보이면 설명이 길어진다.

### 재현
1. 통합 대시보드 › 「KIS 모의투자 시작」(점검 계정은 이미 이 상태).
2. 퀀트자동매매 › 증권사 API 설정을 연다.

### 기대
화면 낱말이 실제 주문 경로와 같다 — 예: 「KIS 모의(Testbed)로 주문」. 모드 고르기와 체크 칸이 같은 뜻을 말한다.

### 실제
- 투자 모드 고르기: 「실전투자 (Live)」 선택됨 · 그 아래 작은 글 「실전으로 바꿔도 실거래 승인이 꺼져 있으면 모의투자 서버로 주문합니다.」
- 「모의투자 (Paper Trading)」 체크: 꺼짐
- 대시보드 KIS 칸: 「자동매매 실행 중 (live · KIS · 10분 주기)」 와 「모의(Testbed)」 를 같은 줄에 씀
- 모의 투자 의사결정 설명: 「… → 가상 주문 실행 → …」(실제로는 KIS 모의 주문도 나감)

### 증거
- 캡처: [캡처 C1-증권사API설정-모드칸.png](https://github.com/EST-team-project/Qurious/blob/main/docs/%EC%A1%B0%EC%82%AC/%EB%B0%B0%EA%B2%BD%EC%A1%B0%EC%82%AC/2026-10-16-%EB%AA%A8%EC%9D%98%ED%88%AC%EC%9E%90%EC%A0%90%EA%B2%80/%EC%BA%A1%EC%B2%98/C1-%EC%A6%9D%EA%B6%8C%EC%82%ACAPI%EC%84%A4%EC%A0%95-%EB%AA%A8%EB%93%9C%EC%B9%B8.png)(App Key · Secret · 계좌번호 칸은 가림)
- 응답: `GET /api/quant/settings` → `mode: "live"`, `paper: false`, `broker: "kis"`, `live_gateway: {configured: false, via: "legacy-direct", environment: "paper"}` · `GET /api/quant/kis/quickstart` → `route: "kis-direct"`, `environment: "paper"`, `route_detail: "KIS 직접 호출(내 키) → 모의(Testbed)"`
- 코드: `app/services/kis_quickstart.py` `TESTBED_DEFAULTS` 의 `quant_mode: "live"`, `paper: False` — 여기서 live 는 「가상 체결 말고 증권사로도 주문」 이라는 뜻인데 화면은 「실전」 으로 읽는다.

### 제안
- 모드 낱말을 실제 경로로: 「앱 안 가상 체결」 · 「증권사 모의 서버로 주문(KIS Testbed)」 · 「실전(실거래 승인 필요)」.
- 체크 칸(`paper`)과 모드 고르기를 하나로 합친다(지금은 둘이 서로 다른 말을 함).
- 「실전」 은 실거래 승인이 켜졌을 때만 고를 수 있게 — 논의(실거래 관문은 건드리지 않고 화면 글만).
