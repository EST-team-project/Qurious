이슈의 2차 안 B 범위로 수정 PR을 올렸습니다: #277

가져오기 확인 창에 상품 안내에서 국내 상장 ETF 정보를 보고 종목코드·목표 비중을 직접 추가하는 절차를 넣었습니다. 목표 표 아래에는 「자산군별 상품 보기 →」 링크를 추가했고, 가져온 결과 줄에도 국내주식·현금 비중과 적용하지 않은 자산군을 남깁니다.

실제 Chrome에서 합성 API로 취소 시 기존 목표 유지, 가져오기 시 주식 30%·현금 70% 표시, 상품 안내의 저장 배분 조회, 왕복 후 편집안과 자동 실행 꺼짐 유지, ETF 직접 추가 후 현금 비중 감소를 확인했습니다. 해당 흐름은 GET만 호출했습니다. 기존 입력·저장 Chrome 검증 14항목과 화면 스캐너·diff 검사도 통과했습니다.

자동 ETF 선정·편입(안 A)은 별도 범위입니다. 현재 배분 정책은 국내주식 부분만 가져오며, 미적용 비중을 사용자가 확인하고 직접 목표를 편집하도록 연결했습니다. 이슈는 OPEN으로 유지하고 자동 종료 연결도 넣지 않았습니다. Docker 최신화 후 localhost:8966 확인 결과를 추가로 남기겠습니다.
