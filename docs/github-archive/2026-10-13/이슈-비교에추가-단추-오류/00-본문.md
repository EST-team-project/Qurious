# [결함] 성과 검증 「비교에 추가」 단추가 눌러도 동작하지 않음 — onclick 속성이 `)` 앞에서 닫힘

> **쉬운 요약 3줄**
> 1. 「성과 검증 (Python)」 화면의 「⚖️ 비교에 추가」 단추를 누르면 비교 트레이에 담기지 않고 스크립트 오류가 난다.
> 2. 단추의 `onclick='…'` 속성이 함수 호출의 닫는 괄호 `)` **앞에서** 끝나, 브라우저가 `compareTrayAdd({…}` 까지만 실행하려다 문법 오류를 낸다.
> 3. 강사님 기초 코드는 10-12 에 같은 결함을 고쳤고(`3a135b1`), 우리 「전략 분석」 화면의 같은 단추는 이동원이 같은 꼴로 고쳤다(이 글과 같은 날 PR). 성과 검증 한 곳이 남았다.

## 어디

| 화면 | 파일 · 줄 | 지금 끝 | 고친 끝 |
|---|---|---|---|
| 성과 검증(Python) · `indicator-backtest` | `public/js/indicator.js` 298 ~ 301 | `}).replace(/'/g, "&#39;")}')">⚖️ 비교에 추가</button>` | `}).replace(/'/g, "&#39;")})'>⚖️ 비교에 추가</button>` |
| (고침) 전략 분석 · `quant-backtest` | `public/js/quant.js` 199 ~ 202 | — | 위와 같은 꼴로 고쳤다 · 지킴이 시험 TC-BM 한 줄 |

속성은 `onclick='compareTrayAdd(${…})'` 처럼 **작은따옴표로 열고**, 안의 JSON 작은따옴표는 `&#39;` 로 바꿔 둔다. 그래서 끝은 `)` → `'` → `>` 차례여야 한다. 지금은 `'` → `)` → `"` → `>` 라 속성 값이 `compareTrayAdd({…}` 에서 끊긴다.

## 재현

- 같은 꼴의 문자열로 속성 값을 잘라 함수로 만들면 옛 꼴은 `SyntaxError: missing ) after argument list`, 고친 꼴은 문법이 맞다(2026-10-13 · node 로 확인).
- 화면에서는 단추를 눌러도 트레이가 비어 있고, 브라우저 콘솔에 같은 문법 오류가 찍힌다.
