PR #267이 main에 병합되었습니다(병합 커밋 `9bea3ee`). 합의한 범위로 이슈 #200의 코드 수정과 검증을 완료했습니다.

- 작업 조회(GET)·취소(DELETE)에 세션/JWT 인증과 소유자 확인을 적용했습니다. 비동기 채팅과 인제스트 4개 경로는 큐 발행 전에 작업 소유자를 저장합니다.
- 타인 작업과 소유자 없는 기존·시스템 작업은 일반 사용자에게 동일한 404를 반환합니다. `admin` 역할만 별도 접근하며, `terminate=true`도 관리자만 허용합니다.
- 내부 예외는 서버 로그에 남기고 사용자에게는 한국어 안내를 반환합니다. 소유자 저장소 장애 시에는 관리자도 접근을 차단합니다.
- 관련 시험 104개가 통과했고, 격리 PostgreSQL·Redis·Celery 워커에서도 실제 발행·조회·실패·취소를 확인했습니다. 새 시험 묶음 `TC-TASK`와 데이터/API 문서도 등록했습니다.

배포 시 앱 교체 전에 `alembic upgrade head`로 `0025_task_ownership`을 적용해야 합니다. 과거 작업의 소유자는 소급 추정하지 않습니다. 운영 배포는 아직 수행하지 않았습니다. DF-116의 코드 대조 시 PR #267을 참고해 주세요.
