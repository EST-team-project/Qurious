## 1. 왜 이 글을 쓰나요

키움증권에서 모의투자를 하는 실제 사용자의 말 가운데 신장환 님 작업에 바로 닿는 것입니다.

- 「ADX 로 추세는 보지만, 같은 섹터 안에서도 강한 종목 · 약한 종목을 나눠 골라야 한다」
- 「섹터별 · 종목별 순위로 매수 쪽 · 보유 · 매도 쪽을 보고, 종목을 누르면 근거가 나오면 좋겠다」

팀 묶음 글이 제안한 **순위 화면(= 섹터 강약 표)** 과 **종목 허브**(어디서든 종목 이름을 누르면 열리는 한 화면)가 신장환 님 작업(다중 주기 신호 기록 · 설명 API · 차트 패턴)을 가장 많이 씁니다.

## 2. 조사 요약

- **ADX(평균 방향 지수)** — 추세의 세기만 잽니다. 방향은 +DI · −DI 가 봅니다. Wilder 기본 14기간 · 「25 위 강한 추세 · 20 아래 추세 없음 · 그 사이 회색 지대」 · 평활 탓 지연 · 휩소 · 변동성 낮은 종목은 신호가 드뭅니다(StockCharts ChartSchool).
- **상대 강도(종목 ÷ 기준선)** — 값 자체는 종목끼리 견줄 수 없어 n일 변화율 · 섹터 안 순위로 견줍니다(같은 곳 Price Relative). RSI(한 종목 안의 오름 · 내림 비교)와 다른 것입니다.
- **열로 나누기** — 「추세가 뚜렷한가(ADX)」 와 「섹터보다 나은가(상대 강도)」 를 한 점수로 섞으면 「왜 이 종목인가」 를 셀 수 없습니다. 열을 나누고 마지막에 「조건 충족 n / 4」 만 두는 꼴을 제안합니다.
- **실서비스** — Seeking Alpha 는 100여 지표를 같은 섹터 종목과 견줘 요인별 등급을 매기고 「종합은 단순 평균이 아니다」 라고 밝힙니다. TradingView 기술 등급은 지표마다 매도 −1 · 중립 0 · 매수 +1 을 내고 묶음 평균을 냅니다(오실레이터 묶음에 ADX 포함). 「Strong Buy」 같은 등급 낱말은 빼고 구조만 빌리는 쪽입니다(팀 묶음 글 4절 「규칙 신호 집계」).

## 4. 여쭐 것

   - 판단 재료: <표 1> 1 · 2행
2. **정렬 기본값 · 판** — 종합 점수 · 신뢰도 · 주기 일치도 가운데 무엇을 기본으로 둘까요? 정의 판은 그날 최신 판 하나만 보이면 될까요? 그날 줄이 없는 종목은 「기록 없음」 으로 남기면 될까요?
   - 판단 재료: `app/models/signal.py:26`(정의 판이 기본키)
3. **ADX · +DI · −DI · 상대 강도 함수** — 지표 정의 한 곳(`ta_utils`)에 두는 것이 맞다고 봅니다. 기간(ADX 14 · 상대 강도 20 · 60 · 120일)과 기준선(섹터 ETF · 섹터 가운데 값 · 시장)을 정해 주실 수 있을까요? 섹터 소속 · 총수익 지수 데이터는 이동원이 붙입니다.
   - 판단 재료: 2절 원문 · `app/services/ta_utils.py:21`(정의 판 `tv-2026`)
4. **규칙 신호 집계** — 지표마다 매수 쪽 · 중립 · 매도 쪽을 내고 개수를 세는 꼴을 신호 API 에 둘지, 다중 주기 신호의 `reasons` 를 그대로 「이유 문장」 으로 쓸 수 있을지 여쭙니다.
