# [화면 설계] 모델 비교 — 시간 순서를 지킨 평가 · 기준선 넷 · 「셋 모두보다 뚜렷할 때만 낫다」 (결정 알림)

ML · 딥러닝 메뉴의 **모델 비교** 화면을 다시 만들었습니다(PR #(PR 번호)). 주인 없던 화면이라 이동원이 맡았고, 이 글은 **결정 알림**입니다 — 기다리지 않고 진행했으며, 의견은 언제든 댓글로 주시면 다음 개선에 넣겠습니다.

**결론: 모델 8개를 아무것도 배우지 않은 기준선 넷과 같은 날들로 견주고, 기준선 셋 모두보다 뚜렷할 때만 「낫다」 고 말합니다. 삼성전자 2년은 8개 모두 「차이 없음」 이었습니다.**

## 1. 지금 — 바꾸기 전 화면의 문제

| 문제 | 왜 문제인가 |
|---|---|
| 교차검증이 시험 구간보다 뒤(미래) 자료로 학습 | 실제로는 알 수 없는 미래를 보고 맞힌 점수라 부풀려진다 |
| 학습 끝과 시험 사이 간격 없음 · 마지막 5행에 가짜 「관망」 라벨 | 5거래일 뒤를 맞히는 문제라 정답이 샌다 |
| 기준선 없음 · 정확도 하나로 1 ~ 3등 메달 | 「관망」 이 많으면 늘 같은 답만 해도 정확도가 높다 · 흩어짐보다 작은 차이로 1등이 갈린다 |
| 「7종」 인데 모델 8개 · 일봉 출처 표시 없음 | 숫자가 틀렸고, 어떤 자료로 계산했는지 알 수 없었다 |

## 2. 세 안 → 고른 안

| 안 | 꼴 | 명확성 · 흐름 · CTA |
|---|---|---|
| A 표 | 순위 · 점수 · 판정을 한 표로 | 숫자는 정확하지만 처음 보는 사람이 「그래서 뭐가 낫나」 를 읽기 어렵다 |
| B 그림 | 겹마다 점 · 합친 값 마름모 · 우연 띠 | 흔들림이 한눈에 보이지만 결론 한 줄이 없다 |
| C 요약 | 카드 셋 + 「왜」 세 줄 | 바로 읽히지만 근거를 따라가기 어렵다 |
| **고른 안 — C 요약 + 자세히(B 그림 · A 표 탭) + 다음 행동** | 위에 결론 · 아래 「자세히」 안에 그림과 표 · 맨 아래 다음 행동 단추 | 숨기지 않고 구조로 — 결론(명확성) → 근거(흐름) → 다음 행동(CTA) |

## 3. 무엇을 정했나

- **잴 점수** — 균형 정확도(오름 · 관망 · 내림마다 맞힌 비율의 평균 · 찍기 ≈ 33%). 정확도는 곁에 두고 「정확도의 함정」 한 줄로 차이를 보입니다.
- **판정** — 기준선 셋(늘 같은 답 · 지난 흐름 그대로 · 이동 평균 위아래) 모두와 같은 날들로 짝지어 견주고, 이웃 날이 겹치는 만큼 20거래일 덩어리로 다시 뽑고, 모델 수만큼 보정(홀름)합니다. 하나만 골라 견주면 무작위 시세에서도 8 ~ 15% 가 「낫다」 로 나와 이렇게 정했습니다.
- **1년** — 시험 날이 200일보다 적어 계산은 하되 판정하지 않습니다.
- **자료** — 우리 수집 일봉(수정주가)만 씁니다 · 다른 출처로 말없이 넘어가지 않습니다 · 기간은 자료 기준일에서 거꾸로 셉니다.
- **기다림** — 처음 계산은 10 ~ 20초라 앱 안에서 돌리고 1초마다 「몇째 모델 · 몇째 겹」 을 보입니다(지어낸 백분율 없음). 한 번 계산하면 자료가 바뀌기 전까지 바로 보입니다.
- **다음 행동** — 종목 스크리닝의 판단 근거(XAI) · 강의실 교차 검증 실습 · 비교에 추가 · 다른 종목.

## 4. 다른 파트에 닿는 곳

- **XAI(신장환 님)** — 이 화면은 「모델이 기준선보다 나은가」 만 말하고, 「왜 그렇게 예측했나」 는 종목 스크리닝의 판단 근거(XAI)로 보냅니다. 경계는 따로 글로 여쭙니다(#(XAI 경계 글 번호)).
- **강사님 `feature_engineer` 라벨** — 마지막 5행에 「관망」 이 채워지는 문제(결함대장 DF-114)는 모델 비교에서는 우리 라벨 함수로 피했습니다. 같은 함수로 학습하는 곳(AI 수익 예측 · 퀀트 학습)은 위 글에서 함께 여쭙니다.
