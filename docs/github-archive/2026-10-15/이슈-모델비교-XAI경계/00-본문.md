# [의견 요청] 모델 비교와 XAI 의 경계 · XAI 다시 학습 권한 · 같은 라벨 함수 — 신장환 님

@janghwan-god 님, 모델 비교 화면을 다시 만들며(PR #202 · 화면 설계 글 #(화면 설계 글 번호)) XAI 쪽에 닿는 곳 셋을 찾았습니다. 셋 다 사실만 적었고 고치지는 않았습니다 — 어떻게 할지는 신장환 님이 정해 주시면 됩니다.

**결론: ① 경계 — 모델 비교는 「기준선보다 나은가」 만, XAI 는 「왜 그렇게 예측했나」 를 맡는 것으로 나눴으면 합니다 ② XAI 다시 학습은 지금 로그인만 하면 누구나 부를 수 있습니다 ③ XAI 가 설명하는 예측 모델도 마지막 5행 라벨 문제가 있는 강사님 함수로 학습합니다.**

## 1. 경계(제안)

| | 모델 비교(이동원) | 판단 근거 XAI(신장환 님) |
|---|---|---|
| 묻는 것 | 이 종목 · 기간에서 모델이 아무것도 배우지 않은 기준선보다 나은가 | 이 예측이 왜 나왔나 — 어느 특징이 얼마나 |

## 2. XAI 다시 학습 권한 (사실)

- `GET /api/ml/explain?refresh=1` 은 로그인만 하면 누구나 부를 수 있고, 부르면 다시 학습합니다(`app/routes/ml.py:352-369` · `main` `8921f92` 기준 · 코드 읽기).
- 학습은 CPU 를 오래 쓰므로, 여러 사람이 누르면 앱이 느려질 수 있습니다. 모델 비교의 계산 시작은 화면에서 보낸 요청만 받고(머리글 · 같은 사이트) 같은 계산은 하나로 붙이며 동시에 둘까지만 돌립니다 — 참고가 되면 씁니다.

## 3. 같은 라벨 함수 (결함대장 DF-114)

- 강사님 `quant_pipeline.feature_engineer` 는 앞날이 없는 마지막 5행에도 라벨을 「관망(0)」 으로 채웁니다(앞날 수익률이 비었는데 라벨을 먼저 0 으로 채워 `dropna()` 에 걸리지 않음).
- XAI 가 설명하는 예측(`app/services/investment_research.py:219`)이 이 함수로 학습합니다. 퀀트 학습(`quant_pipeline.py:538`)도 같습니다. 모델 비교는 우리 라벨 함수로 피했습니다(시험 TC-MV-03).
- 영향은 크지 않을 수 있지만(끝 5행), 마지막 구간의 「관망」 비율이 조금 부풀고 그 구간 평가가 어긋납니다. 강사님 기초 코드라 고친다면 다음 기초 코드 반영 때 겹치지 않게 맞춰야 합니다.
