## How

- **보유 표를 쪼개지 않고 현금을 합쳤습니다.** 문제는 「표가 둘」이 아니라 「현금과 보유가 다른 장부를 본다」이고, 보유 표는 이미 하나라 현금 쪽만 바꾸면 됩니다. D7 ③ 추천안 C1(`paper_accounts` 하나)과 같은 방향입니다. 반대 안(보유를 장부별로)은 작업 이슈 「뒤집을 조건」에 남겼습니다.
- 새 함수를 만들지 않고 수동 주문이 쓰던 `get_account(lock=True)` 를 그대로 불렀습니다 — 두 경로가 **같은 잠금**을 쓴다는 것이 코드로 보입니다.
- 시험은 가짜 세션이 아니라 **실제 Postgres**(도커 `pgvector/pgvector:pg16`, 보유 이미지)로 돌렸습니다. SQLite 는 `FOR UPDATE` 를 무시하고 모델이 `PG_UUID`·`ARRAY` 를 씁니다. 끝난 뒤 컨테이너를 지웠습니다.
