## How

- 저장소 `docker-compose.yml` 을 건드리지 않는 **별도 compose** 로 띄웠습니다 — `.env`(실제 키)를 읽지 않고, 비밀값은 그 자리에서 만들었습니다. neo4j · celery · LEAN 은 띄우지 않았습니다(IA 1.5절 조건 표).
- 화면 이동은 주소가 아니라 **상단 탭 → 왼쪽 메뉴 클릭**(사용자와 같은 길)으로 했습니다.
- 강사님 일정의 칸 날짜는 일정표 JS(`renderSheet()`)를 로컬에서 실행해 뽑았습니다.
- 끝난 뒤 컨테이너 · 볼륨 · 이번에 만든 이미지를 모두 지웠습니다.
