### 가져올 후보(정리 중)

- **th11 python-ml-class → ML 화면 · 개념 학습 실습**: 실습 스크립트 25 · 해설 24 · 결과 46 · Flask 화면 하나다. 우리 ML 다섯 화면(모델 비교 · 회귀 분석 · 종목 군집화 · 튜닝 · 딥러닝)과 겹치고, 특히 지금 설명만 있는 딥러닝 화면을 실습으로 바꿀 재료다. 그대로 넣지 않는 까닭은 셋이다 — 분류 · 튜닝 스크립트 넷이 시계열을 무작위로 나누고(미래 자료로 학습), LSTM 이 전체 구간의 최소 · 최대로 정규화하며, 스크립트 17곳이 야후를 직접 부르고 실패하면 합성 가격으로 바꾼다. 글 · 코드 · 출력은 개념 학습 한 곳에 우리 자료로 다시 쓰고, ML 화면에는 「원리 · 실습 열기」 단추를 두는 안으로 정리하고 있다. 원본에 LICENSE 파일이 없어 출처를 밝히고, 이력은 옮기지 않는다.
- **th06 lumina-invest 의 아직 안 받은 새 기능**: 새 화면 넷(KIS 모의투자결과 · 전략설정 · 설정별 성과 · 수익률 검증)은 지금 이슈(#242 · #244 · #153) 그대로다. 데이터 쪽 새 파일(DART 재무 · 섹터 인디케이터 · 국내 시장 종목 목록 · 딥러닝 실습 노트북 · Pine 문법 점검 · AG Grid)은 이동원이 받는다. 새 파일 자체는 충돌이 없지만, 쓰게 하려면 라우터 등록 · 화면 블록 · 메뉴 같은 붙이는 줄이 우리도 고친 파일에 들어가므로 그 줄만 하나씩 맞춰 얹는다.
- 전략설정은 저장하면 서버 전체 설정이 바뀌는 구조(한 계정의 저장이 모든 계정 자동매매에 걸림)라, 받을 때 본인 설정으로 바꾸고 실거래 차단 시험을 먼저 둔다.
