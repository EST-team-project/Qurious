## How

- **공급자가 준 등락률(`regularMarketChangePercent`)을 그대로 쓰지 않고 계산했습니다.** 필드는 사라집니다 — 실제로 `previousClose` 가 6종목 모두 null 이었고 옛 코드는 `or` 로 겨우 살아 있었습니다. 현재가·전일 종가 두 값으로 계산하면 `price`·`prev_close`·`change` 가 서로 맞고, 공급자 값은 시험에서 **대조용**으로만 씁니다(6종목 모두 소수 둘째 자리까지 일치).
- **`chartPreviousClose` 는 전일 종가가 아닙니다.** 「차트 첫 봉 바로 앞의 종가」입니다. 기간 1일일 때만 전일 종가와 같고, 5일로 받으면 5거래일 전 종가가 됩니다(같은 날 실측 285,500 → 252,500). 그래서 시험이 요청 기간까지 확인합니다.
- 야후 봉인 시험이 `stock.py` 참조 줄을 20줄로 묶고 있어 새 주석에는 영문 공급자 이름을 쓰지 않았습니다(20줄 그대로).
- 알려진 한계 — 거래소·증권사 앱의 공식 등락률은 **기준가** 대비입니다. 권리락·주식배당락·분할·병합 날에는 값이 다를 수 있습니다(주석에 적음).
