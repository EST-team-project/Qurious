> **쉬운 요약**
> 1. 리밸런싱 담당 기능인 시간 기반·이탈률 기반·현금흐름 기반의 설정 기준을 정하려고 합니다.
> 2. 기존 구현을 바탕으로 사용자에게 제공할 선택지와 기본값을 논의하고 싶습니다.
> 3. 아래 항목별로 의견을 남겨주시면 구현 기준에 반영하겠습니다.

## 1. 현재 구현 상태

현재 저장소에는 세 가지 리밸런싱의 기본 구현이 있으며, 기본 설정은 다음과 같습니다. 사용자별로 저장한 값은 다를 수 있습니다.

| 구분 | 현재 기본 설정 |
|---|---|
| 시간 기반 | 사용 안 함. 월·분기·연 선택 가능 |
| 이탈률 기반 | 활성화. 목표 비중에서 **5%p 이상** 벗어나면 조건 충족 |
| 현금흐름 기반 | 활성화. 입금·출금·배당 이벤트 **1건당 10만 원 이상**이면 조건 충족 |
| 자동 체결 | 비활성화. 기본적으로 주문 제안 생성 |

아래 내용은 **확정된 변경 사항이 아닌 논의안**입니다.

## 2. 시간 기반 — 어떤 주기를 제공할까요?

사용자가 실행 주기를 선택하도록 하고, 우선 다음 선택지를 생각하고 있습니다.

| 선택지 | 실행 기준 |
|---|---|
| 매월 | 매월 첫 거래일 |
| 매분기 | 1·4·7·10월의 첫 거래일 |
| 매년 | 1월 첫 거래일 |

의견을 받고 싶은 부분입니다.

- 위 세 가지면 충분할까요? 매주 또는 사용자 지정일도 필요할까요?
- 기본값은 현재처럼 **사용 안 함**으로 둘까요, 특정 주기를 지정할까요?
- 실행 시각은 언제로 할까요?

현재 코드는 달력상 월·분기·연 시작일을 계산하므로, **첫 거래일 기준을 채택하면 휴장일 처리를 추가**해야 합니다.

## 3. 이탈률 기반 — 허용 이탈률을 몇 %p로 설정할까요?

현재 코드의 기본 허용 이탈률은 **5%p**입니다.

예를 들어 목표 비중이 40%, 허용 이탈률이 5%p라면 현재 비중이 45% 또는 35%일 때 차이가 5%p입니다.

- **기본값:** 현재의 5%p를 유지할까요, 다른 값으로 설정할까요?
- **설정 방식:** 사용자가 직접 입력하도록 할까요, 정해진 선택지를 제공할까요?
- **경계 조건:** 정확히 기준값에 도달한 경우에도 실행하는 **‘이상’**으로 할까요, 기준값을 넘어야 하는 **‘초과’**로 할까요?

현재 코드는 **‘이상’**으로 판단합니다.

## 4. 현금흐름 기반 — 기준 금액을 어떻게 설정할까요?

기준 금액은 우선 **이벤트 1건으로 증감한 현금 금액**으로 생각하고 있습니다.

사용자 설정 방식에 대해 의견 부탁드립니다.

| 안 | 설정 방식 |
|---|---|
| A | 사용자가 기준 금액 직접 입력 |
| B | 금액 무관 / 5만 / 7만 / 10만 / 15만 / 20만 원 등에서 선택 |
| C | 기본 선택지 제공 + 직접 입력 |

함께 정할 사항입니다.

- 기본값은 현재의 **10만 원 이상**을 유지할까요?
- 한 번의 이벤트 금액으로 판단할까요, 작은 금액을 누적해서 판단하는 방식도 필요할까요?
- ‘금액 무관’을 선택하면 아래에서 정한 대상 이벤트가 발생할 때마다 점검하도록 할까요?

## 5. 현금흐름의 범위 — 일반 매매로 발생한 현금 증감도 포함할까요?

현재 구현은 입금·출금·배당 이벤트를 대상으로 합니다. 일반 매매로 생기는 현금 증감도 포함할지 의견을 받고 싶습니다.

| 안 | 대상 |
|---|---|
| A | 입금·출금·배당만 포함 |
| B | 입금·출금·배당 + 일반 매수·매도로 인한 현금 증감 포함 |

B안을 선택한다면 다음도 함께 정해야 합니다.

- 매매 주문이 **체결된 시점**에 점검할지
- 여러 주문이 이어질 때 **주문마다 점검할지, 묶어서 점검할지**
- **리밸런싱 자체의 매매**로 발생한 현금 증감도 대상에 포함할지

리밸런싱 자체의 체결까지 포함할 경우에는, 그 체결이 다시 리밸런싱을 유발하는 **반복 실행을 방지할 기준**이 필요합니다.

## 6. 세 조건의 동작 관계

시간·이탈률·현금흐름 조건을 **각각 독립적으로 켜고 끌 수 있게 하는 방향**을 제안합니다.

여러 조건이 동시에 충족되면 중복 주문을 만들지 않고, 하나의 리밸런싱 계획으로 처리하되 충족된 조건을 기록하면 좋겠습니다.

## 7. 의견 요청

전체 항목에 답하지 않으셔도 괜찮습니다. 아래처럼 항목 번호와 의견을 남겨주시면 됩니다.

```text

현금흐름 금액: A·B·C / 기본값 / 건별 또는 누적
현금흐름 범위: A·B / 리밸런싱 자체 체결 포함 여부

```
