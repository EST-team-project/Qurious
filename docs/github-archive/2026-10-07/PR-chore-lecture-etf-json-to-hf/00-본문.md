## 무엇을 바꾸나

강의 2일차의 ETF 창 둘이 읽는 시세 JSON 둘이 **공개 저장소에 커밋돼 있었습니다.** 네이버 금융 · 토스증권에서 모은 값이라 팀 규칙(외부에서 받은 시세는 저장소에 적재하지 않는다)과 어긋납니다. 원본은 이미 비공개 데이터셋 `qurious-quant/rag-lab-display-data` 에 있고(통합본 반입 대장의 「HF 보관」), 강의 빌드가 옮긴 사본만 커밋돼 있었습니다.

| 파일 | 크기 | 내용 |
|---|--:|---|
| `public/lectures/days/assets/etf-catalog.json` | 579,632B | 국내 ETF 1,009종의 3개월 수익률 · 구성종목(네이버 금융 목록 + 토스증권 화면 응답) |
| `public/lectures/days/assets/leverage-etf-volume.json` | 901B | 레버리지 · 인버스 ETF 2종의 월 거래대금 합계 12개(네이버 금융 월봉) |

- 두 사본을 **추적에서만 뺐습니다**(`git rm --cached`) · `.gitignore` 에 두 줄.
- **강의 빌드(`scripts/lectures_build.py`)가 「HF 보관」 파일을 가려 다룹니다** — 반입 대장에서 그 줄을 읽어, 통합본 사본에 받아 둔 파일은 지금처럼 옮기고(사본은 git 무시), 없으면 건너뛰며 받는 명령을 알립니다. 건너뛴 파일은 쓰지도 · 지우지도 · 다르다고 하지도 않습니다.
- 받는 도구(`scripts/raglab_data.py pull`)도 끝에 「앱 강의 화면에 쓰려면 빌드를 한 번」 을 알립니다.
- **git 이력의 옛 사본은 그대로입니다** — 공개 저장소의 이력을 다시 쓰지는 않았습니다. 지금부터 새로 들어가지 않게 막은 것입니다.

## 머지 뒤 각자 PC 에서

- pull 하면 두 파일이 작업 트리에서 지워집니다(추적에서 빠진 파일을 git 이 지움). **2일차의 「국내 주요 운용사 전체 ETF 탐색」 · 「레버리지 ETF 거래대금 추이」 창 둘만** 「불러오지 못했습니다」 로 보이고 다른 화면은 그대로입니다.
- 그 창을 보려면(비공개 데이터셋 접근이 있는 분): `python scripts/raglab_data.py pull` → `python scripts/lectures_build.py`.
- 시험: 받아 둔 PC 에서 사본이 지워진 채로 돌리면 TC-LC-01 이 「빠진 파일 — 빌드 한 번이면 생긴다」 로 실패합니다 — 빌드를 한 번 돌리면 됩니다. 받지 않은 PC 는 그대로 통과합니다.
