## 판을 올리는 법 (머지 뒤)

1. `python scripts/docs_scan.py --bump docs/<종류>/<이름>.md` — 지금 판을 지난판 사본으로
2. 같은 파일(판 없는 이름)을 고치고 머리표의 판 · 최종 수정 · 개정 이력을 올린다
3. 산출물목록 0.1절의 판 칸 — 다른 문서의 링크는 고치지 않아도 된다
4. `python scripts/docs_scan.py --check`
