7절 ③의 U2·U5 화면 검증 근거를 보완했습니다. PR #279입니다.

실제 app.html·rebalance.js를 Chrome에서 실행해 현재/목표/이탈률, 현금·계획 밖 종목, 다음 확인일·달력 대기, 예약/체결/미체결 이력, 주문 상세·비용, 자료 미준비 시 옛 수치 제거, HTML 이스케이프·조회 중 주문 없음 등 17항목을 확인했습니다. pytest 인수 시험 1건 통과·건너뜀 없음입니다. API는 합성 응답이며 차트는 라이브러리에 전달한 계열·범주를 기록합니다. 실제 외부 차트 라이브러리 SVG·배치 평가는 포함하지 않습니다.

TC-RBUI를 U2·U5에 연결하고 요구 대장의 U5 「지금 없음」 비고를 실제 근거로 교체했습니다. 검증 범위·재현 방법은 docs/시험/리밸런싱-화면검증-근거.md에 남겼습니다. 앱 의존성이 있는 격리 환경의 pytest 수집 2341건·168파일을 기준으로 RTM 8개 블록도 재생성했습니다. 전체 2341건을 실행·통과했다는 뜻은 아닙니다.

운영 자료 준비 상태를 읽은 시점에는 ready=false, before_update(12:30 갱신 전 대기)였습니다. 원본 러너의 갱신 후 실제 자료·자동 점검·정산 대조는 여전히 별도 확인입니다. #170 전체 완료나 3차 신규 기능·스트레스 검증 완료로 처리하지 않습니다. 이슈는 OPEN으로 유지하고 자동 종료 연결도 넣지 않았습니다. Docker 확인 결과는 추가로 남기겠습니다.
