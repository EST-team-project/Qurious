# [요청] 자산 배분 비중표를 함수 하나로 — 상품 안내가 같은 표를 읽게

@GoonGuMa 님, 로보 어드바이저 「투자 성향별 상품 안내」(`agent-products`)를 만들면서 자산 배분 쪽에 작은 부탁이 하나 생겼습니다.

## 배경

- 상품 안내의 흐름은 **투자 성향 진단 → 자산 배분(비중) → 자산군마다 상품 정보**입니다.
- 상품 안내 서버(#167 — `/api/products/etfs/overview` · `/api/products/etfs` · `/api/products/savings`)는 **비중을 계산하지 않습니다.** 자산군 다섯(국내주식 · 해외주식 · 국내채권 · 대체자산 · 현금)마다 공시된 상품 정보(ETF 는 우리 수집 자료 · 예금 · 적금 · 연금저축은 금융감독원 실시간)를 정해진 기준으로 늘어놓기만 합니다.
- 비중의 정본은 자산 배분 쪽이라, 화면에서 비중과 상품을 같은 자산군 키로 이으려고 합니다.

## 지금

- 비중표는 `app/routes/ml.py` 의 `robo_allocation` 안 사전(`base_alloc`)과 투자 기간 보정 몇 줄이라 다른 곳에서 불러 쓸 수 없습니다.
- 이 API 는 종목 31개를 훑고 AI 예측까지 해서 첫 부름이 14초 안팎이라, 상품 화면이 비중만 얻으려고 부르기에는 무겁습니다.

## 부탁 (제안 — 방식은 편하신 대로)

1. **비중 계산을 순수 함수 하나로** 빼 주세요. 예: `asset_allocation(risk_profile, horizon_years) -> dict[str, float]` — 자리는 `app/services/robo_profile.py` 나 편한 곳. `robo_allocation` 이 이 함수를 부르게 하면 지금 동작은 그대로입니다.
2. (선택) **비중만 주는 가벼운 길** — 예: `GET /api/ml/robo/weights?risk_profile=&horizon_years=`. 화면이 상품 안내와 함께 부를 수 있게요. 만들지 말지는 정해 주세요.
3. **자산군 키 다섯은 지금 글자 그대로** 써 주세요. 상품 안내가 같은 키로 비중과 상품을 잇습니다. 바꿀 일이 생기면 이 글에 알려 주세요.

## 하지 않는 것

- 비중 값 · 성향 단계 · 진단 문항은 그대로 자산 배분 몫이고, 상품 안내는 읽기만 합니다.
- 제 쪽에 같은 표를 복제하지 않습니다 — 같은 표가 두 곳에 생기면 한쪽만 바뀌는 일이 생겨서요.
