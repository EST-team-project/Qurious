# [개념 학습] 기능별 개념 장 목록 — 자기 기능 장이 맞는지 봐 주세요 (검수 · 의견)

## 한 줄

개념 학습은 회의에서 정한 대로 **제가(이동원) 전 팀 범위를 조사하고 씁니다.** 다만 각 기능의 정의 · 산식 · 규칙은 주담당 님이 정본이라, **자기 기능 장 목록이 맞는지**와 **글을 쓴 뒤 정확성 검수**를 부탁드리려고 올립니다. 영역을 침범하려는 글이 아니고, 의견 · 아이디어는 누구나 자유롭게 남겨 주셔도 됩니다.

## 무엇을 정리했나

- 앱의 학습 메뉴 둘을 이렇게 나누려 합니다.
  - **금융 필수 지식** — 서비스를 쓰는 사람이 화면을 쓰기 전에 알아야 할 금융 기초(강사님 강의 · 교재는 그대로 두고, 빠진 것만 「보완」 으로 붙임). 질문 꼴: 「이게 뭐고, 왜 조심해야 하고, 화면 숫자를 어떻게 읽나」.
  - **개념 학습** — 기능을 만드는 데 쓰는 개념을 교재처럼(정의 · 그림 · 예제 코드와 실제 출력 · 우리 코드 위치 · 흔한 실수 · 확인 문제). 질문 꼴: 「어떻게 계산 · 구현 · 검증하나」.
  - 같은 개념이 두 쪽에 다 필요하면 둘로 나눕니다 — 예: 성과 지표 **읽는 법**(필수 지식) ↔ 성과지표 **계산 정의**(개념 학습). 정본은 한 곳, 다른 곳은 두세 줄 요약 + 링크.
- 요구 대장 59줄을 보고 기능마다 필요한 개념을 뽑았습니다. 지금 개념 장 34편은 데이터 · RAG · 차트 · 서버 쪽뿐이라, **팀원 기능 장은 아직 하나도 없습니다**(아래 표의 「지금」 칸이 거의 「없음」 인 까닭).
- 언제 쓰나: 3차 날짜 칸이 있는 장은 **그 날짜 직전에**, 2차 기능 장은 2차 구현이 끝난 뒤(정의가 굳은 다음) 순서대로 씁니다. 2차 일정을 밀지 않는 범위에서만 합니다.

조사서: `docs/조사/금융지식-개념학습-배치-조사.md`(PR 머지 뒤 링크로 바꿈) · 장 목록 전체(84줄): 같은 PR 의 장 대장 TSV

**같이 알려 드리는 것**

- 앱의 두 학습 메뉴 꼬리에 「교육 · 모의투자용이며 특정 상품의 매수 · 매도를 권유하지 않습니다」 문구를 한 벌로 두려 합니다(강사님 강의 쪽은 원본이 이 문구를 다른 꼴로 바꿔서, 우리 쪽에서 따로 둡니다).
- 각 기능 화면 한쪽에 「이 화면의 개념」 작은 입구(장 1 ~ 3개 링크)를 두면 어떨까 합니다(토스증권이 「더 깊은 이해가 필요한 길목마다」 콘텐츠를 붙이는 방식). **붙일지 · 어디에 둘지는 그 화면 주담당 님이 정합니다** — 의견 칸에 편하게 남겨 주세요.
- 검수 방식 제안: 제가 1.0 을 쓰면 → 주담당 님이 틀린 곳만 짚어 주시고 → 고쳐서 1.1 로 올립니다. **내용 정본은 주담당 님**입니다.
- 답은 편하실 때 주셔도 되고, 답이 없으면 지금 코드 · 설계서를 정본으로 보고 쓴 뒤 검수만 따로 부탁드리겠습니다.
