# [의견 요청] 증권사별 모의투자 환경 차이 · 한 사람 여러 모의 계좌 — 3차 증권사 연동 참고 조사

> **오준영 님 영역(3차 증권사 연동 자동화 · 리밸런싱)** 에 닿는 조사 결과입니다. 코드를 대신 고치자는 글이 아니라 조사로 나온 사실과 아이디어를 드리고, **반영할지 · 언제 할지는 주담당이 정하는** 글입니다. 다른 분들도 의견 · 아이디어는 자유롭게 남겨 주세요.
>
> - 전체 조사서(출처 53개 · 조회일 2026-10-10 · 확실도 표기): `docs/조사/모의투자-증권사규칙-시작금액-조사.md` — 이 글과 함께 올리는 PR 에 들어갑니다
> - 증권사 API 는 **한 번도 호출하지 않았습니다** — 공식 개발자 문서 · 공개 규정 페이지만 읽었습니다. 우리 코드 판정은 코드 읽기 판정입니다.
> - 모의 시작 금액 · 리셋 · 성과 기준점은 강민석 님께 따로 올립니다(이슈 「모의 계좌 시작 금액을 직접 정하기」).

## 1. 짧은 답 — 「실거래 · 모의 계좌가 따로라면 여러 곳에서 다양하게 쓸 수 있나」

- **증권사 쪽에서는 예.** 조사한 10곳 가운데 모의 계좌를 운영하는 곳은 모두 실계좌와 **따로** 둡니다 — 모의 전용 ID · 비밀번호 · 계좌번호 · **API 키** · 접속 주소(또는 포트). 한 사람이 상시 모의 계좌와 그룹 · 대회 모의 계좌를 따로 가질 수 있는 곳이 많습니다(키움 · 미래에셋은 상시 · 그룹을 따로 신청하고, 삼성선물 · KB 대회는 모의 계좌를 먼저 만들어야 참가). 실계좌를 쓰는 것은 「실전투자대회」(키움 영웅전 · NH 투자 챔피언십)뿐입니다.
- **우리 앱은 지금 아니오.** 증권사 설정이 사용자당 한 행(`broker_settings` · `app/models/trading.py:99-111` · `user_id unique`)이라, 한 사람이 KIS 모의 계좌와 키움 모의 계좌를 동시에 붙이거나, 같은 증권사의 상시 · 대회 모의 계좌를 나눠 붙일 수 없습니다. ADR-0004(KIS 키는 사용자마다)와는 맞는 구조이고, 넓힐지는 요구에 없어 의견만 여쭙니다(6절 B6).

## 3. 모의 체결 · 주문 규칙 — 연동하면 겪을 차이

한국투자 · 키움의 공개 모의 규정 원문(2026-10-10)에서 연동에 바로 닿는 것만 뽑았습니다.

<표 2> 모의 규정이 연동에 주는 뜻

| 규정(원문 요지) | 연동에 주는 뜻 |
|---|---|
| 「현재가보다 더 적극적인 가격의 주문을 내어도 즉시 체결되지 않고, **실제 시장에서의 체결이 생겨야만** 모의투자에서도 체결」 · 실제 체결량만큼만 체결 · 상 · 하한가는 실제 체결 비율의 10%(두 곳) | 주문 접수 ≠ 체결. 신호 → 주문 뒤 **체결 조회 · 미체결 정리**가 필요(지금 `app/services/fill_sync.py` 가 그 자리) |
| 「모의투자에서는 시간외매매는 불가」 · 익일 예약주문 15:40 ~ 익일 07:30(한국투자) · 예약 16:00 ~ 익영업일 07:00(키움) | 실행 일정(`P02-⑤-3`)을 정규장 안에 · 장 밖 신호는 예약 주문이나 다음 날로 |
