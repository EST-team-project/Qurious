## 요약

목표 기능 ① W8 근거 품질 — 근거 답이 「근거에 있는 말만 했는가」 를 자동으로 재는 도구를 만들어 사람 판정과 맞춰 보고, 평가에서 찾은 잘못된 답 두 꼴을 서버에서 거르며, 답 모델이 실패했을 때의 화면을 바꿨다. 같은 날 섹터 질문 분류의 낱말을 2판으로 넓혔다.

Ollama 의 OpenAI 호환 길은 문맥 길이를 정할 수 없어(Ollama 문서) 자체 `/api/chat` 으로 부른다. LLM 없는 숫자 근거 확인도 함께 낸다. **사람 판정 61건(같은 답 46)과 맞춰 보니 llama3.1 은 사람 판정을 가르지 못했다** — 맞은 답 34 중 8 에 0.5 아래(조문의 단서 「다만 …」 를 빠뜨린 답을 근거에 없다고 봄) · 근거 밖 단정 A15 에 0.75 · 빗나간 조로 단정한 T11 에 1.0(빗나간 조에는 충실 — 충실도는 정답성이 아니다). 그래서 점수를 품질 지표로 쓰지 않고 평가셋 50 으로 넓히지 않는다 — exaone3.5:2.4b 는 이어서 돌고 결정은 다음 PR. 숫자 근거 확인은 숫자가 있는 답 20 모두 「근거에 없는 숫자 0」(이번 오답은 근거 안의 다른 값 · 잘못 읽기라 못 잡는 꼴).
