**주담당** 정해지지 않음(공용 라우트 — 강사님 기초 코드) · **우선** 🟡 불편 · **곳** `GET /api/stocks/search`(`app/routes/stocks.py`)

> **쉬운 요약**
> 1. 종목 찾기 칸에 국내 상장 목록에 없는 한글 이름(오타 · 상장폐지 · 비상장 회사)을 넣으면 「찾지 못했습니다」 가 아니라 서버 오류(502)가 납니다.
> 2. 그래서 이 API 를 쓰는 화면은 「없음」 과 「잠시 안 됨」 을 가를 수 없습니다.
> 3. 이 API 를 부르는 화면 파일 여섯 가운데 다섯이 이동원 화면이라, 다른 의견이 없으면 이동원이 고치겠습니다(공용 파일이라 먼저 여쭙니다).

### 왜
- 라우트는 국내 목록(KRX)에서 먼저 찾고, 없으면 야후 자동완성으로 넘어갑니다.
- 야후는 일부 한글 검색어에 400(「Invalid Search Query」)을 줍니다 — 라우트 설명 글에도 적힌 알려진 일입니다.
- 라우트는 야후의 실패를 모두 502 로 바꿉니다(`except Exception` → `HTTPException(502)`).

### 재현
1. `GET /api/stocks/search?q=없는회사이름`(국내 목록에 없는 한글)
2. 502 · `{"detail": "종목 검색 실패: …"}`

### 기대
- 국내 목록에 없고 해외 자동완성이 한글을 받지 않으면 → 200 · `{"results": []}`
- 해외 자동완성이 정말 실패했을 때(시간 초과 · 서버 오류)만 오류

### 지금 우회
- 투자 정보 리서치 화면은 502 를 「국내 상장 종목에서 찾지 못했습니다」 로, 그 밖의 오류는 「종목 찾기가 잠시 안 됩니다 — 다시 눌러 보세요」 로 읽습니다(화면 주석에 까닭 · 시험 TC-RS-10). 라우트를 고치면 이 우회를 지웁니다.
