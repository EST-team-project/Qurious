## 완료 (PR #287 )

이슈의 재현 시나리오(토요일 시장가 매수가 안내 없이 종가로 체결)를 **표기 추가**로 해결했습니다.
주문 자체는 막지 않았습니다 — 이슈 제안대로 **주말 연습이 끊기지 않게** 두고, 장 닫힘 사실과 체결 기준가를 화면이 밝히도록 했습니다.

---

### 1. 백엔드 — 서버 한 곳에서 장 상태 판정

이슈 제안 **"장 상태는 서버 한 곳에서"** 를 그대로 반영했습니다.

- `stock_coin_trade_gateway.is_krx_market_open()` 재사용
  - 평일 09:00~15:30 (KST)
  - `KRX_HOLIDAYS_2026` + `KRX_EXTRA_HOLIDAYS` 환경변수 (공휴일 대응)
- `resolve_stock` 응답에 `market_open` 필드 추가 (KRW 종목만, 해외는 `None`)
- `stock_preview` · `stock_order` 응답에도 동일 필드 전달

**시세 응답 예** (`GET /api/paper/stocks/quote?symbol=003620` · 토요일):
```json
{
  "price": 2545,
  "market_open": false,
  "quote_as_of": "2026-10-16 15:30",
  "quote_label": "10-16 종가"
}
