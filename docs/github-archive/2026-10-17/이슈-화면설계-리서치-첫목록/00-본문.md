# [화면 설계] 투자 정보 리서치 — 첫 목록은 「투자 관련만」 · 같은 제목 한 줄 · 종목 칸 Enter (결정 알림)

투자 정보 리서치의 **첫 목록**과 **종목 칸**을 고쳤습니다(PR #(번호)). 이 글은 결정 알림입니다 — 의견은 언제든 댓글로 주세요.

**결론: 첫 화면은 공시 + 종목 · 주제 이름표가 붙은 기사만 보이고(숨긴 기사 수를 스위치 옆에 밝힘), 같은 제목은 한 줄로, 제목이 언론사 이름뿐인 기사는 끝에 모읍니다. 종목 칸은 찾기 줄로 옮겨 Enter · 「검색」 이 바로 종목을 찾습니다.**

## 1. 지금 — 바꾸기 전 (모의투자 점검 2026-10-17)

| 문제 | 왜 문제인가 |
|---|---|
| 첫 화면 맨 위 열 줄 가운데 여섯이 제목 「KBS 뉴스」 뿐 | 언론사 기사(GDELT)는 페이지 머리 제목을 받는데, 어떤 사이트는 모든 기사에 사이트 이름을 제목으로 둔다 — 무엇인지 모를 줄이 첫 화면을 채운다 |
| 정치 · 사회 기사가 섞인다 | 투자 정보 화면인데 첫 목록이 일반 기사 |
| 종목 칸에 「신한지주」 를 치자마자 Enter 를 누르면 아무 일이 없고, 「검색」 은 종목 칸 글을 버린다 | 제안 목록이 잠깐 쉰 뒤에야 떠서, 빨리 누르면 놓친다 |

## 2. 세 안 → 고른 안

| 안 | 꼴 | 좋은 점 · 약점 |
|---|---|---|
| **A 「투자 관련만」 기본 + 스위치(고름)** | 지금 화면 꼴에 기본값만 바꿈(서버 거름 하나 · 화면 스위치 하나) · 같은 제목은 한 줄 | 숨긴 것을 수로 밝혀 말없이 빼지 않는다 / 주제 이름표가 낱말 규칙이라 오탐이 섞인다(「합병증」 → 합병·분할 · 정치 기사의 「검찰」 → 소송·제재 — 다음 묶음에서 규칙을 고친다 · 결함대장 DF-128) |
| B 공시 먼저 · 탭 | 종류 기본을 「공시」 로 · 기사는 탭으로 | 가장 깨끗하다 / 기사(왜 움직였나의 재료)와 금리 · 환율 · 정책 소식이 한 번 더 눌러야 보인다 |
| C 두 단 | 왼쪽 공시 · 오른쪽 종목 붙은 기사 | 오탐을 피한다 / 화면 틀이 크게 바뀌고(쪽 넘기기가 단마다) 좁은 화면은 탭으로 · 서버 거름이 하나 더 · 시장 소식이 빠진다 |

세 안 공통 — 종목 칸 Enter · 「검색」: 정확히 같은 이름이 하나면 그 종목으로, 여럿이면 목록을 열고 첫 줄에 초점, 없으면 「국내 상장 종목에서 찾지 못했습니다」. 종목 칸은 거름 칸 안에서 **찾기 줄로** 옮겼습니다(2026-10-17 결정 — 좁은 화면에서 접혀 안 보이던 칸).
