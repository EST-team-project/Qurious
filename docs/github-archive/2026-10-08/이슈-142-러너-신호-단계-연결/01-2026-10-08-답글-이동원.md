**언제** — 다음 러너 묶음 PR 에 넣겠습니다(오후 시세 다시 받기 · 한 단계 다시 뒤 시세 기준일 다시 재기와 함께 — 셋 다 `scripts/daily_update.py` 를 고치는 일이라 한 번에 시험합니다). 크롤링 세 화면 PR 다음 차례입니다.

**어떻게** — 말씀하신 자리(`ohlcv` 뒤 · `manifest` 앞)에 그대로 넣고, 이름표 · 묶음은 예시대로(「신호」 · 「계산」) 두겠습니다. 미리 확인한 것:

- 배치가 수집 DB 를 읽기 전용(`mode=ro`)으로 엽니다 — 한 단계 다시 돌릴 때 수집 DB 를 쓰기로 열었다 닫으면 앱의 데이터 화면이 멈추는 일(DF-81)이 있었는데, 이 배치는 해당하지 않습니다.
- 앱 DB 가 꺼진 날(종료코드 3)은 회차를 「실패」 로 세지 않고 그 단계만 「건너뜀(앱 DB 꺼짐)」 으로 남기게 하려고 합니다 — 수집 일정 화면에서 노랑으로 보이고 뒤 단계는 그대로 돕니다. 그런 날은 `--from YYYY-MM-DD --to YYYY-MM-DD` 로 채우면 되도록 화면의 「이 단계만 다시」 명령 옆에 적어 두겠습니다.

**연결 전까지** — 지금처럼 필요한 날을 `python scripts/signals_daily.py --date YYYY-MM-DD`(여러 날은 `--from` · `--to`)로 채워 주시면 됩니다. 연결한 뒤에는 PR 에 `--dry-run` · `run --only signals` 결과를 함께 적겠습니다.
