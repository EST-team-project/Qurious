> **결론: 코드로 가져올 것이 없습니다.** 우리 구현이 먼저였고(`stock-coin-trade` 방식 이식), 폴백 경로와 볼륨 처리는 더 넓습니다. D2([#10](../discussions/010.md))의 "AWS 0원 · 로컬 시연" 방향과도 이미 맞습니다.

## 4. 그래도 눈여겨볼 것 하나 — 휴장일 달력

[`market_calendar_data.py`](https://github.com/edumgt/domain-rag-lab/blob/02c5ddb/app/services/market_calendar_data.py)에 국내외 일정이 추가됐습니다. 그중:

D7([#13](../discussions/013.md)) 추천안은 **"매 거래일 1행(관망 포함)"** 기록입니다. 그러려면 **어떤 날이 거래일인지** 판정해야 하는데, Qurious에는 그 달력이 없습니다 🟢. 강사님 파일은 **사람이 적어 넣은 목록**이라 그대로 쓰기는 어렵지만, 문제 자체는 우리에게도 그대로 있습니다.

| 방법 | 장점 | 단점 |
|---|---|---|
| (가) 시세 데이터에 그 날짜가 있으면 거래일로 본다 | 추가 의존성 0 | 데이터 지연·결측과 휴장을 구분 못 함 |
| (나) `pykrx` 등으로 영업일 달력을 받는다 | 정확 | 의존성 추가 · 네트워크 |
| (다) 강사님처럼 연간 휴장일을 직접 적어 둔다 | 오프라인 동작 | 매년 갱신 필요 · 임시 휴장 누락 |

**추천(미확정)**: **(가)를 기본**으로 하고, 2차 모의투자 기간(약 8주)의 휴장일만 **(다)로 한 번 적어 두어 교차 확인**합니다. 8주면 추석 3일 정도라 관리 부담이 작습니다.
