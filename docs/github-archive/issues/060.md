## 본문

ETF 면제 판정이 **체결 동기화 경로에만** 걸려 있었다. 요율표를 쓰는 곳이 넷 더 있는데 판정 함수가 `fill_sync.py` 의 **private 함수**(`_is_etf`)라 아무도 쓸 수 없었다.

**결과: ETF 매도 정산이 0.20%p 과대 계상되고 있었다.** 추정이 아니라 실측이다.

## 1. 실측 — 매도 1,000만원 (KOSPI)

```
  일반주식  비용  21,769.23  실수령 9,978,230.77
  ETF       비용   1,769.23  실수령 9,998,230.77
  차이           20,000.00 원 = 0.2000%
                 ↑ 배선 전에는 ETF 도 위 줄(일반주식)로 계산됐다
```

ETF 를 팔 때마다 **있지도 않은 세금 2만 원**을 뗀 것으로 기록했다. 모의투자 잔고와 백테스트 성과가 그만큼 낮게 나왔다.

## 2. 왜 이렇게 됐나 — private 함수의 사정거리

```
[전]
  fill_sync.py
    def _is_etf(name)  ← private. 이 모듈 안에서만 쓸 수 있다
         │
         └──> order_costs(is_etf=✅)     체결 대조만 맞았다

  stocks.py:290        ──> order_costs(is_etf=❌ 기본값 False)   🔴
  auto_trade.py:79     ──> order_costs(is_etf=❌)                🔴
  auto_trade.py:122    ──> order_costs(is_etf=❌)                🔴
  paper_trading.py:221 ──> order_costs(is_etf=❌)                🔴

[후]
  trading_cost.py
    def is_etf_name(name)  ← 공용. 요율표의 집에 둔다
         │
         ├──> fill_sync.py       (`_is_etf` 는 호환용 별칭으로 남긴다)
         ├──> stocks.py:290      ✅
         ├──> auto_trade.py:79   ✅
         ├──> auto_trade.py:122  ✅
         └──> paper_trading.py   ✅
```

> **용어 — private 함수**
> 이름이 `_` 로 시작하는 함수. 파이썬은 강제하지 않지만 **"이 모듈 밖에서는 쓰지 말라"** 는 표시다.
> **이 이슈에서는** 그 표시 때문에 네 곳이 같은 판정을 못 하고 기본값으로 떨어진 일을 말한다.
> **헷갈리는 점**: 문제는 함수가 틀린 것이 아니다. **맞는 함수가 닿지 않는 곳에 있었다.**

## 3. 판정 실측 — 리츠·인프라펀드가 False 여야 맞다

| 종목명 | `is_etf_name` | 맞는가 |
|---|---|---|
| KODEX 200 | `True` | 🟢 수익증권 — 과세대상 아님 |
| TIGER 미국S&P500 | `True` | 🟢 |
| 삼성 레버리지 WTI원유 ETN | `True` | 🟢 |
| 히어로즈 단기채권 | `True` | 🟢 |
| 삼성전자 | `False` | 🟢 주권 |
| **신한알파리츠** | **`False`** | 🟢 **특별법상 법인의 주권 — 과세대상** |
| **맥쿼리인프라** | **`False`** | 🟢 **같은 이유로 과세대상** |
| **KB발해인프라** | **`False`** | 🟢 |

⚠️ **리츠·인프라펀드를 ETF 와 묶어 '상장상품' 으로 면세 처리하면 리츠 백테스트가 과대평가된다.** 이들은 부동산투자회사법·민간투자법에 따른 **법인이 발행한 주권**이라 증권거래세 과세대상이다.

(같은 이유로 `benchmark.py` 는 이들을 **지수에 넣는다** — 공식 지수도 그렇게 하고, 빼면 코스피 재현 오차가 0.066% → 0.230% 로 나빠진다. [#52](../issues/052.md) 3절)

## 4. 면제 근거 주석을 고쳤다 ([#51](../issues/051.md) 6절 ⑦)

```diff
- ETF 는 증권거래세가 면제된다 — 조세특례제한법 제117조 제1항 제21호(기한 제한 없음).
+ ETF 에는 증권거래세가 붙지 않는다. 근거는 면제 규정이 아니라 과세대상의 정의다 —
+ 증권거래세법은 과세대상을 `주권` 과 지분으로 한정하고(§1-2 ①·②, §2 ①),
+ ETF 수익증권은 그 어느 쪽도 아니다. 애초에 과세대상이 아니다.
```

**결과는 같은데 함의가 다르다.** 조특법상 면제는 **일몰(기한)이 붙는 제도**라 "언젠가 되살아날 수 있다" 는 뜻이 된다. 과세대상 부존재는 그 위험이 없다.

🔴 이것이 실제로 중요해지는 지점이 있다 — 요율표에 **시행일 구조**를 넣을 때(열린 질문) ETF 를 일몰 대상으로 잡으면 안 된다.

## 6. 🟡 아직 배선하지 못한 한 곳

`app/routes/stocks.py:776` 의 **백테스트 경로**(`trading_cost.build`)는 못 고쳤다 — `get_candles()` 응답에 **종목명이 없다**(`{symbol, interval, period, candles}`).

| | 주문 경로 | 백테스트 경로 |
|---|---|---|
| 종목명 | 🟢 있다 (`body.name` · `name` · `info["name"]`) | 🔴 없다 |
| 상태 | ✅ 배선 완료 | 🟡 미배선 |

고치는 방법은 둘이다.

1. `resolve_stock(symbol)` 로 이름을 조회한다 (KRX 목록 캐시를 쓰므로 비용은 작다)
2. `reference` 계열에 **상품 구분 필드**를 적재해 이름 규칙을 버린다 ([#32](../issues/032.md) 8.3)

**2번이 옳은 방향이다.** 1번은 이름 규칙 위에 조회를 한 겹 더 쌓는 것이라, 관행이 깨지는 날 두 곳이 같이 틀린다.

## 7. 한계 · 뒤집힐 조건

- 🔴 **이름 규칙은 규칙이 아니라 관행이다.** 운용사가 브랜드를 바꾸거나 새 운용사가 들어오면 판정이 조용히 틀린다. `reference` 에 증권그룹·주권종류를 적재하면 그것으로 바꾼다 ([#32](../issues/032.md) 8.3)
- 🟡 백테스트 경로 1곳이 남아 있다 (6절)
- 🟡 `"ETN" in n` 은 종목명 **어디에든** ETN 이 있으면 참이다. 지금 오검출은 확인되지 않았으나 이름에 우연히 들어가면 틀린다
- 🔴 이 수정은 **앞으로의 계산**만 고친다. 이미 `orders`·`order_fills` 에 기록된 과대 계상분은 그대로 남아 있다 — 소급 정정이 필요한지는 따로 판단해야 한다
