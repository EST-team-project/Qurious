## 설계서와 달라진 것 — 판 고르기

설계서 v0.1 은 「`현행` 표시가 틀린다 → 공포일이 가장 늦은 판」 이라고 했지만, 원인은 표시가 아니라 **호출 경로**였습니다.

| 경로 | 증권거래세법 시행령 제35947호(「현행」)의 제5조 |
|---|---|
| `target=law` + 일련번호 | 옛 세율(유가증권시장 영) — **공포 때 본문** |
| `target=eflaw` + 시행일 | 새 세율(1만분의 5) — 하루 뒤 공포된 제36001호까지 담은 **시행일 판** |

그래서 eflaw 로 **시행일 ≤ 기준일 중 시행일이 가장 늦은 판**을 고릅니다. 설계서 규칙은 자본시장법 시행령에서 틀립니다 — 같은 날 공포된 제36728호(10-02 시행)와 제36729호(10-01 시행) 중 공포번호가 큰 쪽을 고르면 10-02 에 시행된 4개 조가 빠집니다(세 판 553조를 조마다 대조). 그래도 법령 DB 가 시행일 판을 다시 만들지 않았을 때를 대비해, 고른 판보다 뒤에 공포된 판의 개정이 담겼는지 조마다 확인합니다(14문서 모두 「담겨 있다」 · 소득세법 · 상법의 「다르게 바꿈」 경보는 번호가 밀린 거짓 경보 → 대조 규칙을 고침).
