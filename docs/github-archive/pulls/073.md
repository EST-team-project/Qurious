## 재발 방지 — 규칙을 바꾼다

지금까지의 규칙은 *"부득이하면 base 를 main 으로 바꾼다"* 였다. 세 번 다 그 단서를
지키지 못했으니, **단서가 아니라 금지로 올린다.**

- **스택 PR 을 만들지 않는다.** 아래 PR 이 머지될 때까지 위 작업은 브랜치로만 두고
  PR 을 열지 않는다.
- 부득이 열었다면, **아래 PR 머지 직후 위 PR 을 닫고 base=main 으로 새로 연다.**
  base 편집에 기대지 않는다 — 세 번 다 그 편집을 잊었다.
- 머지 뒤에는 `git ls-tree -r origin/main --name-only | grep <새 파일>` 로
  **파일이 실제로 main 에 있는지** 확인한다. PR 이 MERGED 라는 표시로는 부족하다.
