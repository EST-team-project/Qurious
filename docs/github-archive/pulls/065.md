### 재발 방지

base 가 `main` 이 아닌 PR(스택 PR)은 "순서대로 머지"로 부족하다.

> **아래 PR 을 머지한 뒤, 위 PR 의 base 를 `main` 으로 바꾸고** 머지한다.

사람이 기억해야 하는 규칙인데 두 번 다 기억하지 못했으므로, 다음 판에서 CI 로
검사할 수 있는지 살핀다(`base != main` 인 PR 에 경고).
