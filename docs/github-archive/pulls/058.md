## 1. 🔴 저울이 고장 나 있었다

```python

**`prsm_tlex_smtl`(추정제비용합계)은 `output1` 에 없다.**

```
응답

**주문을 냈어도 「제비용 미제공」만 떴을 것이다. 실계좌로 바꿔도 같다** — 버리는 쪽이 코드였다. 네 세션을 기다린 실험은, 했어도 아무것도 재지 못했다.

🟡 추정 → 🟢 **확정** ([#51](../issues/051.md) 8절 ①). Phase C(모의 1주 매매)가 불필요해졌다.

## 3. 🟢 수수료율도 주문 0건으로

**매수가능조회**는 "이 가격이면 몇 주까지 살 수 있나" 를 증권사가 계산해 준다. **그 계산 안에 수수료가 들어 있다.**

```
최대매수수량 = floor( 주문가능현금 / (주문단가 × (1 + 수수료율)) )
내림이므로 구간으로 나온다:  C/(p(q+1)) − 1  <  f  ≤  C/(p·q) − 1
```

| 단가 | 미수 없는 수량 | 역산 구간 |
|---|---|---|
| 269,000원 | 36주 | (−0.030%, +2.747%] |
| 26,900원 | 369주 | (−0.030%, +0.241%] |
| 2,690원 | 3,698주 | (−0.003%, +0.024%] |
| **269원** | **36,988주** | **(−0.0004%, +0.0023%]** |

마지막 줄에서 갈렸다 — 수수료 0원이면 **36,988주**, 실전 요율(0.017693%)이면 **36,982주**. **6주 차이.** 실측은 36,988주.

```
🟢 모의 수수료는 0원. 상한이 실전 요율의 1/8 이라 실전 요율은 배제된다.
```

**[#51](../issues/051.md) 의 결론(모의로는 요율표 검증 불가)이 독립적으로 증명됐다** ([#51](../issues/051.md) 8절 ②).

## 11. 🔴 ETF 면제가 지금 실제로 돈을 틀리게 하고 있었다 ([#60](../issues/060.md))

요율표를 고치다 찾았다. ETF 판정 함수가 `fill_sync.py` 의 **private 함수**라 요율표를 쓰는 다른 네 곳이 쓸 수 없었고, 기본값 `False` 로 떨어져 **ETF 를 팔 때마다 있지도 않은 증권거래세를 뗀 것으로 기록**했다.

```
  일반주식  비용  21,769.23  실수령 9,978,230.77
  ETF       비용   1,769.23  실수령 9,998,230.77
  차이           20,000.00 원 = 0.2000%   ← 매도 1,000만원 기준 실측
```

**로직은 맞았고 위치가 틀렸다.** `trading_cost.is_etf_name()` 으로 올려 네 곳에 배선했다 — `stocks.py:290` · `auto_trade.py:79,122` · `paper_trading.py:221`.

### 면제 근거 주석도 틀려 있었다 ([#51](../issues/051.md) 6절 ⑦)

```diff
- ETF 는 증권거래세가 면제된다 — 조세특례제한법 제117조 제1항 제21호
+ 증권거래세법이 과세대상을 주권과 지분으로 한정하므로(§1-2①·②, §2①)
+ ETF 수익증권은 애초에 과세대상이 아니다
```

결과는 같지만 함의가 다르다 — **조특법상 면제는 일몰이 붙는 제도**라 되살아날 수 있고, 과세대상 부존재는 그렇지 않다. 요율표에 시행일 구조를 넣을 때 ETF 를 일몰 대상으로 잡으면 안 된다.
