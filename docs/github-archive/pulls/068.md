## 왜

게이트가 막는 대상이 남의 부주의가 아니라 **「작업자가 올리고 작업자가 머지한다」는
우리 운영 방식 자체**였다. 승인자를 0명으로 둬도 검사가 빨간색이면 병합이 잠긴다.

그렇다고 워크플로까지 지우면 **시험 23건 중 3건**을 잃는다 — 이 3건은 저장소 전체를
훑는 스캔이라 PR 리뷰로 원리상 잡히지 않는다(`app/` 전체의 `paper=False` 하드코딩,
야후 참조 기준선 2건).

추측이 아니다. ADR-0001 이 막은 `paper=False` 는 `2e2d3f8` 에서 들어와 `2e3cccc` 가
같은 파일을 또 건드렸는데도 지나갔고, 어제 전수 조사에서야 잡혔다.
