## 왜 추출기를 먼저 만들었나

S41 에서 세운 규칙 그대로다 — **표·목록 산출물은 스캐너와 함께 낸다.** 손으로 옮겨 적은
스키마는 칸 하나가 바뀌는 순간 거짓이 되고, 읽는 사람은 그걸 알 방법이 없다.

```bash
python scripts/schema_scan.py          # 요약 + 문서화 비율 + 어긋난 곳
python scripts/schema_scan.py --erd    # ERD 문서의 그림
python scripts/schema_scan.py --md     # 데이터 사전 §3 이하
python scripts/schema_scan.py --json
```

**설명 칸까지 자동이다.** DDL 의 `-- 주석`(`collector/db.py`)과 모델의 `# 주석`
(`app/models/*.py`)을 긁어 온다. 그래서 설명을 고치려면 문서가 아니라 **코드 주석**을 고친다.

## 🔴 ERD 가 드러낸 것 — 두 DB 가 이어져 있지 않다
