## 1. 벤치마크 — 기준선을 스스로 만든다 ([#52](../issues/052.md))

```
price_daily (4,460,710행)  →  benchmark_index (19,776행)

```

### 검증 — 공식 연말 종가 6점 대조

| 기준일 | 공식 | 재현 | 오차 |
|---|---|---|---|

| 6점 평균 | | | **0.066%** 🟢 |

일별 등락률이 소수 **둘째 자리까지** 일치. 2026-07-31 의 +17.91%(역대 최대 상승)도 재현.

### 🔴 치명 결함 1건 — 감자가 폭등으로 들어가 있었다

```
제일바이오 052670
  2026-02-06  종가   2,080원   상장주식수 29,129,064
  2026-02-09  종가 625,000원   상장주식수     19,419   ← 1,500:1 감자
```

거래정지 중이라 `vs`(기준가)가 0 이었고, 0 으로는 계수를 못 구해 조정이 통과했다. 코스닥 지수에 **가짜 +3.060%p 영구 각인**.

```
KOSDAQ PR  1261.84  →  1225.78
```

### ⚠️ 힌트를 그대로 믿었으면 1,881건이 부서졌다

「가격비 ρ 가 주식수비 c 와 맞으면 감자」는 제일바이오에 완벽히 맞는다. **전 구간에 돌리면 재앙이다.**

| 빠진 조건 | 부서지는 것 |
|---|---|
| ② 주식수 변화 | **진짜 폭락**. 카프로 −94.9% 는 c=1.000000 인 실제 등락 |
| ③ 가격제한폭 | **상한·하한가 날** 104건. −29.2% 가 **+7.6%** 로 뒤집힘 |
| ①④ | **유상증자 신주상장 1,881건**. 바른전자는 하루 **+3,759%** 가 된다 |

네 조건 동시충족으로 좁혀 **전 구간 보정 대상은 1건**이다.

```
    조건 없음        ████████████████████  1,881+건  ← 전부 파괴
    ②③①④          ▏                          1건  ← 제일바이오만
```

### 배운 것 — 바깥 기준점은 언제나 과거에 있다

공식 연말 대조(게이트 2)는 이 버그를 **못 잡았다.** 사건은 2026-02-09 인데 공식 상수의 마지막 점은 2025-12-30 이라, 보정 전후로 대조표가 한 자리도 안 바뀌었다. 그래서 기준점 없이 판정하는 **게이트 6**(하루 20배 상승 탐지)을 뒀다.

## 2. HF 백업 — 파케이만으로 SQLite 를 되살린다 ([#53](../issues/053.md))

### 복원 실측


행 수만 맞는 사본은 백업이 아니다. **원문 해시를 전량 다시 계산**해야 "로컬을 지워도 된다" 고 말할 수 있다.

### 원자료까지 올린다 — 그래야 백업이 완전해진다

### 게이트

`QURIOUS_RAW_SHARING` 이 꺼져 있으면 실행되지 않는다. **2026-09-21 업로드가 실제로 여기서 한 번 멈췄다** — 설계대로다. 환경변수로만 켜진다(`.env` 로는 안 켜진다).
