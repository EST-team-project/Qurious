### 핵심 변경 1 — LLM 백엔드는 로컬 두 가지만 남긴다

```python
# app/lib/llm_client.py
provider = settings.LLM_PROVIDER.lower()
if provider == "vllm":
    _client_cache = VLLMClient(settings.VLLM_BASE_URL, settings.VLLM_MODEL, settings.OLLAMA_TIMEOUT)
elif provider == "ollama":
    _client_cache = OllamaClient(settings.OLLAMA_BASE_URL, settings.OLLAMA_TIMEOUT)
```

## Proof — 트러블슈팅 기록

### 1. main에 직접 push했다가 revert로 되돌렸다

상위 개인 모노레포의 규칙(main 직커밋)을 팀 저장소에 그대로 적용해 `f36e7a2`를 PR 없이 main에 올렸습니다.
Alpha_Stack AGENTS.md 0절처럼 **팀 저장소는 feature 브랜치 → PR**입니다.
force push로 이력을 지우면 팀원 로컬이 깨질 수 있어 `git revert`(`3b63b64`)로 되돌리고 같은 변경을 이 브랜치에 다시 커밋했습니다.

### 2. AWS 참조 검색이 100개 파일에서 잘렸다

원본 전체를 한 번에 검색하니 결과가 100개 파일에서 잘려 `quant_ai_scores.py`·`krx_companies.py`가 목록에 안 나왔습니다.
검색 경로를 `app/` · `public/` · 설정 파일로 좁혀 다시 찾았고, `lambda` 검색어가 파이썬 `lambda` 키워드까지 잡는 오탐을 걸러냈습니다.

### 3. `git diff --no-index`가 종료 코드 1을 냈다

실패가 아니라 "차이가 있음" 신호였습니다. 결과 출력은 정상이라 그대로 썼습니다.
