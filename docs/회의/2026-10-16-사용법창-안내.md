[안내] 모든 화면의 「사용법」 이 가운데 창으로 바뀝니다(#209) — 이동원

- 바뀐 것: 화면 맨 위에 펼치던 사용법 줄 대신, 맨 위 윗줄(왼쪽 지금 위치 · 오른쪽 「사용법」 단추)이 생기고 누르면 가운데 창이 뜹니다. 좁은 화면(760 아래)은 화면 전체로 뜹니다.
- 창 안: 요약 → 이렇게 써요(번호 단계) → 이 화면의 용어(누르면 창 안에서 용어 카드) → 끝줄(그 화면의 개념 학습 장 · 용어사전 · 개념 학습 목차). 창 크기는 화면마다 다릅니다(차트 · 분석 화면은 크게).
- 그대로인 것: 안내 글은 core.js 의 같은 자료(VIEW_GUIDES)라 각 화면 파일은 고치지 않았습니다. 펼침 기억은 없어졌습니다.
- 부탁: 자기 화면의 「사용법」 을 한 번 열어 안내 글이 지금 화면과 맞는지 봐 주세요. 예) 자산배분 2단계가 「'배분 계산' 버튼」 이라고 하는데 지금 단추 이름은 「포트폴리오 최적화 실행」 입니다. 고칠지 · 언제 고칠지는 주담당이 정해 주세요(core.js 의 그 화면 줄만 고치면 됩니다).
- 영상 칸은 시연 녹화를 만든 화면부터 보입니다(지금은 모두 숨김).
- 기초 코드 반영 때: 강사님 판(머리 줄 끝 단추 + 창)이 core.js 에 그대로 들어오면 시험(TC-HT)이 알려 줍니다.
