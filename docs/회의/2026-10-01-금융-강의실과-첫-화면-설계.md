- 강의 안의 시세 그림은 우리 수집 DB(공식 시세)를 먼저 읽어요. 해외 지수 · 1분봉만 밖에서 받고, 받은 값은 저장하지 않아요

통합본은 세부기능 1(제 몫) 전체라, 다른 분이 맡은 화면에도 탭 · 칸을 더하게 돼요. 그 화면의 계산 · API · 저장은 바꾸지 않고, 고칠 결함을 찾으면 이슈로 드릴게요.
- 거시경제 지표 · 산업 분석 — 실시간 · 시뮬레이션 · 산업 경쟁력 탭
- 기업 화면(지표 비교 · 섹터) — 공시(DART) 재무로 다시
- 자산배분 · 최적화 — 위험선호도 R1~R5 · VaR · 시나리오 탭
- LEAN 백테스트 — 저장된 리포트 목록
- ML · 딥러닝 — 실습실(무거운 패키지는 따로 켜는 컨테이너)
- 주가 차트 — 그리기 패널

🗄️ 퀴즈 · 단어장 시험 · 활동 기록은 MongoDB 컨테이너를 더해서 둘 거예요(퀴즈를 옮길 때). 계정 · 매매는 지금처럼 PostgreSQL 이에요.
