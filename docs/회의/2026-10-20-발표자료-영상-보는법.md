# 발표 자료 영상 보는 법 (오늘 PR 머지 뒤)

> 읽는 사람: 팀원 셋(오준영 · 신장환 · 강민석) · 보내는 곳: 팀 대화방

**지금 영상 칸이 비어 보이는 까닭** — 발표 자료(`docs/발표/2차/발표자료.html`)는 `docs/발표/영상/파일/발표/` 의 mp4 를 재생하는데, 그 mp4 가 지금까지 git 밖이라 제 PC 에만 있었습니다.

**오늘 PR 에서 영상을 git 에 올립니다** — 오늘 새 메뉴로 다시 찍은 mp4 · 포스터(발표 15 · 사용법 15)와 옛 `docs/발표/2차/media/` 까지, 모두 약 180 MB 입니다. 받는 데 조금 걸립니다.

**보는 법(PR 이 머지된 뒤)**

1. `git switch main` → `git pull`
2. 탐색기에서 `docs/발표/2차/발표자료.html` 을 두 번 눌러 Chrome 이나 Edge 로 엽니다. 서버 없이 파일로 열어도 재생됩니다.
3. 영상이 든 장에서 ▶ 를 누릅니다. 그래도 비어 있으면 `docs/발표/영상/파일/발표/` 에 `P-` 로 시작하는 mp4 가 있는지 봐 주세요.

영상을 다시 찍을 일이 생기면 장면 파일(`docs/발표/영상/장면/` · `발표/`)만 고쳐 알려 주세요. 찍고 mp4 로 바꿔 올리는 것은 제가 한 번에 하겠습니다(같은 파일을 여럿이 올리면 서로 덮입니다).
