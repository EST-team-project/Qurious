**[Qurious] 로그인 첫 화면과 위 메뉴가 바뀌었어요 — 투자 대시보드 · 「⋮ 더보기」 = 전체 메뉴**

강사님 기초 코드(9478811)의 화면 쪽을 들였어요. PR 이 머지되면 `git pull` 한 번 부탁드려요(브라우저는 새로고침 한 번).

🏠 첫 화면 = 「투자 대시보드」
- 로그인하거나 로고를 누르면 대시보드가 먼저 열려요 — KIS 모의투자 시작 · 사이트별 현재 투자액 탭 다섯 · 기본 전략 성능 · 기능 바로가기
- KIS 는 각자 자기 모의투자 키로 주문해요. 키가 없으면 「증권사 API 설정으로」 단추를 눌러 넣으면 돼요

🧭 위 메뉴
- 정해 둔 순서대로 화면 폭에 들어가는 만큼만 보여요: 로보 어드바이저 → 투자 인디케이터 → 금융 필수 지식 → 모의투자 → 데이터 → 퀀트자동매매 → 직접매매 → 미국주식 → 투자분석 → ML·딥러닝 (1280 노트북이면 셋, 큰 모니터면 더 많이)
- 안 보이는 묶음은 오른쪽 「⋮ 더보기」 를 누르면 나오는 「전체 메뉴」 에 다 있어요 — 지금 보는 묶음이 펼쳐진 채 열려요
- 강사님 판은 위 메뉴를 둘로 줄였는데, 데스크톱에서 메뉴를 숨기면 덜 쓰인다는 연구가 있어서 「들어가는 만큼 보이기」 로 합쳤어요

⚙️ 증권사 API 설정 — 전략(검증 통과분) 고르기 · 자동매매 주기 상태 · 실주문 현황 칸이 생겼어요

🛠️ 새 화면 묶음을 더하실 때 — `public/js/core.js` 의 `MENU_PRIORITY`(위 메뉴 순서)나 `MENU_DRAWER_ONLY`(더보기에만)에도 넣어 주세요. 빠지면 시험(TC-NV)이 알려 줘요. 그리고 잠긴 단추(disabled)가 이제 흐리게 보여요.
