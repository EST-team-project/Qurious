**[Qurious] 「개념 학습」 페이지를 열었어요 · 조사한 자료는 「팀 자료」 로 같이 써요**

구현할 개념을 교재처럼 설명하는 페이지를 앱에 붙였어요. 앱의 **더보기 → 개념 학습**, 또는 **금융 필수 지식 → 금융 교재** 에서 들어가요(주소 `/learn/`).

📚 지금 있는 것
- 장 34편 목록 — 시세 데이터 · 데이터 파이프라인 · 근거 RAG · 지식 구조 · 차트와 Pine · 서버 운영 · 금융 지식 8편
- 완성된 장은 둘이에요 — 「0.1 전체 지도」 와 「3.1 RAG」(우리 PC 에서 실제로 돌린 예제 · 그림 · 확인 문제)
- 나머지는 「뼈대」(목표 · 다룰 질문 · 보여 줄 코드 · 참고 자료)이고, 그 기능을 만들기 직전에 채워요

✍️ 팀 자료 — 누구나 쓰고 고치고 지워요
- 로그인 → 학습 페이지 위 **새 글** → 「장 틀 넣기」 로 틀을 받고 쓰면 오른쪽에 미리보기가 바로 보여요
- **저장** 하면 HF 비공개 데이터셋 `qurious-quant/learn-pages` 에 올라가고, 다른 사람 앱에는 5분 안에 보여요
- 같은 글을 둘이 고치면 늦게 저장한 쪽에 「먼저 고친 사람이 있다」 가 떠요 — 덮어쓰지 않아요

--- 메시지 2 ---

**[Qurious] 팀 자료에 쓰려면 HF 조직 초대가 필요해요**

공용 서버가 없어서(유료 클라우드 0원 · AWS 는 강사님 안내 뒤) 글은 HF 비공개 데이터셋에 두는 방식으로 했어요. 그래서 글을 저장하려면 두 가지가 필요해요.

1. HF 조직 `qurious-quant` 에 쓰기 권한으로 들어오기 — 아이디를 알려 주시면 초대할게요
2. 자기 HF 토큰(쓰기)을 `.env` 의 `HUGGINGFACE_ACCESS_TOKEN` 에 넣기

읽기만 할 거면 로그인만 하면 돼요. 조사 메모에 강의 자료 발췌가 섞여도 괜찮도록 비공개로 뒀어요(공개 저장소에는 올리지 않아요).

🙋 읽다가 모르는 개념이 있으면 이름만 알려 주세요 — 목차에 장을 더할게요.
