**[Qurious] 통합본이 저장소에 들어왔어요 · 용어사전 API 가 생겼어요**

강사님 요구 원문의 첫 세부 기능 「용어사전과 연관 개념 탐색」 의 구현 방안이 「domain-rag-lab 와 investment-analysis 의 통합」 이에요. 제가 만들어 둔 그 통합본을 AWS 만 빼고 저장소로 들여왔습니다.

📁 `rag-lab/` 폴더 — 알아 둘 것 셋
- **앱과 이어져 있지 않은 읽기용 사본**이에요. 여기 코드가 있다고 그 기능이 Qurious 에 있는 건 아닙니다
- **고치지 말아 주세요** — 원본과 같아야 검사가 통과해요. 기능은 묶음마다 `app/` · `public/` 에 새로 씁니다
- 받으면 저장소가 약 58MB 커져요(그림이 대부분). 도커 이미지에는 안 들어갑니다

📚 용어사전 — 서버 쪽만 먼저
- 용어 **755개** · 분류 22개 (통합본의 단어장 · 용어집 · 강의 용어 + 우리 화면 용어를 합친 것)
- API: `GET /api/glossary?q=PER` · `/api/glossary/sharpe` — 이름 · 약어 · 영어 · 초성(ㅅㄱㅊㅇ)으로 찾아요. 로그인 없이 읽습니다
- **화면은 아직 그대로예요.** 어디에 넣을지는 같이 정하고 싶어요(아래)

👀 3분 버전: 요약 → 그림 1(절차) → 그림 2(경우 표 예시)

요지
- 빈 캔버스에서 그리지 않고 **지금 화면을 가져와** 고쳐요. 새 화면을 만들기 전에 「이미 있는 화면에 더하면 되나」 부터 봅니다
- 화면의 **경우**를 먼저 표로 적어요 — 정상 · 비어 있음 · 불러오는 중 · 일부 · 오류, 데스크톱 · 모바일. 다 곱하지 않고 주 경로만 곱합니다
- 검토는 「봐 주세요」 가 아니라 **정할 것 2~4개**를 적어서 열어요. 의견은 결정 기록 표 하나에 모읍니다
- 「개발 준비됨」 표시가 붙은 것만 만들어요
