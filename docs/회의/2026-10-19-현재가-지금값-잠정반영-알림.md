--- 메시지 1 ---

[알림] 「현재가」 칸을 지금 값으로 — 신장환 님 화면 넷에 화면만 잠정 반영 — 이동원

- 까닭: 10-19 오후 투자 인디케이터 「기본 인디케이터 전략」 에서 삼성전자 현재가가 210,000 으로 보였는데 실제는 217,000 이었습니다. 화면이 수집 DB 의 마지막 종가(공공데이터는 다음 영업일에 공개)를 「현재가」 로 보였기 때문입니다. 조사서: docs/조사/실시간시세-지연표기-조사.md v1.0.
- 사용자 결정(10-19): 판단 · 백테스트 · 신호는 저장 자료 그대로 두고, 「현재가」 표시와 모의 주문 체결가만 지금 값으로 바꿉니다. 서버 함수 하나(GET /api/quote/now · app/services/quote_now.py)가 「내 증권사 키 → 지연 시세(약 20분) → 지난 종가」 차례로 값과 출처 · 시각 글을 줍니다. 「실시간」 이라는 말은 쓰지 않습니다.
- 신장환 님 화면에서 바꾼 곳(화면 글만 · 서버 · 계산 · 신호는 그대로):
  ① indicator.js — 기본 인디케이터 전략 「현재가」 카드 = 지금 값 + 출처 글(예: 「장 마감 · 지연 시세(약 20분) · 15:19 체결」) · 카드 아래 「지표 기준: 수집 DB 일봉(수정주가) · … 종가」 한 줄
  ② trading.js — 주가 차트 머리 값 = 지금 값 + 출처 글(못 받으면 예전처럼 /api/stocks/quote)
  ③ quant.js — 퀀트 대시보드 카드 가격 아래 「MM-DD 종가」
  ④ robo.js — 스크리닝 표 머리 「현재가」 → 「가격」(표 아래 기준일 줄은 그대로) · 지지 · 저항 제목 「현재가」 → 「MM-DD 종가」 · 「현재가 대비」 → 「기준 종가 대비」
- PR #282 와 같은 파일(indicator.js · robo.js)이지만 자리가 다릅니다(#282 = 성과 검증 · 커스텀 결과 · 설명 창 / 이쪽 = 현재가 카드 · 표 머리 · 지지 · 저항 제목). #282 가 먼저 머지되면 제가 받아서 맞춥니다.
- 되돌리기: 다른 방향을 원하시면 말씀만 주세요. 위 줄만 원래대로 돌리는 커밋을 바로 올리겠습니다(서버 응답 꼴은 그대로라 화면만 돌아갑니다).
- 시험: tests/test_quote_now.py(TC-QUOT 10건).

--- 메시지 2 ---

[알림] 모의 주문 체결가 = 체결 직전에 다시 받은 값 — 강민석 님 영역 직접 고침 — 이동원

- 사용자 결정(10-19): 「모의 주문 체결가까지」 · 「모의 주문은 체결 직전에 다시 확인까지」. 발표 시연에 걸리는 결함이라 리서치 뒤 제가 고쳤고, 기존 흐름(시세 → 비용 → 장부)은 그대로 두었습니다.
- 서버(app/services/paper_trading.py): 시세 결과에 출처 칸(quote_source · quote_as_of · quote_label)을 더했고, 국내 주문 · 주문 미리보기 · 손절 · 익절 발동이 체결 직전에 quote_now.confirm_for_order 를 거칩니다. 그 사람의 KIS 키가 있으면 그 자리에서 받은 값으로 체결하고, 없으면 받아 둔 값(게이트웨이 · 지연 시세)에 출처 글만 붙입니다. 장부 계산 · 비용 · 체결 함수(_fill_stock_order)는 그대로입니다.
- 화면(paper.js): 시세 칸 아래 「장 마감 · 지연 시세(약 20분) · 15:19 체결 · 체결 직전에 다시 확인합니다」 · 주문 확인 창 문구 · 체결 알림 끝에 출처 글.
- 응답 칸이 늘었을 뿐 이름 · 꼴은 그대로라 다른 화면은 바뀌지 않습니다(API 명세서 v0.35 6절 · DM-05).
- 되돌리기: 말씀 주시면 그 부분만 되돌리는 커밋을 올리겠습니다.
- 시험: tests/test_quote_now.py — 체결 직전 확인을 빼면 실패하는지 깨 보기로 확인했습니다.
