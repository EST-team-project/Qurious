**빠진 주요 산출물 15개 초안을 올렸어요**

강사님 산출물 표에서 비어 있던 15개를 모두 v0.1 로 만들었어요.
- 착수보고서 · 유스케이스 명세서 · WBS · 스프린트 계획 · 주간보고(2차 1주차)
- UI 명세서(화면설계서) · 인프라 · 네트워크 구성도 · 배포 구성도
- 코딩 표준(완료의 정의 포함) · 코드 리뷰 기록 · 백테스트 보고서
- 배포계획서 · 장애 대응 절차서 · 릴리스 노트 · 완료보고서(틀)

함께 바뀐 것도 둘 있어요.
- 문서 작성 기준 v0.2: 실무에서 남에게 보여 주는 형식으로 정리했어요. 그림은 「<그림 1> 제목」 캡션, 상태는 이모지 대신 글자(완료 · 진행 · 예정)로 써요.
- 문서 그림 지침 v0.1: 구성도 · 유스케이스 같은 그림은 Figma 에서 그려 PNG 로 넣고, 코드에서 다시 만드는 그림(ERD · API 표)은 지금처럼 Mermaid 로 둬요. 그림 원본은 Figma 팀 폴더의 「Qurious · 문서 그림」 파일이에요.

일하는 방식은 이렇게 정했어요. **초안은 팀장이 깔고, 각자 기능의 결과와 작업 과정을 채우면서 판을 올리는 것은 주담당, 검수는 팀장**이 해요. 비어 있는 칸에는 누가 · 언제 채우는지 적어 두었어요.

문서는 저장소 docs 폴더에 있어요: https://github.com/EST-team-project/Qurious/tree/main/docs
