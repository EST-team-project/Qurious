--- 메시지 1 ---

**일정 · 리서치 화면을 새로 만들었고, 시스템관리에 API 문서를 더했어요**

- 일정(투자분석 기초 › 일정): 달력 칸에는 종류별 개수, 날짜를 누르면 그날 목록이 50건씩 나와요. 주총이 몰리는 3월(한 달 3,532건)도 잘리지 않아요. 내 보유 종목이 맨 위예요.
- 투자 정보 리서치: 공시 · 정책뉴스 · 언론사 기사 제목을 낱말 · 종류 · 주제 · 기간으로 찾고, 종목을 고르면 그 종목의 공시 · 기사 · 일정이 날짜 한 줄(시간표)로 바뀌어요. AI 가 답을 쓰는 화면은 아니고, 근거를 단 답은 「AI 투자 상담」 이에요.
- API 문서(더보기 › 시스템관리 › API 문서): 앱의 API 228개를 라우터 · 메서드 · 인증 · 부르는 화면으로 찾고, 고른 API 를 Swagger 로 펼쳐 바로 시험 호출할 수 있어요. 지금 로그인한 계정으로 실제로 실행돼서 쓰기 API(주문 · 저장 · 삭제)는 「쓰기 API 시험 허용」 을 켤 때만 돼요.

자기 화면의 API 가 「부르는 화면 —」 로 나오면, 화면 JS 가 주소를 글자로 시작하지 않아서 스캐너가 못 읽은 거예요(API 명세서 10절).

API 명세서: https://github.com/EST-team-project/Qurious/blob/main/docs/인터페이스/API명세서_v0.10.md

--- 메시지 2 ---

**섹터 질문은 섹터 법령까지 찾아요 · 리밸런싱 시험 하나만 부탁드려요**

- AI 투자 상담의 근거 답이 질문에 섹터 법의 이름 · 약칭 · 업 이름(예: 은행업 · 보험업 · ISA)이 있으면 그 섹터 법령까지 근거로 찾아요. 섹터 질문 18개는 정답 0 → 15, 처음 보는 질문 14개는 0 → 7 이 됐고, 기존 질문은 답이 글자까지 같았어요.
- 「인터넷으로 산 옷 반품」 처럼 일상 말로 물으면 아직 못 알아들어요 — 다음에 낱말을 넓혀요.

리밸런싱 정책 시험(PR #114) 잘 받았어요! 다만 새로 띄운 시험 DB 에서는 표가 없어 DB 시험 11건이 실패해요(표를 만든 DB 에서는 33건 다 통과). 시험 파일에 표를 만드는 고정물 하나면 돼서, 고치는 법을 이슈로 올려 둘게요.

개념 학습 · API 문서가 앱과 따로 떨어져 보이는 문제는 조사해 뒀어요 — 머리글 · 색을 한 벌로 맞추는 쪽을 추천하는데, 모든 화면에 닿아서 정하기 전에 여기서 의견을 먼저 여쭐게요.
