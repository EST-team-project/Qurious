# D54 — 공공데이터포털 문의 초안 (사용자가 올림 · 2026-10-18 작성)

- **올릴 곳**: 공공데이터포털 「금융위원회_주식시세정보」(https://www.data.go.kr/data/15094808/openapi.do) 쪽의 문의(「오류신고 및 담당자 문의」 또는 포털 고객센터 「묻고 답하기」) — 로그인한 사용자 계정으로.
- **답은 2차 발표(10-21) 뒤일 수 있다.** 답이 오기 전에는 지금 운영(비공개 데이터셋 · 저장소에 원자료 없음 · 서비스 안에서만 보기 · 내려받기 없음)을 그대로 두고, 공개물(영상 · README)에는 출처 한 줄을 단다(10-19 묶음).
- 답이 오면 원문을 `docs/조사/` 공공데이터 이용 조건 조사서에 붙이고 정할 것 대장 D54 를 다시 연다.

---

**제목**: 공공누리 제4유형(변경금지) 자료로 계산한 지표를 비상업 학습 프로젝트 화면에 보여도 되는지 문의드립니다

**본문**:

안녕하세요. 교육 과정에서 팀 프로젝트로 주식 투자 학습용 웹 서비스를 만들고 있는 수강생입니다. 「금융위원회_주식시세정보」 오픈 API 의 이용 조건(공공누리 제4유형 — 출처표시 · 상업적 이용금지 · 변경금지, 제3자 무단 제공 · 재배포 금지)을 지키려고 하는데, 아래 세 가지가 「변경」 · 「제공」 에 드는지 판단이 서지 않아 여쭙니다.

1. **계산한 값의 표시** — 받은 일별 시세(시가 · 고가 · 저가 · 종가 · 거래량)로 수정주가(분할 · 배당 반영), 이동평균 · RSI 같은 기술 지표, 수익률을 계산해 서비스 화면의 표 · 차트로 보여 주려고 합니다. 원자료 값을 바꾸어 원자료처럼 내보이지는 않고, 화면에 「자료: 금융위원회 주식시세정보(공공데이터포털 · 공공누리 제4유형) · 수정주가 · 지표는 자체 계산」 이라고 밝힙니다. 이렇게 계산한 값을 보여 주는 것이 제4유형의 「변경금지」 에 해당하는지 궁금합니다.
2. **발표 영상 · 자료** — 수업 발표용 시연 영상(일부 공개 링크)과 발표 자료에 위 화면이 나옵니다. 원자료 파일이나 대량의 값은 싣지 않고 화면 모습만 보입니다. 출처를 밝히면 이용할 수 있는지 궁금합니다.
3. **팀 안의 보관** — 받은 원자료는 팀원 네 명만 볼 수 있는 비공개 저장소에 두고, 공개 코드 저장소에는 원자료를 올리지 않습니다. 같은 프로젝트 팀원끼리 나누어 보는 것이 「제3자 제공」 에 드는지 궁금합니다.

영리 목적은 없고, 내려받기 기능도 두지 않습니다. 위 방식 가운데 허용되지 않는 것이 있으면 어떻게 바꾸면 되는지(예: 별도 이용허락 절차, 원자료 선만 보이기 등)도 알려 주시면 그대로 따르겠습니다. 감사합니다.
