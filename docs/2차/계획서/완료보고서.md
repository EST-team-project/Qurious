## 요약

Qurious 는 2차(10-01 ~ 10-21)에 국내 상장 주식 3,308종목(상장폐지 종목 포함)을 매일 모으는 수집 회차 위에, 성향 진단 → 자산 배분 → 상품 안내 → 신호 → 모의 주문 → 자동매매 → 리밸런싱 → 성과 · 근거 상담으로 이어지는 로보 어드바이저를 네 명이 나눠 만들었다. 2차 마감 점검(10-21)에서 자동 시험 2,351건이 통과하고(실패 5건은 모두 결함대장의 알려진 것) 화면 77개가 모두 열리며 기능 점검 85개가 통과했다. 남은 것은 열린 결함 28건(미국 매수 길 DF-137 등) · 팀원 실적 칸 확인 · 3차의 투자 인디케이터(TradingView · Pine)와 강사님 새 기능 가져오기다.

## 1. 사업 개요

착수보고서 1절과 같다. 2차 동안 바뀐 것:

- 일정 — 2차 10-01(목) ~ 10-21(수) 오전(발표) · 3차 10-22(목) ~ 11-11(수) — 우리 반 공식 일정.
- 배포 — AWS 는 2 · 3차에 쓰지 않는다(2026-10-16 팀 결정 · 개인 사용료 한도) — PC 한 대에서 도커 서비스와 도커 밖 수집기가 함께 돈다.
- 발표 자료 — HTML 한 파일 판(그림 · 영상 · 글꼴을 파일 안에)으로 다른 PC 에서도 그대로 연다(2026-10-21 · #308).

- 목차는 실무 완료보고 목차(사업 개요 → 추진 경과 → 목표 대비 실적 → 성과 지표 → 산출물 목록 → 남은 과제 → 교훈 → 넘겨줄 것)를 따랐다([문서 작성 기준 v0.2](../문서기준/문서작성기준.md) 12.2절).

- 숫자는 2026-10-21 에 다시 잰 값이다 — 시험(75차 · `test.ps1`) · API(`api_scan.py`) · 화면(`smoke_views.py`) · 결함(표 9 를 줄로 셈) · 요구(`rtm_scan.py`) · 회차(러너 이력) · 머지 수(`git log --merges`).
