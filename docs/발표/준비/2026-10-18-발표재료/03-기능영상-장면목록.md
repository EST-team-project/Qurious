# 기능 영상 장면 목록 — 여정 일곱 편 밖, 3차가 아닌 기능 (재료 · 2026-10-18)

| 머리표 | 내용 |
|---|---|
| 무엇 | 지금 영상 일곱 편(`docs/발표/영상/장면/V01 ~ V07.yaml` · 로보 어드바이저 여정)에 들어가지 않은 2차 기능을 묶은 영상 후보 8편. 편마다 화면(view 키) · 걸음(장면 파일과 같은 칸) · 길이 어림 · 장중 여부 · 가릴 것 · 주담당 |
| 고른 곳 | 기능 완성도 점검표(`docs/시험/대장/기능완성도-점검표.tsv`)의 화면 · 점수 · 「100%까지」 칸 · 앱 메뉴(`public/app.html` 의 `data-view` 70개) |
| 뺀 것 | 3차 기능 — 투자 인디케이터 메뉴(기본 · 커스텀 · 자유 산식 · 성과 검증 · TradingView · 증권사 API 자동화 · 3차 목표 문장 `docs/조사/시장범위-미국코인-거래기준-조사.md:51`) · Open API 연동 · 알림 설정(점검표 `:25 · 31` 「3차 몫」) · 직접매매 주문 · 포트폴리오(`:19-20` 「3차 — 증권사 연동」). 이미 영상이 있는 화면(V01 ~ V07). 점수가 낮은 설명 전용 화면(재무제표 분석 45 · 기술적 분석 40 · 딥러닝 40 · `:49 · 52-53`) |
| 강사님 기준 | 영상마다 다른 주요 기능 · 목적 → 실행 과정 → 결과 · 자막 · 3분 내외(강사님 발표 안내 01) |
| 편 수 | 후보다. 몇 편을 찍고 몇 편을 발표에서 재생할지는 메인이 정한다(추천은 3절) |
| 상태 | 장면 파일을 만들지 않았다. 아래 걸음은 장면 파일 꼴의 초안이고, 선택자 가운데 「자리 확인」 표시는 녹화 전에 `python tools/demo/record_demo.py --inventory <화면 키>` 로 맞춘다(`docs/발표/영상/README.md` 2절) |

- 길이 어림: 장면의 `chapter` · `pause` 초를 더하고, 자막 한 줄을 2.5초 · 화면 넘김을 2초로 잡았다. 오래 걸리는 계산(모델 비교 · 군집)은 `wait` 의 `cut: true` 로 줄인다. 실제 길이는 녹화 기록 `.json` 의 `over_limit` 으로 본다.
- 장면 파일 꼴은 V01 ~ V07 과 같다: `file` · `title` · `owner` · `start` · (`mask`) · (`dialogs`) · `steps`. 단계 종류는 `chapter` · `say` · `go` · `click` · `fill` · `select` · `key` · `scroll` · `wait` · `ring` · `hover` · `pause` · `js`(`docs/발표/영상/README.md` 2절 끝).

## 1. 영상마다 — 걸음

### F01 매일 자료가 쌓이고 검증되는 모습 (이동원 · 관리자 계정)
- 목적 → 과정 → 결과: 「매일 12:30 공식 자료를 받는다」 → 「단계마다 결과 · 걸린 시간 · 실패 까닭이 남는다」 → 「백업 조건을 하나씩 확인한다」.
- 근거: 관제 93 · 수집 일정 96 · 적재 · 백업 89(점검표 `:13 · 15 · 17`). 수집 세 화면은 관리자에게만 보인다(`public/js/collect.js:59 · 62`).
- 누르지 않는 것: 「전체 수집」 · 「한 단계 다시」 · 「받기」 · 「복원 리허설」 · 「원격 다시 확인」(바깥 호출 · 실제 실행). 보기만 한다.

## 2. 녹화 전에 맞출 것

- 선택자: 「자리 확인」 표시가 붙은 줄은 `record_demo.py --inventory <화면 키>` 로 누를 곳 목록을 받아 고친다. `--no-video` 로 단계만 먼저 돌려 본다(`docs/발표/영상/README.md` 2절).
- 계정: F01 만 관리자 계정이 필요하다. 계정 이름 · 비밀번호는 파일에 쓰지 않고 환경 변수(`DEMO_EMAIL` · `DEMO_PASSWORD`)로만 준다(같은 절).
- 가리기: 장면 맨 위 `mask` 에 선택자를 넣으면 그 칸이 흐려진다(`tools/demo/record_demo.py:388-390`). 개발 티 점검표(키 · 계좌번호 · 내부 영어 낱말 · 주소창 · 콘솔 오류 0 · 3분 안)는 `docs/발표/영상/README.md` <표 2>.
- 화면이 바뀌면 그 장면만 다시 찍는다(같은 README 4절).
