# 2차 발표 A안 · B안 비교 — 통합할 때 고를 것

두 초안은 [발표-A안.html](발표-A안.html) · [발표-B안.html](발표-B안.html)이다. 스타일 · 발표 모드는 함께 쓴다(`assets/`). 공통 규칙은 셋이다 — 이동원 핵심 메시지 M1, 팀 한 문장 T1, 사람마다 영상 1편 전편(3분).

<표 1> A안 · B안의 차이와 통합할 때 고를 것

| 항목 | A안 「한 문장 + 같은 틀 릴레이」 | B안 「사용자 여정 시연형」 | 통합할 때 고를 것 |
|---|---|---|---|
| 뼈대 | 표지 → 배경 2 → 해결 그림 → **사람마다 같은 4장**(나와 내 문제 · 영상 · 증거 셋 · 배운 점) → 마무리 | 표지 → 배경 2 → 여정 지도 → **장면 다섯**(시장 → 종목 → 근거 → 모의 매수 → 성과) → 그 사람이 얻은 것 → 팀원 소개 4 → 마무리 | 섞는 안: A 뼈대에 B 의 여정 지도를 「해결 그림」 자리에 넣는다 |
| 장 수 · 시간 | 본문 21장 · 부록 4장 · 약 26분 + 질의응답 | 본문 19장 · 부록 4장 · 약 26분 + 질의응답 | 시간 제한이 없으니 길이로는 고를 필요 없음 |
| 영상(사람마다 1편) | 사람 장마다 1편 — 팀 4편 | 장면 2 ~ 5 에 4편 · 장면 1(시장)은 캡처 한 장 | 같음 — 녹화본은 어느 안이든 다시 쓸 수 있다 |
| 이동원 몫 | 9장 — 표지 · 배경 2 · 해결 그림 · 이동원 4 · 마무리 | 10장 — 표지 · 배경 2 · 여정 지도 · 장면 1 · 장면 3(2장) · 얻은 것 · 소개 · 마무리 | 배경 2장 · 증거 셋 · V1 은 두 안에서 같은 장이다 |
| 팀원 몫 | 사람마다 같은 4장 — 따로 준비해도 모양이 맞음 | 장면 2장 + 소개 1장 — **장면 주인 짝을 먼저 정해야 함**(다섯 장면 · 네 사람 · 오준영 님 자리) | B 를 고르면: 장면 4 를 오준영 님(리밸런싱의 예약 체결)으로 둘지, 장면 6 「다시 맞춘다」 를 더할지 |
| 강사님 「팀원별 발표」 | 「나」 장이 사람마다 앞에 — 충족 쉬움 | 기능이 앞, 본인 소개는 뒤에 모음 — 「나」 가 약해질 수 있음 | 강사님이 사람마다의 발표를 따로 본다면 A 쪽 |
| 흐름 | 해결 그림 한 장과 넘김 한 줄로 이음 | 여정이 흐름 자체 — **이음 넷 모두 코드에서 확인 안 됨**(정적 검색 · 점선) | B 를 고르기 전에 앱에서 이음 넷 확인(같은 종목을 들고 다음 화면으로 가는지) |
| 위험 | 파트 사이가 목록처럼 들릴 수 있음 | 이음이 끊겨 있으면 영상에서 드러남 · 네 사람이 한 흐름으로 함께 찍어야 함 · 근거 장면(AI 상담)은 종목이 아니라 법령 질문용 | B 의 장면 3 을 어떻게 이을지(규정 질문 · 종목 근거 카드와 나누기) |
| 숫자 · 표 | 본문 증거 숫자 7 · 본문 표 0 | 본문 증거 숫자 8 · 본문 표 0 | 같음 — 장마다 셋 이하 |
| 점검 | 머리 없는 Edge — 25장 넘침 0 · 오프라인(시스템 글꼴)도 0 | 23장 넘침 0 · 오프라인도 0 | — |

추천(이 조사의 판단): 지금은 **A 뼈대로 준비하고 B 의 여정 지도를 「해결 그림」 자리에 넣는 섞는 안**이 위험이 가장 적다. 이음 넷이 앱에서 확인되면 그때 B 로 넓힌다 — 결정은 사용자 · 팀.
