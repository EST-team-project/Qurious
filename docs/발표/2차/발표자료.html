문제
데이터 화면의 API 여러 개가 「unable to open database file」 로 멈춤. 같은 꼴이 근거 문서 DB · 검색 색인 · 수집 DB 에서 세 번
원인
앱은 SQLite 를 읽기 전용으로 붙여 엶. WAL 모드에서는 PC 쪽의 마지막 연결이 닫힐 때 보조 파일(-wal · -shm)이 지워지고, 읽기 전용인 앱은 그것을 다시 만들 수 없음
해결
읽기 전용으로 붙는 근거 문서 DB · 검색 색인은 롤백 저널로 바꿈. 수집 DB 에 쓰는 명령 뒤에는 점검을 돌리고, 시험은 실제 DB 를 열지 않게 함
결과
점검 「데이터」 항목 전부 정상 · 시험이 가짜 단계라 못 잡았던 것을 실제 실행 뒤 점검으로 잡는 규칙이 생김

배운 점 — 시험이 통과해도, 새 명령은 한 번 실제로 돌린 뒤 기능 점검까지 해야 합니다.
