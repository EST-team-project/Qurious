## 2. 다시 찍기 — 명령 한 줄

앱을 개발 모드로 켠 뒤(`scripts/personal/start.ps1 -Dev -NoBrowser`) 저장소 뿌리에서:

```bash
python tools/demo/record_demo.py --ensure-account docs/발표/영상/장면/V03-신호로-종목살피기.yaml   # 한 편
python tools/demo/record_demo.py --no-video docs/발표/영상/장면/V03-신호로-종목살피기.yaml          # 영상 없이 단계만(누를 곳 확인)
python tools/demo/record_demo.py --inventory robo-screening,robo-patterns                          # 화면마다 누를 곳 목록
```

- 결과는 `tools/demo/out/`(git 에 넣지 않음) — `.webm`(1920×1080) · `.ko.vtt`(자막) · `.chapters.vtt`(장) · `.json`(단계별 시각 · 줄인 기다림 · 콘솔 오류 · 실패한 응답).
- 계정은 이 PC 로컬 DB 의 시연 전용 계정이다(없으면 `--ensure-account` 가 만든다 · 바꾸려면 환경 변수 `DEMO_EMAIL` · `DEMO_PASSWORD`).
- AI 답처럼 오래 기다리는 구간은 녹화를 멈췄다가 이어 붙이고, 화면 오른쪽 위에 「기다린 n초를 줄였습니다」 를 띄운다(답은 바꾸지 않는다).
- 브라우저 확인 창(`confirm`)은 기본 「취소」 — 장면이 「확인」 을 눌러야 하면 맨 위에 `dialogs: accept`.

장면 파일 단계: `chapter`(장 제목) · `say`(자막) · `go`(화면 이동) · `click` · `fill` · `select` · `key` · `scroll` · `wait`(`cut: true` 면 기다림을 영상에서 줄임) · `ring`(강조) · `hover` · `pause` · `js`.

## 3. 어느 판이 나은가 — 바꿔 끼우는 기준

<표 2> 팀원 판으로 바꿀 때 보는 넷

| 기준 | 좋은 판 |
|---|---|
| 끊김 | 장면 사이 멈춤 · 로딩 빈 화면이 없다 · 콘솔 오류 0(`.json` 의 `console_errors`) |
| 개발 티 | 화면에 키 · 계좌번호 · 내부 영어 낱말(`moderate` 같은) · 주소창이 보이지 않는다 |
| 자막 | 장마다 목적 · 과정 · 결과가 한 문장씩 · 투자 권유가 아니라는 고지 |
| 길이 | 3분 안(`.json` 의 `over_limit` 이 false) |

## 4. 보관 · 올리기

```bash
python tools/demo/upload_hf.py --dry-run    # 올릴 파일 · 크기
python tools/demo/upload_hf.py              # 전부 · 또는 이름을 주면 그 편만
```

- HF 비공개 데이터셋 `qurious-quant/demo-videos` — 없으면 비공개로 만들고, 공개 저장소면 멈춘다 · 같은 이름으로 다시 올리면 지난 판은 HF 이력에 남는다.
- 발표 PC 에서는 `docs/발표/2차/media/` 에 영상 · 첫 장 그림(`<이름>.jpg`)을 두면 발표 자료(`docs/발표/2차/발표자료.html`)가 바로 재생한다(이 폴더도 git 에 넣지 않는다).
- 강사님 안내 — 화면이 바뀌면 영상도 늘 최신으로: 그 화면의 장면만 다시 찍어 올린다.
