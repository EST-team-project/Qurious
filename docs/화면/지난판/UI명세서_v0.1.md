> **이 문서로 알 수 있는 것**
> 1. 모든 화면에 공통으로 있는 영역은 무엇이고, 무엇을 부르며 어떻게 동작하나?

## 요약

화면설계서의 실무 관행대로 **화면 그림에 번호를 찍고, 번호마다 요소 · 데이터(API) · 동작 · 빈 데이터 · 오류를 표로** 적는다. 이번 판은 모든 화면이 공유하는 공통 영역 11개와 데이터 관제 화면을 본보기로 자세히 썼고, 화면 69개의 목록(부르는 API · 관련 요구 · 주담당)은 IA 전수표와 API 명세서에서 만들었다. 화면 69개 중 51개가 API 를 부르고, 상세를 채울 사람은 목록의 「명세」 칸에 적었다.
