## 3. 다 못 한 것

- 01: 백테스트 엔진 안쪽의 성과 정의(샤프가 몇 곳에서 계산되는지 · `quant_pipeline.py` · `lean_backtest.py`)는 따라가지 못했다. C1 은 실행해 보지 않아 「추정」 이다.
- 02: 화면 JS 의 그리기 함수(응답 칸 → 화면 칸) 일부는 줄 번호를 달지 못했다. UC-13 의 내 정보(`mypage`) 흐름은 넣지 않았다.
- 03: 그림 · 「빈 데이터 · 오류」 칸은 지시대로 비웠다(다음 세션 메인이 캡처). `robo-portfolio` · `indicator-strategy` 는 열 때 부르는 함수를 찾지 못했다. 표시 칸의 뜻은 적지 않았다.
- 04: `propose` · `check_due` 안쪽 분기(같은 날 계획 합치기 · 승인 거절 조건)는 대조하지 않았다.
- 공통: 작업 트리의 커밋 안 된 변경(`public/app.html` 산식 화면 14줄 · `public/js/dashboard.js` 주기 글 · 새 JS 둘)은 기준에서 뺐다. 그 변경이 머지되면 03 의 1264행 뒤 화면 줄 번호가 14씩 밀린다.
