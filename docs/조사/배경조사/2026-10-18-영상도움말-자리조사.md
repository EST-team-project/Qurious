1. 실제 서비스는 **「그 화면 도움말 안 영상 하나 + 아래 글 단계」**(Notion — `youtube-nocookie` 끼워 넣기)와 **「도움말과 따로 둔 학습 · 교육 목록」**(Notion Academy · Figma 강좌 · 한국투자 동영상 교육 · 키움 교육)을 함께 쓰고, 국내 증권사 화면 도움말 본문은 글 · 그림이었다(키움 · 삼성 · 토스 — 영상 끼운 곳은 못 찾음).
2. 우리 사용법 창(F07)에는 영상 칸 · 「▶ 영상」 단추 · `<video>` + `<track>` 재생이 **이미 짜여 있고 `VIDEOS` 표(`public/js/howtoview.js:70`)만 비어 있다** — 남은 것은 파일을 내는 `/help` 주소 · git · 도커 무시 줄 · 받기 명령이다.
3. 원천은 (가) 로컬 같은 출처가 오프라인 · 비공개 · 토큰 안전을 모두 채운다. (다) YouTube 일부 공개는 「링크를 아는 누구나 보고 다시 공유」 라 앱에 끼우면 사실상 공개되고 인터넷 · 덮개 금지 · Referer 규칙이 붙는다.
4. **추천: 안 ③ 을 두 단계로** — 먼저 ① 창 안 칸(영상 일곱 · 화면 11곳), 「배우기」 이름이 정해지면 ② 「사용법 영상」 목록 화면(쓰는 순서 차례 · 「이 화면 열기 →」). 앱 안 원천은 (가), YouTube 는 발표 자료 · README 링크에만.

- 영상 원천은 본 곳 모두 **YouTube**(Notion 은 `youtube-nocookie` · Figma 는 채널로 내보냄). 자체 서버 영상을 쓰는 곳은 이번에 **확인하지 못했다.**
- 화면 도움말 본문(글 · 그림 단계)은 국내 · 해외 모두 그대로 있고, 영상은 그 위에 **덧붙는 칸**이다 — 영상이 없어도 쪽이 성립한다(우리 결정 ⑥ 「영상이 없으면 칸을 숨김」 과 같은 생각).

- **세 원천은 하나만 고를 필요가 없다.** `VIDEOS` 값 하나에 `src`(로컬 · 서버 주소)와 `youtube`(일부 공개 ID)를 같이 두고 「로컬 파일이 있으면 로컬 · 없으면 YouTube · 둘 다 없으면 칸 숨김」 으로 고를 수 있다(제안 — 코드는 다음 세션).
- 「(다)를 앱에 넣으면 영상이 사실상 공개된다」 는 점이 판단의 핵심이다. 10-16 결정은 **발표용**만 일부 공개로 정했다(대장 221줄) — 앱 안 끼워 넣기까지 넓힐지는 따로 묻는다(정할 것 3).

## 5. 추천과 까닭

**추천: 안 ③ 을 두 단계로 — 먼저 ①(창 안 칸), 「배우기」 이름이 정해지면 ②(목록 화면) · 앱 안 원천은 (가) 로컬 같은 출처.**

| 기준(사용자 규칙) | ① 먼저 | ② 를 뒤에 더함 |
| --- | --- | --- |
| **명확성** — 뜻이 바로 읽히나 | 단추에 「▶ 영상 1:03」 · 칸에 「한국어 자막」 · 장 이름이 「목적 · 과정 · 결과」 라 무엇을 얼마나 보는지 누르기 전에 안다 | 「로보 어드바이저를 처음부터 끝까지 — 일곱 편 · 5분 46초」 한 줄로 이 화면이 무엇인지 안다 |
| **흐름** — 앞뒤 화면과 이어지나 | 쓰던 화면을 떠나지 않는다(창 안) · 닫으면 그 자리 | 차례가 실제 쓰는 순서(진단 → 상품 → 신호 → 주문 → 리밸런싱 → 계좌 → 상담) · 「이 화면 열기」 로 실제 화면에 들어감 |
| **다음 행동(CTA)** | 창 끝줄 개념 학습 장 · 용어사전(이미 있음) + 「사용법 영상 모음 →」(② 뒤) | 「이 화면 열기 →」 · 「다음 영상 →」 |
| 크기 | 반나절 안팎(틀이 있음 · 값 · 마운트 · 받기 명령) — 2차 끝 전에도 가능(어림 · 하) | 새 화면 하나 — 메뉴 개편(D129)과 같이 |

### 원천을 (가) 로 고르는 까닭

1. 오프라인에서 된다 — 발표 시연 PC 가 인터넷에 달리지 않는다(2.2).
2. 비공개가 그대로다 — (다) 를 앱에 끼우면 공개 저장소 코드에 주소가 들어가 사실상 공개된다(Y1 「anyone with the link」 · 「reshare」).
3. 토큰이 브라우저에 가지 않는다 — 받는 순간에만 사람 PC 에서 쓴다(Y4 「Try not to leak your token!」).
4. 이미 있는 틀(`<video>` + 같은 출처 `<track>`)을 그대로 쓴다 — `<track>` 같은 출처 조건(S58)을 채우고, 컨테이너 Starlette 가 구간 요청을 처리해 장 건너뛰기가 된다(L1).
5. 없으면 칸을 숨긴다(결정 ⑥) — 공개 저장소를 받은 사람 화면이 깨지지 않는다.

- (나) 는 「팀원마다 받기 명령을 돌리기 번거롭다」 가 실제로 생기면 그때 더한다(개념 학습 팀 자료 `learn_team.py` 꼴을 그대로 — 2.1).
- (다) YouTube 일부 공개는 10-16 결정대로 **발표 자료 · README 링크에만** 쓰고 앱 안에는 끼우지 않는다(추천). 끼운다면 플레이어 위 덮개 금지 · 200×200 이상 · Referer 조건(Y3)을 지켜야 한다.
