## 규칙

- 출처 하나로 정하지 않는다. 원문 · 두 번째 독립 출처 · 이 PC 실측 가운데 하나로 다시 맞추고, 맞추지 못한 것은 「일부 확인」 으로 둔다.
- 검색 도구의 요약은 출처가 아니다. 논문은 초록 원문, 라이선스는 원문, 가격은 공식 페이지를 연다.
- 계산한 값(비용 · 걸린 시간 추정)은 「계산」 이라고 적고, 잰 값과 섞지 않는다.
- 판은 다른 문서와 같다 — 큰 변화 X.0 → (X+1).0 · 작은 변화 +0.1 · 파일 이름은 판 없이 하나 · 판을 올릴 때 `python scripts/docs_scan.py --bump docs/조사/<이름>.md` 로 지금 판을 `지난판/` 사본으로 남기고 같은 파일을 고친다([docs 폴더 지도](../README.md) 3절 · 2026-10-07 정리 전에는 판마다 새 파일이었다).
