## 조사서 틀

큰 조사는 이 폴더에 따로 두고, 한 설계서 안에서 끝나는 작은 조사는 그 설계서의 부록(조사 출처)에 둔다.

| 절 | 담는 것 |
|---|---|
| 머리표 | 판 · 상태 · 구분(어느 기능의 착수 전 검증인가) · 작성 · 검토 · 최종 수정 · 기준(조회 시각 · 실측 환경 · 코드 커밋) · 관련 문서 |
| 이 문서로 알 수 있는 것 | 조사 질문 목록 |
| 요약 | 결론을 문단 첫 문장에 · 숫자와 출처 |
| 1. 조사 범위와 방법 | 질문마다 1차 출처 · 2차 검증 · 확실도(확인 · 일부 확인 · 추정) · 조사하지 않은 것 |
| 본문 | 근거 표 · 반대 증거와 한계 · 그림 |
| 우리 프로젝트에 주는 뜻 | 설계 · 구현에 넣을 규칙 후보 · 정할 것(누가) |
| 이 조사를 뒤집을 조건 | 다시 조사할 때 |
| 부록 | 출처(URL · 조회일 · 확인 방법) · 실측 기록 · 용어 · 개정 이력 |

## 규칙

- 출처 하나로 정하지 않는다. 원문 · 두 번째 독립 출처 · 이 PC 실측 가운데 하나로 다시 맞추고, 맞추지 못한 것은 「일부 확인」 으로 둔다.
- 검색 도구의 요약은 출처가 아니다. 논문은 초록 원문, 라이선스는 원문, 가격은 공식 페이지를 연다.
- 계산한 값(비용 · 걸린 시간 추정)은 「계산」 이라고 적고, 잰 값과 섞지 않는다.
- 판은 다른 문서와 같다 — 큰 변화 X.0 → (X+1).0 · 작은 변화 +0.1 · 새 파일 · 옛 판은 그대로.
