# 이 폴더는 무엇인가 — 통합본 반입 폴더

> **이 폴더의 코드는 Qurious 앱과 이어져 있지 않다.** 여기서 앱을 띄우거나 고치지 않는다.
> Qurious 를 띄우는 법은 저장소 루트의 [로컬 실행 안내서](../docs/배포/로컬실행안내서_v0.1.md)를 본다.

## 한 줄

팀장의 개인 프로젝트 **investment-rag-lab**(강사님 `domain-rag-lab` 과 `investment-analysis` 를 합친 통합본)을
**AWS 만 빼고 통째로 옮겨 놓은 사본**이다. 기능을 하나씩 다시 설계해 Qurious 의 `app/` · `public/` 으로 옮기기 위해 둔다.

| 항목 | 값 |
|---|---|
| 원본 | `investment-rag-lab` 커밋 `2f0e71f` (2026-09-28) |
| 들어온 것 | 314개 · 57.6MB — 원본과 내용이 같다 |
| 뺀 것 | AWS 12개(배포 · 인프라 설정 9 · AWS 서비스 연동 코드 3) |
| 따로 둔 것 | 시세 자료 3개 — 팀 비공개 데이터셋(`python scripts/raglab_data.py pull` 로 받는다) |
| 이 파일 | 폴더 안에서 **원본에 없는 유일한 파일**이다 |

4. 이 폴더의 `README.md` · `docs/` — 통합본 자체의 설명(원본 그대로)

## 지킬 것

- **이 폴더의 파일을 고치지 않는다.** 고치면 `python scripts/raglab_scan.py --check` 가 「대장의 blob 과 다르다」 로 알린다.
  기능을 옮길 때는 필요한 코드를 Qurious 쪽(`app/` · `public/`)에 **새로 쓴다** — 여기 것을 제자리에서 고쳐 잇지 않는다.
- **여기서 앱을 띄우지 않는다.** `app/main.py` 는 반입에서 뺀 AWS 연동 파일을 부르므로 그대로는 뜨지 않는다.
  통합본을 돌려 보고 싶으면 원본 저장소에서 띄운다.
- **시세 자료 3개를 커밋하지 않는다.** 받아 두어도 `.gitignore` 에 있어 커밋되지 않는다.
- 파이썬 패키지 이름이 Qurious 와 같은 `app` 이다 — 이 폴더를 파이썬 경로에 넣지 않는다.

## 빠진 파일을 가리키는 줄 (그대로 둔 것)

원본을 글자 그대로 두었기 때문에, 뺀 파일을 부르는 줄이 남아 있다. 오류가 아니라 「뺐다」 는 흔적이다.

| 어디 | 무엇을 가리키나 |
|---|---|
| `app/main.py` | `lex` · `llm_bench` 라우터 import 와 등록 |
| `app/openapi_docs.py` | `/api/lex/*` 설명 |
| `frontend/analysis/js/app.js` · `api.js` | `llmBenchView` · `/api/llm-bench/*` |
| `frontend/analysis/js/sidebarUI.js` | `/api/lex/chat` 호출 |
| `.dockerignore` · `.env.example` · `docker-compose-analysis.yml` · `llms.txt` · `README.md` | 배포용 파일 이름 |

출처와 조건은 저장소 루트의 [NOTICE](../NOTICE.md)에 있다.
